## 02 一句话总结

本文提出一个结合 top-k 稀疏自编码器与因果消融的框架，在 Nucleotide Transformer 和 DNABERT-2 两个基因组语言模型的隐藏激活上提取单语义特征，通过 GC 组成匹配的对照协议排除序列组成混淆，并用前向传播中的特征消融证明特定特征被模型因果地用于表征细胞类型特异的 TF 结合（CTCF、GATA1、REST），而非仅与基序共现。

## 03 研究问题

- **具体问题**：基因组语言模型在调控基因组学任务上表现优异，但其内部表征是否真实编码转录因子结合信息？现有"概念验证"方法（如 PWM 富集）是否会被序列组成混淆误导？
- **为什么重要**：如果无法区分"模型真正使用的特征"与"与基序共现的伪特征"，则基于这些模型进行的调控机制推断和假设生成将不可靠，直接影响对 TF–DNA 结合机制的理解。
- **现有方法不足**：PWM 富集分析未控制 GC 含量和重复元件（如 Alu）的组成混淆，导致大量假阳性"TF 特征"；且相关性分析无法区分模型"使用"特征与"包含"特征。
- **精确研究问题**：Can we extract, validate, and causally verify transcription-factor binding features in genomic language models, such that the validated features reflect genuine binding information rather than sequence-composition artifacts?

## 04 背景与发展脉络

> 注：以下脉络基于本文 Introduction 与 Related Work 的叙述，属「仅本文框架」，未经外部独立核验。

1. **阶段一：监督模型时代**（DeepSEA、Basenji、Enformer）
   - 优点：预测性能强，有明确输入-输出映射
   - 局限：特征为人工设计或端到端黑箱，无法提供可复用的"概念词汇表"

2. **阶段二：自监督基因组语言模型**（Nucleotide Transformer、DNABERT-2、HyenaDNA、Caduceus、Evo）
   - 优点：在大规模参考基因组上预训练，泛化到多种调控任务
   - 局限：高维激活中神经元多语义（polysemantic），难以解释模型学到了什么

3. **阶段三：稀疏字典学习**（NLP 中 SAE 方法迁移至基因组）
   - 优点：将稠密激活分解为稀疏、近似单语义的特征
   - 局限：特征验证仍停留在相关性层面（如 PWM 富集），未控制序列组成混淆，缺乏因果检验

4. **本文主张的位置**：在阶段三基础上增加两层关键改进——(i) GC 匹配的对照协议消除组成混淆；(ii) 前向传播中的特征消融 + KL 散度测量，将验证从"相关性"提升到"因果性"。

## 06 核心思想

**1) 表面方法**：
- 在基因组语言模型的隐藏激活上训练 top-k 稀疏自编码器（SAE），获得稀疏、近似单语义的字典特征
- 用 PWM 富集做初步筛选，但必须经过 GC 匹配的对照协议
- 对候选特征做前向传播消融，测量 masked-token 预测分布的 KL 散度偏移，区分"结合特异"与"一般重要"特征

**2) 核心洞察**：
- 基因组序列的组成偏差（GC 含量、重复元件）会使朴素的 PWM 富集产生大量假阳性——验证特征必须控制组成，而非仅看富集显著性
- 特征消融的**绝对效应大小**与**结合特异性**是正交的：一个特征可以对模型整体预测影响巨大（如检测 Alu），但对结合状态毫无区分力。因果检验必须比较 bound vs unbound 的**差异效应**，而非绝对效应
- 模型在预训练中仅见过参考基因组序列（无细胞类型标签），却能内化细胞类型特异的结合信息，说明 TF 结合的序列决定因素以隐式方式编码在基因组上下文中

**3) 可能的普适教训 [Analysis]**：
- 任何基于"特征富集"的生物学验证，若未控制背景组成，都可能将组成伪影误认为生物学信号——这一原则不仅适用于基因组语言模型，也适用于 ChIP-seq 基序分析、ATAC-seq footprint 等经典方法
- "因果使用"与"相关性存在"的区分，应成为可解释性研究的默认标准：一个特征被模型"包含"不等于被模型"使用"

## 07 方法总览

**输入**：
- 两个预训练基因组语言模型：Nucleotide Transformer v2（500M 参数，6-mer tokenization，24 层）和 DNABERT-2（117M 参数，BPE tokenization，12 层）
- 人类参考基因组 hg38 上的 200bp 窗口（5×10⁴ 调控元件窗口 + 5×10⁴ 随机窗口）
- 实验数据：ENCODE ChIP-seq IDR peak（CTCF/GM12878、GATA1/K562、REST/K562）、JASPAR 2024 PWM

**输出**：
- 每层一个稀疏字典（m = 16×隐藏维度，k = 32）
- 每个 TF-模型组合下通过因果验证的结合特征列表

**模块**：
1. **SAE 训练**：对每层隐藏激活训练 top-k 稀疏自编码器，重建损失 + 辅助损失（复活死特征），字典方向从随机激活初始化
2. **特征-窗口映射**：将每个特征的最大池化激活映射到基因组坐标（跨 tokenization 统一）
3. **组成匹配的绑定测试**：对每个特征，比较 bound vs GC-matched unbound 窗口的激活（Mann-Whitney U，Bonferroni 校正），要求 AUC > 0.55 且 |corr(feature, GC)| < 0.2
4. **因果消融**：在前向传播中移除单个字典方向，测量 masked-token 预测的 KL 散度偏移，比较 bound vs unbound 的差异效应

**反馈回路**：无显式反馈回路（单次前向流程）

**假设**：
- 字典方向近似单语义（SAE 的稀疏性假设）
- 消融的 KL 偏移可近似为局部二次型（Proposition 2 的一阶/二阶近似）
- ChIP-seq 结合峰代表真实的体内结合事件

**文字流程**：
采样窗口 → 提取隐藏激活 → 训练 SAE → 获得字典特征 → 对每个特征做 GC 匹配的绑定测试（筛选结合敏感特征）→ 对候选特征做因果消融（验证模型实际使用）→ 跨 TF、跨模型比较 → 负对照验证

## 09 关键公式符号

**1) SAE 编码-解码**（Methods 3.1 节）：
- **f** = TopKₖ(W_enc(x - b_pre))：编码，TopKₖ 保留 k 个最大条目，其余置零
- **x̂** = W_dec **f** + b_pre：解码，W_dec 列（字典方向）约束为单位范数
- 符号：**x**∈ℝᵈ 隐藏激活，**f**∈ℝᵐ 稀疏码，m=16d，W_enc∈ℝᵐˣᵈ，W_dec∈ℝᵈˣᵐ，b_pre∈ℝᵈ

**2) 训练目标**（Methods 3.1 节）：
- L = ‖**x** - **x̂**‖² + α‖**x** - **x̂**_aux‖²，α=1/16
- **x̂**_aux 仅用"死"特征重建残差，用于复活不活跃特征

**3) 绑定测试**（Methods 3.2 节）：
- AUCⱼ = U/(n_b · n_u)：特征 j 区分 bound vs unbound 的 Mann-Whitney U 效应量
- 判定标准：AUCⱼ > 0.55（Bonferroni 校正后显著）且 |corr(fⱼ, GC)| < 0.2

**4) 因果消融**（Methods 3.3 节）：
- h_ℓ'(**x**) = h_ℓ(**x**) - s⁻¹·fⱼ(**x**)·**d**ⱼ：移除特征 j 的贡献
- Δⱼ(**x**) = (1/T)·Σₜ KL(pₜ(g(h_ℓ)) ‖ pₜ(g(h_ℓ - cⱼ)))：消融引起的预测分布偏移
- 符号：s 为激活缩放因子，**d**ⱼ 为字典方向，g_ℓ→L 为剩余网络，pₜ 为位置 t 的 softmax 分布

**5) Proposition 1**（Methods 3.4 节）：
- 若 fⱼ = φ(ρ(S)) 为纯组成检测器，且 𝔼[σ(S)|ρ(S)=r] 随 r 递增，则未匹配组成时特征在 σ 高分窗口富集，尽管 fⱼ ⊥ B|ρ——即 PWM 富集必然产生假阳性

**6) Proposition 2**（Methods 3.4 节）：
- Δⱼ(S) ≈ ½·s⁻²·fⱼ(S)²·**d**ⱼᵀG(S)**d**ⱼ，其中 G(S) = J(S)ᵀH_KL J(S) ≥ 0
- 绝对效应由 𝔼[fⱼ²γ] 决定，结合特异性由 𝔼[fⱼ²γ|B=1] - 𝔼[fⱼ²γ|B=0] 决定——两者可完全分离

## 10 实验设计与证据链

**数据集/群体**：
- 基因组：人类 hg38
- 调控元件：ENCODE SCREEN cCRE（5×10⁴ 窗口）
- 背景：随机 200bp 窗口（5×10⁴）
- ChIP-seq：CTCF（GM12878）、GATA1（K562）、REST（K562）的 ENCODE IDR peak
- 基序：JASPAR 2024 CORE 脊椎动物 PWM

**规模**：
- 每层 SAE 字典大小 m = 16×隐藏维度（NT：~16,000；DNABERT-2：~12,000）
- 每条件测试 6,576 个特征（NT 层 14）
- 每条件消融 top 15 结合敏感特征 + 15 随机特征

**指标**：
- 重建方差解释比（74-76%）
- 活特征比例（45%→93%）
- 绑定测试 AUC（Mann-Whitney U）
- 因果消融 KL 散度偏移的 bound-vs-unbound 差异

**基线/对照**：
- 朴素 PWM 富集（未匹配组成）→ 440 个假阳性特征
- 随机特征消融 → AUC ≈ 0.51（无结合特异效应）
- scramble 负对照（随机窗口+随机标签）→ 零特征通过
- gata1-scram 负对照（真实基序+随机标签）→ 零特征通过

**评测协议**：
- 每 TF-模型组合独立跑完整流程
- 所有 p 值 Bonferroni 校正
- 跨两个架构（NT 6-mer vs DNABERT-2 BPE）验证可重复性

**关键实验与结果**：

## 11 结论正确解读

**任务范围**：本文只针对两个 masked-language-model 架构（NT、DNABERT-2）和三个 TF（CTCF、GATA1、REST），不覆盖自回归模型（如 Evo）、状态空间模型（如 HyenaDNA、Caduceus）或其他 TF。

**Oracle/真值输入**：ChIP-seq peak 作为结合真值，但 ChIP-seq 本身有抗体特异性、细胞类型覆盖度等局限；PWM 来自 JASPAR，其本身是基序的近似表示。

**端到端状态**：框架是"提取→验证"流程，不是端到端训练系统。SAE 是事后训练的（post-hoc），不改变原模型参数。

**算力成本**：未报告具体训练时间或 GPU 需求。SAE 训练 1 epoch、batch size 4096，推测成本可控，但未量化。

**历史数据依赖**：完全依赖预训练模型的固定权重，不涉及新预训练。窗口采样来自 hg38 和 ENCODE 数据。

**模型依赖**：结论绑定于 NT 和 DNABERT-2 的具体架构和预训练数据。跨架构的可重复性只在这两个模型上验证过。

**最难情形**：GATA1 是最难案例——其基序（WGATAR）短且简并，相关性检验几乎失效，只有因果检验能恢复信号。这说明框架在"基序信息弱"的场景下价值最大。

**有边界的复述**：在 NT（6-mer）和 DNABERT-2（BPE）两个基因组语言模型中，结合 GC 匹配对照和单特征消融，可以提取出被模型因果使用的 TF 结合特征；朴素 PWM 富集在此场景下不可靠；GATA1 的结合表征主要通过基序之外的序列上下文实现。

## 13 批判性分析

## 14 学到什么

> 标题：Agent 提炼的知识候选

1. **组成匹配对照是 TF 特征验证的底线**：任何声称"发现 TF 特征"的工作，若未控制 GC 含量和重复元件组成，其富集结果不可信。可迁移到本课题：在分析 TF–DNA 结合预测模型（如 DeepSEA、Enformer）的中间表征时，必须加入组成匹配的负对照，否则无法区分"结合编码"与"组成编码"。

2. **绝对效应大小与结合特异性正交**：一个特征可以对模型输出有巨大影响（如检测 Alu 重复），但对结合状态毫无区分力。这提示本课题：在解释 TF–DNA 结合模型时，不能只看特征重要性（如 attention 权重、saliency map），必须做 bound-vs-unbound 的差异分析。

3. **因果消融优于相关性分析**：通过在前向传播中移除单个特征并测量预测分布偏移，可以区分"模型使用"与"模型包含"。可迁移到本课题：对 TF–DNA 结合预测模型，可对特定隐藏单元做消融，观察其对结合位点预测的因果贡献，而非仅看激活相关性。

4. **GATA1 案例的启示**：结合信息可能编码在基序之外的序列上下文中，基序匹配本身不足以捕捉结合特异性。这提示本课题：TF–DNA 结合机制研究不应局限于 PWM 匹配，需考虑更广泛的序列语境特征（如侧翼序列、核小体定位倾向、DNA 形状特征）。

5. **跨 tokenization 的可迁移性**：6-mer 和 BPE 两种完全不同的分词方案下都能提取因果结合特征，说明结合信息编码在序列层面而非 tokenization 层面。可迁移到本课题：无论使用何种序列编码（one-hot、k-mer、BPE、tokenizer-free），TF 结合信号应可被一致地提取。

6. **中间层最优**：SAE 可解释性在中间层（50% 深度）达到峰值，与 NLP 中的观察一致。可迁移到本课题：分析 TF–DNA 结合模型的内部表征时，应优先关注中间层而非最后一层。

7. **Proposition 1 的数学框架**：用条件期望和单调性严格证明了组成混淆导致假富集。可迁移到本课题：在设计 TF–DNA 结合特征验证时，可借鉴此数学框架来证明/证伪其他潜在混淆源（如 CpG 甲基化状态、染色质可及性）。

## 15 与已有知识连接

1. **Sparse autoencoders 在 NLP 中的发展**：本文直接继承 Cunningham et al. (2023)、Bricken et al. (2023) 等人在语言模型上的 SAE 工作，将其首次系统迁移到基因组模型。可对比：NLP 中的 SAE 特征多为语义/句法概念，基因组中的 SAE 特征对应序列基序和调控元件。

2. **基因组模型可解释性工作**：与 DNABERT 可解释性分析（如 attention 可视化、motif 发现）形成对照——本文指出这些方法未控制组成混淆，可能高估模型内部的"调控知识"。

3. **TF–DNA 结合机制的传统方法**：PWM/基序富集分析（如 HOMER、MEME）是领域标准，本文揭示了其在基因组语言模型验证场景下的系统性缺陷，与近期关于 PWM 局限性的讨论一致（如 DNA 形状特征在结合特异性中的作用，Zhou et al. 2015）。

4. **因果干预在可解释性中的应用**：与 activation patching (Wang et al. 2022)、causal mediation analysis 一脉相承，本文将其应用于基因组模型，并引入 bound-vs-unbound 的差异设计，这是对 NLP 中"因果追踪"方法的领域适配。

5. **ChIP-seq 作为外部真值**：本文用 ENCODE ChIP-seq 作为结合真值，与 TF–DNA 结合预测领域的基准数据集（如 ENCODE-DREAM challenge）一致，但本文不训练预测器，而是用 ChIP-seq 验证模型内部表征。

6. **GC 组成混淆的经典问题**：GC 含量偏差对序列分析的影响在基因组学中早有讨论（如 ChIP-seq 峰 calling 中的 GC 校正），本文将其引入深度学习可解释性验证，属于跨领域方法迁移。

7. **与 AlphaFold 等结构预测的关系 [Analysis]**：本文不涉及结构预测，但其"验证模型内部表征"的思路可类比为"功能层面的结构验证"——即不只看模型能否预测结合，而是验证模型内部是否有可解释的、因果使用的结合表征。未来可与基于结构的 TF–DNA 相互作用模型（如 AlphaFold 3、RoseTTAFoldNA）结合，探索序列模型与结构模型在结合机制编码上的一致性。

## 16 研究想法

> 标题：Agent 生成的研究候选

**候选 1：基于因果消融的 TF–DNA 结合机制图谱**
- **来源局限/观察**：本文仅验证了 3 个 TF × 2 个模型，且未将因果特征映射到具体序列元件或结构 motif
- **核心假设**：不同 TF 的因果结合特征在序列空间和模型层间分布上呈现可区分的模式，且这些模式与 TF 的结构类别（锌指、bZIP、bHLH 等）相关
- **增量**：将框架扩展到全部 ENCODE TF（~300+），构建"TF-特征-序列元件"三层映射
- **初步方法**：对每个 TF 训练 SAE → 因果消融筛选 → 将特征映射回序列 motif → 按 TF 结构家族聚类
- **验证方式**：与 ChIP-seq 的 motif 富集交叉验证；检查同一结构家族的 TF 是否共享因果特征
- **创新状态**：unverified

**候选 2：DNA 形状特征作为因果中介的检验**
- **来源局限/观察**：本文的 GC 匹配对照控制了组成，但未检验 DNA 形状特征（roll、tilt、minor groove width）是否作为中介变量
- **核心假设**：部分因果结合特征通过编码 DNA 形状而非直接编码碱基序列来影响模型预测
- **增量**：将 DNA 形状预测（如 DNAshape）纳入中介分析框架
- **初步方法**：对因果特征做形状富集分析；在消融实验中同时扰动形状特征，观察 KL 偏移是否被中介
- **验证方式**：与实验测定的形状-结合亲和力数据（如 HT-SELEX 变体）对比
- **创新状态**：unverified

**候选 3：跨物种的因果结合特征保守性分析**
- **来源局限/观察**：本文仅用人类基因组数据，未检验特征的进化保守性
- **核心假设**：因果验证的 TF 结合特征在哺乳动物中保守，且保守程度与 TF 的功能重要性相关
- **增量**：将框架迁移到小鼠、斑马鱼等模式生物基因组
- **初步方法**：在多个物种上训练 SAE → 跨物种特征对齐 → 计算保守性得分
- **验证方式**：与 phyloP/PhastCons 保守性评分对比；检查保守特征是否富集在已知调控元件
- **创新状态**：unverified

**候选 4：从"验证"到"编辑"——因果特征驱动的序列设计**
- **来源局限/观察**：本文止步于验证，未利用因果特征进行序列设计
- **核心假设**：通过编辑因果结合特征对应的序列元件，可以可预测地改变模型对结合位点的判断，从而实现 in silico 序列设计
- **增量**：将因果消融从"诊断工具"升级为"设计工具"
- **初步方法**：对因果特征做梯度回传 → 生成最小序列编辑 → 验证模型预测变化
- **验证方式**：与湿实验（如电泳迁移率实验 EMSA）对比编辑后序列的结合亲和力
- **创新状态**：unverified

**候选 5：结构感知的 TF 结合特征验证**
- **来源局限/观察**：本文完全基于序列模型，未利用三维结构信息
- **核心假设**：因果结合特征中有一部分对应特定的蛋白质-DNA 接触模式（如氢键、疏水接触），可通过结构模型（AlphaFold 3）验证
- **增量**：将序列层面的因果特征与结构预测结合，形成"序列-结构-功能"闭环
- **初步方法**：对因果特征对应的序列片段做结构预测 → 检查预测的接触界面是否与特征激活一致
- **验证方式**：与已知共晶结构（PDB）对比；检查结构预测的置信度是否与特征因果强度相关
- **创新状态**：unverified

**候选 6：因果特征的时间动态——从静态结合到动态调控**
- **来源局限/观察**：本文分析的是静态模型快照，未考虑结合动态
- **核心假设**：因果结合特征在模型的不同层间传递时呈现动态模式，这些模式与 TF 的结合动力学（驻留时间、交换速率）相关
- **增量**：引入时间维度的因果分析（如动态因果追踪）
- **初步方法**：在推理时逐层记录特征激活 → 构建层间因果图 → 分析信息流路径
- **验证方式**：与单分子 FRET 或 smFRET 测定的结合动力学数据对比
- **创新状态**：unverified
