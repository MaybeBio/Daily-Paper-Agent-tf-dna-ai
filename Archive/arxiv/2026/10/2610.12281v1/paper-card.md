## 02 一句话总结

ARGUS 提出一个证据约束的 agentic 框架，通过多智能体协作检索并整合调控基因组注释（如 TF motif、染色质可及性、eQTL），对单核苷酸变异（SNV）在调控区的功能影响进行可解释的解读，并在基准数据集上验证其优于单一模型基线。

## 03 研究问题

- **具体问题**：如何准确且可解释地解读非编码区单核苷酸变异（SNV）对基因调控（尤其是转录因子结合）的功能影响？
- **为什么重要**：绝大多数疾病相关 SNV 位于非编码区，其功能机制不明；现有方法（如单模型预测器）缺乏对多源生物学证据的整合与推理能力，且预测结果难以解释。
- **现有方法为何不足**：单一深度学习模型（如 Enformer、DeepSEA）虽能预测调控效应，但（a）依赖固定输入窗口，难以利用外部知识；（b）输出为黑盒分数，缺乏机制层面的证据链；（c）无法动态检索和整合不断增长的调控注释数据库。
- **精确研究问题（Can 问题）**：Can an agentic framework that dynamically retrieves and constrains predictions with external regulatory evidence outperform static single-model baselines in interpreting the functional impact of non-coding SNVs?

## 04 背景与发展脉络

> 注：以下脉络基于本文框架，未做外部系统核验，标记为「仅本文框架」。

1. **阶段一：序列-based 预测模型**（如 DeepSEA, Enformer）
   - 优点：端到端学习序列-功能映射，捕获长程调控。
   - 局限：黑盒、无证据解释、无法整合外部注释。

2. **阶段二：变异效应评分工具**（如 CADD, Eigen, FATHMM-MKL）
   - 优点：提供全基因组变异排序。
   - 局限：多为通用保守性/功能分数，缺乏调控机制特异性。

3. **阶段三：调控注释整合方法**（如 RegulomeDB, FunSeq2）
   - 优点：整合 motif、DNase、eQTL 等注释。
   - 局限：静态权重，无动态推理，难以处理新变异。

4. **本文主张的位置**：ARGUS 将「agentic AI」引入调控变异解读，以多智能体动态检索证据并约束预测，填补「静态模型」与「动态知识整合」之间的空白。

## 06 核心思想

1. **表面方法**：ARGUS 是一个多智能体（multi-agent）框架，包含检索智能体（retriever）、证据整合智能体（integrator）、预测智能体（predictor）和解释智能体（explainer），通过协作完成 SNV 功能解读。

2. **核心洞察**：将「证据约束」作为预测的硬性条件——即预测结果必须与检索到的调控证据（如 TF motif 破坏、染色质状态变化）一致，而非仅依赖序列特征。这使预测从「统计关联」转向「机制一致」。

3. **可能的普适教训** [Analysis]：在生物信息学中，将外部知识作为「约束」而非「特征」注入模型，可显著提升可解释性和鲁棒性。这一思路可迁移到 TF–DNA 结合预测：用已知 motif 或 ChIP-seq 峰作为约束，而非仅作为训练标签。

## 07 方法总览

- **输入**：单核苷酸变异（SNV）的基因组坐标及参考/替代等位基因。
- **输出**：变异的功能影响解读（如「破坏 TF motif」「影响增强子活性」）及置信度。
- **模块**：
  1. 检索智能体（Retriever Agent）：从外部数据库（如 JASPAR, ENCODE, GTEx）检索相关调控注释。
  2. 证据整合智能体（Integrator Agent）：将检索到的证据与序列上下文融合，形成约束条件。
  3. 预测智能体（Predictor Agent）：基于约束条件预测变异效应。
  4. 解释智能体（Explainer Agent）：生成人类可读的机制解释。
- **训练**：未提供具体训练细节（可能为 prompt-based 或微调 LLM）。
- **工具**：未提供（推测使用 LLM API 或本地部署模型）。
- **反馈回路**：预测结果可反馈至检索智能体，进行迭代证据补充。
- **假设**：外部调控注释数据库的准确性和覆盖度足以约束预测。

**文字流程**：输入 SNV → 检索智能体查询多个数据库 → 整合智能体筛选并格式化证据 → 预测智能体结合序列与证据输出效应分数 → 解释智能体生成机制描述 → 输出解读报告。

## 14 学到什么

**Agent 提炼的知识候选**：

1. **证据约束（Evidence Constraint）作为预测硬条件**：在 TF–DNA 结合预测中，可将已知 motif 匹配、ChIP-seq 峰、DNase 可及性作为约束条件，而非仅作为输入特征。迁移方式：在现有深度学习模型（如 DeepSEA）的损失函数中加入「约束一致性」正则项。

2. **多智能体协作架构**：将「检索-整合-预测-解释」拆分为独立智能体，可模块化替换。迁移方式：在 TF–DNA 结合研究中，用检索智能体自动获取最新 JASPAR motif 或 ENCODE 数据，避免手动特征工程。

3. **可解释性优先设计**：通过解释智能体生成机制描述，而非仅输出分数。迁移方式：在 TF–DNA 结合预测中，输出「该变异破坏 ETS1 motif 第 3 位碱基」等结构化解释。

4. **动态知识更新**：框架可随数据库更新而调整，无需重训练。迁移方式：在 TF–DNA 结合预测中，建立「数据库版本感知」的预测管线。

## 16 研究想法

**Agent 生成的研究候选**：

1. **候选名称**：TF–DNA 结合变异的证据约束微调（Evidence-Constrained Fine-tuning for TF–DNA Binding Variants）
   - **来源局限/观察**：ARGUS 未提供定量验证；TF–DNA 结合预测模型缺乏证据整合。
   - **核心假设**：将 motif 破坏证据作为约束，可提升 TF–DNA 结合变异预测的精度和可解释性。
   - **相对本文的增量**：将 agentic 框架简化为可微分的约束正则项，适配现有深度学习模型。
   - **初步方法**：在 DeepSEA 或 Enformer 的损失函数中加入 motif 一致性正则项；用 JASPAR 和 ChIP-seq 数据构建约束集。
   - **验证方式**：在 ClinVar 非编码变异和 eQTL 基准上对比 AUC 和解释一致性。
   - **创新状态**：unverified

2. **候选名称**：多智能体 TF–DNA 结合机制解读器（Multi-Agent Interpreter for TF–DNA Binding Mechanisms）
   - **来源局限/观察**：ARGUS 的 agentic 框架可迁移至 TF–DNA 结合机制解读，但需适配结合特异性数据。
   - **核心假设**：多智能体协作可自动整合 motif、结构、表达数据，生成机制级解释。

   - **核心假设**：动态追踪数据库版本可提升预测的时效性和准确性。

   - **验证方式**：对比固定版本与动态版本在最新 eQTL 数据上的表现。
   - **创新状态**：unverified
