## 02 一句话总结

本文提出 MHCBind——一个结合 GAT（从预测接触图学习拓扑特征）与 1D CNN（从 ESM-1b 序列嵌入学习多尺度模式）的双视图深度学习框架，通过交叉注意力融合模块显式建模 MHC 与肽段间的互作，在等位基因特异（RMSE 0.1485, PCC 0.7231）和泛等位基因（SCC 0.7102）任务上优于 NetMHCpan、MHCFlurry、MHCnuggets 等基线。

## 03 研究问题

- **具体问题**：如何更准确地预测 MHC Class I 分子与肽段之间的结合亲和力（连续值回归），同时兼顾等位基因特异性和泛等位基因泛化能力？
- **为什么重要**：MHC-肽结合是适应性免疫的核心事件，准确预测可加速疫苗设计、肿瘤新抗原发现和免疫治疗靶点筛选。实验测定成本高、通量低，计算预测是必要补充。
- **现有方法不足**：主流方法（如 NetMHCpan、MHCFlurry）主要依赖序列信息，隐式学习互作规则，未显式利用结构拓扑信息；且对 censored 数据（IC50 < 50 nM 或 > 10000 nM）处理粗糙，常直接丢弃或简单替换，损失信息。
- **精确研究问题**：Can a dual-view deep learning architecture that explicitly models MHC-peptide interaction via cross-attention on both sequence and structural features achieve higher binding affinity prediction accuracy than sequence-only baselines across both allele-specific and pan-allele settings?

## 06 核心思想

### 1) 表面方法
MHCBind 是一个端到端深度学习框架，包含四个并行特征提取器（MHC-GAT、MHC-CNN、肽-GAT、肽-CNN），一个交叉注意力融合模块，以及一个 MLP 回归头。输入为 MHC 和肽段的序列（经 ESM-1b 嵌入）及预测接触图（经 GAT 处理），输出为结合亲和力连续值。

### 2) 核心洞察
- **双视图互补**：序列视图（CNN）捕捉局部基序和多尺度模式，结构视图（GAT）捕捉残基间空间邻近关系——两者互补，共同构成更完整的分子表征。
- **显式互作建模**：交叉注意力模块让 MHC 和肽段的表征相互「查询-键-值」流动，显式建模结合事件，而非依赖隐层隐式学习。
- **Censored 数据插补**：利用已知定量数据的分布特征，对不等式型测量值进行截断正态分布采样插补，保留数据信息而非丢弃。

### 3) 可能的普适教训 [Analysis]
- 对 TF-DNA 互作：DNA 的「结构视图」可类比为 DNA 形状特征（如 minor groove width、roll、helix twist），与序列视图（one-hot 或 k-mer 嵌入）结合，可能优于纯序列模型。
- 显式互作建模（交叉注意力）比简单拼接特征更能捕捉结合界面上的协同效应。
- 处理实验数据中的阈值型/截断型测量（如 ChIP-seq 峰强度、SELEX 富集分数）时，统计插补优于简单丢弃。

## 07 方法总览

- **输入**：MHC 等位基因序列 + 肽段序列（长度通常 9-11 mer）
- **特征生成**：
  - 序列嵌入：可训练氨基酸嵌入 + ESM-1b 预训练嵌入（拼接或相加）
  - 接触图：ESM-1b 预测的残基-残基接触概率矩阵，作为图的邻接矩阵
- **特征提取**：
  - 结构视图：GAT 堆叠层，处理接触图（节点=残基，边=预测接触）
  - 序列视图：1D CNN，多核大小（k ∈ [3]），捕捉多尺度局部模式
- **互作建模**：交叉注意力模块（Cross-Fusion Block），MHC 表征与肽段表征互为 Query/Key/Value，双向信息流动；加入可学习模态嵌入（modality embedding）区分序列/结构来源
- **输出**：MLP 回归头，输出结合亲和力分数（连续值）
- **训练**：5-fold 交叉验证，回归损失（具体损失函数未在摘要中明确）
- **Censored 数据插补**：三步流程——(1) 按不等式阈值分箱统计已知定量数据分布；(2) 对每个 censored 数据点，从对应箱的截断正态分布采样；(3) 若箱内定量数据 < 10 个，退化为均匀随机采样
- **反馈回路**：未明确提及（如主动学习、迭代优化等未在摘要中描述）
- **代码**：https://github.com/drugparadigm/MHCBind/tree/main

## 09 关键公式符号

> 注：摘要中公式以文字描述为主，以下为文中明确出现的公式及符号。

**1. GAT 注意力系数**（Methods 节 2.2）：
```
α_ij = softmax_j( LeakyReLU( a^T [ W h_i || W h_j ] ) )
```
- `α_ij`：节点 i 对节点 j 的注意力系数
- `W`：可训练权重矩阵
- `a`：可学习注意力向量
- `||`：向量拼接
- `h_i`：节点 i 的特征向量

**2. GAT 特征更新**（Methods 节 2.2）：
```
h_i^{g,l+1} = ReLU( Σ_{j ∈ N_i} α_ij W h_j^{g,l} )
```
- `N_i`：节点 i 的邻居集合
- `h_i^{g,l}`：第 l 层图视图下节点 i 的特征

**3. 1D 卷积操作**（Methods 节 2.2）：
```
y_i = Σ_{k=1}^{K} x_{i+k-1} · w_k
```
- `x`：输入序列
- `w`：卷积核权重
- `K`：核大小（文中 k ∈ [3]）

**4. 交叉注意力**（Methods 节 2.3）：
```
CrossHead_H = Attention( Q_H, K_P, V_P ) = softmax( Q_H K_P^T / √d_k ) V_P
```
- `Q_H`：MHC 视图的 Query 投影
- `K_P, V_P`：肽段视图的 Key/Value 投影
- `d_k`：特征维度

**5. 最终预测**（Methods 节 2.4）：
```
ŷ = MLP( [ H ; P ] )
```
- `H`：MHC 最终表征（拼接图/序列视图）
- `P`：肽段最终表征
- `[ ; ]`：拼接操作

## 11 结论正确解读

- **任务范围**：仅限 MHC Class I 分子与 9-11 mer 肽段的结合亲和力预测，不涉及 MHC Class II、TCR 识别、抗原加工等下游环节。
- **Oracle/真值输入**：训练标签来自实验测定的 IC50 值（定量）和 MS 洗脱配体（定性），后者经插补转为连续值——插补值本身是估计而非真值。
- **端到端状态**：是端到端训练（序列 → 亲和力），但接触图由 ESM-1b 预测而非实验结构，因此「结构视图」依赖预测质量。
- **算力成本**：未报告训练时间、GPU 型号、参数量等。
- **历史数据依赖**：训练数据来自 IEDB 和 2014 年 MS 数据集，存在数据偏差（如等位基因覆盖不均、肽段长度分布偏斜）。
- **模型依赖**：依赖 ESM-1b 嵌入和接触图预测质量；ESM-1b 的偏差会传导至 MHCBind。
- **最难情形**：低亲和力肽段（IC50 接近阈值）、稀有等位基因（数据稀疏）、非经典肽段（长度异常或修饰）。
- **群体/领域边界**：仅人类 MHC Class I；不覆盖小鼠等其他物种；不覆盖 MHC Class II。
- **有边界的复述**：MHCBind 在 185,985 条 MHC Class I-肽互作数据上，通过双视图（序列+接触图）和交叉注意力融合，在等位基因特异任务上达到平均 RMSE 0.1485、PCC 0.7231，在泛等位基因任务上达到 SCC 0.7102，优于 MHCFlurry 2.0、NetMHCpan 4.0 和 MHCnuggets；但未报告统计显著性检验、消融实验和计算成本。

## 14 学到什么

> 以下为面向「蛋白质-DNA 互作（TF-DNA 结合机制）× AI/物理模拟」课题的可迁移知识。

1. **双视图特征提取范式**：将「序列视图（CNN）+ 结构视图（GAT on contact map）」并行处理再融合，可迁移到 TF-DNA 结合预测——DNA 侧可用「序列视图（one-hot/k-mer）+ 结构视图（DNA shape 特征如 minor groove width、roll、helix twist 或预测的 3D 结构）」，TF 侧可用「序列视图（ESM 嵌入）+ 结构视图（AlphaFold 预测结构或实验结构的 contact map）」。

2. **交叉注意力作为互作建模模块**：用 Query-Key-Value 机制让两个分子互相「查询」对方特征，比简单拼接更能捕捉结合界面的协同效应。对 TF-DNA，可让 TF 的残基特征查询 DNA 的碱基/形状特征，反之亦然。

3. **Censored 数据插补策略**：实验数据常含阈值型测量（如 ChIP-seq 峰强度截断、SELEX 富集分数下限），本文的「按阈值分箱 → 截断正态分布采样」策略可迁移到 TF-DNA 结合数据预处理。

4. **ESM-1b 作为通用特征提取器**：ESM-1b 嵌入可同时用于蛋白质（TF）和核酸（DNA/RNA）序列，其上下文感知能力对捕捉结合基序附近的序列环境有价值。

5. **泛化 vs 特化的权衡**：本文同时训练泛等位基因和等位基因特异模型，对应 TF-DNA 领域可类比为「泛 TF 结合模型」vs「特定 TF 家族模型」，两种模式各有适用场景。

6. **评估指标选择**：同时报告 PCC（线性相关性）、SCC（排序相关性）、RMSE/MAE（绝对误差）——对 TF-DNA 结合强度预测同样适用，尤其 SCC 对排序型应用（如筛选候选位点）更相关。

## 15 与已有知识连接

- **ESM-1b**：由 Facebook AI Research 发布的蛋白质语言模型（Rives et al., 2021, PNAS），本文将其用于 MHC 和肽段的嵌入与接触图预测。该模型同样可用于 TF 蛋白的嵌入，且已有工作将其用于 DNA 结合蛋白预测。
- **NetMHCpan 4.0**：经典 MHC-肽结合预测工具（Jurtz et al., 2017, JI），基于 ANN 集成，本文将其作为基线。对应 TF-DNA 领域可类比为 DeepSEA、DeepBind 等早期深度学习工具。
- **MHCFlurry 2.0**：基于 CNN 的 MHC-肽结合预测器（O'Donnell et al., 2020, Cell Systems），本文将其作为主要对比基线。其架构与 TF-DNA 领域的 CNN 方法（如 DeepBind）同源。
- **MHCnuggets**：基于 LSTM 的 MHC-肽预测器（Shao et al., 2020, Briefings in Bioinformatics），代表 RNN 类方法。
- **接触图预测**：本文使用 ESM-1b 预测接触图，与 AlphaFold2 的接触图预测思想一致。在 TF-DNA 领域，可类比为使用 AlphaFold2 预测 TF 结构后提取接触信息。
- **交叉注意力**：源自 Transformer 架构（Vaswani et al., 2017），在蛋白质-配体互作预测中已有应用（如 HoloProt、DeepInteract），本文将其用于 MHC-肽互作，可迁移到 TF-DNA 互作建模。
- **TF-DNA 领域对应工作**：DeepSEA（Zhou & Troyanskaya, 2015）、DeepBind（Alipanahi et al., 2015）、BPNet（Avsec et al., 2021）等均为序列-only 方法，本文的「序列+结构」双视图思路与近期结构感知方法（如 AlphaFold 辅助的 TF-DNA 预测）方向一致。

## 16 研究想法

> 以下为面向「蛋白质-DNA 互作（TF-DNA 结合机制）× AI/物理模拟」的研究候选。

### 候选 1：TF-DNA 双视图结合预测模型（TF-DNA-Bind）
- **来源局限/观察**：现有 TF-DNA 结合预测主要依赖序列（one-hot、k-mer、ESM 嵌入），忽略 DNA 结构特征和 TF 结构信息；MHCBind 的双视图+交叉注意力范式可迁移。
- **核心假设**：将 TF 的序列+结构视图与 DNA 的序列+形状视图通过交叉注意力融合，可提升结合强度预测精度，尤其在结合基序模糊的 TF 家族上。
- **初步方法**：TF 侧用 ESM-1b 嵌入 + AlphaFold2 预测结构提取 contact map；DNA 侧用 one-hot + DNA shape 特征（DNAshapeR 工具）或预测的 DNA 结构；交叉注意力模块建模 TF-DNA 互作；MLP 回归输出结合强度。
- **验证方式**：使用 ENCODE ChIP-seq 数据、SELEX 数据、Protein-DNA 结合亲和力数据库（如 PDIdb）进行评测，对比 DeepSEA、BPNet 等基线。
- **可能的失败模式**：DNA shape 特征预测误差传导；TF 结构预测质量差（尤其无序区域）；数据异质性导致泛化困难。
- **创新状态**：unverified

### 候选 2：Censored 结合数据插补策略用于 TF-DNA 亲和力数据
- **来源局限/观察**：TF-DNA 结合实验数据（如 PBM、SELEX）常含阈值型测量（信号饱和、检测下限），MHCBind 的统计插补策略可迁移。
- **核心假设**：对 censored 的 TF-DNA 结合数据进行截断正态分布插补，优于直接丢弃或二值化，可提升下游模型训练效果。
- **初步方法**：按实验平台和信号阈值分箱，计算箱内已知数据的均值和标准差，对 censored 值从截断正态分布采样；对比插补 vs 丢弃 vs 二值化对下游预测模型的影响。
- **验证方式**：在 SELEX 和 PBM 数据集上训练结合预测模型，比较不同处理策略下的 AUC、PCC。
- **可能的失败模式**：箱内数据量不足导致插补不稳定；不同实验平台的分布差异大。
- **创新状态**：unverified

### 候选 3：TF-DNA 互作的显式注意力可解释性分析
- **来源局限/观察**：MHCBind 的交叉注意力模块可解释为「哪些残基-碱基对贡献了结合信号」；TF-DNA 领域同样需要可解释性工具来识别关键接触残基和碱基。
- **核心假设**：交叉注意力权重可映射为 TF 残基-DNA 碱基的接触重要性，与实验解析的 TF-DNA 共晶体结构中的接触残基一致。
- **初步方法**：在 TF-DNA-Bind 模型上提取交叉注意力权重，与 PDB 中 TF-DNA 复合物结构的接触残基对比，计算一致性。
- **验证方式**：使用 PDB 中 TF-DNA 复合物结构（如 p53、GATA、FOXO 等）进行验证。
- **可能的失败模式**：注意力权重与物理接触不完全对应；结构预测误差影响一致性。
- **创新状态**：unverified

### 候选 4：结合物理模拟的 TF-DNA 结构视图增强
- **来源局限/观察**：MHCBind 使用 ESM-1b 预测接触图作为结构视图；TF-DNA 领域可用 MD 模拟或 docking 生成更精确的复合物结构特征。
- **核心假设**：用 MD 模拟或分子对接生成的 TF-DNA 复合物结构特征（如界面残基、氢键网络）替代纯预测接触图，可提升结合亲和力预测精度。
- **初步方法**：对高置信 TF-DNA 对进行 MD 模拟（如 GROMACS）或 docking（如 HADDOCK），提取界面特征作为结构视图输入；与纯预测接触图对比。
- **验证方式**：在已知亲和力数据的 TF-DNA 对上进行评测。
- **可能的失败模式**：MD 模拟计算成本高，难以扩展到全基因组规模；docking 精度有限。
- **创新状态**：unverified

### 候选 5：泛 TF vs TF 家族特异模型的权衡分析
- **来源局限/观察**：MHCBind 同时训练泛等位基因和等位基因特异模型，发现不同任务各有优势；TF-DNA 领域可类比「泛 TF 模型」vs「TF 家族特异模型」。
- **核心假设**：TF 家族特异模型在家族内预测精度更高，但泛 TF 模型在未见 TF 上泛化更好；存在最优权衡点。
- **初步方法**：在多个 TF 家族（如 bZIP、C2H2、Homeodomain）上分别训练家族特异模型和泛 TF 模型，比较家族内和跨家族性能。
- **验证方式**：使用 ENCODE 和 CIS-BP 数据进行评测。
- **可能的失败模式**：某些家族数据量不足，家族特异模型过拟合。
- **创新状态**：unverified
