## 03 研究问题
- **具体问题**：如何从噬菌体基因组中可靠地计算鉴定受体结合蛋白（RBP）候选，以用于食源性病原体（Salmonella、E. coli、L. monocytogenes）的生物传感器开发？
- **为什么重要**：食源性病原体每年导致约 6 亿人次患病；传统检测方法慢、贵、特异性不足。RBP 是理想的生物传感器识别元件，但其序列多样性极高，传统序列同源方法难以覆盖。
- **现有方法为何不足**：RBP 序列多样性极高，基于序列同源的传统注释方法（如直系同源聚类、HMM 搜索）召回率低，无法识别远缘但功能相似的 RBP。
- **精确的「Can ... ?」研究问题**：Can a deep learning-based pipeline (using protein language model embeddings + structure prediction + structural homology + docking) reliably identify high-confidence RBP candidates from phage genomes targeting three priority foodborne pathogens?

## 06 核心思想

**1) 表面方法**：四阶段级联管线——PhageRBPdetect（ESM-2 微调）预测 RBP → ESMFold 预测 3D 结构 → Foldseek 对 PDB100 做结构同源验证 → 刚性对接评估与宿主受体互作。

**2) 核心洞察**：RBP 的序列多样性使序列同源失效，但结构保守性可能保留——因此用结构同源（而非序列同源）作为验证层；同时用对接能量作为功能优先级排序，而非仅停留在"是否为 RBP"的二分类。

**3) 可能的普适教训 [Analysis]**：对于高多样性结合蛋白（如 TF 的 DNA 结合域），"序列预测 → 结构验证 → 互作打分"的级联策略可显著提高候选置信度；结构层面的验证能捕捉序列层面丢失的远缘同源性。

## 14 Agent 提炼的知识候选

**面向课题方向（蛋白质-DNA 互作 × AI/物理模拟）的可迁移知识：**

1. **级联筛选范式**：本文"序列预测 → 结构验证 → 互作打分"的三级管线可直接迁移到 TF-DNA 结合位点预测。具体做法：用 PLM（如 ESM-2 或 ProtBERT）微调预测 DNA 结合域（DBD）→ AlphaFold/ESMFold 预测 DBD 结构 → 用 Foldseek 对已知 TF 结构库验证 → 对候选 DBD 与目标 DNA 序列做 docking（如 HDOCK、HADDOCK）排序。此范式可解决 TF 家族序列多样性导致的同源搜索失效问题。

2. **结构同源替代序列同源**：本文用 Foldseek 对 PDB100 验证，而非 BLAST 序列比对——这一思路对 TF 尤其重要，因为 TF 的 DBD 结构折叠类型有限（如 helix-turn-helix、zinc finger、bZIP），但序列差异极大。可构建"TF 结构折叠类型数据库"作为验证层。

3. **对接能量作为优先级排序**：本文用刚性对接结合能排序候选，而非仅停留在分类。迁移到 TF-DNA：对候选 TF 与已知/预测的 DNA 基序做 docking 或 MD 模拟，用结合自由能排序，可显著缩小实验验证范围。

4. **置信度阈值策略**：本文用"结构匹配概率 = 1.0"作为严格阈值，虽降低召回但提高精确率。在 TF-DNA 场景中，可设计两级阈值：宽松阈值用于全基因组扫描，严格阈值用于实验优先级。

5. **可复现管线设计**：本文强调"open-source"与"reproducible"，提示在 TF-DNA 课题中应同样发布完整管线（含数据、超参数、版本锁定），便于领域内复用与基准测试。

6. **缺失的环节——实验闭环**：本文最大短板是无实验验证。迁移到 TF-DNA 课题时，应在管线设计之初就规划实验验证层（如 EMSA、ChIP-seq 验证），避免纯计算结论的脆弱性。

- **验证方式**：在 ChIP-seq 基准数据集（如 ENCODE）上比较预测结合位点与实验位点的重叠率
- **可能的失败模式**：AlphaFold3 对 TF-DNA 复合物预测精度不足；计算成本过高；DBD 分类边界模糊
- **创新状态**：unverified（需文献调研确认是否已有类似管线）

**候选 2：TF 结构折叠类型数据库驱动的同源验证层**
- **名称**：TF-FoldDB：A structural fold-type database for transcription factor validation
- **来源局限/观察**：本文用 PDB100 做结构同源验证，但 PDB100 对 TF 覆盖不全，且未按折叠类型分类
- **核心假设**：TF 的 DBD 折叠类型有限且保守，结构折叠类型匹配可替代序列同源
- **相对本文的增量**：构建 TF 专属结构数据库；按折叠类型（HTH、zinc finger、bZIP 等）分类；支持 Foldseek 快速搜索
- **初步方法**：从 PDB 与 AlphaFold DB 收集 TF 结构 → 按 CATH/SCOP 分类 → 构建 Foldseek 可搜索数据库 → 作为验证层集成到 TF 预测管线
- **验证方式**：在已知 TF 数据集上测试折叠类型匹配的精确率/召回率
- **可能的失败模式**：TF 结构覆盖不足；折叠类型分类存在争议；无法区分同折叠不同功能的蛋白
- **创新状态**：partially checked（已有类似数据库如 Pfam 的 structural 分类，但 TF 专属且集成 Foldseek 的未见报道）

**候选 3：结合能排序与实验优先级的闭环验证框架**
- **名称**：BindRank-TF：A docking-energy-based prioritization framework with experimental feedback
- **来源局限/观察**：本文的对接排序无实验验证，导致结论脆弱
- **核心假设**：对接结合能与实验结合亲和力（如 Kd）存在可学习的相关性，可用少量实验数据校准排序模型
- **相对本文的增量**：引入主动学习——用少量 EMSA/SPR 数据校准对接打分，迭代优化排序
- **初步方法**：对候选 TF-DNA 对做刚性/柔性对接 → 用 10-20 个实验 Kd 值训练校准模型（如线性回归或 GPR）→ 迭代选择最不确定的候选做实验 → 更新模型
- **验证方式**：在留出集上比较校准前后排序的 Spearman 相关性
- **可能的失败模式**：对接打分与实验亲和力相关性弱；实验通量限制；校准模型过拟合
- **创新状态**：unverified（需确认是否已有类似主动学习框架用于 TF-DNA）
