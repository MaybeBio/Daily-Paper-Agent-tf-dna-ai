## 02 一句话总结

本文通过开发计算流水线 CEseek 从免疫/造血细胞开放染色质区域中发现 5,063 个候选复合元件（CEs），用定制 MPRA 文库在三种人类细胞系中实验验证其转录活性，并训练深度学习模型 GRACE 在单核苷酸分辨率上学习 CE 活性词典，进而与 ChromBPNet 染色质可及性模型对比，揭示 CE 对转录与染色质结构的差异化贡献。

## 03 研究问题

- **具体问题**：真核生物增强子/启动子中，两个 TF 基序以特定相对方向（orientation）和间距（spacing）排列形成的复合元件（CEs）是否构成一个尚未被系统编目的、功能上重要的「高阶调控词典」？能否通过整合计算发现、高通量实验和深度学习来系统性地发现并功能验证这一词典？
- **为什么重要**：现有调控注释几乎完全基于**单个 TF 基序**（simple motifs），但真实增强子功能往往依赖多个 TF 的协同结合。单基序词典信息量低、冗余度高，导致：(1) TF→靶基因推断质量差；(2) 非编码变异解读困难——许多疾病相关变异落在 CE 而非单基序上；(3) 基因调控网络（GRN）构建精度受限。
- **现有方法不足**：
  - 先前的 CE 研究多为**个案式**（如 EICE、AICE 等逐个鉴定），缺乏系统性发现框架；
  - CAP-SELEX 等体外方法使用大肠杆菌表达蛋白和合成 DNA，缺乏体内染色质背景与细胞类型特异性；
  - 仅用 ChIP-seq 共结合分析无法区分功能性 CE 与偶然共定位；
  - 深度学习模型（如 Enformer、Basenji）虽能预测调控活性，但内部表征难以直接映射到「双基序构型」这一可解释单元。
- **精确研究问题（Can...?）**：Can a computational-experimental-deep learning integrated framework systematically discover, functionally validate, and predict the activity of composite DNA elements (CEs) at single-nucleotide resolution across cell types?

## 06 核心思想

### 1) 表面方法

三层整合框架：
- **CEseek（计算发现）**：用 153 个非冗余核心 TF 基序（来自 CIS-BP + HOMER），在 ImmGen 联盟 86 种免疫/造血细胞类型的 512,595 个开放染色质区域（OCRs）中，系统扫描所有双基序组合（4 种相对方向 × 16 种间距，−5 到 +10 bp），用 Fisher 精确检验识别统计显著富集的构型，生成 5,063 个高置信候选 CE。
- **定制 MPRA（实验验证）**：设计 60,714 条 30 bp 序列的文库，包含 3,795 个 CE（每个 CE 取 4 个最高分基因组实例）+ 153 个简单基序 + 突变对照（左基序突变、右基序突变、双突变），在 K562、GM12878、Jurkat 三种细胞系中测量转录活性。
- **GRACE（深度学习建模）**：基于卷积 + 自注意力 + 位置编码的架构，在 MPRA 数据上训练，预测 50 bp 序列的转录活性，并通过贡献权重矩阵（CWM）在单核苷酸分辨率上解释基序贡献。

### 2) 核心洞察

- **CE 是「数字」与「模拟」的混合编码**：部分 TF 对表现出严格的数字式（digital）构型约束（≤6 种允许构型），部分则表现出模糊式（fuzzy）灵活性（≥49 种构型），形成双峰分布。这提示 CE 语法同时包含「硬性结构规则」和「软性组合逻辑」。
- **CE 的活性不等于其组成基序活性的简单加和**：通过比较 CE 活性与单基序活性之和，可量化协同（synergy）或拮抗（antagonism），且这种非加和性在特定构型下被放大。
- **转录活性与染色质可及性编码部分重叠但不等价**：GRACE（转录活性）与 ChromBPNet（染色质可及性）在简单基序上高度一致，但在 CE 上出现分化——某些 CE 主要贡献于转录活性而不影响可及性，反之亦然。这提示 CE 是「功能分工」的单元。

### 3) 可能的普适教训 [Analysis]

- **「中间层」策略**：在单基序（过简）与完整序列语法（过复杂）之间，CE 提供了一个可解析、可实验、可建模的中间表征层。类似策略可迁移到其他分子互作问题（如 RNA–蛋白互作中的双位点元件）。
- **「计算发现→定制实验→深度学习→跨模型对比」闭环**：深度学习模型的价值不仅在于预测精度，更在于其可作为「表征对齐」工具——将实验测得的活性映射到可解释的序列特征，再与独立训练的模型对比，实现交叉验证。
- **有限但设计良好的数据 > 海量但嘈杂的数据**：GRACE 仅在 <50,000 条序列上训练即达到高精度，关键在于 MPRA 文库的系统性设计（突变对照、构型覆盖），这为数据匮乏的课题提供了范式。

## 07 方法总览

- **输入**：
  - CEseek：153 个 TF 基序 PWM + ImmGen 512,595 个 OCR 序列（180 bp）
  - MPRA：60,714 条 30 bp 寡核苷酸序列（含 CE、简单基序、突变对照）
  - GRACE：MPRA 测得的序列活性（log2FC），输入为 50 bp 序列（30 bp 核心 + 两侧随机延伸）
- **输出**：
  - CEseek：5,063 个高置信 CE 及其 PWM
  - MPRA：每个序列在 3 种细胞系中的转录活性（log2FC）
  - GRACE：50 bp 序列的预测活性 + 单核苷酸贡献权重矩阵（CWM）
- **模块**：
  1. **CEseek 扫描模块**：双基序组合枚举（4 方向 × 16 间距）、Fisher 精确检验、PWM 构建
  2. **MPRA 文库设计模块**：CE 实例选择、突变设计（左/右/双突变）、barcode 连接
  3. **MPRA 实验模块**：三种细胞系转染、GFP mRNA 捕获、barcode 测序
  4. **GRACE 模型模块**：卷积层（多核大小）→ 自注意力层（位置编码）→ 全连接输出；训练用 AdamW + 学习率调度 + 早停
  5. **CWM 生成模块**：in silico 饱和突变 → 预测活性变化 → 归一化为贡献权重
  6. **跨模型对比模块**：GRACE CWM vs ChromBPNet CWM 的相关性分析
- **反馈回路**：MPRA 实验数据 → GRACE 训练 → GRACE 预测新构型 → 与 CEseek 发现交叉验证 → 指导后续文库设计
- **文字流程**：
  1. 用 CEseek 扫描 ImmGen OCRs，识别统计显著富集的双基序构型 → 5,063 个 CE
  2. 从每个 CE 中选取基因组实例，设计 30 bp 寡核苷酸及突变对照，构建 MPRA 文库
  3. 在 K562/GM12878/Jurkat 中转染文库，测量转录活性
  4. 用 MPRA 数据训练 GRACE，评估预测精度（Pearson r = 0.766–0.813）
  5. 对 GRACE 做 in silico 饱和突变，生成 CWM，与 CEseek PWM 对比（80.3%–95.6% 一致率）
  6. 将 GRACE 应用于全基因组 OCRs，预测内源增强子/启动子活性
  7. 与 ChromBPNN 对比，区分 CE 对转录活性 vs 染色质可及性的贡献

## 09 关键公式符号

> 本文为基因组学/深度学习论文，核心公式较少，以下为理解必需者：

1. **Fisher 精确检验（CEseek 富集统计）**
   - 用于比较 CE 构型在目标 OCR 集与背景集中的出现频率
   - 列联表：{CE 出现, CE 不出现} × {目标集, 背景集}
   - 显著性阈值：p < 1e-20（全基因组扫描）、p < 1e-10（ChIP-seq 富集验证）

2. **DESeq2 差异分析（MPRA 活性定量）**
   - 比较 RNA 与 DNA 中 barcode 计数，估计序列活性
   - 关键步骤：负二项分布建模、大小因子归一化、log2 fold change 收缩（lshrink）
   - 过滤标准：≥30 个唯一 barcode/序列

3. **贡献权重矩阵（CWM）生成**
   - 对每个位置 i 的每个碱基 b：CWM(i,b) = 预测活性(突变体) − 预测活性(野生型)
   - 归一化：减去该位置平均活性，得到相对贡献
   - 与 PWM 对比：将 CWM 经 softmax 转换为概率矩阵，再用 Tomtom 计算相似性（FDR < 0.05）

4. **GRACE 模型损失函数**
   - 均方误差（MSE）：L = (1/N) Σ (y_pred − y_true)²
   - 评估指标：Pearson 相关系数（预测 vs 实测活性）

5. **CE 协同效应量化**
   - 预期加性活性：A_add = A_motif1 + A_motif2 − A_background
   - 协同效应：Δ = A_CE − A_add
   - Δ > 0 且显著（p < 0.05）→ 协同激活；Δ < 0 → 拮抗

## 11 核心结论

1. **CE 是普遍存在的调控单元**：在免疫/造血细胞 OCRs 中，5,063 个高置信 CE 构成一个此前未系统编目的「高阶调控词典」，其规模远超已知个案。
2. **CE 具有可测量的功能性**：893 个 CE 在 MPRA 中表现出转录活性，其中 190 个为协同激活（AND 门），25 个为拮抗（AND-NOT 门），1 个为 XOR 门。
3. **CE 语法包含数字与模糊两种模式**：TF 对构型约束呈双峰分布——部分严格受限（≤6 构型），部分高度灵活（≥49 构型）。
4. **深度学习可学习 CE 词典**：GRACE 在 <50,000 条序列上训练即达到高精度（Pearson r = 0.766–0.813），且其 CWM 与 CEseek PWM 高度一致（80.3%–95.6%），证明 CE 是可学习的、有规律的编码单元。
5. **CE 对转录与染色质可及性贡献不同**：GRACE 与 ChromBPNet 的对比揭示，简单基序对两者的贡献高度相关，但 CE 出现分化——某些 CE 主要驱动转录活性，另一些主要影响染色质开放。
6. **CE 有助于解读非编码变异**：30.9% 的功能性 GWAS 变异落在 CE 上，提示 CE 应纳入变异优先级排序框架。

## 12 局限与未解问题

### 作者明确承认的局限（Results/Discussion 中）

1. **MPRA 检测的是合成序列活性**，不直接等同于内源基因组位点的调控功能；需要 CRISPR 扰动或等位基因替换验证。
2. **CE 文库仅覆盖免疫/造血细胞 OCRs**，其他细胞类型/发育阶段的 CE 词典可能不同。
3. **GRACE 训练数据有限**（<50,000 条序列），可能未覆盖全部可能的 CE 构型空间。
4. **CE 的功能验证仅在 3 种细胞系中进行**，未涵盖原代细胞或体内组织。
5. **CE 的机制解释有限**：虽然观察到协同/拮抗，但未解析其分子机制（如蛋白-蛋白互作界面、DNA 构象变化）。

### 作者未明确提及但值得注意的局限 [Analysis]

1. **PWMs 的局限性**：CEseek 依赖已知单基序 PWM，无法发现由非经典基序或全新 TF 结合模式构成的 CE。
2. **二基序假设**：框架仅考虑二元组合，未涉及三基序或更高阶组合。
3. **方向/间距的离散化**：间距以整数 bp 计，未考虑 DNA 弯曲、扭结等导致的非整数间距效应。
4. **细胞类型特异性的机制**：虽然观察到细胞类型特异性 CE 活性，但未解释其上游机制（如 TF 表达水平、竞争性结合）。
5. **深度学习模型的可解释性**：CWM 与 PWM 的一致性虽高，但未证明 GRACE 学到的注意力模式对应真实的蛋白-蛋白互作界面。

## 14 术语解释

| 术语 | 定义 | 在本文中的角色 |
|---|---|---|
| **Composite Element (CE)** | 两个或多个 TF 基序以特定相对方向与间距排列形成的 DNA 调控元件 | 本文核心研究对象，被视为调控代码的「高阶词汇」 |
| **Simple Motif** | 单个 TF 识别的 6–10 bp DNA 序列模式 | CE 的组成单元，本文使用 153 个非冗余核心基序 |
| **CEseek** | 本文开发的计算流水线，用于系统发现 CE | 计算发现层，输出候选 CE 及其 PWM |
| **MPRA (Massively Parallel Reporter Assay)** | 大规模平行报告基因分析，同时测量数千条 DNA 序列的转录活性 | 功能验证层，提供 CE 活性的金标准数据 |
| **GRACE (Genome Regulatory Analysis of Simple and Composite Transcriptional Elements)** | 本文开发的深度学习模型 | 预测层，学习 CE 活性词典并生成 CWM |
| **CWM (Contribution Weight Matrix)** | 通过 in silico 饱和突变生成的单核苷酸分辨率贡献矩阵 | 连接深度学习预测与可解释基序特征的桥梁 |
| **PWM (Position Weight Matrix)** | 位置权重矩阵，描述 TF 结合位点的核苷酸偏好 | 用于表示 CE 的序列模式，与 CWM 对比验证 |
| **Digital vs. Fuzzy CE** | 数字式 CE 指构型严格受限（≤6 种）；模糊式 CE 指构型灵活（≥49 种） | 本文发现的 CE 语法双峰分布 |
| **ChromBPNet** | 基于染色质可及性训练的深度学习模型 | 正交模型，用于对比 CE 对转录 vs 染色质可及性的贡献 |
| **逻辑门（AND/AND-NOT/XOR）** | 描述两个输入信号如何组合产生输出的布尔逻辑 | 用于分类 CE 的协同/拮抗/互斥调控逻辑 |
| **Cook's Distance** | 回归诊断中用于识别高影响力异常值的统计量 | 用于 MPRA 数据中过滤异常 barcode |
| **Tomtom** | 基序比较工具，用于评估两个基序的相似性 | 用于 CWM-PWM 一致性分析 |
| **GRO-cap (Global Run-On sequencing)** | 检测正在进行的转录起始的测序方法 | 用于验证 GRACE 预测的内源转录活性 |
| **emVAR (expression-modulating variant)** | 影响基因表达的遗传变异 | 用于 GWAS 变异功能解读 |

## 15 与已有知识连接

### 可直接连接的已发表工作

1. **ETS::IRF (EICE) 与 AP-1::IRF (AICE)**：本文以这些经典 CE 作为验证基准。EICE 由 ETS 与 IRF 家族成员协同结合，是 B 细胞和巨噬细胞中 TLR 信号响应的关键元件（Glasmacher et al., 2012; Mancino et al., 2015）。本文的 CEseek 成功恢复这些已知 CE，验证了方法的有效性。

2. **CAP-SELEX**：Jolma et al. (2015) 开发的高通量体外方法，用于系统鉴定 TF 对协同结合。本文用 CAP-SELEX 数据作为 CE 的体外验证证据（44.0% 匹配率），但指出其缺乏体内功能信息。

3. **MPRA 方法学**：Patwardhan et al. (2009)、Melnikov et al. (2012) 等建立的 MPRA 技术。本文的定制 MPRA 文库设计（突变对照、barcode 连接）遵循并扩展了这些方法。

4. **深度学习调控预测**：DeepSEA (Zhou & Troyanskaya, 2015)、Basenji (Kelley et al., 2018)、Enformer (Avsec et al., 2021) 等模型预测调控活性。本文的 GRACE 与这些模型的区别在于：训练数据为定制 MPRA（而非自然序列），且输出为单核苷酸分辨率的 CWM。

5. **ChromBPNet**：Bentsen et al. (2020) 开发的染色质可及性预测模型。本文使用 ChromBPNet 作为正交模型，对比 CE 对转录活性 vs 染色质可及性的贡献。

6. **ImmGen 图谱**：Heng et al. (2008) 等建立的免疫细胞基因调控图谱。本文的 CE 发现完全基于 ImmGen 的 OCR 数据。

### 与课题方向的连接

- **TF–DNA 结合机制**：本文的 CE 概念直接指向 TF 协同结合的 DNA 编码规则。CE 的方向/间距约束反映了 TF 二聚体在 DNA 双螺旋上的空间几何关系（如大沟/小沟朝向、螺旋周期 ~10.5 bp）。这为结构生物学（如冷冻电镜、X 射线晶体学）提供了候选复合物清单。
- **AI/深度学习**：GRACE 的 CWM 生成方法可迁移到其他序列-功能预测任务。其「有限但设计良好的训练数据」策略对数据匮乏的调控问题具有方法论价值。
- **物理模拟**：CE 的方向/间距约束可作为分子动力学（MD）模拟的初始约束条件，用于预测 TF 二聚体的结合自由能。本文未涉及 MD，但其 CE 词典为 MD 研究提供了候选系统。

## 16 研究想法

> 以下为基于本文的候选研究方向，标注创新状态。

### 候选 1：CE 感知的变异优先级排序框架
- **来源局限/观察**：本文显示 30.9% 的功能性 GWAS 变异落在 CE 上，但现有变异注释工具（如 CADD、FunSeq2）仅考虑单基序破坏。
- **核心假设**：破坏 CE 构型（方向/间距）的变异比破坏单基序的变异具有更大的调控效应。
- **初步方法**：将 CEseek 的 CE 词典整合到变异注释流程中，对落在 CE 内的变异赋予额外权重；用本文的 MPRA 数据训练一个 CE 特异性效应预测器。
- **验证方式**：在独立 GWAS 数据集（如自身免疫病）中比较 CE-aware 与单基序注释的富集度。
- **创新状态**：unverified（本文未直接提出此应用，但数据支持其可行性）。

### 候选 2：CE 构型与 TF 二聚体结构的映射
- **来源局限/观察**：本文发现 CE 的方向/间距约束（数字式 vs 模糊式），但未解释其结构基础。
- **核心假设**：数字式 CE 对应刚性蛋白-蛋白互作界面（如 ETS::IRF 的 β 片层-螺旋界面），模糊式 CE 对应柔性界面或间接协同（如通过染色质重塑因子）。
- **初步方法**：选取代表性数字式与模糊式 CE，用 AlphaFold3 或 MD 模拟预测 TF 二聚体-DNA 复合物结构，比较结合自由能与构型约束的关系。
- **验证方式**：突变 CE 中的关键间距/方向残基，测量结合亲和力变化（如 EMSA、SPR）。
- **创新状态**：unverified（本文未涉及结构分析，但 CE 词典为结构研究提供了输入）。

### 候选 3：跨细胞类型的 CE 活性预测
- **来源局限/观察**：本文的 MPRA 仅在 3 种细胞系中测试，CE 活性具有细胞类型特异性，但未建模其决定因素。
- **核心假设**：CE 活性由「CE 序列 + 细胞类型特异的 TF 表达谱 + 染色质环境」共同决定。
- **初步方法**：将 GRACE 扩展为条件模型，输入 CE 序列 + 细胞类型 TF 表达向量，输出预测活性；用本文的 3 细胞系数据训练，用公开 MPRA 数据（如 ENCODE 的 STARR-seq）验证。
- **验证方式**：预测新细胞类型中的 CE 活性，与实验测量对比。
- **创新状态**：unverified（本文未提出此扩展，但 GRACE 架构支持条件化输入）。

### 候选 4：CE 词典在合成增强子设计中的应用
- **来源局限/观察**：本文显示 CE 的活性高于其组成单基序之和，提示 CE 是增强子设计的「功能模块」。
- **核心假设**：将 CE 作为模块化元件组合，可设计出具有可预测活性的合成增强子。
- **初步方法**：从本文的 893 个活性 CE 中选取模块，按不同组合方式构建合成增强子，用 MPRA 测量活性，与 GRACE 预测对比。
- **验证方式**：设计 100 个合成增强子，测量活性，评估 GRACE 预测精度。
- **创新状态**：unverified（本文未涉及合成生物学应用，但 CE 词典提供了模块库）。

### 候选 5：CE 与 pioneer 因子的协同机制
- **来源局限/观察**：本文发现 GATA 基序在 K562 中贡献染色质可及性，但未深入分析 pioneer 因子在 CE 中的作用。
- **核心假设**：含 pioneer 因子（如 GATA、FOXA）的 CE 具有「先开放染色质、再招募协同因子」的两步机制，其 CE 构型约束与 pioneer 因子的核小体结合能力相关。
- **初步方法**：将 CE 分为含/不含 pioneer 因子基序两组，比较其染色质可及性贡献（ChromBPNN）与转录活性贡献（GRACE）的差异；用核小体定位数据验证。
- **验证方式**：对选定的 pioneer CE 进行 MNase-seq 或 ATAC-seq 时间序列分析。
- **创新状态**：unverified（本文观察到 GATA 的差异化贡献，但未系统分析 pioneer 因子）。

### 候选 6：CE 词典的进化保守性分析
- **来源局限/观察**：本文的 CE 来自人类/小鼠 OCRs，但未分析 CE 的进化保守性。
- **核心假设**：功能重要的 CE（如协同激活型）在哺乳动物中高度保守，且保守的 CE 构型（方向/间距）比保守的单基序更能预测功能。
- **初步方法**：将 CE 映射到多物种基因组比对（如 Zoonomia），计算 CE 构型的保守性得分；比较保守 CE 与非保守 CE 的 MPRA 活性。
- **验证方式**：在斑马鱼或果蝇中测试保守 CE 的异源活性。
- **创新状态**：unverified（本文未涉及进化分析，但 CE 词典为比较基因组学提供了新注释层）。
