## 02 一句话总结

本文开发了 STRUMP-I——一种基于同源建模结构、以 FoldX 力场能量项为特征的梯度提升机（GBM）分类器，用于 pMHC-I 结合预测；该方法在整体性能上与 SOTA 序列方法相当，但在低表示等位基因上显著更稳健，并能作为序列方法的后置过滤器提升精度。

## 03 研究问题

- **具体问题**：能否利用 pMHC-I 三维结构的力场能量项作为机器学习特征，实现与序列方法相当甚至更优的 pMHC-I 结合预测，尤其是在训练数据稀少的 MHC 等位基因上？
- **为什么重要**：MHC-I 是超多态基因，绝大多数等位基因缺乏足够的训练数据；序列方法依赖大数据，对低表示等位基因泛化差。准确预测 pMHC-I 结合是肿瘤新抗原发现和疫苗设计的关键步骤。
- **现有方法不足**：序列方法（NetMHCpan、MHCflurry、HLAthena）依赖大规模训练数据，对低表示等位基因性能下降；传统结构方法依赖单一全局最小能量假设，而 pMHC 结合具有内在混杂性（promiscuity），该假设常不成立。
- **精确研究问题**：Can a machine learning classifier trained on force-field-derived energy features from homology-modeled pMHC-I structures achieve comparable overall performance to sequence-based SOTA methods while generalizing better to underrepresented MHC alleles?

## 04 背景与发展脉络

> 注：以下脉络基于本文 Introduction 的叙述，属「仅本文框架」，未经外部系统核验。

1. **序列方法主导期**：NetMHCpan、MHCflurry、HLAthena 等利用大规模结合数据训练 ML/DL 模型，直接从肽和 MHC 序列预测结合。优点：快速、准确度高；局限：依赖训练数据规模与质量，对低表示等位基因泛化差。
2. **结构方法早期尝试**：基于 pMHC 晶体结构或同源模型，用分子力学/对接打分函数评估结合。优点：不依赖训练数据、可解释；局限：计算昂贵、精度低于序列方法，且依赖单一全局最小能量假设。
3. **结构+ML 融合期**：近年方法开始将结构信息与 ML 结合，如 AlphaFold-FineTune（AF-FT）微调 AlphaFold 同时学习结构与结合。优点：利用结构泛化性；局限：计算成本高，对低表示等位基因仍有不足。
4. **本文主张的位置**：STRUMP-I 提出「多能量项作为特征 + GBM 分类」的中间路线——不依赖单一全局能量，而是将力场分解为多个能量项（相互作用能、溶剂化、静电等）作为 ML 输入，在保持结构方法泛化优势的同时达到序列方法的整体精度。

## 06 核心思想

### 1) 表面方法
构建 pMHC-I 同源模型 → 用 FoldX 计算多种力场能量项 → 将这些能量项作为特征输入 GBM（LightGBM）分类器 → 输出结合/非结合预测。

### 2) 核心洞察
**pMHC 结合的能量景观是混杂的（promiscuous），不应依赖单一全局最小能量构象；将力场分解为多个能量项并让 ML 学习其组合模式，比使用单一总能量更有效。** 此外，结构信息本身具有序列无关的泛化能力——即使某个等位基因训练样本极少，只要其结构可建模，能量特征仍能提供有效信号。

### 3) 可能的普适教训 [Analysis]
- 对 TF–DNA 互作：TF 与 DNA 的结合同样具有混杂性（同一 TF 可识别多个 motif），单一 docking 得分或 MD 结合自由能往往不足以预测结合特异性。将相互作用分解为多个能量项（静电、范德华、溶剂化、氢键等）作为 ML 特征，可能比端到端预测更鲁棒。
- 结构模板质量对特征质量影响大：STRUMP-I 依赖模板选择（BLOSUM62 选 MHC、PAM30 选肽），提示在 TF–DNA 中模板选择策略（如基于 DNA 序列相似性选模板）同样关键。

## 07 方法总览

- **输入**：肽序列 + MHC-I 等位基因序列（HLA-A/B/C 等）
- **输出**：二分类（结合/非结合，阈值 500 nM）
- **主要模块**：
  1. **模板选择**：从 826 个 pMHC-I 晶体结构（IMGT 数据库）中，按肽长度筛选，BLOSUM62 比对 MHC 序列选最相似模板，PAM30 比对肽序列选最相似肽
  2. **同源建模**：FoldX BuildModel 模块将模板中的肽和 MHC 非匹配区域替换为查询序列
  3. **结构优化**：Tinker MD 包（v8.9.5），AMBER99sb 力场 + GB-HPMF 隐式溶剂模型，松弛结构去除突变引入的冲突
  4. **能量特征提取**：FoldX AnalyzeComplex 模块计算最终能量项（含相互作用能、溶剂化、静电等，完整特征列表见表 S1）
  5. **分类器**：LightGBM（GBM），Optuna 超参数调优（10,000 轮，含剪枝）
- **训练**：IEDB+HLAthena 数据集，8:1:1 训练/验证/测试划分，100 个随机种子
- **反馈回路**：无显式主动学习或迭代优化；模型为单轮训练
- **推理流程**：输入序列 → 模板选择 → 同源建模 → MD 松弛 → FoldX 能量计算 → GBM 预测

## 09 关键公式符号

本文为 ML 分类方法，未提供显式数学公式。核心概念符号如下：

- **结合阈值**：500 nM（IC50/KD ≤ 500 nM 定义为结合）
- **FoldX 能量项**：ΔG_binding（总结合自由能）、ΔG_solvation（溶剂化能）、ΔG_electrostatic（静电相互作用）、ΔG_vdW（范德华力）等（完整列表见表 S1）
- **GBM 目标函数**：LightGBM 二分类对数损失（log loss），未给出显式公式
- **评估指标**：AUROC、PRAUC、MCC、precision、recall

> 注：本文未提供能量项的具体计算公式，FoldX 力场能量定义参见 FoldX 原始文献。

## 11 结论正确解读

- **任务范围**：仅限 MHC-I 类分子（HLA-A/B/C 等），不涉及 MHC-II；仅限肽长度与模板库匹配的场景
- **Oracle/真值输入**：训练标签来自 IEDB 实验结合数据（KD/IC50 测量）和 HLAthena 的 eluted ligand 数据；eluted ligand 数据中所有肽均视为结合物，可能引入标签噪声
- **端到端状态**：**非端到端**。需要预先选择模板、建模、MD 松弛，流程复杂；输入为序列，但中间依赖结构模板库
- **算力成本**：结构建模 + MD 松弛计算成本显著高于纯序列方法；作者建议作为后置过滤器而非全基因组筛选
- **历史数据依赖**：模板库（826 个 pMHC 结构）覆盖的等位基因和肽长度有限；对模板库中无相似结构的等位基因，性能未知
- **模型依赖**：仅测试了 LightGBM；其他 ML 模型（逻辑回归、随机森林、TabNet）性能较低，但未测试深度学习架构
- **最难场景**：PRIME 数据集（高表示等位基因）上 STRUMP-I 表现弱于序列方法，说明其优势集中在低数据场景
- **有边界的复述**：STRUMP-I 在 pMHC-I 结合预测中，整体性能与 SOTA 序列方法相当，在训练数据 <500 样本的等位基因上显著更优，并可作为序列方法的后置过滤器提升 precision；但其计算成本高、依赖模板库覆盖度，且在高表示等位基因上无优势。

## 14 学到什么

> 以下为 Agent 提炼的知识候选，面向「蛋白质-DNA 互作（TF–DNA 结合机制）× AI/物理模拟」课题。

1. **多能量项特征优于单一全局能量**：STRUMP-I 的核心洞见——不依赖单一 ΔG_binding，而是将 FoldX 力场分解为多个能量项（相互作用、溶剂化、静电、范德华等）作为 ML 特征。**迁移到 TF–DNA**：MD 或 docking 计算的单一结合自由能往往预测力有限，可将 MM/PBSA 或 MMPBSA 分解为各能量项（静电、范德华、溶剂化、熵贡献），或按 DNA 碱基对/磷酸基团分区计算能量谱，作为 ML 特征。

2. **模板选择策略**：STRUMP-I 对 MHC 和肽分别选择模板（BLOSUM62 选 MHC、PAM30 选肽），而非整体选最相似复合物。**迁移到 TF–DNA**：TF 蛋白结构域和 DNA 序列的模板选择可解耦——蛋白部分按序列相似性选，DNA 部分按序列 motif 相似性选，避免单一相似性度量偏差。

3. **低资源泛化验证**：STRUMP-I 专门评测了低表示等位基因（<500 样本）上的性能，这是序列方法最薄弱的场景。**迁移到 TF–DNA**：多数 TF 家族只有少数成员有实验数据，评测模型在低数据 TF 家族上的泛化能力（而非仅报告整体 AUC）是更严格的检验标准。

4. **集成策略提升 precision**：STRUMP-I 与序列方法集成（取交集）可显著提升 precision，因为假阳性通常是方法特异的。**迁移到 TF–DNA**：序列-based 的 TF 结合预测（如 DeepSEA、DeepBind）与结构-based 方法（docking、MD）的假阳性模式可能互补，集成可提升 ChIP-seq 验证率。

5. **SHAP 特征归因用于机制解释**：STRUMP-I 用 SHAP 识别关键能量项，发现非键相互作用和模板比对质量最重要。**迁移到 TF–DNA**：对 TF–DNA 模型做 SHAP 分析可识别哪些物理相互作用项（如特定碱基的静电贡献、DNA 弯曲能）驱动预测，为机制研究提供假设。

6. **结构方法作为后置过滤器**：STRUMP-I 定位为序列方法的补充而非替代，在序列方法初筛后做结构验证。**迁移到 TF–DNA**：全基因组 TF 结合位点预测可用序列方法初筛，再用结构建模（docking/MD）对候选位点做精筛，平衡通量与精度。

## 15 与已有知识连接

- **FoldX 力场**：FoldX 是蛋白质设计/突变效应预测的常用力场（Guerois et al., 2002; Schymkowitz et al., 2005）。本文将其扩展到 pMHC 结合预测，与 TF–DNA 领域用 FoldX 评估蛋白-DNA 结合界面突变效应的思路类似（如 Alibés et al., 2010 用 FoldX 研究 TF-DNA 结合）。
- **pMHC 预测方法谱系**：序列方法 NetMHCpan（Andreatta & Nielsen, 2016）、MHCflurry（O'Donnell et al., 2018）、HLAthena（Sarkizova et al., 2020）代表当前主流；结构方法如 AF-FT（2023-2024）代表 AlphaFold 微调路线。STRUMP-I 介于两者之间，与 Rosetta 能量打分用于 pMHC 预测的早期工作（Yanover & Bradley, 2011）思路相近。
- **AlphaFold-FineTune**：AF-FT 用 AlphaFold 微调同时预测结构和结合，STRUMP-I 与 AF-FT 对比显示，在低数据场景下传统同源建模+力场特征可能优于端到端深度结构预测。
- **TF–DNA 互作预测的可迁移方法**：本文的「模板选择→建模→力场特征→ML 分类」管线与 TF–DNA 领域的结构-based 预测方法（如 3D-DART + HADDOCK docking + 能量打分）结构相似；「多能量项作为特征」的思路可迁移到 TF–DNA 的 MM/PBSA 分析。
- **SHAP 可解释性**：SHAP（Lundberg & Lee, 2017）在生物信息学中广泛用于特征归因，本文将其用于力场能量项，与 TF–DNA 领域用 SHAP 解释 CNN 模型（如 DeepSEA）的碱基贡献类似。

## 16 研究想法

> 以下为 Agent 生成的研究候选，面向「TF–DNA 互作 × AI/物理模拟」课题。

### 候选 1：TF–DNA 多能量项特征 ML 分类器
- **名称**：STRUMP-TF：基于力场能量特征的 TF–DNA 结合预测
- **来源局限/观察**：现有 TF–DNA 结构预测方法依赖单一 docking 得分或结合自由能，预测力有限；STRUMP-I 证明多能量项特征可显著提升分类性能
- **核心假设**：TF–DNA 结合的能量景观同样具有混杂性，分解为多能量项（静电、范德华、溶剂化、氢键、DNA 弯曲能）后，ML 可学习更鲁棒的结合模式
- **初步方法**：对已知 TF–DNA 复合物结构做同源建模 → MD 模拟或 FoldX 计算多能量项 → LightGBM 分类 → 与 DeepSEA、DeepBind 等序列方法对比
- **验证方式**：在低数据 TF 家族上评测泛化；与 ChIP-seq 实验数据对比；SHAP 分析识别关键能量项
- **创新状态**：unverified

### 候选 2：TF 与 DNA 模板解耦选择策略
- **名称**：解耦模板选择：蛋白结构域与 DNA motif 分别选模板的 TF–DNA 建模
- **来源局限/观察**：STRUMP-I 对 MHC 和肽分别选模板（BLOSUM62 + PAM30），显著提升建模质量；TF–DNA 建模通常整体选模板，忽略了蛋白和 DNA 的独立进化
- **核心假设**：TF 蛋白结构域和 DNA 结合位点的模板选择应解耦——蛋白按序列相似性、DNA 按 motif 相似性分别选，可提升同源模型质量
- **初步方法**：构建 TF–DNA 复合物模板库 → 对查询 TF 和 DNA 分别计算相似性 → 组合选模板 → 建模后评估结构质量与下游预测性能
- **验证方式**：与整体选模板策略对比结构 RMSD 和结合预测 AUC
- **创新状态**：unverified

### 候选 3：TF–DNA 结合预测的序列-结构集成管线
- **名称**：SeqStruct-TF：序列方法初筛 + 结构能量精筛的两阶段 TF–DNA 结合预测
- **来源局限/观察**：STRUMP-I 作为序列方法的后置过滤器可显著提升 precision；TF–DNA 全基因组预测同样面临序列方法假阳性高的问题
- **核心假设**：序列方法（如 DeepSEA）初筛候选位点，再用结构建模（docking + 力场能量）精筛，可显著提升 ChIP-seq 验证率
- **初步方法**：全基因组扫描 → 序列模型初筛 Top-K → 对候选位点做 TF 结构 docking → 能量特征 ML 精筛 → 输出高置信位点
- **验证方式**：在 ChIP-seq 数据集上对比两阶段 vs 单阶段方法的 precision@K
- **创新状态**：unverified

### 候选 4：TF–DNA 能量特征的可解释性分析
- **名称**：从能量特征到结合机制：TF–DNA 模型的 SHAP 归因分析
- **来源局限/观察**：STRUMP-I 的 SHAP 分析揭示了关键能量项；TF–DNA 模型的可解释性分析多集中在序列 motif，缺乏物理能量层面的归因
- **核心假设**：SHAP 归因可识别驱动 TF–DNA 结合预测的关键物理相互作用项（如特定碱基的静电贡献、DNA 构象变化能），为突变效应预测提供机制解释
- **初步方法**：训练 TF–DNA 能量特征 ML 模型 → SHAP 全局/局部归因 → 与已知 TF–DNA 晶体结构接触界面比对 → 验证归因的生物学合理性
- **验证方式**：归因结果与突变实验数据（如 SELEX 突变体）对比
- **创新状态**：unverified

### 候选 5：低资源 TF 家族的泛化评测基准
- **名称**：TF-LowBench：面向低数据 TF 家族的结合预测泛化基准
- **来源局限/观察**：STRUMP-I 专门评测低表示等位基因，发现结构方法在此场景优势显著；TF–DNA 领域缺乏类似的低资源评测标准
- **核心假设**：现有 TF–DNA 预测模型在低数据 TF 家族上的性能被整体 AUC 掩盖，需要专门的评测协议
- **初步方法**：构建 TF 家族数据量分层基准 → 评测序列方法、结构方法、混合方法在各层级的性能 → 发布标准化评测协议
- **验证方式**：多方法对比，识别各方法在低资源场景的优劣
- **创新状态**：unverified
