## 02 一句话总结

本文构建了 AbDesign 数据库（7 个抗原 × 2 个抗体 = 14 个复合物，658 个 CDR-H3 单点突变，ELISA 统一测量，每个亲本复合物有晶体结构），并在此非重叠测试集上评测了三个 SOTA 机器学习亲和力预测模型（DSMBind、Binding-DDG-predictor、RDE-PPI），发现其在训练分布内表现尚可（ρ ≈ 0.4–0.7）但在 AbDesign 上相关性骤降至 ≈ 0.0–0.1，而经验力场方法 FoldX 反而保持合理预测力（R ≈ 0.3–0.5）。

## 03 研究问题

- **具体问题**：当前抗体亲和力预测的机器学习模型能否泛化到训练分布之外、结构新颖、突变类型多样的抗体-抗原复合物？
- **为什么重要**：抗体亲和力成熟是生物药开发的核心环节，计算预测若仅在训练集分布内有效，则无法可靠指导实验设计。数据稀缺和实验条件不统一是制约该领域发展的主要瓶颈。
- **现有方法不足**：现有数据集（SKEMPI、AB-Bind）规模小、实验条件不统一、以丙氨酸扫描为主、且与训练集高度重叠，导致模型评估存在信息泄漏（information leakage），无法真实反映泛化能力。
- **精确研究问题**：Can state-of-the-art machine learning models trained on SKEMPI/AB-Bind generalize to a structurally non-overlapping, experimentally consistent, mutationally diverse set of antibody point mutants?

## 04 背景与发展脉络

> 注：以下脉络基于本文 Introduction 和 Discussion 的叙述，属于「仅本文框架」，未经外部系统核验。

1. **结构数据库阶段**：PDB、SAbDab、AbDb 提供抗体-抗原复合物结构，为计算建模提供模板。
2. **亲和力数据库阶段**：SKEMPI 2.0、AB-Bind 汇集突变-亲和力实验数据，成为 ML 模型训练和评测的基础。
3. **ML 预测模型阶段**：DSMBind（SE(3) denoising score matching + ESM-2）、Binding-DDG-predictor（attention-based geometric NN）、RDE-PPI（flow-based generative model for rotamer distributions）等模型在 SKEMPI/AB-Bind 上报告了有竞争力的性能。
4. **泛化性挑战阶段**：本文指出，这些模型在训练分布内表现良好，但在结构非重叠、突变类型多样的新数据集上性能骤降，暴露了数据偏差和模型脆弱性。
5. **本文主张的位置**：AbDesign 作为第一个大规模、实验一致、结构关联的抗体单点突变数据库，充当「盲测」基准，揭示 ML 模型的泛化局限，并重新确认物理/经验方法（FoldX）的价值。

## 06 核心思想

**1) 表面方法**：
- 构建 AbDesign 数据库：14 个抗体-抗原复合物（7 抗原 × 2 抗体），对 CDR-H3 中与抗原重原子距离 < 4.5 Å 的残基进行系统点突变，共 658 个单点突变 + 14 个野生型对照，全部用统一 ELISA 协议测量，每个亲本复合物有晶体结构。
- 用两种结构建模管线（ABodyBuilder2 和基于 rotamer 文库的构象替换）生成突变体结构。
- 在三个数据集（SKEMPI full、SKEMPI train-only、AbDesign）上评测三个 ML 模型（DSMBind、Binding-DDG-predictor、RDE-PPI）和 FoldX。

**2) 核心洞察**：
- ML 模型的「好性能」很大程度上是训练分布内的记忆而非物理泛化。一旦面对结构非重叠、突变类型多样的新数据，性能即崩溃。
- 数据偏差（丙氨酸扫描主导）和结构预测误差是 ML 模型泛化失败的两大主因。
- 物理/经验方法（FoldX）虽然精度有限，但其基于普适化学原理，在分布外数据上反而更稳健。

**3) 可能的普适教训 [Analysis]**：
- 对 TF–DNA 互作预测领域：任何在已知复合物上训练的 ML 模型，若未在结构新颖、突变类型多样的独立测试集上验证，其报告性能都可能高估。构建「实验一致、结构关联、突变多样」的基准数据集，并明确区分 leaking / non-leaking 测试协议，是评估模型真实泛化能力的必要条件。
- 物理模拟（力场、分子动力学）在分布外场景中的稳健性值得重视，混合方法（如将物理能量项注入 ML 架构）可能是更可靠的前进方向。

## 07 方法总览

- **输入**：
  - 14 个抗体-抗原复合物的晶体结构（PDB）
  - 每个复合物的 CDR-H3 接触残基列表（< 4.5 Å 重原子距离）
  - 突变方案（每个接触残基 → 尽可能多的氨基酸替换，排除半胱氨酸）
- **输出**：
  - AbDesign 数据库：658 个突变体的 ELISA 结合保留率（相对于野生型的比值）
  - 每个突变体的两种预测结构（ABB2 和构象替换）
  - 三个 ML 模型和 FoldX 的 ΔΔG 预测值
- **模块**：
  1. 抗原/抗体选择与突变设计
  2. 抗体表达与纯化（Icosagen QMCF 平台）
  3. ELISA 测量（统一协议）
  4. 结构建模（ABB2 和 rotamer 替换）
  5. 基准评测（3 个 ML 模型 + FoldX）
- **训练**：无新模型训练；评测已有模型的零样本（zero-shot）预测能力
- **反馈回路**：无（静态数据集 + 离线评测）
- **文字流程**：从 PDB 选择 14 个复合物 → 计算 CDR-H3 接触残基 → 设计突变面板（每残基尽可能覆盖多种氨基酸）→ 表达纯化 672 个抗体变体 → 统一 ELISA 测量 → 用两种方法建模突变体结构 → 运行 3 个 ML 模型和 FoldX 预测 ΔΔG → 计算预测与实验的相关性（per-PDB 和整体）→ 与 SKEMPI/AB-Bind 上的性能对比。

## 09 关键公式符号

本文核心评测指标为相关性系数，无复杂公式。ΔΔG 的定义如下：

- **ΔG**（结合自由能变化）：
  \[
  \Delta G = RT \ln K_d
  \]
  其中 R = 气体常数（1.987 cal/(mol·K) 或 8.314 J/(mol·K)），T = 温度（通常 298 K），K_d = 解离常数（M）。

- **ΔΔG**（突变引起的结合自由能变化）：
  \[
  \Delta\Delta G = \Delta G_{mut} - \Delta G_{wt}
  \]
  - ΔΔG > 0：突变降低结合亲和力
  - ΔΔG < 0：突变增强结合亲和力
  - ΔΔG = 0：突变不影响结合

- **结合保留率（binding retainment）**：突变体 ELISA 信号 / 野生型 ELISA 信号，比值 > 1 表示增强，< 1 表示减弱。

- **评测指标**：Spearman 秩相关系数（ρ）和 Pearson 相关系数（R），按 per-PDB 平均和整体两种方式计算。

## 11 结论正确解读

- **任务范围**：本文评测的是**零样本（zero-shot）ΔΔG 预测**，即模型未见 AbDesign 中任何复合物或突变。这不排除模型在微调（fine-tuning）后能改善。
- **oracle/真值输入**：评测使用实验 ELISA 测量作为真值，但 ELISA 是间接的亲和力代理（结合保留率），并非直接测得的 K_d 或 ΔG。ELISA 的动态范围和灵敏度有限，极端高/低亲和力可能被压缩。
- **端到端状态**：评测管线包含结构预测步骤（ABB2 或构象替换），因此预测性能同时受结构预测误差和 ΔΔG 模型本身误差的影响，二者未完全解耦。
- **算力成本**：未报告推理时间或算力需求；FoldX 为经验力场方法，计算成本远低于深度学习模型。
- **历史数据依赖**：ML 模型全部在 SKEMBI/AB-Bind 上训练，这些数据以丙氨酸扫描为主，且复合物结构多样性有限。AbDesign 的突变类型更均匀、复合物结构非重叠，因此是更严格的泛化测试。
- **最难情形**：非丙氨酸突变、结构新颖的 CDR-H3 构象、以及需要精确区分中间效应（retainment 在 0.5–0.9 区间）的突变。
- **群体/领域边界**：结论仅适用于抗体-抗原互作，且限于单点突变。不直接推广到多点突变、非抗体蛋白互作或 TF–DNA 互作，但方法学教训可迁移。
- **不确定性**：样本量有限（14 个复合物），per-PDB 相关性波动大；ELISA 测量本身有实验噪声；FoldX 数据来自预计算，可能未覆盖所有突变。

| 「非重叠」声明需更严格验证 | 作者仅检查了 PDB ID 层面的重叠，但同一抗原的不同抗体或同一抗体的不同表位可能仍存在结构相似性 | 若存在隐式相似性，AbDesign 并非完全独立的测试集 | 在序列和结构层面计算训练集与 AbDesign 的最大相似性 | Methods 未报告序列/结构相似性分析 |
| ELISA 比值作为「结合保留率」的线性假设可疑 | ELISA 信号与亲和力非线性相关，高亲和力区域可能饱和 | 若非线性严重，相关性计算可能失真 | 用稀释系列验证 ELISA 动态范围；对饱和区域做灵敏度分析 | Methods "ELISA Measurements" 节未讨论线性范围 |
| 仅评测 3 个 ML 模型，代表性有限 | 未包含更近期的大模型（如 ESM 系列微调变体、结构预测+能量头组合） | 结论「ML 泛化差」可能只适用于特定模型架构 | 扩展至更多模型，特别是混合物理-ML 方法 | 表 3 仅列出 3 个模型 |

## 14 学到什么

> 以下为 Agent 提炼的知识候选，面向「蛋白质-DNA 互作（TF–DNA 结合机制）× AI/物理模拟」课题。

1. **数据集构建策略可迁移**：AbDesign 的「固定实验条件 + 结构关联 + 异质突变覆盖」三原则，可直接用于构建 TF–DNA 结合突变数据库。当前 TF–DNA 数据集（如来自 SELEX、HT-SELEX、B1H 等）实验条件混杂、突变类型单一（多为丙氨酸扫描），缺乏统一协议下的系统突变数据。

2. **Leaking / non-leaking 评测协议是刚需**：TF–DNA 结合预测模型（如基于 DeepSEA、DeepBind 架构的变体）同样存在训练/测试泄漏问题——同一 TF 家族或同源 DNA 基序常出现在训练和测试集中。采用「训练集完全排除测试 TF 家族」的严格协议，才能评估真实泛化能力。

3. **物理方法在分布外的稳健性**：FoldX 在抗体-抗原上的表现提示，对 TF–DNA 互作，基于物理的能量函数（如 Rosetta DNA 界面能量、MM/PBSA）在未见过的 TF–DNA 组合上可能比纯数据驱动模型更可靠。可探索将物理能量项作为 ML 模型的正则化或特征。

4. **结构预测误差是隐变量**：AbDesign 显示 ΔΔG 预测对突变体结构质量高度敏感。对 TF–DNA，突变体结构通常由同源建模或对接获得，误差更大。需要系统评估结构预测管线（如 AlphaFold3、RoseTTAFoldNA）对下游结合预测的影响。

5. **突变效应是连续谱而非二元**：AbDesign 显示多数突变并非完全破坏或保留结合。TF–DNA 结合预测应避免二元分类框架，改为回归或分布预测，并报告不确定性。

6. **数据规模 vs 数据质量**：AbDesign 仅 672 个数据点即揭示了重要结论，说明「小而精」的实验一致数据集可能比「大而杂」的聚合数据集更有价值。TF–DNA 领域可考虑优先构建高质量、小规模基准而非继续扩大噪声数据。

## 15 与已有知识连接

- **SKEMPI 2.0**（Jankauskaitė et al., 2019）：蛋白-蛋白互作突变数据库，本文的对比基准之一。TF–DNA 领域可类比使用 ProTherm 或 ProNIT 中的 DNA 结合数据，但需注意其覆盖度和一致性远低于 SKEMPI。
- **AB-Bind**（Sirin et al., 2016）：抗体-抗原结合突变数据库，与 SKEMPI 重叠度高，本文指出其突变类型偏差问题。TF–DNA 领域类似地存在 SELEX 数据偏好强结合基序的偏差。
- **DSMBind**（Luo et al., 2023）：基于 SE(3) denoising score matching 的无监督结合能模型。其架构思想（从结构分布中学习能量）可迁移到 TF–DNA 结合预测，但需注意 DNA 的柔性远大于蛋白抗原。
- **RDE-PPI**（Liu et al., 2023）：基于 rotamer 分布的流模型，预测突变对结合的影响。其「侧链构象熵」概念对 TF–DNA 互作中 DNA 构象变化的建模有启发。
- **FoldX**（Schymkowitz et al., 2005）：经验力场，本文显示其在分布外数据上的稳健性。TF–DNA 领域已有 FoldX 应用于蛋白-DNA 界面的先例（如 AlQuraishi 组的工作），但精度有限。
- **ABodyBuilder2**（Abanades et al., 2023）：抗体结构预测的深度学习方法。TF–DNA 领域对应工具为 AlphaFold3 和 RoseTTAFoldNA，但后者的 DNA 结合域预测精度尚未系统评估。
- **IgDesign 数据集**（本文引用）：约 1,000 个抗体变体，但突变距离大、结构信息缺失。TF–DNA 领域类似地缺乏「小突变距离 + 结构关联」的数据集。
- **Lippow et al. (2007)**：使用 CHARMM 力场进行抗体亲和力成熟的计算设计，本文引用以说明物理方法的历史价值。TF–DNA 领域可参考其「计算设计-实验验证」闭环策略。

## 16 研究想法

> 以下为 Agent 生成的研究候选，面向「蛋白质-DNA 互作（TF–DNA 结合机制）× AI/物理模拟」课题。

### 候选 1：TF-DNA 结合突变基准数据库（TF-BindMut）
- **来源局限/观察**：AbDesign 证明「实验一致 + 结构关联 + 突变多样」的数据库能揭示 ML 泛化失败；TF–DNA 领域缺乏类似资源。
- **核心假设**：在统一实验条件下构建的 TF–DNA 单点突变数据集，能暴露现有结合预测模型的泛化缺陷，并指导改进。
- **增量**：首个针对 TF–DNA 互作的、实验条件统一的点突变基准；覆盖多种 TF 家族和 DNA 基序。
- **初步方法**：选择 5–10 个有晶体结构的 TF–DNA 复合物（如 p53、Myc-Max、GATA 等），对 DNA 结合域和 DNA 接触碱基进行系统点突变，用 EMSA 或 HT-SELEX 统一测量结合变化；提供突变体结构（实验或高精度预测）。
- **验证方式**：在基准上评测现有模型（DeepSEA 变体、AlphaFold3 能量头、FoldX-DNA），对比分布内/分布外性能。
- **失败模式**：TF–DNA 结合对单个突变的敏感性可能低于抗体-抗原，导致数据区分度不足；或实验通量不足以覆盖足够突变空间。
- **创新状态**：unverified

### 候选 2：物理-机器学习混合 TF–DNA 结合预测框架
- **来源局限/观察**：AbDesign 显示纯 ML 模型分布外泛化差，而 FoldX 相对稳健；TF–DNA 领域可借鉴「物理能量项 + ML 校正」的混合架构。
- **核心假设**：将力场能量项（范德华、静电、溶剂化）作为 ML 模型的先验特征或正则化，可提升分布外泛化。
- **增量**：首个针对 TF–DNA 的物理-ML 混合预测框架，显式建模 DNA 构象变化。
- **初步方法**：以 FoldX 或 Rosetta DNA 界面能量为基线特征，叠加图神经网络编码 TF 和 DNA 序列/结构信息；在 TF-BindMut 基准上训练和评测。
- **验证方式**：与纯 ML 和纯物理方法对比，报告分布内/分布外性能差异。
- **失败模式**：物理能量项计算成本高，且 DNA 力场参数精度不足可能引入噪声。
- **创新状态**：unverified

### 候选 3：TF–DNA 突变效应连续谱建模与不确定性量化
- **来源局限/观察**：AbDesign 显示突变效应是连续分布而非二元分类；现有 TF–DNA 预测模型多采用分类或排序框架，忽略中间效应。
- **核心假设**：将 TF–DNA 突变效应建模为连续分布并输出预测不确定性，能更好指导实验设计。
- **增量**：首个针对 TF–DNA 的连续效应预测 + 不确定性量化框架。
- **初步方法**：在 TF-BindMut 数据上训练深度集成或贝叶斯神经网络，输出 ΔΔG 的均值和方差；用主动学习策略选择高不确定性突变进行实验验证。
- **验证方式**：与点估计模型对比，评估不确定性校准质量（如期望校准误差）和主动学习效率。
- **失败模式**：数据量不足以训练可靠的不确定性模型；或实验验证成本过高。
- **创新状态**：unverified

### 候选 4：结构预测误差对 TF–DNA 结合预测影响的系统评估
- **来源局限/观察**：AbDesign 显示 ΔΔG 预测对突变体结构质量高度敏感；TF–DNA 领域对结构预测误差的影响缺乏系统评估。
- **核心假设**：AlphaFold3/RoseTTAFoldNA 对 TF–DNA 复合物的预测误差会显著传播到下游结合预测，且不同 TF 家族误差模式不同。
- **增量**：首个系统评估结构预测管线对 TF–DNA 结合预测影响的 benchmark。
- **初步方法**：对 TF-BindMut 中每个突变体，用 AlphaFold3、RoseTTAFoldNA、传统同源建模分别生成结构，输入同一 ΔΔG 预测器，比较预测差异与实验的吻合度。
- **验证方式**：报告不同结构来源下的预测性能差异，识别误差传播的关键结构特征。
- **失败模式**：结构预测误差与 ΔΔG 预测误差的耦合难以解耦，需要精心设计对照。
- **创新状态**：unverified

### 候选 5：TF–DNA 结合预测的跨物种/跨家族泛化测试
- **来源局限/观察**：AbDesign 强调「非重叠」测试集的重要性；TF–DNA 领域模型常在相近 TF 家族内测试，泛化性被高估。
- **核心假设**：在 TF 家族层面完全隔离的训练/测试划分下，现有模型性能将显著下降，且下降幅度与 TF 家族间结构/序列差异相关。
- **增量**：首个 TF 家族级别隔离的泛化基准，量化「家族外」预测的真实难度。
- **初步方法**：从 CIS-BP、JASPAR 等数据库收集多家族 TF–DNA 结合数据，按 TF 家族划分训练/测试集；评测现有模型并分析失败模式。
- **验证方式**：报告家族内/家族间性能差异，识别影响泛化的关键特征（如 DNA 结合域折叠类型、基序复杂度）。
- **失败模式**：数据覆盖不足，某些 TF 家族样本过少，统计功效有限。
- **创新状态**：unverified
