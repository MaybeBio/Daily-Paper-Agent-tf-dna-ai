## 02 一句话总结

该文开发了一个部分可解释的编码器-解码器神经网络 CITRUS，利用自注意力机制建模体细胞变异（突变/拷贝数）对转录因子（TF）活性的影响，并通过 ATAC-seq 衍生的 TF 结合 motif 先验约束 TF→靶基因关系，在 TCGA 17 种癌症类型上预测患者特异性 TF 活性和基因表达，优于正则化双线性回归基线。

## 03 研究问题

- **具体问题**：如何从体细胞变异（突变、拷贝数变异）推断患者特异性的转录程序变化，特别是识别哪些 TF 的活性被这些变异所扰动？
- **为什么重要**：癌症是基因调控失调的疾病，体细胞变异通过影响信号通路和转录因子活性导致基因表达异常。理解变异→TF→靶基因的因果链条有助于精准肿瘤治疗决策。
- **现有方法不足**：
  - 传统方法（如亲和回归 AR）将体细胞变异与基因表达线性关联，无法捕捉变异之间的非线性交互和上下文依赖效应。
  - 已有深度学习模型（如 GIT）虽用自注意力编码变异，但未显式建模中间 TF 层，缺乏生物学可解释性。
  - 染色质可及性数据（ATAC-seq）虽能提供 TF 结合的上下文信息，但尚未被整合到变异→表达建模中。
- **精确研究问题**：Can a self-attention-based neural network with explicit TF intermediate layer and chromatin-informed priors predict patient-specific TF activities and gene expression from somatic alterations better than linear baselines, while providing interpretable links between alterations and TF dysregulation?

## 04 背景与发展脉络

*注：以下脉络基于本文引用和论述，属于「经外部核验」的领域发展框架，但具体分期和代表性方法选择是本文作者的叙述。*

1. **早期：变异-表达关联的统计方法**
   - 代表：PARADIGM、CONEXIC 等，利用通路先验连接变异与表达。
   - 优点：可解释；局限：线性假设，无法捕捉非线性交互。

2. **中期：基于网络/通路的方法**
   - 代表：利用蛋白-蛋白互作网络或信号通路传播变异效应。
   - 优点：整合先验知识；局限：网络不完整，难以扩展到全基因组。

3. **近期：深度学习应用于癌症基因组**
   - 代表：GIT（Genomic Impact Transformer）用自注意力编码变异预测差异表达基因。
   - 优点：捕捉非线性交互；局限：缺乏中间 TF 层，可解释性有限。

4. **本文位置**：CITRUS 在 GIT 基础上引入显式 TF 中间层，并用 ATAC-seq 衍生的 TF 结合 motif 先验约束 TF→靶基因权重，实现「部分可解释」——变异→TF 通过注意力权重可解释，TF→表达通过稀疏先验可解释。

## 06 核心思想

### 1) 表面方法
CITRUS 是一个编码器-解码器架构：
- **编码器**：将高维体细胞变异输入（>20K 基因的突变/拷贝数状态）通过自注意力机制压缩为肿瘤嵌入向量。
- **解码器**：从肿瘤嵌入推断 TF 活性（隐层），再通过稀疏权重矩阵 W 预测靶基因表达。
- **先验整合**：W 的非零模式由 ATAC-seq 衍生的 TF 结合 motif 矩阵 C 硬约束，即只有存在 motif 结合的 TF-基因对才允许非零权重。

### 2) 核心洞察
- **中间 TF 层作为「可解释瓶颈」**：强制模型通过 TF 活性向量传递信息，使得变异→TF→表达 的因果链可被追踪。
- **染色质先验作为「生物学正则化」**：利用 ATAC-seq 数据提供 TF 结合的上下文信息，将「哪些 TF 可能调控哪些基因」的先验知识硬编码到网络结构中，减少参数空间并增强生物学合理性。
- **自注意力捕捉变异上下文**：变异的影响不是独立的，注意力机制可以学习变异之间的协同关系（如 TP53 和 PIK3CA 突变共现时的联合效应）。

### 3) 可能的普适教训 [Analysis]
- **「硬先验」vs「软先验」的权衡**：本文选择硬约束（W 非零仅当 C=1），这保证了可解释性但可能丢失真实调控关系。在 TF–DNA 结合机制研究中，若 motif 预测不可靠，硬约束可能引入系统性偏差。可考虑软约束（如 L1 正则化 + 先验加权）。
- **中间层作为可解释性设计模式**：在 AI 辅助的 TF–DNA 结合机制研究中，显式建模中间生物学实体（如 TF 活性、染色质状态）比纯端到端黑箱更有利于机制发现。
- **多组学整合的时机**：本文在模型结构层面整合 ATAC-seq（而非仅作为输入特征），这种「结构先验」比「特征拼接」更有效地利用了生物学知识。

## 07 方法总览

- **输入**：每个肿瘤样本的体细胞变异状态向量（基因×样本，二值：突变/拷贝数改变=1，否则=0），维度 >20K。
- **输出**：每个样本的基因表达向量（5541 个基因，log2 RSEM 值）。
- **模型结构**：
  1. **编码器**：输入变异向量 → 基因嵌入（gene embedding）→ 多头自注意力 → 肿瘤嵌入（tumor embedding）。
  2. **解码器**：肿瘤嵌入 → 全连接层（tanh 激活）→ TF 活性向量 → 稀疏线性层（权重 W 受 C 约束）→ 预测表达。
- **先验矩阵 C**：由 ATAC-seq 峰扫描 TF motif 得到，C(i,j)=1 表示 TF j 的 motif 出现在基因 i 的开放染色质区域（基因体、TSS 上游 100kb、3' 下游 100kb）。
- **训练**：Adam 优化器，学习率 1e-3，权重衰减 1e-5，早停 patience=30，最大迭代 1000。损失函数为均方误差（MSE）。
- **正则化**：dropout（0.2）应用于输入层、肿瘤嵌入层、TF 活性层。
- **集成**：10 次不同随机初始化训练，TF 活性取平均。
- **基线**：亲和回归（AR），一种正则化双线性回归，按癌症类型独立训练。
- **评估**：测试集上预测表达与实测表达的 Spearman 相关系数（ρ）。
- **下游分析**：
  - 注意力权重 vs 变异频率的相关性分析。
  - TF 活性聚类识别癌症亚型。
  - 亚型与体细胞变异的关联分析（Fisher 精确检验）。
  - 计算机模拟敲除（in silico knockout）：移除特定变异后重新预测 TF 活性，识别关键 TF。

## 09 关键公式符号

1. **编码器输出（肿瘤嵌入）**：
   e_t = Attention(e_g1, e_g2, ..., e_gm; e_s)
   - e_t：肿瘤 t 的嵌入向量
   - e_gi：基因 i 的嵌入向量
   - e_s：癌症类型 s 的嵌入向量
   - Attention：多头自注意力机制

2. **TF 活性推断**：
   f = tanh(W_e · e_t)
   - f：TF 活性向量
   - W_e：编码器到 TF 层的权重矩阵
   - tanh：双曲正切激活函数

3. **表达预测**：
   ŷ = W · f
   - ŷ：预测的基因表达向量
   - W：TF→基因权重矩阵，受先验 C 约束：W(i,j) ≠ 0 仅当 C(i,j) = 1，且 W(i,j) ≥ 0

4. **损失函数**：
   L = MSE(y, ŷ) = (1/N) Σ (y_i - ŷ_i)²
   - y：实测表达
   - ŷ：预测表达
   - N：基因数

5. **先验矩阵 C**：
   C ∈ {0,1}^{k×l}，C(i,j) = 1 当 TF j 的 motif 出现在基因 i 的开放染色质区域

## 11 结论正确解读

- **任务范围**：该模型预测的是「体细胞变异→TF 活性→基因表达」的统计关联，不是物理结合机制。TF 活性是推断的隐变量，不是直接测量的 TF 结合或蛋白活性。
- **Oracle/真值输入**：TF 活性没有实验真值，是模型隐变量；基因表达有实测值（RNA-seq），但模型预测的是「由变异解释的部分」，不是全部表达。
- **端到端状态**：模型是端到端训练的（变异→表达），但 TF 层是中间瓶颈，不是独立训练的。
- **先验依赖**：TF→基因关系完全依赖 ATAC-seq motif 扫描，motif 的假阳性/假阴性会直接影响模型结构。
- **历史数据依赖**：模型基于 TCGA 回顾性数据，变异-表达关系可能受治疗史、肿瘤异质性等混杂因素影响。
- **算力成本**：未提供具体训练时间或硬件需求。
- **最难情形**：低频变异、罕见癌症类型、非编码变异（模型仅使用基因水平变异状态，不区分突变类型和位置）。
- **群体/领域边界**：仅覆盖 17 种癌症类型，不适用于非癌症疾病或正常组织。
- **不确定性**：未提供预测置信区间或不确定性量化。

**有边界的复述**：CITRUS 在 TCGA 17 种癌症中，利用基因水平体细胞变异状态和 ATAC-seq 衍生的 TF 结合先验，通过自注意力编码器和显式 TF 隐层，预测患者特异性基因表达，其预测性能优于线性基线，并能通过注意力权重和 in silico knockout 生成「变异→TF」关联假设。该模型不提供 TF–DNA 物理结合机制的直接证据，其 TF 活性是统计推断而非实验测量。

## 14 学到什么

**Agent 提炼的知识候选**：

1. **中间生物学层作为可解释瓶颈**：在 TF–DNA 结合机制研究中，可设计「显式 TF 状态层」作为模型瓶颈，强制信息流经 TF 节点，使变异→TF→靶基因的因果链可追踪。迁移方式：在预测 TF 结合位点或结合亲和力的模型中，插入可解释的「TF 活性」或「染色质状态」隐变量。

2. **染色质先验的结构化整合**：本文不是将 ATAC-seq 作为额外输入特征，而是将其编码为网络权重约束（W 的非零模式）。这种「结构先验」比「特征拼接」更有效地利用生物学知识。迁移方式：在 TF–DNA 结合预测中，可将已知的 motif 位置权重矩阵（PWM）或 ChIP-seq 峰作为权重约束，而非仅作为输入。

3. **自注意力用于变异上下文建模**：变异对 TF 的影响不是独立的，注意力机制可捕捉变异共现的协同效应。迁移方式：在预测 TF 结合位点突变效应时，可考虑周围变异或表观遗传标记的上下文。

4. **In silico knockout 作为因果推断工具**：通过移除特定输入并观察输出变化，可生成可操作的因果假设。迁移方式：在 TF–DNA 结合机制研究中，可系统敲除候选 TF 结合位点或上游调控因子，预测对下游表达的影响。

5. **多癌种联合建模揭示保守 vs 特异性调控**：跨 17 种癌症的联合建模可区分保守的 TF 调控（如 TP53 相关）和癌症特异性调控。迁移方式：在 TF–DNA 结合机制研究中，可跨细胞类型或物种联合建模，识别保守结合 motif 和谱系特异性结合。

6. **硬约束 vs 软约束的权衡**：硬约束保证可解释性但可能引入偏差。在 TF–DNA 结合机制研究中，若 motif 预测不确定，可考虑软约束（如先验加权正则化）以平衡可解释性和准确性。

## 15 与已有知识连接

- **GIT（Genomic Impact Transformer）**：本文直接基于 GIT 的自注意力机制，但增加了显式 TF 中间层和染色质先验。GIT 是本文的主要技术前身。
- **亲和回归（AR）**：本文的基线方法，一种正则化双线性回归，用于连接变异和表达。AR 是更简单的线性替代方案。
- **TCGA 泛癌 ATAC-seq 图谱**：本文使用的染色质可及性数据来自 TCGA 泛癌 ATAC-seq 项目，该图谱提供了跨癌症类型的开放染色质区域。
- **Cis-BP 数据库**：本文使用的 TF motif 来源，是 TF 结合特异性数据库。
- **FIMO/MEME**：用于扫描 motif 的工具，本文用 FIMO 在 ATAC-seq 峰中识别 TF 结合位点。
- **可解释深度学习在基因组学中的应用**：本文属于「可解释 AI + 癌症基因组学」方向，与 DeepSEA、Basenji 等模型不同，本文关注的是体细胞变异→转录程序，而非序列→染色质/表达的直接预测。
- **与物理模拟的关系**：本文不涉及 MD 或对接，但其 TF 活性推断可作为物理模拟（如分子对接预测 TF–DNA 结合亲和力）的上游或下游模块——例如，用物理模拟验证本文推断的关键 TF-靶基因边。

## 16 研究想法

**Agent 生成的研究候选**：

1. **候选名称**：软约束先验的 TF–DNA 结合预测模型
   - **来源局限/观察**：CITRUS 的硬约束 W 可能过于严格，遗漏真实调控边。
   - **核心假设**：将 motif 先验作为软约束（如 L1 正则化 + motif 置信度加权）可提高预测性能并保持可解释性。
   - **初步方法**：在 CITRUS 架构中，将 W 的约束从「非零仅当 C=1」改为「W 的 L1 惩罚按 C 的置信度加权」，比较硬/软约束下的预测性能和 TF 活性稳定性。
   - **验证方式**：TCGA 数据上比较 Spearman ρ；用 ChIP-seq 数据验证推断的 TF-靶基因边。
   - **创新状态**：unverified

2. **候选名称**：物理模拟增强的 TF 活性验证
   - **来源局限/观察**：CITRUS 推断的 TF 活性是统计隐变量，无物理结合证据。
   - **核心假设**：对 CITRUS 识别的高置信 TF-靶基因边，用分子对接或 MD 模拟预测 TF–DNA 结合亲和力，可验证或修正统计推断。
   - **初步方法**：选取 CITRUS 在特定癌症中识别的关键 TF-靶基因对，用 AlphaFold 预测 TF 结构，用 HDOCK 或 MD 模拟预测结合亲和力，与 CITRUS 推断的活性变化比较。
   - **验证方式**：统计物理预测的亲和力变化与 CITRUS 推断的 TF 活性变化的相关性。
   - **创新状态**：unverified

3. **候选名称**：单细胞分辨率的变异→TF 活性推断
   - **来源局限/观察**：CITRUS 使用 bulk RNA-seq，无法解析肿瘤内异质性。
   - **核心假设**：将 CITRUS 架构扩展到单细胞 RNA-seq + 单细胞 ATAC-seq，可推断细胞亚群特异的 TF 活性。
   - **初步方法**：将 CITRUS 的编码器改为处理单细胞变异（或基因表达）输入，TF 层先验使用单细胞 ATAC-seq 衍生的 motif 可及性。
   - **验证方式**：在已发表的单细胞肿瘤数据上验证，比较与 bulk 推断的差异。
   - **创新状态**：unverified

4. **候选名称**：TF 结合 motif 的上下文依赖建模
   - **来源局限/观察**：CITRUS 使用静态 motif 扫描，未考虑染色质状态（如增强子-启动子互作）的上下文。
   - **核心假设**：将 Hi-C 或增强子-启动子互作数据整合到 TF-靶基因先验中，可提高 TF 活性推断的准确性。
   - **初步方法**：在 C 矩阵中，仅当 TF motif 出现在与靶基因有染色质互作的开放区域时才置 1，比较与原始 C 的性能差异。
   - **验证方式**：TCGA 数据上比较预测性能；用 CRISPR 验证新识别的 TF-靶基因边。
   - **创新状态**：unverified

5. **候选名称**：跨物种保守 TF 调控模块识别
   - **来源局限/观察**：CITRUS 仅覆盖人类癌症，未利用进化保守性。
   - **核心假设**：跨物种（如小鼠、斑马鱼）的保守 TF-靶基因边更可能是功能性调控。
   - **初步方法**：将 CITRUS 应用于多物种同源数据，比较 TF-靶基因边的保守性，识别跨物种保守的调控模块。
   - **验证方式**：用 CRISPR 或报告基因实验验证保守边的功能。
   - **创新状态**：unverified
