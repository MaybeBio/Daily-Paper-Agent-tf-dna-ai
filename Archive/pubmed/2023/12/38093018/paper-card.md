## 03 研究问题

- **具体问题**：如何破解 cis-regulatory code——即细胞如何解读 DNA 序列来决定基因表达的时机、位置和水平？
- **为什么重要**：基因表达调控是几乎所有生物学过程的核心，理解 cis-regulatory code 对疾病机制、发育生物学、合成生物学和精准医学均有根本性意义。
- **现有方法为何不足**：
  1. 仅用基因组序列训练模型时，同源区域（regions of homology）会导致预测性能被高估——模型可能是在记忆同源序列而非学习真正的调控逻辑。
  2. 人类基因组长度有限（约 3×10⁹ bp），序列多样性不足以覆盖所有可能的调控序列组合，无法学习所有相关参数。
- **精确研究问题**：Can the cis-regulatory code be solved by training machine learning models on randomly synthesized and designed DNA sequences, rather than on genomic sequences alone?

## 04 背景与发展脉络

> 注：以下脉络基于本文框架整理，标注为「仅本文框架」，未经外部文献核验。

- **阶段一：基因组序列直接训练模型**
  - 代表性方法：基于基因组序列的深度学习模型（如预测 TF 结合、染色质可及性、基因表达）
  - 优点：直接利用天然数据，无需额外实验
  - 局限：同源区域导致性能高估；基因组序列多样性不足，参数无法充分学习
- **阶段二：功能基因组学 assay 提供标注数据**
  - 代表性方法：ChIP-seq、ATAC-seq、STARR-seq 等大规模平行 assay
  - 优点：提供实验标注，提升模型监督信号
  - 局限：仍受限于基因组序列本身的覆盖范围
- **阶段三：合成 DNA 大规模平行实验（本文主张的位置）**
  - 代表性方法：随机合成 DNA + 设计 DNA 的 massively parallel reporter assays (MPRAs) 等
  - 优点：可覆盖远超基因组的序列空间；设计序列可定向补足模型弱点
  - 局限：合成 DNA 的实验成本与通量仍是瓶颈；需要有效的实验设计策略
- **本文主张**：将阶段三与机器学习结合，作为破解 cis-regulatory code 的核心路线。

## 06 核心思想

**1) 表面方法**：
- 放弃仅用基因组序列训练模型的做法。
- 采用随机合成 DNA 序列进行大规模平行实验，覆盖远超基因组的序列空间。
- 采用设计 DNA 序列进行定向查询，以最大化模型改进效率。
- 将合成 DNA 实验数据与机器学习模型训练结合，形成迭代闭环。

**2) 核心洞察**：
- 无论 DNA 来源是基因组还是合成序列，细胞解读 DNA 的生化原理是相同的（"the same biochemical principles are used to interpret DNA regardless of its source"）。
- 因此，用合成 DNA 训练的模型可以预测基因组活性，且往往优于仅用基因组训练的模型。
- 基因组本身不是训练模型的充分数据源——它是一个「样本」，而非完整的「分布」。

**3) 可能的普适教训 [Analysis]**：
- 在 TF–DNA 结合建模中，训练数据的分布覆盖度比数据来源的「天然性」更重要。合成数据可以系统性地覆盖序列空间，避免天然数据中的偏差和冗余。
- 模型性能评估必须警惕数据中的隐式相关性（如同源区域），否则会高估泛化能力。
- 实验设计与模型训练应形成闭环：模型指出知识缺口，设计序列定向补足，新数据再改进模型。

## 07 方法总览

- **输入**：随机合成 DNA 序列 + 设计 DNA 序列（通过大规模平行 assay 测量其调控活性）
- **输出**：可预测任意 DNA 序列调控活性的机器学习模型（即 cis-regulatory code 的数值表征）
- **模块**：
  1. 合成 DNA 生成模块（随机 + 设计）
  2. 大规模平行实验模块（测量序列活性）
  3. 机器学习模型训练模块
  4. 模型-实验迭代闭环模块
- **训练**：以合成 DNA 序列及其实验测得的活性为训练数据，训练模型预测序列→活性的映射
- **工具**：大规模平行 reporter assay（如 MPRA）、深度学习模型
- **反馈回路**：模型在合成序列上预测不确定性高的区域 → 设计新序列定向测试 → 新数据更新模型 → 重复
- **假设**：细胞对合成 DNA 与基因组 DNA 的解读遵循相同生化原理；合成序列的活性测量可反映其在基因组环境中的调控潜力
- **文字流程**：生成合成 DNA 序列（随机+设计）→ 通过大规模平行实验测量各序列的调控活性 → 用（序列，活性）对训练机器学习模型 → 评估模型在基因组序列上的预测能力 → 根据模型弱点设计下一轮合成序列 → 迭代直至模型收敛

## 14 Agent 提炼的知识候选

**可迁移概念与方法**：

1. **「基因组作为 hold-out 集」的评估哲学**
   - 核心思想：训练数据与评估数据应来自不同分布；基因组序列应作为最终测试集，而非训练集。
   - 迁移到 TF–DNA 结合建模：训练 TF 结合模型时，可将基因组序列完全排除在训练集外，仅用合成 DNA 数据训练，用基因组数据做最终评估。这能避免同源区域导致的高估，得到更真实的泛化性能估计。

2. **合成 DNA 覆盖序列空间的策略**
   - 核心思想：随机合成 + 设计合成双轨并行，前者保证覆盖广度，后者保证针对性。
   - 迁移到 TF–DNA 结合建模：对特定 TF，可设计包含已知 motif 的突变体库（设计合成）与随机 k-mer 库（随机合成），结合高通量结合 assay（如 SELEX、MITOMI、SMiLE-seq）测量结合强度，训练结合特异性模型。

3. **模型-实验迭代闭环**
   - 核心思想：模型不确定性高的区域 → 设计序列 → 实验测量 → 更新模型 → 重复。
   - 迁移到 TF–DNA 结合建模：对 TF–DNA 结合模型，可计算模型在序列空间中的预测不确定性（如 ensemble 方差、贝叶斯不确定性），对高不确定性区域设计序列进行实验验证，定向补足模型知识。

4. **「生化原理与来源无关」的假设**
   - 核心思想：细胞解读 DNA 的生化机制不依赖 DNA 来源，因此合成数据可迁移到基因组预测。
   - 迁移到 TF–DNA 结合建模：TF 与 DNA 的物理化学结合机制（氢键、形状读码、水介导相互作用）不依赖序列来源，因此从合成序列学习的结合规则可外推到基因组位点。这为「用合成数据训练、预测基因组」提供了理论依据。

5. **同源区域作为性能高估源的警惕**
   - 核心思想：数据中的隐式相关性（同源区域）会导致模型看似优秀实则泛化差。
   - 迁移到 TF–DNA 结合建模：TF 结合位点常位于重复元件或同源区域附近，若训练/测试划分不当，模型可能记忆同源序列而非学习结合规则。评估时应采用严格划分（如染色体级别、去除同源序列）。
