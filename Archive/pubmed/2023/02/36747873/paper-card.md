## 02 一句话总结

本文提出一种名为 tiSFM 的卷积神经网络架构，通过将 CIS-BP 数据库中的 TF 基序（PWM）直接作为第一层卷积核并配合可训练池化与互作层，在预测小鼠造血谱系开放染色质状态的任务上超越了定制化 SOTA 模型 AI-TAC，同时无需任何事后分析即可从网络参数中直接读出 TF-细胞类型贡献及 TF-TF 互作信息。

## 03 研究问题

- **具体问题**：现有序列到功能（sequence-to-function, S2F）深度学习模型虽然预测性能强，但其内部机制高度不透明，模型解释依赖计算昂贵的**事后归因分析**（如 DeepLift、kernel-PWM 匹配），且无法揭示内部层如何编码 TF 结合与互作机制。
- **为什么重要**：在蛋白质-DNA 互作研究中，仅知道"哪些 TF 重要"不够，还需要理解**TF 如何通过基序识别、协同/拮抗互作来调控染色质状态**。可解释的模型参数可以直接产生生物学假设，加速机制发现。
- **现有方法不足**：
  - 标准 CNN 的第一层卷积核虽可匹配 PWM，但后续层高度非线性，无法追踪 TF 贡献的符号与大小；
  - 归因分析（如 DeepLift）结果依赖所选方法，且计算量大、可重复性差；
  - 已有可解释模型（如 AI-TAC）仍需结合 kernel 匹配与归因两步才能得到 TF-细胞类型图。
- **精确的 Can 问题**：Can we design a neural network architecture whose internal parameters are *directly* interpretable as TF binding motifs, TF-细胞类型贡献, and TF-TF interactions, without any post hoc analysis, while maintaining or exceeding the predictive performance of state-of-the-art black-box CNN models?

## 04 背景与发展脉络

> 注：此脉络基于本文 Introduction 与 Discussion 的叙述，属于「仅本文框架」，未经外部系统综述核验。

1. **早期阶段：序列特征 + 传统机器学习**
   - 代表方法：k-mer 计数、PWM 扫描 + SVM/逻辑回归
   - 优点：可解释性强
   - 局限：无法捕捉长程互作与复杂非线性关系

2. **深度学习阶段：端到端 S2F 模型**
   - 代表方法：DeepSEA（Zhou & Troyanskaya, 2015）、Basenji（Kelley et al., 2016）、Enformer（Avsec et al., 2021b）
   - 优点：预测性能大幅提升，可处理长序列
   - 局限：黑箱性质，解释依赖事后分析

3. **可解释性增强阶段：kernel 匹配 + 归因**
   - 代表方法：DeepLift（Shrikumar et al., 2017）、AI-TAC（Maslova et al., 2020）
   - 优点：可识别关键 TF 及其贡献方向
   - 局限：需要多步事后处理，无法解释内部层机制，计算开销大

4. **本文主张的位置**：tiSFM 将可解释性从"事后分析"前移到"架构设计"，通过固定 PWM 卷积核 + 可训练缩放/偏置 + 可训练池化 + 显式互作层，使每一层都有明确的生物学对应物（基序匹配 → 结合强度 → 结合计数 → TF-TF 互作 → 细胞类型贡献），实现"totally interpretable"。

## 06 核心思想

### 1) 表面方法
tiSFM 是一个多层 CNN，输入为 one-hot 编码的 DNA 序列（300 bp，以 ATAC-seq 峰中心为中心），第一层卷积核固定为 CIS-BP 数据库的 862 个小鼠 TF PWM。网络包含：位置嵌入 + 自注意力（可选）、PWM 卷积 + 可训练缩放/偏置 + sigmoid 激活、可训练池化（在平均池化与最大池化之间插值）、TF-TF 互作层（矩阵 A）、最终线性层（B）输出各细胞类型的预测值。

### 2) 核心洞察
**将生物学先验直接编码为网络结构，而非仅作为事后解释工具。** 具体而言：
- 第一层卷积核 = TF 基序（PWM），固定不变 → 每个通道对应一个已知 TF；
- 可训练缩放/偏置 = TF 结合强度的序列无关调节（相当于"结合亲和力的细胞类型特异性调制"）；
- 可训练池化 = 在"计数所有结合位点"（平均池化）与"只取最强结合位点"（最大池化）之间插值，模拟 TF 结合是加性还是饱和效应；
- 互作层 A = 显式建模 TF-TF 协同/拮抗，A[i,j] 表示 TF j 对 TF i 贡献的调制；
- 最终线性层 B = 直接给出 TF-细胞类型贡献矩阵，无需任何事后分析。

### 3) 可能的普适教训 [Analysis]
- **先验嵌入优于事后解释**：将领域知识（如 PWM）作为网络结构的硬约束，比训练黑箱模型再试图解释更高效、更可靠。
- **可解释性不必然牺牲性能**：本文证明在特定任务上，带强先验的轻量模型可以超越参数多 3 倍的黑箱模型。
- **池化策略是生物学假设的载体**：平均池化 vs 最大池化的插值参数 α 直接对应"TF 结合是加性计数还是单强位点主导"的机制假设，这种"可调生物学假设"的设计模式值得推广。

## 07 方法总览

- **输入**：one-hot 编码的 DNA 序列，长度 L = 300 bp（以 ATAC-seq 峰 summit 为中心）
- **输出**：c 个细胞类型（或谱系）的开放染色质活性预测值（z-score）
- **模块**：
  1. 数据变换：位置嵌入（可学习）+ 自注意力（可选）
  2. 卷积与缩放：固定 PWM 卷积核（862 个 CIS-BP 基序）+ 每基序可训练缩放 a_i 与偏置 b_i + sigmoid 激活
  3. 可训练池化：对每个基序的位点得分进行加权池化，权重由 α_i 控制（α→0 为平均池化，α→∞ 为最大池化）
  4. 基序互作：互作矩阵 A ∈ R^(m×m)，对池化后的基序得分进行线性调制
  5. 预测层：线性层 B ∈ R^(c×m) + 偏置 γ，输出各细胞类型预测
- **训练**：
  - 损失：MSE（对 z-score 化的标签）
  - 优化器：Adam，带 L1 或 MCP 稀疏化正则（通过近端算子实现）
  - 两阶段训练：先冻结 PWM 卷积核训练其余参数，再解冻微调约 10 epochs
  - 数据划分：10 折交叉验证，每折轮流作测试集
- **反馈回路**：验证集上的 MSE 用于早停和学习率衰减（验证损失 10 epochs 不改善则 lr × 0.1，lr < 5×10⁻⁷ 停止）
- **假设**：PWM 先验足以覆盖关键 TF 结合特异性；TF 贡献可分解为基序匹配 × 结合强度 × 池化策略 × 互作调制 × 细胞类型权重

**文字流程**：
```
DNA序列(one-hot, 300bp) 
→ [可选] 位置嵌入 + 自注意力 
→ 固定PWM卷积(862通道) + 可训练缩放/偏置 + sigmoid 
→ 可训练池化(每基序一个α参数) 
→ 互作层(矩阵A) 
→ 线性层(矩阵B) → 细胞类型预测
```

## 09 关键公式符号

1. **数据变换**：
   - x_input ∈ R^(4×L)：one-hot 编码的 DNA 序列
   - p ∈ R^(4×L)：可学习位置嵌入（广播加到 x_input 的每一行）
   - x ← x_input + SelfAttention(x_input)（可选）

2. **卷积与缩放**：
   - conv1d(x | {PWM_i}_{i=1..m})：以 862 个固定 PWM 为卷积核的一维卷积
   - a ∈ R^m：每基序可训练缩放参数
   - b ∈ R^m：每基序可训练偏置
   - 输出：s_i,j = sigmoid(a_i · score_i,j + b_i)，其中 score_i,j 为 PWM_i 在位置 j 的匹配得分

3. **可训练池化**：
   - w[i] ← softmax(α_i · s_i) ∈ [0,1]^L，其中 α_i ∈ R 为池化温度参数
   - 聚合值：z_i = Σ_j w[i]_j · s_i,j
   - 当 α_i → 0：w[i] 均匀 → 平均池化；当 α_i → ∞：w[i] 为 one-hot → 最大池化

4. **互作层**：
   - z_interacted = σ(A · z) ∈ R^m，其中 A ∈ R^(m×m) 为互作矩阵，σ 为 sigmoid
   - A[i,j] > 0 表示 TF j 增强 TF i 的贡献；A[i,j] < 0 表示抑制

5. **预测层**：
   - y = B · z_interacted + γ ∈ R^c，其中 B ∈ R^(c×m) 为 TF-细胞类型贡献矩阵，γ ∈ R^c 为偏置

6. **稀疏化正则（MCP）**：
   - 对 B 施加 MCP 惩罚：ρ_λ,b(θ) = λ∫₀^|θ| (1 - x/(λb))₊ dx
   - 近端算子更新：θ_{t+1} = sign(θ̂_t) · min( max(|θ̂_t| - α_t λ/(C_t+δ), 0) / (b-1), |θ̂_t| )

## 10 实验设计与证据链

### 数据集与评测协议
- **数据集**：ImmGen ATAC-seq（Gal-Oz et al., 2019），小鼠造血谱系 81 种免疫细胞类型，共 512,596 个开放染色质区域（峰）
- **预处理**：峰 summit 为中心取 300 bp；标签为各细胞类型中该峰的 ATAC-seq 活性（z-score 化）
- **训练/验证/测试**：10 折交叉验证，每折 8 折训练、1 折验证、1 折测试；报告 10 折平均性能
- **基线模型**：AI-TAC（Maslova et al., 2020），一个针对该数据集定制优化的 3 卷积层 + 3 线性层 CNN，参数 2,974,908
- **评测指标**：R²（决定系数），比较 tiSFM 与 AI-TAC 的 R² 差值
- **消融变体**：无自注意力、无互作层、无位置嵌入、固定 vs 微调核、不同池化策略
- **稀疏化**：MCP 正则化（b=3），路径算法从全模型逐步增加 λ

## 11 结论正确解读

- **任务范围**：本文结论仅适用于**小鼠造血谱系开放染色质预测**这一具体任务，使用 ImmGen ATAC-seq 数据。不能外推至其它物种、其它表观遗传标记（如组蛋白修饰、甲基化）或其它细胞系统。
- **Oracle/真值输入**：模型输入为 DNA 序列（300 bp），标签为实验测量的 ATAC-seq 活性（z-score）。标签本身是群体平均信号，不反映单细胞异质性。
- **端到端状态**：模型是端到端训练的（除第一层核固定外），但第一层核来自 CIS-BF 数据库先验，并非从数据学习。因此"端到端"是部分意义上的。
- **算力成本**：未报告训练时间、GPU 型号等。但参数仅约 100 万，远小于 AI-TAC 的 300 万，推断训练成本较低。
- **历史数据依赖**：模型依赖 CIS-BP 数据库的 PWM 质量。若 PWM 不准确或缺失，对应 TF 的预测与解释将失效。
- **模型依赖**：结论依赖于 MCP 稀疏化超参数（b=3）和两阶段训练策略。不同超参数可能改变性能与可解释性平衡。
- **最难情形**：树差分任务（预测发育转变）R² 仅 ~0.05，说明模型在捕捉动态变化方面能力有限。作者也承认大部分转变不可预测。
- **不确定性**：未报告预测置信区间或不确定性量化。R² 的折间方差未给出。
- **有边界的复述**：在 ImmGen 小鼠造血 ATAC-seq 数据上，将 CIS-BP PWM 作为固定第一层卷积核的 tiSFM 架构，以约 1/3 的参数超越了定制化 CNN 基线 AI-TAC 的预测性能，且其最终线性层参数可直接解释为 TF-细胞类型贡献，无需事后归因分析。该结论限于此数据集与任务，且树差分预测能力有限。

## 14 学到什么

> 标题：Agent 提炼的知识候选

1. **先验嵌入架构（Prior-Embedded Architecture）**：将 TF 基序数据库（PWM）直接作为卷积核固定值，而非从零学习，是一种"知识蒸馏到结构"的范式。可迁移到 TF–DNA 结合预测任务：任何已知的 DNA 结合偏好（如来自 HT-SELEX、ChIP-seq 的基序）都可作为第一层先验，减少参数空间并保证可解释性。

2. **可训练池化作为机制假设的载体**：α 参数在平均池化与最大池化之间连续插值，直接对应"TF 结合是加性计数还是饱和效应"的生化假设。这一设计可推广到其他序列-功能任务：将生物学机制假设编码为可学习的池化/聚合策略，而非固定选择。

3. **显式互作层优于隐式非线性**：用矩阵 A 显式建模 TF-TF 互作，比依赖深层非线性隐式编码互作更可解释，且性能不降反升。对 TF–DNA 结合机制研究，这意味着"协同/拮抗"可以直接从 A 矩阵读出，无需事后推断。

4. **两阶段训练策略**：先冻结先验层训练下游，再解冻微调，既保证先验不被破坏，又允许小幅修正。实验表明微调后核与初始 PWM 的 MSE 仅 0.04，说明先验质量高时微调幅度小。此策略可迁移到任何带先验知识的深度学习任务。

5. **稀疏化路径分析**：通过 MCP 路径算法逐步增加稀疏惩罚，观察哪些 TF 先被置零、哪些最后保留，可以揭示 TF 的重要性层级。这种"正则化路径"本身是一种可解释性工具，可迁移到 TF 重要性排序。

6. **树差分任务设计**：将预测目标从"绝对活性"改为"亲-子发育转变的活性差"，可以更精准地定位关键调控事件。这一思路可迁移到 TF–DNA 结合研究：预测"结合差异"而非"绝对结合"，可能更易识别谱系特异的 TF。

7. **可解释性验证框架**：本文通过 (a) 已知 TF 重现（Pax5/Ebf1/Rorc）、(b) 参数生物学相关性（α vs 信息含量）、(c) 互作矩阵与已知调控网络一致性，三层验证可解释性。这一验证框架可直接用于评估其它可解释模型。

## 15 与已有知识连接

- **DeepSEA / Basenji / Enformer**（Zhou & Troyanskaya, 2015; Kelley et al., 2016; Avsec et al., 2021b）：这些模型是序列到功能预测的 SOTA，但依赖事后归因。tiSFM 与之形成对照：先验嵌入 vs 从零学习。可组合使用：用 Enformer 做长程特征提取，用 tiSFM 做局部 TF 机制解释。

- **AI-TAC**（Maslova et al., 2020）：本文的直接基线，使用同一 ImmGen 数据集。AI-TAC 需要 kernel 匹配 + DeepLift 两步解释，tiSFM 将解释内建。两者对比展示了"解释后处理"与"解释前设计"的范式差异。

- **TF–DNA 结合机制**：本文的 TF-细胞类型贡献矩阵 B 与 TF-TF 互作矩阵 A 可直接与已知的 TF 协同/拮抗数据库（如 TRANSFAC、JASPAR 共结合数据）交叉验证。其"弱基序 + 互作调制"的建模方式与已知的"辅助因子协同结合"机制一致。

- **可解释 AI 方法**：LIME、SHAP、DeepLift 等事后方法（Ribeiro et al., 2016; Lundberg & Lee, 2017; Shrikumar et al., 2017）与本文的"内在可解释"形成互补。对 TF–DNA 研究，内在可解释模型更适合机制发现，事后方法更适合验证。

- **PWM 数据库**：CIS-BP（Weirauch et al., 2014）是本文先验来源。类似地，JASPAR、HOCOMOCO 也可作为先验。本文方法对 PWM 质量敏感，提示先验数据库选择的重要性。

- **正则化路径**：Park & Hastie (2007) 的路径算法是本文稀疏化的基础。这一方法在基因组学中较少使用，本文展示了其在 TF 选择中的应用潜力。

- **造血分化调控**：本文识别的 Pax5、Ebf1、Rorc、Cebpb、Sfpi1 均为已知的谱系决定因子，与文献一致（如 Busslinger, 2004; Rothenberg, 2011）。这为模型提供了外部生物学验证。

## 16 研究想法

> 标题：Agent 生成的研究候选

### 候选 1：TF–DNA 结合强度预测的"先验嵌入 + 可解释互作"框架
- **名称**：PRIOR-TF（Prior-Embedded Interpretable TF Binding Predictor）
- **来源局限/观察**：tiSFM 证明固定 PWM 核在开放染色质预测上有效，但未直接测试 TF–DNA 结合强度（如 ChIP-seq peak 强度或 HT-SELEX 亲和力）预测。
- **核心假设**：将 PWM 先验嵌入 + 可训练池化 + 互作层迁移到 TF–DNA 结合强度预测，可同时获得高精度和可解释的 TF 协同/拮抗关系。
- **初步方法**：以 ChIP-seq 峰序列为输入，预测结合强度（如 log2 enrichment）；第一层固定为 JASPAR PWM，后续加入可训练池化与互作层；输出为结合强度。
- **验证方式**：与 DeepBind、DeepSEA 等基线比较 AUPRC；用已知 TF 协同对（如 GATA1:TAL1）验证互作矩阵 A 的正系数。
- **创新状态**：unverified

### 候选 2：TF 基序间距与方向敏感的可解释互作层
- **名称**：SPATIAL-TF
- **来源局限/观察**：tiSFM 的互作层在全局池化后应用，丢失了基序间的距离与方向信息。作者也承认这是局限。
- **核心假设**：TF-TF 协同/拮抗依赖于基序间的空间关系（如间距 10-20 bp 的周期性），显式建模空间关系可提升预测精度和机制解释。
- **初步方法**：在池化前引入位置编码的互作注意力，或使用二维互作核（基序对 × 相对距离）；输出仍为可解释的 TF 对 × 距离贡献矩阵。
- **验证方式**：在 ImmGen 数据上比较与 tiSFM 的 R²；用已知的"增强子-启动子环"或"TF 二聚体"基序对验证距离偏好。
- **创新状态**：unverified

### 候选 3：细胞类型特异的 TF-TF 互作网络推断
- **名称**：CELL-TF-INTERACT
- **来源局限/观察**：tiSFM 的互作矩阵 A 对所有细胞类型共享，无法建模细胞类型特异的互作。作者明确承认此局限。
- **核心假设**：TF-TF 互作是细胞类型特异的，通过引入细胞类型条件化互作层可提升预测精度并揭示谱系特异的调控网络。
- **初步方法**：将互作矩阵 A 扩展为 A_c（c 为细胞类型），或使用低秩分解 A_c = U_c V^T 共享基序对但细胞类型特异权重；用稀疏化正则选择关键互作。
- **验证方式**：比较与共享 A 的 R²；用已知的 B 细胞特异（Pax5-Ebf1）和 T 细胞特异（Gata3-Tcf7）互作验证。
- **创新状态**：unverified

### 候选 4：从开放染色质到 TF 结合动力学的迁移学习
- **名称**：ATAC2BIND
- **来源局限/观察**：tiSFM 在 ATAC-seq 上训练，但 ATAC-seq 反映的是开放染色质而非直接 TF 结合。TF 结合动力学（如 residence time）与开放染色质相关但不等价。
- **核心假设**：在 ATAC-seq 上预训练的 tiSFM 可迁移到 TF 结合动力学预测，且迁移后的可解释参数（B 矩阵）能揭示结合动力学与染色质开放性的关系。
- **初步方法**：在 ImmGen ATAC-seq 上预训练 tiSFM，然后在少量 TF 结合动力学数据（如 SMF-seq、MITOMI）上微调；比较迁移 vs 从零训练。
- **验证方式**：在动力学数据上比较 R²；检查迁移后 B 矩阵与已知的"先锋因子 vs 沉降因子"分类是否一致。
- **创新状态**：unverified

### 候选 5：结合物理模拟的可解释 TF-DNA 结合验证
- **名称**：TI-MD（Interpretable TF-MD）
- **来源局限/观察**：tiSFM 的互作层是统计性的，未与物理结合机制（如氢键、形状读码）对接。MD 模拟可提供原子级验证。
- **核心假设**：tiSFM 识别的高贡献 TF 对在 MD 模拟中应表现出显著的结合自由能协同/拮抗效应。
- **初步方法**：选取 tiSFM 互作矩阵 A 中权重最高的 5-10 个 TF 对，用 MD 模拟（如 GROMACS）计算结合自由能；比较协同/拮抗方向与 A 矩阵符号。
- **验证方式**：统计 A 矩阵符号与 MD 自由能变化的相关性；若一致，则 tiSFM 的互作层具有物理基础。
- **创新状态**：unverified

### 候选 6：未知基序发现的可解释框架
- **名称**：NOVO-TF
- **来源局限/观察**：tiSFM 受限于 CIS-BP 数据库，无法发现新基序。但可训练池化与互作层的残差可能包含未建模的序列信号。
- **核心假设**：tiSFM 预测残差中富集的序列模式对应未知或未注释的 TF 结合位点。
- **初步方法**：对 tiSFM 预测残差进行 de novo motif 发现（如 MEME）；将新 motif 与已知 TF 数据库比对；对高置信新 motif 进行 ChIP-seq 验证。
- **验证方式**：新 motif 在独立数据集上的富集显著性；与已知 TF 的序列相似性。
- **创新状态**：unverified
