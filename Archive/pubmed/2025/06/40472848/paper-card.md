## 02 一句话总结
本文通过迭代式「深度学习预测器 + 多种序列优化算法」设计合成人类增强子，在 HepG2 与 K562 两种细胞系中实现强细胞类型特异性活性，并揭示其机制为高密度、选择性 TFBS 词汇表与紧凑的序列语法（短至 50 bp 仍保持特异性）。

## 03 研究问题
- **具体问题**：如何利用深度学习模型指导设计具有强细胞类型特异性活性的合成人类增强子？迭代重训练能否提升设计性能？合成增强子实现特异性的序列语法是什么？
- **为什么重要**：细胞类型特异性基因表达是合成生物学与基因治疗的核心挑战。天然增强子的顺式调控代码尚未完全解析，而现有设计方法（如人工嵌入已知 TFBS）受限于先验知识，难以实现强特异性。
- **现有方法不足**：(1) 基于先验 TFBS 嵌入的设计受限于已知 motif 与语法规则；(2) 单轮深度学习设计缺乏实验反馈迭代；(3) 大规模 MPRA 数据（如 Gosai 等 750K 序列）成本高，难以推广到体内场景；(4) 对设计序列的机制性理解（哪些 TFBS、何种语法）不足。
- **精确研究问题（Can 句式）**：Can iterative deep learning design, trained on small high-quality datasets enriched for functional enhancers, produce synthetic human enhancers with cell-type specificity exceeding that of genomic enhancers, and can the underlying sequence grammar be mechanistically characterized?

## 04 背景与发展脉络
*（注：以下脉络基于本文框架，未完全经外部核验，标注为「仅本文框架」）*

1. **增强子功能解析时代**：MPRA 技术（如 Sharpr-MPRA，467K 序列）提供了大规模增强子活性定量数据，但仅覆盖有限细胞类型。
2. **染色质可及性作为代理**：DNase-seq/ATAC-seq 提供全基因组可及性图谱，但可及性 ≠ 活性，缺乏功能验证。
3. **深度学习预测顺式调控代码**：CNN 模型（如 Basset、DeepSEA）学习序列→染色质/活性映射，但多用于预测而非设计。
4. **模型引导的序列设计**：Taskiran 等（果蝇，单细胞 ATAC + CNN + GAN）与 De Almeida 等（CNN + 微调）实现体内验证；Gosai 等（人类，CNN + 梯度/随机搜索，750K 训练数据）实现大规模设计。
5. **生成式模型**：DaSilva 等（扩散模型）与 Lal 等（自回归 transformer）提出 in silico 设计，但缺乏实验验证。
6. **本文位置**：首次在人类细胞系中实现「迭代设计-实验验证-重训练」闭环，以 ~1K 序列的小数据实现性能跃升，并通过扰动实验、scMPRA 与 motif 分析系统刻画合成增强子的序列语法（高密度、选择性 TFBS 词汇表、短序列仍有效）。

## 06 核心思想
1. **表面方法**：训练 CNN 预测器（基于 Sharpr-MPRA 数据），用多种序列优化算法（Simulated Annealing、Fast SeqProp、DENs）生成候选增强子，经 MPRA 实验验证后，用新数据微调模型，再进行第二轮设计（R2）。
2. **核心洞察**：
   - 迭代重训练的价值不在于数据量，而在于数据质量——R1 库富集了高活性、高特异性序列，使模型在「设计相关」的序列空间中获得更精确的梯度信号。
   - 合成增强子实现特异性的机制是「浓缩语法」：高密度 TFBS（motif 密度显著高于天然增强子）+ 选择性词汇表（少数强驱动 motif 如 TP53、HNF4A）+ 短序列（50 bp 仍有效）。
   - 模型能够外推至「非天然」序列空间，发现天然增强子中罕见的 motif 组合（如 TP53 与 HNF4A 共现）。
3. **可能的普适教训 [Analysis]**：在序列-功能映射任务中，「设计-实验-重训练」闭环可以系统性克服初始训练数据的分布偏差；小规模但功能富集的数据集可能比大规模噪声数据更有效。这一策略可迁移到其他 TF–DNA 互作预测任务（如 TF 结合位点预测、染色质状态建模）。

## 07 方法总览
- **输入**：DNA 序列（one-hot 编码，长度 145 bp 或 200 bp）
- **输出**：预测的 log2FC（HepG2 与 K562 活性）或 log2FCH2K（特异性）
- **模型架构**：多任务 CNN，3 个并行卷积分支（核大小 7/11/25 或 11/15/21），BatchNorm + ReLU + Global MaxPooling + Dropout，后接全连接层（64 或 224 维），输出 2 个节点（HepG2、K562 活性）
- **训练策略**：
  - M0：在 R0-MPRA（29,891 序列，DESeq2 标准化）上训练，120 个模型（10 Single + 100 Boot + 10 Ensemble）
  - M0+1：在 R0 预训练基础上，用 R1-MPRA + R1-DHS 数据微调
  - M1：仅用 R1 数据从头训练
  - M2：在 M0+1 基础上用 R2 数据微调（用于最终评估）
- **设计算法**：
  - Simulated Annealing：随机突变 + 温度退火
  - Fast SeqProp：基于梯度的 PWM 优化 + 直通估计器
  - DENs：生成式网络，联合优化 fitness + 多样性 + 熵
- **实验验证**：MPRA（R1、R2 库），scMPRA（R1 库，10,640 细胞）
- **分析工具**：FIMO（motif 扫描，JASPAR 2022 非冗余脊椎动物库）、SHAP（模型解释）、motif 聚类（RSAT 137 簇）
- **反馈回路**：R1 实验数据 → 微调模型 → R2 设计 → R2 实验验证
- **假设**：CNN 能够学习序列→细胞类型特异性活性的映射；迭代重训练可提升设计性能；motif 密度与词汇表选择是特异性的关键决定因素。

## 09 关键公式符号
*（注：原文未提供显式数学公式，以下为方法描述中隐含的关键概念）*

1. **预测目标**：log2FCH2K = log2FCHepG2 − log2FCK562，其中 log2FC = log2(mRNA counts / DNA counts)
2. **Fast SeqProp 损失函数**（R1 设计）：
   - HepG2 目标：L = max(log2FCK562 − log2FCHepG2 + fitness_target, 0)
   - K562 目标：L = max(log2FCHepG2 − log2FCK562 + fitness_target, 0)
   - 其中 fitness_target = 3（R1）或 1.1 × 最大预测特异性（R2）
3. **DEN 损失函数**：L_total = fitness_cost + λ₁·diversity_cost + λ₂·entropy_cost
   - fitness_cost = max(log2FCK562 − log2FCHepG2 + fitness_target, 0)
   - entropy_min_bits = 1.8，similarity_margin = 0.5
4. **R2 附加损失**：L_R2 = target_weight·fitness + pwm_weight·pwm_loss + entropy_weight·entropy
   - target_weight = 1，pwm_weight = 2.5（惩罚单核苷酸重复），entropy_weight = 1e-3
5. **ablation score**：f_a = 1 − (活性_ablation / 活性_original)，f_a = 0 表示无影响，f_a = 1 表示完全消除
6. **deviation score**：f_dev = f_double − (f_single1 + f_single2)，f_dev ≈ 0 表示加性，f_dev << 0 表示冗余，f_dev >> 0 表示协同

## 10 实验设计与证据链
- **数据集**：
  - R0-MPRA：SHARPR-MPRA 29,891 序列（过滤后），145 bp，HepG2/K562 活性测量

## 11 结论正确解读
- **任务范围**：本文结论仅限于两个细胞系（HepG2、K562）和报告基因检测体系（质粒转染、minP 启动子），不适用于内源基因组位点、其他细胞类型或体内环境。
- **oracle/真值输入**：模型训练依赖 SHARPR-MPRA 数据（质粒体系），R1/R2 验证同样在质粒体系中进行；未在基因组整合位点验证。
- **端到端状态**：实现了「设计→合成→实验验证→重训练」闭环，但未实现「体内组织特异性」验证。
- **算力成本**：120 个 CNN 模型训练 + 多轮微调，但未报告具体 GPU 时数；Fast SeqProp 单序列优化计算量未量化。
- **历史数据依赖**：初始模型依赖 SHARPR-MPRA 数据质量；该数据仅覆盖 4 种细胞类型，且为质粒体系。
- **模型依赖**：CNN 架构、损失函数、超参数均经过调优；不同架构（如 transformer）可能表现不同。
- **最难情形**：K562 特异性设计显著难于 HepG2，且 25 bp 序列活性极低，说明语法压缩存在下限。
- **群体/领域边界**：结论适用于「启动子邻近增强子」场景；远端增强子、绝缘子、边界元件等未涉及。
- **不确定性**：单细胞分析中 TF-活性相关性受 dropout 和转染效率影响；扰动实验仅覆盖 top 5 增强子。
- **有边界的复述**：在质粒报告基因体系中，迭代深度学习设计可产生强细胞类型特异性的合成增强子（HepG2 优于 K562），其机制为高密度、选择性 TFBS 词汇表与可压缩至 50 bp 的序列语法；小规模高质量重训练数据可显著提升设计性能。

## 14 学到什么
**Agent 提炼的知识候选**：

1. **迭代「设计-实验-重训练」闭环**：即使初始模型预测精度有限，通过实验筛选高功能序列并微调模型，可在 1-2 轮内显著提升设计成功率。**可迁移到 TF–DNA 结合预测**：对特定 TF 的预测模型，可用少量高置信结合序列（如 SELEX、ChIP-seq 峰值）微调，而非依赖大规模噪声数据。

2. **浓缩 TFBS 语法作为设计原则**：高密度、选择性 motif 词汇表（而非大量不同 motif）是实现细胞类型特异性的关键。**可迁移到 TF–DNA 互作机制研究**：提示 TF 协同结合可能遵循「少数强驱动 TF + 辅助 TF」的层级结构，而非均匀分布的多 TF 组合。

3. **模型外推能力与序列「非天然性」**：深度学习模型能够发现天然序列中罕见的 motif 组合（如 TP53 + HNF4A），表明序列空间远大于天然进化所探索的范围。**可迁移到 TF 结合位点设计**：可系统探索非天然 TFBS 组合，发现新的协同结合模式。

4. **扰动实验作为因果验证工具**：通过系统敲除单个/成对 motif 并测量活性变化，可区分加性、冗余与协同互作。**可迁移到 TF–DNA 互作机制解析**：对预测的 TFBS 组合进行实验扰动，验证其因果贡献，而非仅依赖序列共现分析。

5. **短序列（50 bp）仍可编码特异性**：核心调控语法可高度压缩，提示 TF–DNA 互作的关键信息可能集中在少数核心 motif 及其相对位置。**可迁移到 TF 结合机制研究**：设计最小结合单元（如 50 bp）有助于解析 TF 协同结合的物理约束。

6. **scMPRA 连接单细胞 TF 表达与增强子活性**：在单细胞水平同时测量增强子活性与 TF 表达，可揭示 TF 剂量与增强子活性的定量关系。**可迁移到 TF–DNA 互作研究**：在异质细胞群中解析 TF 表达异质性对靶基因调控的影响。

7. **模型架构选择**：多任务 CNN（同时预测多个细胞类型）优于单任务模型，且集成（Ensemble）优于单模型。**可迁移到 TF 结合预测**：多任务学习（同时预测多个 TF 或多种细胞状态）可提升泛化性。

## 15 与已有知识连接
- **SHARPR-MRPA 数据集**（Ernst 等，2016）：本文的 R0 训练数据来源，提供了大规模增强子活性定量测量。本文展示了如何将该数据用于深度学习设计而非仅用于描述性分析。
- **Basset**（Kelley 等，2016）：本文 CNN 架构的参考实现之一，展示了卷积网络在染色质可及性预测中的应用。本文将其扩展为多任务活性预测器。
- **Fast SeqProp**（Linder 等，2020）：本文使用的梯度序列优化算法，展示了如何将预测器转化为设计工具。
- **Deep Exploration Networks**（Gontijo-Lopes 等，2019）：本文使用的生成式设计方法之一，强调多样性约束。
- **Taskiran 等（2020，Nature Genetics）**：果蝇增强子设计，使用单细胞 ATAC + CNN + GAN。本文将其扩展到人类细胞系，并加入迭代重训练。
- **Gosai 等（2023，Nature Biotechnology）**：大规模人类增强子设计（51K 序列）。本文的迭代策略在数据量上更小（~1K），但性能相当或更优，提示数据质量优先于数量。
- **Zhao 等（2022，Nature Genetics）**：scMPRA 方法学参考，本文在此基础上进行了修改以适配其文库。
- **JASPAR 数据库**：motif 扫描与词汇表分析的基础资源，本文使用 2022 版非冗余脊椎动物库。
- **SHAP**（Lundberg 等，2017）：模型解释工具，本文用于识别对预测贡献最大的序列特征。
- **与 TF–DNA 互作机制研究的连接**：本文的「浓缩语法」概念与已知的「增强子逻辑」研究（如 Spitz & Furlong, 2012）一致，但提供了定量、可设计的证据。其扰动实验方法可推广到其他 TF 组合的协同/冗余关系解析。

## 16 研究想法
**Agent 生成的研究候选**：

1. **候选名称**：TF–DNA 结合特异性的「最小语法单元」系统解析
   - **来源局限/观察**：本文发现 50 bp 增强子仍保持特异性，但未系统扫描长度与 motif 组合的交互作用。
   - **核心假设**：存在一个「最小语法单元」——由 2-3 个核心 TFBS 及其相对间距/方向组成——足以驱动细胞类型特异性。
   - **初步方法**：基于本文的 Fast SeqProp 框架，设计长度梯度（25/50/75/100/145 bp）的增强子库，系统改变 motif 组合、间距、方向，用 MPRA 测量活性。
   - **验证方式**：比较不同长度下特异性保持率；用 SHAP 识别关键位置效应。
   - **创新状态**：unverified

2. **候选名称**：多任务 CNN 预测 TF 协同结合的泛化性评估
   - **来源局限/观察**：本文的多任务 CNN 在 HepG2/K562 中表现良好，但未测试其在不同细胞类型或 TF 组合中的泛化性。
   - **核心假设**：多任务学习可提升 TF 结合预测的泛化性，尤其在 TF 表达谱差异大的细胞类型间。
   - **初步方法**：使用 ENCODE 多细胞类型 ChIP-seq 数据训练多任务 CNN，比较单任务 vs 多任务在未见细胞类型上的预测精度。
   - **验证方式**：留一细胞类型交叉验证；比较 AUPRC。
   - **创新状态**：partially checked（多任务学习在其他领域有效，但在 TF 结合预测中未系统验证）

3. **候选名称**：基于深度学习的 TF 协同结合 motif 组合发现
   - **来源局限/观察**：本文的扰动实验揭示了 TP53+HNF4A 协同，但仅覆盖 top 5 增强子，且依赖人工选择 motif。
   - **核心假设**：深度学习模型可以自动发现新的 TF 协同组合，超越已知 motif 数据库。
   - **初步方法**：用可解释性方法（如 Integrated Gradients、DeepSHAP）扫描设计序列，识别高贡献的未知 motif 组合；用电泳迁移率变动分析（EMSA）验证。
   - **验证方式**：预测的协同组合在独立 MPRA 中验证；与已知协同组合比较。
   - **创新状态**：unverified

4. **候选名称**：单细胞 TF 表达-增强子活性的因果推断框架
   - **来源局限/观察**：本文的 scMPRA 仅显示相关性，未做因果验证。
   - **核心假设**：通过 scMPRA 数据 + 扰动（如 CRISPRi 靶向 TF 基因），可以建立 TF 表达→增强子活性的因果模型。
   - **初步方法**：在混合细胞群中做 scMPRA + CRISPRi 扰动，用因果推断方法（如基于扰动的回归）估计每个 TF 对增强子活性的因果贡献。
   - **验证方式**：与已知 TF-增强子关系比较；在独立细胞系中验证。
   - **创新状态**：unverified

5. **候选名称**：增强子序列「非天然性」与功能可及性的关系
   - **来源局限/观察**：本文的设计序列与天然序列高度不同，但功能更强，提示天然序列空间可能未充分探索。
   - **核心假设**：存在大量「非天然但功能强大」的增强子序列，其功能与序列距离天然序列的程度呈非线性关系。
   - **初步方法**：计算设计序列与天然序列的 k-mer 距离，分析其与活性的关系；用生成模型系统采样「非天然」序列空间。
   - **验证方式**：在多个细胞类型中验证；比较不同生成策略（GAN vs 梯度优化）的序列特征。
   - **创新状态**：unverified

6. **候选名称**：TF–DNA 结合预测中的不确定性量化与主动学习
   - **来源局限/观察**：本文未报告模型预测的不确定性，且迭代重训练依赖实验筛选。
   - **核心假设**：通过量化预测不确定性，可以更高效地选择实验验证序列，减少迭代轮次。
   - **初步方法**：在 CNN 预测器中加入 MC-dropout 或深度集成，输出预测方差；设计「不确定性采样」策略选择下一轮实验序列。
   - **验证方式**：比较不确定性采样 vs 随机采样 vs 纯预测值采样的设计成功率。
   - **创新状态**：partially checked（主动学习在其他领域有效，但在增强子设计中未系统验证）
