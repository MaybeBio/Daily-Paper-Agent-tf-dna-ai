## 02 一句话总结

该文构建了一个以 DNA 序列为输入、以脑组织/细胞多类表观标签（染色质可及性、组蛋白修饰、TF 结合）为输出的多标签深度学习模型 Neur-Ally，通过 in silico 突变扫描计算 SNP 的调控效应得分（SAD），并在神经疾病 GWAS、脑 eQTL、ASD 变异及已报道的脑调控 SNP 上验证其区分调控与非调控变异的能力。

## 03 研究问题

- **具体问题**：神经疾病相关 SNP 大多位于非编码区，其中大量 SNP 因连锁不平衡而出现在关联信号中，但并非真正的调控变异。如何从序列层面区分「有调控功能的非编码 SNP」与「无调控功能的 SNP」？
- **为什么重要**：神经疾病 GWAS 和 eQTL 研究产生了大量候选 SNP，实验验证每个 SNP 的调控功能成本极高。一个可靠的、组织特异性的计算优先级排序工具可以大幅缩小实验验证范围。
- **现有方法不足**：多数已有模型（如 DeepSEA、Enformer）使用多组织混合数据训练，缺乏神经组织特异性；且部分模型未提供针对神经疾病的预训练权重和易用的变异效应预测流程。
- **精确研究问题**：Can a deep learning model trained exclusively on brain-relevant epigenomic datasets accurately predict the regulatory effect of neurological disorder-associated noncoding SNPs via in silico mutagenesis?

## 04 背景与发展脉络

> 注：此脉络为「经外部核验」的领域常识，结合本文引用整理。

1. **阶段一：实验方法定位调控变异**（2010s 前）
   - 代表性方法：报告基因实验、电泳迁移率变动分析（EMSA）、DNase-seq  footprinting。
   - 优点：直接测定调控活性；局限：通量低、无法覆盖全基因组 SNP。

2. **阶段二：基于序列的调控预测模型兴起**（2015–2020）
   - 代表性方法：DeepSEA（2015）、Basenji（2018）、Enformer（2021）。
   - 优点：从序列直接预测调控标签，支持 in silico 突变扫描；局限：多为多组织混合训练，组织特异性不足；部分模型对非编码 SNP 的效应预测精度有限。

3. **阶段三：组织/细胞特异性调控模型**（2020–至今）
   - 代表性方法：视网膜特异性模型（本文引用 [31]）、胰岛 β 细胞模型（本文引用 [32]）、阿尔茨海默病调控模型（本文引用 [33]）。
   - 优点：组织特异性数据提升局部预测精度；局限：数据量有限，模型泛化性待验证。

4. **本文位置**：在上述脉络中，Neur-Ally 属于「阶段三」的扩展——使用**最大规模的神经相关表观数据集（758 个）**训练，覆盖多种脑组织、细胞系、类器官，并针对神经疾病 SNP 提供端到端的变异效应预测流程。

## 05 核心思想

### 1) 表面方法

构建一个序列→多标签表观预测的深度学习模型（卷积 + 多头注意力），输入为 200 bp 基因组 bin 及其侧翼共 2000 bp 的 DNA 序列，输出为多个表观标签（染色质可及性、组蛋白修饰、TF 结合）的概率。训练完成后，对目标 SNP 进行 in silico 突变（参考等位基因 vs 替代等位基因），计算 SAD 得分，并通过与阴性 SNP 集比较的 E-value 判定显著性。

### 2) 核心洞察

- **组织特异性的价值**：神经疾病相关 SNP 的调控效应最可能在神经相关组织中体现，因此使用纯神经来源的表观数据训练，比混合组织模型更能捕捉疾病相关信号。
- **多标签联合预测的信息增益**：一个 SNP 可能只影响某一种调控标签（如仅影响特定 TF 结合而不影响染色质可及性），多标签输出可以捕捉这种「标签选择性」效应。
- **E-value 框架的稳健性**：通过构建大规模阴性 SNP 集（1000 Genomes 中过滤掉已知调控/编码区域的变异），以经验分布而非理论分布来评估显著性，避免了对 SAD 得分分布形态的假设。

### 3) 可能的普适教训 [Analysis]

- **序列嵌入的「类别化」处理**：将 A/C/G/T/N 视为独立类别而非 one-hot 编码的变体，配合 masking 处理未知碱基，这一设计对含 N 较多的参考基因组区域更鲁棒，可迁移到其他基因组序列建模任务。
- **卷积核大小与生物学先验对齐**：选择 10 bp 的卷积核大小，明确对应 TF 结合基序的典型长度（6–20 bp），这种「以生物学尺度指导架构选择」的思路值得借鉴。
- **训练/验证/测试的染色体分离策略**：按染色体划分数据（chr7/8 作为验证/测试），避免同源区域泄漏，是基因组深度学习中的关键实践。

## 07 方法总览

- **输入**：200 bp 基因组 bin + 两侧各 900 bp 侧翼序列（共 2000 bp），以整数编码（A=1, C=2, G=3, T=4, N=0），dtype=int8
- **输出**：多标签二值预测（每个标签独立二分类），标签类型包括：
  - 染色质可及性（ATAC-Seq、DNase-Seq）
  - 组蛋白修饰（ChIP-Seq）
  - TF 结合（ChIP-Seq）
- **模型架构**：
  1. 嵌入层（embedding dim = 128）
  2. 位置编码（sin/cos 函数，遵循 Transformer 方案）
  3. 两层 1D 卷积 + 最大池化（第一层 64 filters，第二层 32 filters，kernel size = 10，池化 stride = 3）
  4. 多头注意力层（MHA）
  5. Squeeze 操作降维
  6. 全连接层 + sigmoid 输出
- **训练**：二值交叉熵损失，39 epochs
- **变异效应预测**：
  - 对参考/替代等位基因分别生成输入序列
  - 计算 SAD = |P_ref − P_alt|（逐标签）
  - 与阴性 SNP 集比较，计算 E-value（阴性集：1000 Genomes 随机 SNP，过滤掉外显子/候选 cis-调控区域；重复 10 次取均值）
  - 显著性阈值：E-value ≤ 1e−05
- **数据来源**：ENCODE 的 narrow peak BED 文件（神经组织/细胞）
- **工具**：Keras（深度学习框架）、scikit-learn（指标计算）、liftover（坐标转换）

**文字流程**：
1. 从 ENCODE 下载神经相关表观数据 → 2. 将 peak 区域划分为 200 bp bin，与参考基因组序列对齐 → 3. 整数编码 + 位置编码 → 4. 卷积提取局部基序特征 → 5. 注意力捕捉长程依赖 → 6. 多标签 sigmoid 输出 → 7. 对目标 SNP 进行双序列（ref/alt）预测 → 8. 计算 SAD → 9. 与阴性集比较得 E-value → 10. 判定调控显著性。

## 09 关键公式符号

**1. 位置编码（Positional Encoding）**

对于位置 p 和维度 d：

PE(p, 2i) = sin(p / 10000^(2i/dim))

PE(p, 2i+1) = cos(p / 10000^(2i/dim))

- p ∈ {0, 1, …, seqlen − 1}：序列中的位置索引
- i：维度索引（0 ≤ i < dim/2）
- dim = 128：嵌入维度

**用途**：为序列注入位置信息，使注意力机制能感知碱基顺序。

**2. 1D 卷积**

Y[t, f] = Σ_k Σ_d X[t + k, d] · W[k, d, f] + b[f]

- X ∈ R^(batch × seqlen × dim)：输入张量
- W ∈ R^(kernel_size × dim × filters)：卷积核权重
- b ∈ R^filters：偏置
- kernel_size = 10，filters 分别为 64 和 32

**用途**：提取局部序列基序。

**3. 最大池化**

Z[i, t, f] = max_{k=0}^{p−1} Y[i, t·s + k, f]

- p = 3：池化窗口大小
- s = 3：步长

**用途**：降维并保留最强基序信号。

**4. SAD 得分（SNP Activity Difference）**

SAD = |P_ref − P_alt|

- P_ref：参考等位基因序列的预测概率
- P_alt：替代等位基因序列的预测概率

**用途**：量化 SNP 对调控标签的影响程度。

**5. E-value**

E-value = (阴性集中 SAD ≥ 观测 SAD 的 SNP 数) / 阴性集总数

- 重复 10 次阴性采样取均值
- 显著性阈值：E-value ≤ 1e−05

**用途**：以经验分布判定 SNP 调控效应的统计显著性。

**6. 阳性类别占比（Prevalence）**

p = N+ / (N+ + N−)

- N+：阳性样本数
- N−：阴性样本数

**用途**：计算 PR-AUC 的基线值。

## 11 结论正确解读

- **任务范围**：该模型预测的是「序列变异对表观标签的扰动」，而非直接预测「疾病风险」或「基因表达变化」。SAD 得分反映的是调控信号的改变，不等同于致病性。
- **Oracle/真值输入**：训练标签来自 ENCODE 的 peak calls（窄峰），这些 peak 本身是实验测定的近似，存在假阳性和假阴性；模型学到的是「与 peak 相关的序列模式」，而非「真实的调控机制」。
- **端到端状态**：从序列到表观标签预测是端到端的，但从 SNP 到疾病关联的推断不是端到端的——中间依赖 GWAS/eQTL 的预先筛选。
- **算力成本**：未报告具体训练时间/硬件配置；39 epochs 的训练在 9M 样本上可能需要数天 GPU 时间（[Analysis] 未提供具体数据）。
- **历史数据依赖**：训练数据来自 ENCODE 特定版本（hg38），peak calling 方法、抗体质量、细胞状态都会影响标签质量；模型无法泛化到未覆盖的细胞类型或物种。
- **模型依赖**：结果高度依赖训练数据的组织覆盖度；对于 ENCODE 中神经样本覆盖不足的脑区或细胞类型，预测可靠性下降。
- **最难情形**：SNP 位于 peak 边界附近、影响弱 TF 结合、或仅影响特定细胞亚型的调控时，SAD 可能低于检测阈值。
- **群体/领域边界**：模型基于人类参考基因组（hg38），不适用于非人类物种；神经疾病范围受限于 GWAS 关键词筛选，可能遗漏未标注的疾病类型。
- **不确定性**：E-value 基于经验分布，受阴性集构建方式影响；阴性集过滤了外显子和已知调控区域，可能低估了这些区域中 SNP 的调控潜力。

**有边界的复述**：Neur-Ally 是一个在神经组织/细胞表观数据上训练的多标签深度学习模型，能够以较高 AUROC 预测染色质可及性、组蛋白修饰和 TF 结合，并可通过 in silico 突变扫描对神经疾病相关非编码 SNP 进行调控效应优先级排序；其预测能力局限于训练数据覆盖的调控特征和组织类型，且未与其他主流模型进行直接对比。

## 14 学到什么

> Agent 提炼的知识候选

1. **多标签表观预测框架可迁移至 TF–DNA 结合研究**：Neur-Ally 将「序列→多种表观标签」的映射作为核心任务，这一框架可直接迁移到 TF 结合位点预测——将「TF 结合 ChIP-Seq」作为标签之一，与染色质可及性、组蛋白修饰联合建模，可捕捉 TF 结合对染色质状态的依赖关系。

2. **SAD 得分 + E-value 的变异效应评估流程**：通过双序列（ref/alt）预测差异 + 经验分布显著性检验，这一流程可迁移到 TF 结合位点内的 SNP 效应评估——例如评估某个 SNP 是否破坏或创建某个 TF 的基序，并量化其对结合概率的影响。

3. **卷积核大小与生物学尺度对齐**：10 bp 卷积核对应 TF 基序典型长度，这一设计原则可推广到其他序列特征（如核小体定位周期 ~10.5 bp、增强子-启动子间距等），指导模型架构选择。

4. **组织特异性训练数据的价值**：使用纯神经组织数据训练而非混合多组织数据，这一策略提示在 TF–DNA 结合研究中，应优先使用目标细胞类型/组织的 ChIP-Seq 数据，而非跨组织混合数据。

5. **N 碱基的显式处理**：将 N（未知碱基）作为独立类别并映射到 0，配合 masking 机制，这一设计对参考基因组中低复杂度/未测序区域更鲁棒，可迁移到其他基因组序列建模任务。

6. **染色体级别数据划分**：按染色体划分训练/验证/测试集，避免同源区域泄漏，是基因组深度学习中的关键实践，应作为 TF 结合预测模型的标准评估协议。

7. **多标签输出的信息增益**：同时预测多种表观标签而非单一标签，可捕捉不同调控特征间的协同/拮抗关系——例如某个 SNP 可能同时影响 TF 结合和染色质可及性，这种联合信号比单一标签更稳健。

## 15 与已有知识连接

- **DeepSEA**（Zhou & Troyanskaya, 2015）：首个从序列预测染色质特征的深度学习模型，Neur-Ally 是其「组织特异性 + 注意力机制」的扩展。DeepSEA 使用多组织混合数据，Neur-Ally 则聚焦神经组织。
- **Enformer**（Avsec et al., 2021）：基于 Transformer 的调控预测模型，支持长序列（200 kb）输入。Neur-Ally 的注意力层设计受此启发，但输入窗口更短（2 kb），聚焦局部调控。
- **Basenji**（Kelley et al., 2018）：序列→表观标签的卷积模型，Neur-Ally 的架构与其类似，但增加了注意力机制和神经特异性训练数据。
- **MPRA / STARR-seq**（实验验证方法）：Neur-Ally 的预测结果需通过此类实验验证；其 SAD 得分可作为 MPRA 文库设计的优先级排序工具。
- **GTEx eQTL**：Neur-Ally 使用 GTEx 脑组织 eQTL 作为验证集，与 eQTL 研究的连接表明其预测可解释基因表达调控的遗传基础。
- **TF–DNA 结合机制**：Neur-Ally 的 TF 结合标签预测可视为 TF 结合位点注释的补充工具，与 ChIP-Seq 基序分析（如 MEME、HOMER）互补——模型可捕捉非基序依赖的结合机制（如辅助因子协同）。
- **AlphaFold / 结构预测**：Neur-Ally 是序列→功能的「黑箱」映射，而结构方法（如 AlphaFold 3 的蛋白-DNA 复合物预测）提供物理机制解释；两者可结合——用结构预测验证 Neur-Ally 识别的高置信调控 SNP 是否影响 TF-DNA 结合界面。

## 16 研究想法

> Agent 生成的研究候选

**候选 1：TF 结合位点内 SNP 的「结合方向性」效应预测**
- **名称**：Directional TF-binding disruption score (dTFBS)
- **来源局限/观察**：Neur-Ally 的 SAD 得分取绝对值，丢失了「增强 vs 减弱」的方向信息；而 TF 结合的方向性改变（增强或减弱）对疾病机制的意义不同。
- **核心假设**：在 TF 结合位点内引入 SNP 后，预测概率的变化方向（正/负）与实验测定的结合亲和力变化方向一致。
- **增量**：在 Neur-Ally 框架上增加方向性输出，或对 SAD 得分进行符号化处理。
- **初步方法**：使用同一 TF 的 ChIP-Seq 数据训练模型，对已知影响 TF 结合的 SNP（如从 AlleleDB 或自身 MPRA 数据获取）计算方向性得分，与实验亲和力变化做相关分析。
- **验证方式**：用已发表的 TF 结合 QTL（bQTL）数据验证方向性预测的准确性。
- **创新状态**：unverified

**候选 2：跨细胞类型的 TF 结合特异性迁移学习**
- **名称**：Cell-type-adaptive TF binding transfer
- **来源局限/观察**：Neur-Ally 聚焦神经组织，但 TF 结合具有细胞类型特异性；训练数据有限的细胞类型预测精度不足。
- **核心假设**：在数据丰富的细胞类型上预训练的 TF 结合模型，通过少量目标细胞类型数据微调，可达到与全量训练相当的精度。
- **增量**：将迁移学习策略引入 TF 结合预测，降低新细胞类型建模的数据成本。
- **初步方法**：在神经数据上预训练模型，在少量其他组织（如肝脏、心脏）的 TF ChIP-Seq 数据上微调，比较与从头训练的精度差异。
- **验证方式**：使用 ENCODE 跨组织 TF ChIP-Seq 数据，评估微调样本量-精度曲线。
- **创新状态**：unverified

**候选 3：SNP 调控效应与 TF 结合基序破坏的联合建模**
- **名称**：Motif-aware regulatory variant prioritization (MARVP)
- **来源局限/观察**：Neur-Ally 是纯序列驱动的黑箱模型，未显式利用 TF 基序先验知识；而已知大量调控 SNP 通过破坏/创建基序发挥作用。
- **核心假设**：将基序匹配得分（如 PWM 评分）作为先验特征注入模型，可提高低置信度 SNP 的预测精度。
- **增量**：在 Neur-Ally 架构中增加基序先验通道，或对 SAD 得分与基序破坏得分做集成。
- **初步方法**：对每个 SNP 计算参考/替代等位基因的 PWM 匹配得分差，作为额外特征与模型预测融合。
- **验证方式**：在已功能验证的调控 SNP 数据集上比较有/无基序先验的预测精度。
- **创新状态**：unverified

**候选 4：从调控变异预测到 TF–DNA 结合机制解释**
- **名称**：Interpretable TF-binding mechanism discovery via attention analysis
- **来源局限/观察**：Neur-Ally 的注意力层可提供序列位置的重要性权重，但作者未进行机制层面的解释分析。
- **核心假设**：注意力权重高的位置富集已知 TF 基序，且这些位置的 SNP 更可能具有调控效应。
- **增量**：将注意力权重作为「可解释性」输出，连接预测结果与 TF–DNA 结合机制。
- **初步方法**：对预测显著的 SNP，提取其所在区域的注意力权重分布，与 PWM 基序位置做重叠分析；统计注意力峰值与已知 TF 结合位点的共定位。
- **验证方式**：用 CTCF、SP1 等已知结合特征的 TF 验证注意力模式是否符合预期。
- **创新状态**：unverified

**候选 5：结合结构预测的调控 SNP 效应验证**
- **名称**：Structure-guided validation of regulatory SNP effects
- **来源局限/观察**：Neur-Ally 预测的是序列→表观标签的映射，不提供物理机制；而 AlphaFold 3 等结构预测工具可预测 TF–DNA 复合物结构。
- **核心假设**：Neur-Ally 预测的高置信调控 SNP 中，位于 TF–DNA 结合界面的 SNP 更可能通过改变结合亲和力发挥作用。
- **增量**：将序列预测与结构预测结合，提供「序列→结构→功能」的完整解释链。
- **初步方法**：选取 Neur-Ally 预测显著的 SNP，用 AlphaFold 3 预测参考/替代等位基因的 TF–DNA 复合物结构，比较结合界面残基接触变化。
- **验证方式**：对预测的结构变化与实验结合亲和力数据（如 SPR、EMSA）做相关性分析。
- **创新状态**：unverified
