## 02 一句话总结

本文提出 IceQream（IQ）框架，用 TF 的 PWM 物理结合模型、空间偏好曲线、非线性剂量-响应函数及 TF-TF 成对互作项，对单细胞 ATAC-seq 衍生的可及性概率（AP）差异进行回归，在小鼠原肠胚和人类造血分化数据上达到与深度学习模型相当的预测精度，同时提供完全可解释的调控机制。

## 03 研究问题

- **具体问题**：能否用完全可解释的 TF 物理结合模型（而非黑箱深度学习）从 DNA 序列定量预测染色质可及性差异？
- **为什么重要**：深度学习模型（如 Borzoi、DeepTopic）预测精度高但不可解释，无法直接揭示 TF 结合、协同互作等机制；而传统基于 motif 的简单方法精度不足。需要一个兼具精度和可解释性的基线模型，以判断深度模型是否真正发现了超越已知物理机制的新规律。
- **精确的 "Can ... ?" 问题**：Can a fully interpretable physical TF binding model, integrating weak-affinity sites, spatial preferences, and pairwise TF interactions, achieve predictive accuracy comparable to state-of-the-art deep learning models for single-cell chromatin accessibility?

## 04 背景与发展脉络

> 注：以下脉络基于本文框架及摘要内容，部分为作者论述的框架，标注为「仅本文框架」；涉及外部方法的部分标注「经外部核验」。

1. **早期 motif 扫描时代**：用 PWM/PSSM 在序列中扫描高亲和力 motif，预测 TF 结合位点。局限：仅考虑最优位点，忽略弱亲和力位点，预测精度低（经外部核验，如 TRANSFAC、JASPAR 数据库方法）。
2. **深度学习时代**：CNN（如 DeepTopic、ChromBPNet）和 transformer 语言模型（如 Borzoi、Enformer）直接从序列预测可及性/表达，精度大幅提升，但不可解释（经外部核验）。
3. **可解释性探索**：对深度模型做注意力分析、梯度归因等，但仍是"事后解释"，非"事前机制"（仅本文框架）。
4. **物理模型回归**：本文主张的位置——用 TF-DNA 结合热力学（PWM 能量 + 空间权重 + 非线性响应）作为模型组件，直接回归可及性差异，既保持精度又天然可解释（仅本文框架）。

## 06 核心思想

1. **表面方法**：用 PWM 计算序列结合能量，通过空间权重曲线加权，经非线性剂量-响应函数变换，加上 TF-TF 成对互作项，用逻辑回归预测 dAP。

2. **核心洞察**：TF-DNA 结合不是"有/无"的二元事件，而是连续的能量积分——一个调控元件内所有潜在结合位点（包括弱位点）的贡献应被积分求和，而非只取最优位点。这一物理假设使模型既能捕捉弱亲和力位点的协同效应，又保持每个组件的生物学可解释性。

3. **可能的普适教训** [Analysis]：在基因组调控预测中，"可解释性"与"精度"并非必然对立。将领域物理知识（热力学结合、空间约束）编码为模型结构，可以在不牺牲精度的情况下获得可解释性。这为深度学习时代提供了一个重要对照：当物理模型与深度模型精度相当时，说明现有深度模型可能并未发现超越已知物理机制的新规律。

## 07 方法总览

- **输入**：目标位点（peak）的 DNA 序列（约 500 bp）、单细胞 ATAC 原始 read count、可选的表观遗传特征（组蛋白修饰、TAD 区域可及性等）
- **输出**：每个位点的可及性概率差异（dAP）预测值，以及每个 TF 组分的贡献分解
- **模块**：
  1. AP 归一化模块：raw count → 区域归一化 → 组成性位点归一化 → AP（0-1）
  2. TF 物理结合模块（PWM + 空间权重 + 能量积分）
  3. 非线性响应模块（剂量-响应曲线族）
  4. TF-TF 互作模块（成对乘积项）
  5. 回归模块（逻辑回归 + L1 正则化）
- **训练**：分阶段进行——先 motif 库筛选，再 L1 逻辑回归过滤，再 PREGO 聚类整合，最后加互作项
- **工具**：PREGO（motif 回归）、glmnet（弹性网络逻辑回归）、自定义 Python 实现
- **反馈回路**：多阶段逐步精化——每阶段用上一阶段残差作为新目标
- **假设**：TF 结合贡献可加性；空间偏好可用平滑曲线描述；非线性响应可用有限基函数逼近

**文字流程**：
1. 将单细胞 ATAC 原始计数归一化为 AP（利用组成性开放位点作为内部标准）
2. 计算每个位点相对轨迹起点的 dAP
3. 从 PWM 数据库（如 JASPAR）和 de novo motif 回归初始化候选 TF 模型库
4. 用 L1 逻辑回归过滤无关 motif
5. 对保留 motif 进行聚类整合（PREGO），每个簇生成一个代表性 PWM + 空间曲线
6. 加入非线性响应函数和 TF-TF 互作项，重新回归
7. 输出最终模型，可用 IQ-plots 可视化单个位点的调控架构

## 09 关键公式符号

1. **PWM 结合能量**（公式 2）：
   PB_k^abs(S) = log₂( Σᵢ 2^(PWM_k(S[i..i+L_k]) · wᵢ) )
   - PB_k^abs：TF k 对序列 S 的绝对结合能量
   - PWM_k：位置权重矩阵，L_k bp 窗口
   - wᵢ：空间权重（位置 i 的偏好）
   - 含义：对所有可能结合位点的能量做 log-sum-exp 积分，而非取最大值

2. **能量归一化**（公式 3）：
   PB_k(S) = min(max(10 + PB_k^abs(S) − Q^0.99_{S'∈NORM}(PB_k^abs(S')), 0), 10)
   - Q^0.99：背景序列集 NORM 的 99 分位数
   - 含义：将能量归一化到 [0, 10] 范围，10 为最大亲和力

3. **非线性响应函数**（公式 4）：
   fⱼ(B) = μⱼ / (1 + exp(−αⱼ(B − βⱼ)))
   - μⱼ、αⱼ、βⱼ：逻辑斯蒂函数形状参数（模拟不同 TF 浓度下的响应）
   - 含义：将结合能量映射为调控效应，可模拟饱和、阈值等非线性

4. **完整回归模型**（公式 1）：
   dAP = σ( Σᵢ Σⱼ βᵢ,ⱼ fⱼ(PBᵢ) + Σ_(i₁,i₂) Σⱼ γₖ,ⱼ fⱼ(PBᵢ₁·PBᵢ₂) + Σₖ Σⱼ δₖ,ⱼ fⱼ(Eₖ) )
   - σ：逻辑斯蒂函数
   - βᵢ,ⱼ：单个 TF 的回归系数
   - γₖ,ⱼ：TF-TF 互作系数
   - δₖ,ⱼ：表观遗传特征系数
   - 含义：dAP 由 TF 单独效应、成对互作效应和表观遗传背景共同决定

5. **AP 归一化**（公式 5-7，未完整给出）：
   unᵢ = uᵢ − mean_{1k≤|i′−i|<20k} uᵢ′
   - uᵢ：原始 read count；unᵢ：区域归一化值
   - 含义：减去 20 kbp 窗口内的背景信号，消除区域偏差

## 11 结论正确解读

- **任务范围**：本文解决的是"从序列预测染色质可及性差异"的回归任务，而非可及性位点检测或 TF 结合位点预测。模型输出是连续 dAP 值，不是二元开放/关闭分类。
- **oracle/真值输入**：dAP 由单细胞 ATAC 数据计算，本身是群体平均的近似；模型使用轨迹起点和终点的 AP 差，不建模中间动态过程。
- **端到端状态**：IQ 是端到端可训练的，但训练分阶段进行，非单次反向传播。最终模型参数（PWM、空间曲线、响应函数、互作系数）均有明确生物学解释。
- **算力成本**：训练约 17 分钟/轨迹（32 核 CPU），远低于深度模型（GPU 训练），这是 IQ 的实用优势。
- **历史数据依赖**：模型依赖输入的 PWM 数据库和 de novo motif 初始候选；不同数据库可能影响结果。
- **最难情况**：模型对非单调响应、三体及以上互作、以及长程调控（>500 bp）的建模能力有限。
- **群体/领域边界**：仅在两个数据集（小鼠原肠胚、人类造血）上验证；未测试其他物种或疾病状态。
- **不确定性**：论文未报告预测的置信区间或不确定性量化。

**有边界的复述**：在小鼠原肠胚和人类造血分化背景下，IQ 用可解释的 TF 物理结合模型达到了与深度模型相当的 dAP 预测精度，但这一结论限于这两个数据集、约 500 bp 的局部序列窗口、以及成对互作水平。

## 14 学到什么

> 标题：Agent 提炼的知识候选

1. **物理模型作为可解释基线**：在 TF–DNA 互作预测中，PWM 能量积分 + 空间权重 + 非线性响应的组合可以作为深度学习模型的强可解释基线。当物理模型与深度模型精度相当时，说明现有深度模型可能未发现超越已知物理机制的新规律。可迁移到本课题：在开发新的 TF–DNA 结合预测模型时，先建立物理基线，再评估深度模型的增量价值。

2. **弱亲和力位点的积分贡献**：传统方法只取最优 motif 位点，但 IQ 证明多个弱位点的积分贡献对预测精度至关重要。可迁移到本课题：在 MD 模拟或对接计算中，不应只关注最高亲和力构象，而应对 ensemble 做 Boltzmann 加权积分。

3. **空间偏好曲线的可学习性**：TF 结合位置相对 peak 中心的偏好可以通过数据学习，而非预设固定窗口。可迁移到本课题：在构建 TF–DNA 结合模型时，将空间偏好作为可学习参数，而非固定假设。

4. **成对互作项的可解释发现**：通过显式建模 TF-TF 成对互作，可以自动发现协同/拮抗关系，且系数大小直接反映互作强度。可迁移到本课题：在分析 TF 协同结合时，可用类似方法从可及性数据中推断互作网络，再与结构预测（如 AlphaFold 多聚体）交叉验证。

5. **跨轨迹模型同质化**：不同分化轨迹的模型可通过 motif 聚类统一，使模型可比较且更泛化。可迁移到本课题：在跨细胞类型或跨物种的 TF–DNA 结合分析中，先做 motif 同质化再比较，避免因冗余 motif 导致的假差异。

6. **归一化到绝对概率**：将 read count 归一化为 0-1 的绝对可及性概率（而非相对信号），使不同位点、不同细胞状态的比较更有意义。可迁移到本课题：在比较不同条件下的 TF 结合时，使用绝对结合概率而非相对富集分数。

## 15 与已有知识连接

- **PWM/PSSM 模型**：本文的物理结合模型基于经典 PWM 框架（如 JASPAR、TRANSFAC 数据库），但扩展为能量积分而非最大位点。与 Berg & von Hippel (1987) 的统计力学结合模型一脉相承。
- **PREGO**：本文改编自 PREGO (Tanay 实验室前期工作)，用于 motif 回归和 de novo 发现。
- **单细胞 ATAC-seq 分析**：与 SnapATAC、ArchR、cisTopic 等工具链互补，本文聚焦于"从序列到可及性"的正向建模，而非聚类或可视化。
- **深度学习基因组模型**：与 Borzoi、Enformer、DeepTOPIC 直接对比，本文提供可解释替代方案。与 AlphaFold 等结构预测工具互补——本文预测"哪里开放"，结构工具预测"如何结合"。
- **TF 结合机制**：本文的成对互作项与已知 TF 二聚体（如 bZIP、bHLH 家族）的协同结合机制一致，为结构生物学提供计算预测。
- **核小体定位**：空间偏好曲线与核小体排斥的物理模型（如 Segal 等）相关，可迁移到染色质重塑研究。

## 16 研究想法

> 标题：Agent 生成的研究候选

**候选 1：物理-深度混合模型（Physics-informed hybrid）**
- 来源局限/观察：IQ 精度与深度模型相当但不超越；深度模型不可解释但可能捕捉未知模式
- 核心假设：将 IQ 的物理组件作为深度模型的归纳偏置（inductive bias），可同时获得精度和可解释性
- 初步方法：在 Borzoi 架构中，将 IQ 的 PWM 能量作为注意力机制的初始化或正则化项
- 验证方式：在本文的小鼠/人类数据集上对比纯深度、纯物理、混合三者的 R² 和可解释性指标
- 创新状态：unverified

**候选 2：TF 结合构象 ensemble 的 Boltzmann 加权预测**
- 来源局限/观察：IQ 对序列做能量积分，但未考虑 TF 的构象自由度
- 核心假设：将 MD 模拟或对接得到的 TF–DNA 构象 ensemble 的能量分布，替代 PWM 作为结合能量输入，可提升预测精度
- 初步方法：对关键 TF（如 Eomes、Gata）做 MD 模拟，提取结合自由能谱，替换 IQ 的 PWM 能量
- 验证方式：对比 PWM 能量 vs MD 能量作为 IQ 输入的 R²
- 创新状态：unverified

**候选 3：从可及性数据逆向推断 TF 协同结合的结构基础**
- 来源局限/观察：IQ 发现 Eomes-Mesp2 和 Atf4-Atf3 的协同互作，但未解释结构基础
- 核心假设：IQ 推断的互作对中，空间距离 <20bp 的位点对对应直接物理互作（二聚体），>100bp 的对应间接互作（染色质环）
- 初步方法：用 AlphaFold 多聚体预测 IQ 显著互作对的结合模式，与距离-效应曲线交叉验证
- 验证方式：结构预测的互作界面与 IQ 互作系数的相关性
- 创新状态：unverified

**候选 4：跨物种 TF–DNA 结合物理模型的迁移学习**
- 来源局限/观察：IQ 在小鼠和人类上分别建模，未利用跨物种保守性
- 核心假设：TF 的 DNA 结合物理特性在哺乳动物中高度保守，可迁移
- 初步方法：用小鼠训练的 IQ 模型初始化人类模型，对比随机初始化的收敛速度和精度
- 验证方式：迁移学习后的 R² 提升幅度
- 创新状态：unverified

**候选 5：动态可及性预测（Time-resolved accessibility）**
- 来源局限/观察：IQ 是静态模型，不建模可及性随时间的变化
- 核心假设：将 IQ 的物理组件嵌入 ODE 或 RNN 框架，可预测分化过程中的可及性动态
- 初步方法：在分化时间序列的 Multiome 数据上，用 IQ 特征作为 RNN 输入
- 验证方式：时间序列预测的 RMSE 对比静态模型
- 创新状态：unverified
