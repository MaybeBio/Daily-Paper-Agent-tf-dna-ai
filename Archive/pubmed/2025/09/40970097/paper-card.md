## 03 研究问题
- **具体问题**：如何利用计算工具整合基因组与转录组数据，解析 HSC 的异质性、调控网络与谱系分化机制，并最终实现纯 HSC 群体的鉴定与功能验证？
- **为什么重要**：HSC 的分离与功能表征因细胞异质性、动态转录与表观调控而困难；纯 HSC 群体对造血系统恶性肿瘤、自身免疫病等的移植治疗至关重要。
- **现有方法为何不足**：单一组学数据（仅转录组或仅表观组）无法全面捕捉 HSC 命运决定的调控逻辑；HSC 稀有性、异质性及动态变化使传统 bulk 分析丢失关键亚群信息。
- **精确研究问题（Can...?）**：Can integrative computational pipelines (scRNA-seq + ChIP-seq + network inference + ML) reliably identify and characterize true self-renewing HSC populations from heterogeneous bone marrow samples?

## 04 背景与发展脉络
- **阶段一：bulk 转录组分析**。代表性方法：DESeq2、edgeVar、Limma-voom。优点：成熟、统计框架完善；局限：丢失细胞异质性信息，无法区分稀有 HSC 亚群。
- **阶段二：单细胞转录组（scRNA-seq）**。代表性方法：Cell Ranger、Seurat、SCANPY、Monocle。优点：单细胞分辨率揭示异质性与分化轨迹；局限：稀疏性、dropout、技术噪声需复杂预处理。
- **阶段三：表观组学（ChIP-seq）**。代表性方法：Bowtie2、MACS2、SICER、GREAT、HOMER。优点：直接鉴定 TF 结合位点与组蛋白修饰，揭示顺式调控元件；局限：需大量细胞、抗体质量依赖、peak calling 阈值选择敏感。
- **阶段四：网络推断与机器学习**。代表性方法：ARACNE、WGCNA、SCENIC、GENIE3、CellNet、随机森林、SVM、深度学习。优点：从数据中重建 GRN、预测调控关系与功能元件；局限：推断结果需实验验证，模型可解释性有限。
- **本文主张的位置**：主张四类方法应整合使用，形成从数据生成→预处理→分析→网络重建→预测验证的完整计算流程，以系统解析 HSC 调控机制。

## 06 核心思想
1. **表面方法**：综述四类计算流程——scRNA-seq（预处理→归一化→降维→聚类→轨迹推断）、ChIP-seq（质控→比对→peak calling→注释→motif 发现）、网络推断（ARACNE/WGCNA/SCENIC/GENIE3）、机器学习（SVM/随机森林/深度学习）——并给出每类流程的步骤、工具与 HSC 应用案例。
2. **核心洞察**：HSC 命运决定由多层级调控（转录、表观、调控网络）共同驱动，单一方法无法捕捉全貌；整合多组学数据与计算建模可系统重建 GRN，识别关键调控因子（如 GATA2、PU.1、Runx1、Scl/Tal1），并预测新的增强子、TF 与治疗靶点。
3. **可能的普适教训 [Analysis]**：计算流程的价值不在于单个工具的精度，而在于「数据整合 + 网络视角 + 实验验证」的闭环；对 TF–DNA 互作研究而言，ChIP-seq 的 peak 与 motif 信息应作为网络推断的锚点，而非终点。

## 07 方法总览
- **输入**：HSC 相关的高通量数据——scRNA-seq 表达矩阵、ChIP-seq 测序 reads、bulk RNA-seq 计数、表观数据（组蛋白修饰、染色质可及性）。
- **输出**：细胞类型/状态注释、分化轨迹、TF 结合位点与顺式调控元件、GRN、关键调控因子与治疗靶点预测。
- **模块**：
  1. scRNA-seq 流程：质控（Cell Ranger/Seurat）→ 归一化（SCnorm/DESeq2）→ 降维（PCA/t-SNE/UMAP）→ 聚类 → 轨迹推断（Monocle）
  2. ChIP-seq 流程：质控（FastQC/Trimmomatic）→ 比对（Bowtie2/BWA）→ peak calling（MACS2/SICER）→ 注释（ChIPseeker/GREAT）→ motif 发现（HOMER）
  3. 网络推断：ARACNE（互信息）、WGCNA（共表达模块）、SCENIC（TF–靶基因）、GENIE3（树集成）
  4. 机器学习：SVM、随机森林、深度学习（预测 TF 结合、增强子、细胞间互作）
- **训练**：各工具独立训练/推断，无统一端到端训练流程；机器学习模型需特征选择（如 mRMR）与交叉验证。
- **反馈回路**：网络推断结果经实验（遗传扰动、功能验证）确认后反馈修正模型。
- **文字流程**：原始数据 → 质控与预处理 → 归一化/比对 → 降维/peak calling → 聚类/注释 → 轨迹推断/网络重建 → 机器学习预测 → 实验验证 → 生物学解释。

## 14 学到什么
**Agent 提炼的知识候选**：

1. **ChIP-seq 流程作为 TF–DNA 互作锚点**：MACS2 peak calling + HOMER motif 发现 + GREAT 功能注释的流程可直接迁移到 TF–DNA 结合研究，用于鉴定 TF 结合位点与顺式调控元件。可迁移方式：在特定 TF 的 ChIP-seq 数据上运行该流程，获得候选结合位点后，用分子模拟（如 MD）验证 TF 与 DNA 基序的物理结合稳定性。

2. **SCENIC 的 TF–靶基因推断策略**：SCENIC 将共表达与 motif 富集结合，推断 TF 调控网络。可迁移方式：将 ChIP-seq 获得的 TF 结合位点作为先验约束，改进网络推断精度，减少假阳性调控关系。

3. **多组学整合框架**：scRNA-seq（细胞状态）+ ChIP-seq（调控元件）+ 网络推断（调控关系）的三层整合思路，可迁移到 TF–DNA 互作研究：用 scRNA-seq 定义细胞状态，用 ChIP-seq 定位 TF 结合，用网络推断连接 TF 与靶基因，形成从结合到功能的完整链条。

4. **机器学习预测增强子/TF 结合**：随机森林和深度学习可用于预测 TF 结合位点与增强子活性。可迁移方式：将 ChIP-seq peak 序列作为训练数据，结合 DNA 序列特征（k-mer、motif 位置权重矩阵）训练预测模型，再用分子模拟验证 top 预测位点的结合亲和力。

5. **网络验证的实验闭环**：作者强调网络推断结果需遗传扰动验证。可迁移方式：对预测的关键 TF–DNA 互作，设计 CRISPR 敲除或点突变实验，验证结合位点突变对靶基因表达的影响，形成「计算预测 → 实验验证 → 模型修正」的闭环。
