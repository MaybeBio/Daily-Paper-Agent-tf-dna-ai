## 02 一句话总结
本文开发了一个多目标、ML 引导的无细胞生物传感器工程工作流，通过将序列对（sequence pairs）标注为方向性 token（如"增加铅响应/减少锌响应"），训练 T5 架构的序列到序列模型，在主动学习循环中迭代预测并实验验证 PbrR 突变体，最终获得能在 EPA 铅行动水平（~5.7 ppb）检测铅且不受锌干扰的工程化 aTF 变体。

## 03 研究问题
- **具体问题**：如何同时优化 aTF 类生物传感器的多个性能指标（灵敏度、选择性），使其满足实际饮用水检测需求？
- **为什么重要**：天然 aTF 通常无法同时满足实际应用所需的灵敏度和选择性；传统定向进化难以同时优化多个相互制约的性状；铅污染是严重的公共卫生问题（美国仍有约 920 万条铅服务管线）。
- **现有方法不足**：
  - 传统定向进化难以同时优化多个性状（灵敏度 vs 选择性常呈 trade-off）
  - 预测性 ML 模型依赖数值标签，在数据稀缺时不可靠
  - 偏好学习方法（如 ProteinDPO）仅关注改进方向，未利用"有害突变"信息
  - 理性设计难以处理别构蛋白的复杂性（突变效应分布在整个蛋白，不仅限于配体结合域）
- **精确研究问题**："Can a multi-objective, directionally-labeled sequence-to-sequence model, integrated with cell-free expression screening in an active learning loop, simultaneously improve the sensitivity and selectivity of the allosteric transcription factor PbrR for lead detection at the EPA action level?"

## 04 背景与发展脉络
*（注：此脉络基于本文框架，未经外部核验）*

1. **aTF 生物传感器阶段**：利用天然 aTF 的别构机制（配体结合→构象变化→DNA 结合亲和力改变）构建检测系统。代表工作包括环境污染物、健康标志物检测。局限：天然 aTF 性能不足，需工程改造。
2. **定向进化阶段**：通过随机突变/易错 PCR 等筛选高性能变体。局限：难以同时优化多性状；别构蛋白的突变效应难以理性预测。
3. **计算辅助设计阶段**：结构预测（如 AlphaFold）、分子对接、MD 模拟等物理方法辅助设计。局限：别构机制动态性强，静态结构信息不足；计算成本高。
4. **ML 引导的定向进化（MLDE）阶段**：用监督学习模型打分序列，指导突变库设计。局限：依赖数值标签，数据稀缺时预测不可靠；单目标优化为主。
5. **偏好学习阶段**（如 ProteinDPO）：利用相对比较（好/坏）训练模型。局限：仅关注改进方向，未利用双向信息。
6. **本文位置**：提出**多目标受控外推（Multi-Objective Controlled Extrapolation）**框架，用**方向性 token** 编码多性状变化方向，在**单一生成步骤**中实现受控外推，无需数值预测器，天然支持多目标优化，且通过配对数据实现数据增强。

## 05 核心思想
### 1) 表面方法
- 构建配对数据集：将实验测得的突变体两两配对，根据功能变化方向标注为 token（如 ⟨inc⟩⟨dec⟩）
- 使用 T5 架构（ProtT5-XL-UniRef50）进行参数高效微调（LoRA）
- 在主动学习循环中：ML 模型生成候选 → CFE 高通量筛选 → 新数据加入训练集 → 迭代

### 2) 核心洞察
- **方向性标签替代数值标签**：配对比较天然消除批次效应和测量噪声，且将 N 个样本扩展为 O(N²) 个训练对，实现数据增强
- **单步生成替代迭代优化**：模型直接学习"从当前序列到目标方向"的映射，一次生成即可获得多突变组合，避免多轮迭代的误差累积
- **双向学习**：同时利用有益和有害突变信息，提供更丰富的序列–功能关系信号
- **受控外推**：通过 token 条件化生成，模型在保持与已知数据相似性的同时，向目标方向外推

### 3) 可能的普适教训 [Analysis]
- 对于 TF–DNA 互作研究，**配对比较**策略可推广到其他功能标签（如 DNA 结合亲和力、别构响应幅度），尤其适用于实验噪声大、数据量小的场景
- **方向性 token 条件化**为多目标蛋白质工程提供了一种无需重新训练预测器的灵活框架，可扩展到任意数量的目标性状
- 主动学习与理性设计（组合已知有益突变）的互补，提示**人机协同**可能是蛋白质工程的高效策略

## 07 方法总览
- **输入**：蛋白质序列（氨基酸序列），方向性 token 序列（如 ⟨inc⟩⟨dec⟩）
- **输出**：满足目标方向的突变体序列集合
- **核心模块**：
  1. **数据生成模块**：CFE 高通量筛选系统（1 μL 反应体系，384 孔板）
  2. **配对数据构建模块**：基于噪声阈值 τκ 将实验数据转化为方向性标签
  3. **ML 模型模块**：ProtT5-XL-UniRef50 + LoRA 微调，序列到序列生成
  4. **主动学习循环模块**：模型生成 → 实验验证 → 数据更新 → 再训练
- **训练**：交叉熵损失，AdamW 优化器（lr=1e-4, weight decay=1e-4），SacreBLEU 评估生成质量
- **推理**：top-k 采样（k=10），每个种子序列生成 20 个候选，按突变阶数过滤
- **反馈回路**：每轮实验数据（含失败突变）全部反馈至训练集，模型持续学习
- **假设**：序列对之间的功能差异可由方向性 token 充分编码；T5 架构能捕捉氨基酸替换的上下文依赖效应

## 09 关键公式符号
**1. 方向标签定义**：
```
label_κ = ⟨inc⟩, if f_κ(X₂) - f_κ(X₁) > τ_κ
          ⟨dec⟩, if f_κ(X₂) - f_κ(X₁) ≤ τ_κ
```
- f_κ(X)：序列 X 在目标 κ（铅或锌）下的功能测量值（fold change 或 response）
- τ_κ：目标 κ 的实验噪声阈值
- X₁, X₂：突变体序列对

**2. 条件生成概率**：
```
P_θ(X₂ | d, X₁) = ∏_{t=1}^{L} P_θ(X₂,t | d, X₁, X₂,<t)
```
- d：方向性 token 向量（如 ⟨inc⟩⟨dec⟩）
- X₂,t：目标序列第 t 个氨基酸
- X₂,<t：目标序列前 t-1 个氨基酸
- L：序列长度

**3. 训练目标**：
```
L(θ) = Σ_{i=1}^{N} log P_θ(X₂⁽ⁱ⁾ | d⁽ⁱ⁾, X₁⁽ⁱ⁾)
```
- N：配对样本总数
- θ：模型参数

**用途**：公式 1 将连续测量转化为离散方向标签，实现数据增强和噪声鲁棒；公式 2-3 定义序列生成的条件概率和训练目标，使模型学习"给定方向 token 和起始序列，生成目标序列"的映射。

## 10 实验设计与证据链
**数据集与规模**：
- 初始数据集（Round 0）：1,155 个 PbrR 突变体（含丙氨酸扫描 145 个、位点饱和突变 931 个、组合突变 79 个）
- 3,465 个 CFE 反应（每个突变体在 1 μM 铅、30 μM 锌、无配体条件下测试）
- Round 1：382 个预测突变体
- Round 2：200 个高阶突变体（100 个基于 FC 训练，100 个基于 DR 训练）
- Round 2b：10 个理性组合突变体（4-5 阶）
- Round 3：108 个重叠预测突变体
- Round 3b：169 个高阶组合突变体（4-6 阶）
- 总计筛选 2,024 个突变体

**指标**：
- 归一化 fold change（FC）：突变体相对野生型的响应倍数变化
- 归一化动态范围（DR）：配体存在/不存在时的信号差
- 铅/锌选择性：铅响应与锌响应的比值

**评测协议**：
- 每轮筛选后，通过手工实验验证 top 候选
- 最终候选在冻干无细胞反应中测试，使用真实市政水样（Evanston 和 Chicago, IL）
- 水样金属浓度通过 ICP-MS 定量

## 11 结论正确解读
- **任务范围**：本文工程化的是**转录因子 PbrR 的配体敏感性和选择性**，而非其 DNA 结合特异性。突变效应涉及 DNA 结合域（DBD）、螺旋-转角-螺旋域（HTH）和配体结合域（LBD），说明别构信号传导涉及全蛋白协同。
- **oracle/真值输入**：实验测量值（荧光强度）作为功能真值，但存在批次间噪声，通过方向性标签和噪声阈值缓解。
- **端到端状态**：从序列到功能的全流程闭环（ML 预测 → CFE 验证 → 数据反馈），但最终验证仅在冻干无细胞系统中完成，未进行活体细菌或动物实验。
- **算力成本**：使用 ProtT5-XL-UniRef50（约 30 亿参数）+ LoRA 微调，需要 GPU 资源，但 LoRA 显著降低显存需求。
- **历史数据依赖**：模型依赖初始 1,155 个突变体的筛选数据，这些数据来自先前工程化努力，可能引入选择偏差。
- **模型依赖**：T5 架构的选择基于其在蛋白质序列建模中的表现，但未与其他架构（如 ESM-2、MSA Transformer）系统比较。
- **最难情形**：同时优化多个相互制约的性状（灵敏度 vs 选择性）；低数据量下的外推；别构蛋白的非加性突变效应。
- **群体/领域边界**：结果基于 PbrR 单一蛋白，推广到其他 aTF 需要重新训练和筛选；无细胞系统与体内环境的差异未充分讨论。
- **不确定性**：未报告 ML 模型预测的置信区间；未进行多次独立实验的变异性分析。

## 14 学到什么
**Agent 提炼的知识候选**：

1. **配对方向性标签策略**：将连续测量值转化为离散方向 token（inc/dec），可消除批次效应、增强数据量（N→O(N²)），适用于任何噪声较大的高通量筛选数据。**可迁移到 TF–DNA 结合实验**：如将不同突变体的 DNA 结合亲和力变化标注为"增强/减弱"方向，训练模型学习序列–结合力映射。

2. **多目标 token 条件化生成**：通过组合多个方向 token（如 ⟨inc⟩⟨dec⟩），在单一模型中实现多目标优化，无需为每个目标训练独立预测器。**可迁移到 TF 工程**：同时优化 DNA 结合特异性、配体响应幅度、热稳定性等多个性状。

3. **主动学习 + 理性设计互补**：ML 模型提出非直观突变组合，理性设计组合已验证有益突变，两者交替使用可加速收敛。**可迁移到 TF–DNA 互作研究**：ML 预测候选 TF 突变体 → 实验验证 DNA 结合变化 → 反馈训练。

4. **全蛋白突变效应分布**：PbrR 的 DBD、HTH、LBD 域突变均影响配体敏感性，提示别构调控涉及全蛋白协同。**对 TF–DNA 互作的意义**：研究 TF 突变对 DNA 结合的影响时，不应局限于 DNA 结合域，需考虑远端别构效应。

5. **无细胞系统作为筛选平台**：CFE 系统可实现高通量、低成本、无细胞毒性的蛋白质功能筛选，特别适合毒性配体（如铅）的传感器开发。**可迁移**：TF–DNA 结合实验可在无细胞系统中进行，避免体内环境干扰。

6. **数据质量优先于数据量**：通过噪声阈值过滤低置信度数据，确保训练标签可靠性。**可迁移**：在构建 TF–DNA 结合数据集时，应设置结合亲和力测量的最小可信变化阈值。

## 15 与已有知识连接
- **Iterative Controlled Extrapolation (ICE)**：本文扩展了 ICE 框架（参考文献 58），从单目标扩展到多目标，从数值预测器改为方向性 token。ICE 原始框架用于蛋白质工程中的受控外推。
- **ProtT5-XL-UniRef50**：Rostlab 发布的蛋白质语言模型（参考文献 87），基于 T5 架构，在蛋白质序列表示学习上表现优异。本文首次将其用于方向性条件化序列生成。
- **ProteinDPO**（参考文献 57）：偏好学习用于蛋白质工程，但仅支持单目标。本文的多目标 token 方法是对其的推广。
- **DeepTFactor**（参考文献 51）和 **ESM-DBP**（参考文献 52）：分别用于 TF 识别和 DNA 结合蛋白预测，属于分类/发现任务，与本文的序列生成任务互补。
- **ROSALIND 系统**（参考文献 9）：冻干无细胞生物传感器，本文的冻干验证部分借鉴了该系统。
- **PbrR 生物学**：PbrR 来自 Cupriavidus metallidurans 的 pMOL30 大质粒（参考文献 65），是研究重金属响应的模式 aTF。其别构机制（Pb²⁺ 结合→DNA 弯曲→转录激活）已有较多研究。
- **与课题方向的连接**：本文虽未直接研究 TF–DNA 结合机制，但其**序列–功能映射方法**可迁移到 TF–DNA 结合特异性预测；其**别构突变效应分布**发现（DBD/HTH/LBD 均参与）为理解 TF 别构调控提供了数据支持。

## 16 研究想法
**Agent 生成的研究候选**：

1. **方向性 token 框架用于 TF–DNA 结合特异性工程**
   - **来源**：本文的多目标 token 方法可推广到 DNA 结合特异性优化
   - **核心假设**：TF 突变对 DNA 结合特异性的影响可通过方向性 token 编码（如"增强对位点 A 结合/减弱对位点 B 结合"）
   - **方法**：构建 TF 突变体配对数据集，标注 DNA 结合特异性变化方向，训练 T5 模型生成特异性改变的 TF 变体
   - **验证**：EMSA、SELEX-seq 或高通量结合实验
   - **创新状态**：unverified

2. **结合 MD 模拟与 ML 的别构路径预测**
   - **来源**：本文发现 PbrR 突变效应分布在整个蛋白，提示别构信号传导涉及多域协同
   - **核心假设**：MD 模拟可揭示突变如何通过别构路径影响 DNA 结合域构象，ML 可学习这些路径特征
   - **方法**：对 PbrR 突变体进行 MD 模拟，提取别构路径特征（如动态网络分析），训练 ML 模型预测突变对 DNA 结合的影响
   - **验证**：与本文实验数据对比
   - **创新状态**：unverified

3. **无细胞系统高通量 TF–DNA 结合筛选平台**
   - **来源**：本文的 CFE 筛选平台可扩展到 TF–DNA 结合实验
   - **核心假设**：CFE 系统可同时表达 TF 和报告基因，实现 TF–DNA 结合的高通量定量
   - **方法**：将 TF 表达与 DNA 结合报告系统（如荧光共振能量转移、报告基因）整合到 CFE 中
   - **验证**：与体外结合实验（EMSA、SPR）对比
   - **创新状态**：unverified

4. **多目标 TF 工程：同时优化 DNA 结合特异性与配体响应**
   - **来源**：本文的多目标优化框架可扩展到 TF 的多个功能维度
   - **核心假设**：TF 的 DNA 结合特异性和配体响应可通过组合方向 token 同时优化
   - **方法**：构建双目标数据集（DNA 结合特异性 + 配体响应），训练多 token 条件生成模型
   - **验证**：工程化 TF 在细胞和无细胞系统中的功能验证
   - **创新状态**：unverified

5. **利用有害突变信息改进 TF–DNA 结合预测模型**
   - **来源**：本文强调同时利用有益和有害突变信息
   - **核心假设**：功能丧失突变携带的序列–功能关系信息可提高预测模型对保守位点的识别
   - **方法**：将功能丧失突变作为负样本，训练对比学习模型，识别对 DNA 结合关键的残基
   - **验证**：与已知 TF–DNA 结合结构域注释对比
   - **创新状态**：unverified
