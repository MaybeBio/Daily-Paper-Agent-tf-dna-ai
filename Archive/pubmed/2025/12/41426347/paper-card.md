## 02 一句话总结

本文提出 Leonine 框架，将增强子（enhancer）序列设计重构为多模态问答任务，利用 HyenaDNA 大语言模型，以启动子序列、细胞类型和基因表达谱为条件，通过两阶段指令微调生成细胞类型特异性的增强子序列，并在 7 种脑细胞类型上验证了生成序列的生物学合理性。

## 03 研究问题

- **具体问题**：如何生成与特定启动子（promoter）在特定细胞类型中有效互作的增强子（enhancer）序列？现有方法要么只做增强子活性分类，要么独立生成序列，未考虑细胞类型特异性的多 TF 协同招募需求。
- **为什么重要**：增强子-启动子互作是基因调控的核心机制，细胞类型特异性的 TF 组合决定了转录激活的精确性。合成生物学和基因治疗需要设计在特定细胞环境中功能正确的调控序列。
- **现有方法不足**：
  1. 分类模型（如预测 promoter-enhancer 互作）只能判别已有序列，不能生成新序列；
  2. 生成模型通常从零训练或独立生成 enhancer，未利用细胞类型和基因表达等关键调控环境信息；
  3. 未将 enhancer 设计视为「给定启动子，生成配套增强子」的条件生成问题。
- **精确研究问题**：Can a DNA LLM, fine-tuned with multimodal cell context (cell type + gene expression + promoter sequence), generate enhancer sequences that are both cell-type-specific and functionally compatible with the given promoter?

## 06 核心思想

### 1) 表面方法
将 enhancer 序列生成定义为条件概率建模问题：给定细胞类型索引、基因表达谱和启动子序列，最大化增强子序列的似然。采用两阶段训练：先冻结 DNA LLM 和基因表达编码器，仅训练对齐模块；再端到端微调全部参数。

### 2) 核心洞察
- **增强子设计本质上是条件生成问题**：增强子不是孤立存在的序列，其功能取决于与特定启动子的配对关系以及所在细胞类型的 TF 环境。将问题重构为「promoter 作为问题，enhancer 作为答案」的问答形式，使模型天然学习 enhancer-promoter 的配对约束。
- **细胞上下文可作为语言 token 注入**：通过可训练的对齐张量（alignment tensors），将非序列模态（细胞类型、基因表达）转换为与 DNA token 嵌入同维度的向量，使 LLM 能「理解」细胞环境。
- **预训练 DNA LLM 是关键**：在人类基因组上预训练的 HyenaDNA 显著优于从零训练的 GPT-2，说明 DNA 序列的统计规律（如 motif 分布、GC 含量偏好）是生成生物学合理序列的基础。

### 3) 可能的普适教训 [Analysis]
- **将生物问题重构为条件生成任务**：许多生物序列设计问题（如启动子设计、sgRNA 设计）都可类比为「给定上下文，生成序列」的条件生成问题，多模态指令微调范式可迁移。
- **非序列模态的对齐注入**：细胞类型、基因表达等离散/连续信息可通过简单的线性投影注入 LLM 嵌入空间，无需复杂架构改动。
- **预训练的重要性超越参数规模**：本文中 14.2M 参数的预训练模型优于 137M 参数的从零训练模型，提示在生物序列任务中，领域预训练比模型容量更关键。

## 07 方法总览

- **输入**：
  - 细胞类型索引 $x_c \in \{0, \ldots, N\}$（离散）
  - 基因表达谱 $x_g \in \mathbb{R}^{d_g}$（连续向量）
  - 启动子序列 $x_p = x_1, \ldots, x_L$（DNA token 序列，L=1024 bp）
- **输出**：增强子序列 $y = y_1, \ldots, y_L$（L=500 bp，DNA token 序列）
- **模型架构**：
  - 主模型：HyenaDNA（预训练 DNA LLM，14.2M 参数）
  - 基因表达编码器：Geneformer（单细胞转录组编码器，冻结）
  - 细胞类型嵌入模块：可训练嵌入层 $e_\phi(\cdot)$
  - 模态对齐张量：$W_g$（基因表达→语言嵌入）、$W_c$（细胞类型→语言嵌入）
- **训练策略**：
  - **Stage 1（特征对齐预训练）**：冻结 Geneformer 和 HyenaDNA，仅训练 $\phi, W_g, W_c$，最小化条件似然损失
  - **Stage 2（端到端生成微调）**：更新 $\psi, \phi, W_g, W_c$（Geneformer 始终冻结）
- **损失函数**：负对数似然（公式 3）
- **生成方式**：从训练好的条件概率 $p_\theta(y | x_c, x_g, x_p)$ 中采样
- **文字流程**：
  1. 基因表达谱 $x_g$ 经 Geneformer 编码为特征 $z_g$，再经 $W_g$ 投影为语言嵌入 token $H_g$
  2. 细胞类型索引 $x_c$ 经嵌入层 $e_\phi$ 映射为向量 $z_c$，再经 $W_c$ 投影为语言嵌入 token $H_c$
  3. 拼接上下文 token $H_{ctx} = [H_c; H_g]$ 与启动子 token $H_p$
  4. 以自回归方式逐 token 生成增强子序列 $y$

## 09 关键公式符号

**公式 1（条件生成概率）**：
$$p(y | x_c, x_g, x_p) = \prod_{i=1}^{L} p_\theta(y_i | x_c, x_g, x_p, y_{<i})$$

- $y_i$：增强子序列第 $i$ 个位置的 DNA token（A/T/C/G）
- $y_{<i}$：前 $i-1$ 个已生成的 token
- $x_c$：细胞类型索引（离散值）
- $x_g$：基因表达谱（连续向量）
- $x_p$：启动子序列
- $L$：增强子序列长度（500 bp）
- $\theta$：可训练参数集合

**公式 2（模态对齐）**：
$$H_g = W_g \cdot z_g, \quad \text{其中 } z_g = g(x_g)$$
$$H_c = W_c \cdot z_c, \quad \text{其中 } z_c = e_\phi(x_c)$$

- $g(\cdot)$：Geneformer 编码器（冻结）
- $e_\phi(\cdot)$：可训练的细胞类型嵌入层
- $W_g \in \mathbb{R}^{l_g \times d_h}$：基因表达对齐张量
- $W_c \in \mathbb{R}^{l_c \times d_h}$：细胞类型对齐张量
- $H_g, H_c$：投影后的语言嵌入 token
- $d_h$：LLM 隐藏维度

**公式 3（训练损失）**：
$$\mathcal{L} = -\sum_{i=1}^{L} \log p_\theta(y_i | x_c, x_g, x_p, y_{<i})$$

- 标准自回归负对数似然损失
- $\theta = \{\psi, \phi, W_g, W_c\}$：可训练参数（$\psi$ 为 HyenaDNA 参数，$\phi$ 为细胞类型嵌入参数）

## 10 实验设计与证据链

### 数据集与设置
- **数据来源**：PsychENCODE 联盟
- **数据类型**：scATAC-seq（染色质可及性）和 scRNA-seq（基因表达）
- **互作对识别**：ArchR 工具，搜索距离 ±500kb，相关性 > 0.45
- **数据规模**：>150 万对 promoter-enhancer
- **细胞类型**：7 种脑细胞类型——兴奋性神经元（Ex）、抑制性神经元（In）、星形胶质细胞（Ast）、内皮细胞（End）、小胶质细胞（Mic）、少突胶质细胞（Oli）、少突胶质前体细胞（OPC）
- **序列长度**：promoter 1024 bp，enhancer 500 bp
- **参考基因组**：hg38
- **模型骨干**：HyenaDNA（14.2M 参数，预训练于人类基因组）；对比模型：Leonine-Gpt-2（137M 参数，从零训练）
- **基因表达编码器**：Geneformer（冻结）
- **评测指标**：
  - TF motif 富集分数（基于 JASPAR 2024 数据库，879 个 motif）
  - Jensen-Shannon (JS) 散度（比较生成与观测增强子的 motif 富集分布）
  - FID 分数（基于 7 个细胞类型二分类器的隐藏层嵌入）

## 11 结论正确解读

- **任务范围**：本文解决的是**增强子序列的条件生成**问题，而非增强子活性预测或 TF 结合位点预测。生成序列的「正确性」以分布相似性（JS 散度、FDR、R²）衡量，而非功能实验验证。
- **Oracle/真值输入**：训练数据中的 promoter-enhancer 配对来自 ArchR 基于共可及性（co-accessibility）的推断，并非实验验证的功能互作对。这意味着模型学习的是「统计关联」而非「因果功能」。
- **端到端状态**：模型是端到端训练的（Stage 2），但 Geneformer 编码器始终冻结，未参与微调。
- **算力成本**：未报告训练时间、GPU 数量等计算资源信息。
- **历史数据依赖**：模型依赖 PsychENCODE 数据集的细胞类型注释和基因表达测量质量；数据来自人脑组织，泛化到其他组织/物种未验证。
- **模型依赖**：依赖 HyenaDNA 预训练权重；依赖 Geneformer 的基因表达编码质量。
- **最难情形**：数据量较少的细胞类型（如内皮细胞）生成质量下降（R²=0.91），提示模型对数据稀疏性敏感。
- **不确定性**：未报告生成序列的多样性/重复性分析；未提供生成序列的生物学功能验证（如报告基因实验、CRISPR 扰动）。
- **有边界的复述**：Leonine 在 PsychENCODE 7 种脑细胞类型上，能够生成在 TF motif 分布和细胞类型特异性方面与观测增强子统计相似的序列，且预训练 DNA LLM 显著优于从零训练模型。但该结论仅限于统计分布层面，不涉及功能验证。

## 14 学到什么

> 标题：Agent 提炼的知识候选

### 可迁移概念

1. **条件生成作为互作建模的替代范式**：传统 TF–DNA 互作研究聚焦于「预测」——给定序列，预测 TF 是否结合。本文展示了「生成」路径——给定细胞环境，生成可能被 TF 结合的序列。这种生成视角可反向验证我们对 TF 结合规则的理解：如果生成序列在 motif 分布上与真实增强子一致，说明模型学到了部分 TF 结合规律。

2. **多模态上下文注入的轻量方案**：通过可训练的对齐张量（$W_g, W_c$）将非序列模态投影到 LLM 嵌入空间，无需修改 LLM 架构。这一思路可直接迁移到 TF–DNA 互作建模中：例如将 TF 浓度、染色质状态、表观遗传修饰等作为条件注入序列模型。

3. **两阶段训练策略**：先冻结主干模型仅训练对齐模块，再端到端微调。这种策略在数据有限时尤其有效，可避免随机初始化的对齐模块破坏预训练表示。对课题读者而言，若要在 DNA LLM 上添加新的条件模态（如 TF 结合谱），可借鉴此策略。

4. **「promoter 作为问题，enhancer 作为答案」的问答框架**：将互作关系编码为条件生成关系，而非直接预测互作概率。这种重构使模型隐式学习互作规则，且生成结果可直接用于合成生物学设计。

### 可迁移方法

5. **TF motif 富集分数作为生成质量的评估指标**：本文使用 JASPAR motif 富集分数和 JS 散度评估生成序列的生物学合理性。课题读者可借鉴此评估框架：在生成候选 TF 结合位点后，用 motif 富集分析验证生成序列是否富集目标 TF 的 motif。

6. **FID 风格的生成质量评估**：本文借鉴图像生成领域的 FID 指标，用分类器隐藏层嵌入的 Wasserstein 距离评估生成质量。此方法可迁移到 TF–DNA 结合位点生成任务中，用 TF 结合预测模型的嵌入层评估生成序列的「真实性」。

### 对课题方向的启示

7. **预训练 DNA 模型的价值再确认**：本文用 14.2M 参数的预训练 HyenaDNA 击败 137M 参数的从零训练 GPT-2，为课题方向选择预训练 DNA 模型（如 Nucleotide Transformer、DNABERT-2）作为骨干提供了实证支持。

8. **细胞类型条件生成的局限**：内皮细胞表现较差提示，数据稀疏的细胞类型是条件生成的主要瓶颈。课题读者在设计 TF–DNA 互作生成模型时，需考虑细胞类型/组织类型的数据覆盖度。

## 15 与已有知识连接

- **HyenaDNA**（Nguyen et al., 2023）：本文使用的骨干模型，一种基于 Hyena 架构的 DNA 专用 LLM，支持超长上下文（160k 核苷酸）。与课题方向的连接：HyenaDNA 已被用于多种基因组任务，其生成能力在本文中得到验证。

- **Geneformer**（Theodoris et al., 2023）：本文使用的单细胞转录组编码器，基于 BERT 架构在 3000 万个人类单细胞转录组上预训练。与课题方向的连接：Geneformer 提供了将基因表达谱编码为稠密向量的现成方案，可用于将细胞状态注入 DNA 序列模型。

- **PsychENCODE 联盟**（Wang et al., 2018）：提供人脑多组学数据，包括本文使用的 scATAC-seq 和 scRNA-seq。与课题方向的连接：该数据集的 promoter-enhancer 配对和细胞类型注释可作为 TF–DNA 互作研究的训练资源。

- **JASPAR 数据库**（Rauluseviciute et al., 2024）：本文使用的 TF motif 数据库（879 个 motif）。与课题方向的连接：JASPAR 是 TF–DNA 结合研究的基础资源，本文将其用于生成序列的评估。

- **Fréchet Inception Distance (FID)**（Heusel et al., 2017）：本文借鉴的生成质量评估指标，原用于图像生成。与课题方向的连接：将 FID 从图像域迁移到序列域，为 DNA 序列生成评估提供了新思路。

- **Instruction Tuning**（Wei et al., 2022; Ouyang et al., 2022）：本文借鉴的 LLM 微调范式，将多模态条件作为「指令」注入模型。与课题方向的连接：指令微调在 NLP 中已被广泛验证，本文将其扩展到 DNA 序列生成，为 TF–DNA 互作的条件建模提供了方法论参考。

- **ArchR**（Granja et al., 2021）：本文使用的 scATAC-seq 分析工具，用于识别 peak-to-gene 连接。与课题方向的连接：ArchR 的共可及性分析是推断增强子-启动子互作的常用方法，可作为 TF–DNA 互作研究的数据预处理工具。

## 16 研究想法

> 标题：Agent 生成的研究候选

### 候选 1：TF 条件化的 DNA 序列生成
- **名称**：TF-Conditioned Regulatory Sequence Generation
- **来源局限/观察**：Leonine 以细胞类型和基因表达为条件，但未显式指定目标 TF。细胞类型是 TF 环境的粗粒度代理，无法精确控制「生成富集特定 TF motif 的增强子」。
- **核心假设**：以 TF 名称（或 TF 结合谱）为条件，可生成富集特定 TF motif 的增强子序列，且生成质量优于以细胞类型为条件。
- **增量**：将条件从「细胞类型」细化为「TF 身份」，使生成更具可解释性和可操控性；可借鉴本文的多模态对齐框架，将 TF 名称嵌入为 token。
- **初步方法**：使用 JASPAR 的 TF 名称作为条件 token，与 promoter 序列一起输入 DNA LLM；训练数据使用 ChIP-seq 验证的 TF 结合增强子。
- **验证方式**：计算生成序列中目标 TF motif 的富集分数，与随机生成基线比较；用独立的 TF 结合预测模型（如 DeepSEA）验证生成序列的 TF 结合概率。
- **创新状态**：unverified

### 候选 2：多模态消融实验——解耦细胞类型与基因表达的贡献
- **名称**：Ablation Study of Multimodal Context Contributions
- **来源局限/观察**：本文未做消融实验，无法判断细胞类型和基因表达各自对生成质量的贡献。二者高度相关，可能冗余。
- **核心假设**：基因表达信息比细胞类型标签提供更细粒度的调控信号，单独使用基因表达即可达到与多模态相当的性能。
- **增量**：为多模态条件生成提供可解释的组件贡献分析，指导未来模型设计（是否可简化输入）。
- **初步方法**：在 Leonine 框架上分别训练三个变体：仅细胞类型、仅基因表达、两者皆有；在相同评测指标下比较。
- **验证方式**：JS 散度矩阵、FDR 分数、TF motif 富集 R² 的组间比较；统计显著性检验。
- **创新状态**：unverified

### 候选 3：生成序列的功能验证框架
- **名称**：In Silico Functional Validation of Generated Enhancers
- **来源局限/观察**：本文仅用统计分布指标评估生成序列，未验证其功能活性。分布相似不等于功能等价。
- **核心假设**：生成序列在功能预测模型（如染色质状态预测、表达定量）上的表现与观测增强子相当，可作为统计指标的补充验证。
- **增量**：建立生成序列的多层次验证框架，从序列统计→表观遗传状态→功能活性。
- **初步方法**：将生成序列输入 Enformer、Basenji 等模型，预测染色质状态和基因表达；比较生成与观测增强子的预测分布。
- **验证方式**：预测分布的 KL 散度或 Wasserstein 距离；与随机序列基线比较。
- **创新状态**：unverified

### 候选 4：TF–DNA 结合机制的可解释性分析
- **名称**：Interpretable Analysis of TF Binding Mechanisms in Generated Enhancers
- **来源局限/观察**：Leonine 生成序列的「黑箱」特性未提供 TF 结合机制层面的解释。生成序列中哪些位置对 TF 结合至关重要尚不明确。
- **核心假设**：对生成序列进行注意力权重分析，可揭示模型学到的 TF 结合位点位置偏好，与已知 motif 位置分布一致。
- **增量**：将生成模型从「工具」提升为「机制发现平台」，为 TF–DNA 结合规则提供新假设。
- **初步方法**：提取 HyenaDNA 的注意力权重，定位生成序列中对条件 token（细胞类型/基因表达）响应最强的位置；与 JASPAR motif 位置比较。
- **验证方式**：注意力热点与已知 motif 位置的重叠率；与随机位置基线的富集分析。
- **创新状态**：unverified

### 候选 5：跨物种/跨组织的泛化性测试
- **名称**：Cross-Species Generalization of Context-Aware Enhancer Generation
- **来源局限/观察**：本文仅在人类脑组织数据上验证，未测试模型对非脑组织或非人物种的泛化能力。
- **核心假设**：Leonine 框架可迁移到其他物种/组织，但需要重新训练或领域自适应。
- **增量**：评估模型泛化边界，为合成生物学的跨物种应用提供依据。
- **初步方法**：使用 ENCODE 或 FANTOM 数据训练/微调 Leonine，在小鼠或非脑组织上测试。
- **验证方式**：跨物种/组织的 JS 散度、FDR 分数；与人类脑组织结果对比。
- **创新状态**：unverified
