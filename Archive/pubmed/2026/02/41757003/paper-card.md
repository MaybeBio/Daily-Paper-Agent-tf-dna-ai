## 02 一句话总结
本文提出 Mahi——一个可扩展、可解释的图神经网络框架，通过预训练（掩码边重建）学习跨 290 个组织/细胞类型的基因嵌入，再整合 DeepSEA 调控序列特征与 ESM-C 蛋白结构特征，在 1,183 个癌细胞系上预测基因必需性（ROCAUC=0.921），并支持 in silico 基因敲除模拟以识别组织特异性通路。

## 03 研究问题
- **具体问题**：如何建模基因功能在组织/细胞类型特异性背景下的扰动效应（如基因敲除后果）？
- **为什么重要**：理解组织特异性基因功能是发现药物靶点和精准医学的关键；同一基因敲除在不同组织中可能产生完全不同的表型。
- **现有方法不足**：序列模型（DeepSEA、ESM）将每个基因/蛋白视为静态实体，缺乏组织背景；表达模型（Borzoi、scGPT）虽捕捉表达变异，但未整合调控与结构信息；图嵌入方法（node2vec）仅利用网络拓扑，忽略分子特征。
- **精确研究问题**：Can integrating tissue-specific network topology with multi-modal molecular features (chromatin accessibility, TF binding, histone modifications, protein structure) improve prediction of context-dependent gene essentiality and enable interpretable in silico perturbation modeling?

## 04 背景与发展脉络
（标注：以下脉络为「经外部核验」——基于文中引用与领域常识）

1. **序列→功能预测时代**：DeepSEA、Sei、Enformer 从 DNA 序列预测调控功能（TF 结合、染色质状态），但输出为静态调控注释，不直接建模基因级功能或组织背景。
2. **蛋白结构/功能模型**：ESM、AlphaFold2 从氨基酸序列推断蛋白结构与功能，但缺乏组织/细胞类型背景。
3. **表达图谱模型**：Borzoi（序列→表达）、scGPT（单细胞表达嵌入）捕捉表达变异，但未显式整合调控特征与网络拓扑。
4. **图嵌入方法**：node2vec 等学习网络节点嵌入，但仅利用拓扑，忽略分子特征。
5. **本文主张的位置**：Mahi 是首个将「调控序列特征 + 蛋白结构特征 + 组织特异性网络拓扑」三者整合的框架，通过两阶段（预训练 + 传播）实现组织感知的基因嵌入，填补了「静态分子特征」与「动态组织背景」之间的鸿沟。

## 06 核心思想
1. **表面方法**：两阶段框架——(1) 在 35 个代表性组织网络构成的 multigraph 上预训练 GNN（TransformerConv + 掩码边重建）；(2) 将 DeepSEA 调控嵌入与 ESM-C 蛋白嵌入拼接，通过 APPNP 在 290 个组织特异性网络上传播，得到组织感知的基因嵌入；下游用 XGBoost 预测必需性，用嵌入距离模拟敲除效应。
2. **核心洞察**：基因功能 = f(分子特征, 组织网络上下文)。预训练捕捉跨组织共享拓扑结构，APPNP 传播将静态分子特征「情境化」到具体组织，使嵌入空间反映组织特异性功能组织。
3. **可能的普适教训** [Analysis]：多模态特征整合的关键不是简单拼接，而是通过「预训练 + 传播」两阶段实现「先学通用结构，再调组织背景」；扰动模拟（敲除节点+边）比直接预测标签更具可解释性，可迁移到 TF–DNA 互作中的 TF 敲除模拟。

## 07 方法总览
- **输入**：(1) 19,073 个蛋白编码基因的 DNA 序列（hg38.p14，TSS 为中心 ±20,900 bp）；(2) 蛋白氨基酸序列（MANE 转录本）；(3) 290 个组织/细胞类型特异性功能网络（来自 HumanBase）；(4) 35 个代表性网络构成的 multigraph。
- **输出**：每个基因在 290 个组织中的 512 维嵌入向量；下游任务输出（必需性概率、敲除效应评分）。
- **模块**：(1) 序列嵌入生成（DeepSEA 滑动窗口 + 指数衰减加权）；(2) 蛋白嵌入生成（ESM-C 600M，残基平均）；(3) GNN 预训练（TransformerConv ×4，掩码边重建）；(4) APPNP 组织特异性传播（k=8, α=0.6）；(5) 下游预测（XGBoost）与扰动分析。
- **训练**：预训练用自监督掩码边重建（二元交叉熵，Adam，lr=0.001，batch=128，20 epochs）；下游 XGBoost 每细胞系独立训练（80/20 划分，5 折交叉验证调参）。
- **反馈回路**：无显式反馈回路；预训练与下游任务解耦。
- **文字流程**：DNA 序列→DeepSEA 嵌入；蛋白序列→ESM-C 嵌入；两者拼接→作为节点特征；在 multigraph 上预训练 GNN 得到基础嵌入→对每个组织网络用 APPNP 传播→得到组织特异性嵌入→XGBoost 预测必需性 / 敲除模拟计算嵌入位移。

## 09 关键公式符号
1. **TransformerConv 层**（方法节）：
   - $q_i^{(l)} = W_Q^{(l)} x_i^{(l)}$（query）
   - $k_{ij}^{(l)} = W_K^{(l)} x_j^{(l)} + W_E^{(l)} e_{ij}$（key，含边特征）
   - $v_{ij}^{(l)} = W_V^{(l)} x_j^{(l)} + W_E^{(l)} e_{ij}$（value，含边特征）
   - 用途：图注意力传播，整合节点与边特征
   - 直觉：节点 i 从邻居 j 聚合信息时，同时考虑边（组织关系）特征

2. **注意力系数**：
   - $\alpha_{ij}^{(l)} = \text{softmax}_{j \in N(i)} \frac{(q_i^{(l)})^T k_{ij}^{(l)}}{\sqrt{d}}$
   - 用途：控制节点 i 从 j 接收的信息量
   - 直觉：与标准 Transformer 注意力一致，但分母为 $\sqrt{d}$（d=512）

3. **聚合**：
   - $x_i^{(l+1)} = W_{\text{root}} x_i^{(l)} + \sum_{j \in N(i)} \alpha_{ij}^{(l)} v_{ij}^{(l)}$
   - 用途：更新节点表示，保留自身信息（root 连接）+ 邻居聚合

4. **掩码边重建损失**（预训练）：
   - $L_{ij} = -\frac{1}{d} \sum_{t=1}^{d} [y_{ij}^{(t)} \log(\sigma(\hat{y}_{ij}^{(t)})) + (1-y_{ij}^{(t)}) \log(1-\sigma(\hat{y}_{ij}^{(t)}))]$
   - 其中 d=35（组织数），$y_{ij}^{(t)}$ 为边在组织 t 中的真实标签，$\hat{y}_{ij}^{(t)}$ 为预测
   - 用途：多标签二元交叉熵，预测掩码边属于哪些组织

5. **APPNP 传播**（方法节）：
   - $P = D^{-1/2} A D^{-1/2}$（对称归一化邻接矩阵）
   - $X^{(k)} = (1-\alpha) P X^{(k-1)} + \alpha X^{(0)}$
   - 用途：在组织网络上传播特征，k=8 步，α=0.6
   - 直觉：每次迭代保留 60% 原始特征，40% 来自邻居，避免过平滑

6. **敲除效应评分**：
   - $FC_i = \frac{d_i}{\bar{d}_{\text{random}}}$，其中 $d_i = \|E_{WT,i} - E_{KO,i}\|_2$
   - 用途：归一化敲除后嵌入位移，与 200 次随机敲除背景比较

## 11 结论正确解读
- **任务范围**：预测基因必需性（二元分类）和模拟单基因敲除的嵌入位移；不涉及 TF–DNA 结合位点预测或结合亲和力。
- **oracle/真值输入**：必需性标签来自 DepMap 实验 CRISPR 数据；网络结构来自 HumanBase（基于表达+PPI 推断）。
- **端到端状态**：非端到端——预训练 GNN 与下游 XGBoost 解耦；敲除模拟依赖预训练模型，未重新训练。
- **算力成本**：未报告；预训练 20 epochs，4 层 TransformerConv，可推断为中等规模。
- **历史数据依赖**：依赖 HumanBase 网络（基于大量历史表达/PPI 数据）和 DepMap 筛选数据。
- **模型依赖**：DeepSEA 和 ESM-C 为冻结特征提取器，不微调。
- **最难情形**：上下文必需性基因（仅在少数细胞系中必需）预测难度高；类别不平衡（10-12% 阳性）。
- **群体/领域边界**：仅限人类蛋白编码基因；癌细胞系必需性可能不完全代表正常组织。
- **不确定性**：未报告置信区间（除 ROCAUC/PRAUC 标准差）；敲除模拟未与实验敲除转录组验证。
- **有边界的复述**：Mahi 在 1,183 个癌细胞系上，利用组织特异性网络+多模态分子特征，能以 ROCAUC≈0.92 预测基因必需性，并能通过嵌入位移模拟敲除效应、富集到已知疾病通路；但该性能限于人类基因、依赖 HumanBase 网络质量、且敲除模拟未经实验验证。

## 14 Agent 提炼的知识候选
**可迁移到 TF–DNA 互作 × AI/物理模拟课题的方法与概念**：

1. **多模态调控特征整合策略**：将「序列调控特征（DeepSEA 输出，含 TF 结合预测）+ 蛋白结构特征（ESM-C）」拼接后作为节点特征，在网络上传播。→ 可迁移：预测 TF–DNA 结合时，可将「DNA 序列特征 + TF 蛋白结构特征 + 染色质状态」整合，而非仅用序列。
2. **两阶段「预训练+传播」范式**：先在大规模多组织网络上预训练通用嵌入，再用 APPNP 在特定组织网络上情境化。→ 可迁移：TF–DNA 结合具有细胞类型特异性，可先预训练通用 TF 结合模型，再在特定细胞类型的调控网络上传播以细化。
3. **掩码边重建作为自监督任务**：预测掩码边属于哪些组织，迫使模型学习跨组织共享与特异的结构。→ 可迁移：可设计「掩码 TF–DNA 结合边重建」任务，预训练模型学习调控网络结构。
4. **In silico 扰动模拟框架**：移除节点+边后重算嵌入，计算位移并做通路富集。→ 可迁移：模拟 TF 敲除或 TF 结合位点突变，观察下游基因嵌入位移，识别受影响的调控通路。
5. **上下文必需性分析**：区分 pan-essential 与 context-essential 基因，评估模型对稀有事件的预测能力。→ 可迁移：区分「通用 TF」与「细胞类型特异 TF」的结合模式，评估模型对特异结合的预测能力。
6. **嵌入空间可视化验证**：PCA + 凸包面积量化组织特异性分散度。→ 可迁移：验证 TF 嵌入是否反映其已知的组织特异性表达/功能。

## 15 与已有知识连接
- **DeepSEA**（Zhou & Troyanskaya, 2015, Nature Methods）：本文直接使用 DeepSEA 作为调控特征提取器，其输出包含 TF 结合、染色质可及性、组蛋白修饰预测。→ 与 TF–DNA 结合预测直接相关。
- **ESM**（Lin et al., 2023, Science）：蛋白语言模型，本文用于编码蛋白结构/功能特征。→ 可用于编码 TF 蛋白序列特征。
- **Graph Transformer / TransformerConv**（Shi et al., 2021, arXiv:2103.03236）：本文 GNN 骨干，整合边特征。→ 可迁移到 TF–DNA 互作图（TF-基因-调控元件异质图）。
- **APPNP**（Klicpera et al., 2019, ICLR）：传播方法，避免过平滑。→ 可用于调控网络上的特征传播。
- **DepMap / CRISPR 筛选**（Tsherniak et al., 2017, Cell）：必需性数据来源。→ 可提供 TF 必需性的实验标签。
- **HumanBase**（Greene et al., 2015, Nature Genetics）：组织特异性功能网络。→ 可提供组织特异性调控网络。
- **与 AlphaFold2 的关系**：本文未用 AlphaFold2，但 ESM-C 与 AlphaFold2 同源。→ 对 TF–DNA 互作，AlphaFold2 或 AF3 可预测 TF 结构，与本文的蛋白特征思路互补。
- **与分子模拟（MD/对接）的关系**：本文是纯数据驱动，未涉及物理模拟。→ 可迁移思路：将 MD 模拟得到的 TF–DNA 结合构象特征作为额外模态，替代或补充 ESM-C 嵌入。

## 16 Agent 生成的研究候选

**候选 1：TF 组织特异性结合预测器（TF-TissueGNN）**
- **名称**：Tissue-aware GNN for cell-type-specific TF–DNA binding prediction
- **来源局限/观察**：现有 TF–DNA 结合预测模型（如 DeepSEA、Enformer）为静态预测，缺乏细胞类型背景；Mahi 证明组织网络传播可提升下游预测。
- **核心假设**：将 TF 结合预测从「序列+染色质」扩展到「序列+染色质+组织网络传播」，可提升细胞类型特异结合预测。
- **初步方法**：以 TF 结合位点（peak）为节点，构建跨细胞类型调控网络；节点特征 = DNA 序列嵌入（DeepSEA）+ TF 蛋白嵌入（ESM-C）；预训练掩码边重建（预测 peak 在哪些细胞类型中结合）；下游用 XGBoost 预测细胞类型特异结合。
- **验证方式**：ENCODE 或 Cistrome 细胞类型特异 ChIP-seq 数据；对比 DeepSEA、Enformer 基线。
- **创新状态**：unverified

**候选 2：TF 敲除的 in silico 模拟与通路重布线分析**
- **名称**：In silico TF knockout for regulatory network rewiring
- **来源局限/观察**：Mahi 的敲除模拟（移除节点+边）能富集到疾病通路，但未与实验验证；TF 敲除的调控后果预测是 TF–DNA 互作领域的关键问题。
- **核心假设**：在组织特异性调控网络上模拟 TF 敲除（移除 TF 节点及其结合边），计算下游基因嵌入位移，可预测 TF 敲除的转录组后果。
- **初步方法**：用 Mahi 框架（或类似 GNN）在 TF–基因调控网络上预训练；对目标 TF 执行节点+边移除；计算全网络嵌入位移；对位移大的基因做 GO/KEGG 富集。
- **验证方式**：与 CRISPR 敲除 TF 的转录组数据（如 DepMap 或 LINCS L1000）对比；检查富集通路是否与已知 TF 功能一致。
- **创新状态**：unverified

**候选 3：TF–DNA 结合的多模态特征消融研究**
- **名称**：Ablation study of multi-modal features for TF–DNA binding prediction
- **来源局限/观察**：Mahi 未做消融实验，无法判断 DeepSEA 与 ESM-C 特征的相对贡献；TF–DNA 结合预测中，DNA 序列特征与 TF 蛋白特征的相对重要性未知。
- **核心假设**：不同 TF 家族对 DNA 序列特征与蛋白结构特征的依赖不同（如锌指蛋白更依赖 DNA 序列，bHLH 更依赖二聚化结构）。
- **初步方法**：在 TF–DNA 结合预测任务上，分别使用 (a) 仅 DNA 序列特征、(b) 仅 TF 蛋白特征、(c) 两者拼接，对比性能；按 TF 家族分层分析。
- **验证方式**：Cis-BP 或 TRANSFAC 结合数据；报告各特征组合的 ROCAUC/PRAUC。
- **创新状态**：unverified

**候选 4：结合物理模拟的 TF–DNA 结合能预测**
- **名称**：Hybrid GNN-MD for TF–DNA binding affinity prediction
- **来源局限/观察**：Mahi 使用 ESM-C 蛋白嵌入，但未利用原子级结构信息；MD 模拟可提供 TF–DNA 结合的构象与能量信息，但计算昂贵。
- **核心假设**：将 MD 模拟得到的结合自由能或构象特征作为额外模态，可提升结合亲和力预测，尤其对突变体。
- **初步方法**：对已知 TF–DNA 复合物做短 MD 模拟，提取结合界面特征；与 Mahi 式嵌入拼接；训练回归模型预测结合亲和力。
- **验证方式**：ProTherm 或 DeepBind 突变数据；对比仅用序列/结构嵌入的基线。
- **创新状态**：unverified
