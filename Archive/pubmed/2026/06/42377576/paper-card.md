## 02 一句话总结

RGTBind 将 AlphaFold2 预测结构建模为残基级图，用多尺度 RBF 距离编码和可学习阈值门控的图 transformer 实现空间偏置注意力，在 Test_129 和 Test_181 基准上取得最优 F1、AUC 和 MCC，验证了距离感知注意力与结构引导邻居选择对残基级蛋白-DNA 结合位点预测的有效性。

## 03 研究问题

- **具体问题**：给定一个蛋白质（其三维结构已知或可由 AlphaFold2 预测），如何准确预测哪些残基参与 DNA 结合（即残基级 binding-site 预测）？
- **为什么重要**：蛋白-DNA 结合位点识别是理解基因调控、转录因子结合机制和蛋白质功能注释的基础；准确的残基级预测可为后续分子对接、突变分析和 TF–DNA 互作机制研究提供候选位点。
- **现有方法为何不足**：传统序列方法（如 PSSM/HMM 特征 + 分类器）忽略三维空间邻近性；早期结构方法依赖实验解析结构（成本高、覆盖有限）；已有图神经网络方法虽利用结构，但**邻居选择缺乏结构引导**，且**距离信息编码方式单一**（如二值化或线性 bin），难以捕捉多尺度空间相互作用。
- **精确研究问题（Can 问题）**：Can a graph transformer with multi-scale RBF distance encoding and a learnable threshold gate for neighbor selection outperform existing methods on residue-level protein-DNA binding-site prediction benchmarks?

## 06 核心思想

### 1) 表面方法
将蛋白质表示为残基级图（节点=残基，边=基于空间距离的邻居关系），节点特征融合 AlphaFold2 单表示、DSSP 结构描述符、PSSM 和 HMM profile；边特征用多尺度 RBF 编码 Cα-Cα 距离；通过图 transformer 的 self-attention 引入空间偏置，并用可学习阈值门控选择结构引导的邻居。

### 2) 核心洞察
- **多尺度 RBF 距离编码**：不同尺度的 RBF 基函数可以同时捕捉短程（接触）和长程（结构域间）距离信息，比单一 bin 编码更丰富。
- **可学习阈值门控**：不是所有空间邻近残基都同等重要，模型应**学习**哪些距离范围内的邻居对当前残基的 DNA 结合状态最有判别力——即邻居选择本身是可学习的。
- **空间偏置注意力**：在注意力权重中显式注入距离偏置，使模型在聚合邻居信息时优先关注空间上更相关的残基。

### 3) 可能的普适教训 [Analysis]
- 对 TF–DNA 结合机制研究：**结合位点残基往往在空间上聚集而非序列上连续**，因此任何基于序列的模型都天然受限；结构感知的图模型是更自然的选择。
- 距离编码的**多尺度性**可能对 DNA 结合界面特别重要，因为结合界面既包含直接接触残基（短距离），也包含支撑界面的结构残基（中长距离）。
- 可学习邻居选择的思想可迁移到其他互作预测任务（如蛋白-蛋白、蛋白-RNA），因为不同界面残基的局部几何环境差异显著。

## 07 方法总览

- **输入**：蛋白质氨基酸序列（用于 AlphaFold2 预测结构 + 序列特征提取）
- **输出**：每个残基的 DNA 结合概率（二分类：结合/非结合）
- **特征构建**：
  - 节点特征：AlphaFold2 单表示（single representation）+ DSSP 结构描述符 + PSI-BLAST PSSM + HHblits HMM profile
  - 边特征：Cα-Cα 距离经多尺度 RBF 编码
- **图构建**：以 AlphaFold2 预测结构为几何基础，残基为节点，边由空间距离决定（结合可学习阈值门控）
- **模型架构**：Graph Transformer，含 spatially biased multi-head self-attention + learnable threshold gate
- **训练**：AdamW 优化器，五折交叉验证（Train_573），CD-HIT 去冗余
- **评测**：独立测试集 Test_129 和 Test_181，指标为 F1、AUC、MCC
- **文字流程**：
  1. 输入蛋白序列 → AlphaFold2 预测 3D 结构
  2. 从序列和结构提取节点特征（AF2 单表示、DSSP、PSSM、HMM）
  3. 计算所有残基对 Cα-Cα 距离 → 多尺度 RBF 编码为边特征
  4. 构建残基级图（节点+边）
  5. 图 transformer 前向传播：空间偏置注意力 + 阈值门控邻居选择
  6. 输出每个残基的结合概率 → 与阈值比较得二分类预测

## 14 Agent 提炼的知识候选

> 面向「蛋白质-DNA 互作（聚焦 TF–DNA 结合机制）× AI/物理模拟」课题的可迁移知识：

1. **多尺度 RBF 距离编码（可直接迁移）**
   - 概念：用多个不同中心/带宽的 RBF 基函数编码残基间 Cα-Cα 距离，替代单一 bin 或线性编码。
   - 迁移到 TF–DNA：在 TF–DNA 复合物建模中，可用多尺度 RBF 编码 TF 残基与 DNA 碱基/骨架原子间的距离，作为几何特征输入到图网络或作为 MD 模拟的偏置势。
   - 理由：TF–DNA 结合界面同时包含直接接触（氢键、范德华，短距离）和间接支撑（结构域折叠、长程静电，中长距离），多尺度编码天然匹配这种多尺度物理相互作用。

2. **可学习阈值门控的邻居选择（可迁移）**
   - 概念：不预设固定 k-NN 或固定半径阈值，而是让模型学习哪些距离范围内的邻居对预测最有判别力。
   - 迁移到 TF–DNA：在 TF–DNA 互作界面预测中，不同 TF 家族（如锌指、bZIP、homeodomain）的结合界面几何差异大，可学习邻居选择可自适应不同结合模式。
   - 理由：TF 结合界面的空间尺度因家族而异，固定阈值无法覆盖所有情况。

3. **空间偏置注意力（可迁移）**
   - 概念：在 transformer 注意力权重中显式注入距离偏置，使模型优先关注空间邻近残基。
   - 迁移到 TF–DNA：在 TF–DNA 共折叠或复合物结构预测中，可用空间偏置注意力引导模型关注空间接触的 TF 残基-DNA 碱基对。
   - 理由：DNA 结合界面本质上是空间邻近的残基-碱基接触，空间偏置可减少注意力分散。

4. **AlphaFold2 结构作为输入的可行性验证（可迁移）**
   - 概念：使用 AF2 预测结构而非实验结构作为几何输入，在基准上取得最优性能。
   - 迁移到 TF–DNA：对无实验结构的 TF，可用 AF2 预测结构作为 MD 模拟起点或对接输入，本文验证了 AF2 结构在结合位点预测中的可用性。
   - 理由：许多 TF 缺乏实验结构，AF2 结构是实际可用的替代方案。

5. **多源特征融合策略（可迁移）**
   - 概念：融合序列进化信息（PSSM、HMM）与结构信息（DSSP、AF2 表示）。
   - 迁移到 TF–DNA：TF–DNA 结合特异性既由序列决定（motif），也由结构决定（构象适配），多源融合是自然选择。
   - 理由：单一特征源信息不完整，融合可互补。

## 15 与已有知识连接

- **AlphaFold2 结构预测**：本文使用 AF2 预测结构作为输入，与 Jumper et al. (2021, Nature) 的 AF2 工作直接相关。AF2 结构在结合位点预测中的可用性已被多项工作验证（如 DeepSite、GraphSite 等），本文延续此方向。
- **图 transformer 在蛋白质任务中的应用**：与 ProteinMPNN (Dauparas et al., 2022)、GearNet (Zhang et al., 2022) 等图神经网络方法同属「结构-图」范式。本文的贡献在于空间偏置注意力和可学习邻居选择。
- **RBF 编码在结构建模中的应用**：RBF 在分子描述符（如 Behler-Parrinello symmetry functions）和等变网络（如 SchNet, Schütt et al., 2017）中广泛使用。本文将其引入图 transformer 的边编码，属于跨领域迁移。
- **DNA 结合位点预测**：与 DeepSite、DNABind、ProNA2020 等方法同任务。本文的差异化在于使用 AF2 结构 + 图 transformer + 空间偏置。
- **TF–DNA 结合机制**：本文预测的是「哪些残基结合 DNA」，是 TF–DNA 互作机制研究的上游步骤。结合位点预测结果可作为 MD 模拟的初始接触残基集合，或作为突变实验的候选位点。
- **[Analysis] 候选连接**：本文方法可进一步与等变图网络（如 EGNN、SE(3)-Transformer）结合，以显式利用旋转等变性；也可与 DNA 序列信息联合建模，预测 TF 结合特异性（motif 偏好）。

## 16 Agent 生成的研究候选

> 以下候选均基于本文方法，面向「TF–DNA 结合机制 × AI/物理模拟」课题。

### 候选 1：TF–DNA 复合物界面残基-碱基对预测
- **名称**：RGTBind-Interface：扩展 RGTBind 到 TF–DNA 复合物界面预测
- **来源局限/观察**：RGTBind 仅预测蛋白侧结合残基，未建模 DNA 侧碱基；TF–DNA 结合机制需要残基-碱基配对信息
- **核心假设**：将 RGTBind 的图 transformer 扩展为「双图」（蛋白图 + DNA 图），用空间偏置注意力建模残基-碱基交叉注意力，可同时预测结合残基和结合碱基
- **初步方法**：蛋白残基图 + DNA 碱基图，交叉注意力层用 RBF 编码残基-碱基距离；训练数据用 PDB 中 TF–DNA 复合物结构
- **验证方式**：在 TF–DNA 复合物基准上评估残基-碱基配对预测的 F1/AUC；与 RGTBind 单侧预测对比
- **创新状态**：unverified

### 候选 2：结合位点预测引导的 TF–DNA 对接
- **名称**：Bind2Dock：RGTBind 预测结果作为 TF–DNA 对接的约束
- **来源局限/观察**：RGTBind 预测结合残基，但未利用该信息进行构象采样；TF–DNA 对接（如 HADDOCK、ATTRACT）需要接触残基先验
- **核心假设**：将 RGTBind 预测的结合残基作为对接中的「主动残基」约束，可提高 TF–DNA 对接的命中率
- **初步方法**：RGTBind 预测结合残基 → 映射为 HADDOCK 主动残基 → 执行对接 → 评估近天然构象比例
- **验证方式**：在已知 TF–DNA 复合物上做对接回测，比较有/无 RGTBind 约束的对接成功率
- **创新状态**：unverified

### 候选 3：结合位点预测与 MD 模拟的闭环
- **名称**：Bind-MD：RGTBind 预测位点作为 MD 模拟的初始接触集合
- **来源局限/观察**：RGTBind 是静态预测，未考虑结合过程中的构象动态；TF–DNA 结合是动态过程
- **核心假设**：以 RGTBind 预测的结合残基为初始接触集合，进行 MD 模拟，可揭示结合路径和关键中间态
- **初步方法**：RGTBind 预测 → 构建 TF–DNA 初始复合物 → 全原子 MD 模拟 → 分析接触残基演化
- **验证方式**：与实验已知的结合路径/中间态对比；分析预测残基在模拟中的稳定性
- **创新状态**：unverified

### 候选 4：TF 家族特异性的结合位点预测
- **名称**：RGTBind-Family：按 TF 家族分组建模
- **来源局限/观察**：RGTBind 是通用模型，未区分 TF 家族；不同家族（锌指、bZIP、homeodomain）结合模式差异大
- **核心假设**：按 TF 家族分别训练 RGTBind，可捕捉家族特异的结合模式，提升预测精度
- **初步方法**：按 TF 家族划分训练集，分别训练 RGTBind 变体；测试时先预测家族再选择模型
- **验证方式**：对比通用模型与家族特异模型在各家族测试集上的 F1/AUC
- **创新状态**：unverified

### 候选 5：结合位点预测与结合亲和力预测的联合建模
- **名称**：Bind-Affinity：多任务学习同时预测结合位点和结合亲和力
- **来源局限/观察**：RGTBind 仅预测二分类结合位点，未输出结合强度；TF–DNA 结合机制需要定量理解
- **核心假设**：结合位点预测与结合亲和力预测共享表征，多任务学习可互相促进
- **初步方法**：RGTBind 架构增加亲和力回归头；训练时联合优化分类损失和回归损失
- **验证方式**：在包含结合亲和力数据的 TF–DNA 数据集上评估两个任务的性能
- **创新状态**：unverified

### 候选 6：RBF 门控机制迁移到蛋白-RNA 互作预测
- **名称**：RGTBind-RNA：迁移到蛋白-RNA 结合位点预测
- **来源局限/观察**：RGTBind 的 RBF 距离编码和门控机制是通用的，不限于蛋白-DNA
- **核心假设**：RGTBind 架构可迁移到蛋白-RNA 结合位点预测，且同样优于现有方法
- **初步方法**：替换训练数据为蛋白-RNA 结合数据集，保持架构不变
- **验证方式**：在蛋白-RNA 基准上评估，与现有方法对比
- **创新状态**：unverified
