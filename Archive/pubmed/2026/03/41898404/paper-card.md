## 02 一句话总结

本文用随机森林模型，以 379 个已知 TFBS 的 PWM 在杨树启动子上的出现与否为特征，从多组织 RNA-seq 数据中预测组织特异性 TFBS，据此在根特异基因 PopRTS1 的启动子中锁定 −396~−781 bp 区域，组装出合成启动子 PRTS1，并通过 GUS 染色在杨树和烟草中验证了其根特异性表达。

## 03 研究问题

- **具体问题**：如何从全基因组启动子序列和转录组数据中，系统性地识别组织特异性 cis-regulatory modules (CRMs)，并据此设计功能性的组织特异性合成启动子？
- **为什么重要**：合成启动子是实现转基因植物精准时空表达的关键工具，但传统设计依赖人工拼接已知 CRE，效率低、特异性差。杨树是木本模式植物，其组织特异性启动子（尤其是根特异）对林木遗传改良和生物燃料生产有直接应用价值。
- **现有方法不足**：
  1. 传统合成启动子设计多基于文献中已知 CRE 的随机拼接，缺乏系统性的全基因组筛选；
  2. 已有 ML 工作多聚焦诱导型（inducible）启动子，对组织特异性（尤其是木本植物）研究较少；
  3. 保守基序（conserved motif）与功能性基序（functional motif）并不等价——本文发现保守性排名与 ML 特征重要性排名无正相关（Results 2.4 节），说明仅靠保守性无法识别组织特异性元件。
- **精确研究问题（Can...?）**：Can a random forest model trained on genome-wide TFBS presence/absence and tissue-specific gene expression labels identify functional root-specific cis-regulatory modules that can be assembled into a synthetic promoter with experimentally verifiable root specificity in poplar?

## 04 背景与发展脉络

> 注：以下脉络基于本文 Introduction 和 Discussion 的引用与论述，属于「仅本文框架」，未经外部系统核验。

1. **阶段一：合成启动子的早期设计（拼接已知 CRE）**
   - 代表方法：将多个已知 cis-elements 或随机序列与核心启动子（如 35Smini）拼接，再筛选。
   - 优点：简单直接，已有成功案例。
   - 局限：依赖已知元件，难以发现新元件；组织特异性难以精确控制；耗时耗力。

2. **阶段二：计算预测辅助启动子设计**
   - 代表方法：用生物信息学工具（如 FIMO）扫描启动子中的已知 TFBS 基序。
   - 优点：可批量处理全基因组。
   - 局限：仅给出「存在与否」，不提供组织特异性信息；保守基序 ≠ 功能性基序。

3. **阶段三：机器学习解码 cis-regulatory code（本文位置）**
   - 代表方法：以 TFBS 出现与否为特征，以基因表达模式（τ 值分类）为标签，训练随机森林分类器，用特征重要性筛选组织特异性 TFBS。
   - 优点：可同时处理全基因组数据，输出可直接用于启动子设计的「信息性 TFBS」列表；不依赖先验的 CRE 功能注释。
   - 局限（本文承认）：模型仅用 TFBS 有无作为特征，未纳入基序间距、方向、染色质状态等；预测的是「TFBS 对分类的贡献」，而非直接的 TF–DNA 结合亲和力或三维结构信息。

4. **阶段四（展望）**：整合表观基因组（染色质可及性、甲基化）、单细胞数据、以及更先进的深度学习模型（如 CNN/Transformer 直接读序列）来进一步提升组织特异性 CRM 的预测精度。

## 06 核心思想

### 1) 表面方法
- 用 FIMO 以 379 个已知 TFBS 的 PWM 扫描所有基因的启动子区域（0.5–3.2 kb 多种长度）；
- 以 TFBS 出现与否构建二元特征矩阵；
- 用 τ 值将基因分为组织特异、组成型、沉默、中间频率四类；
- 训练随机森林分类器，用置换重要性（permutation importance）筛选对组织特异性分类贡献最大的 TFBS；
- 在根特异基因 PopRTS1 的启动子中，用筛选出的高重要性 TFBS 富集区域组装合成启动子 PRTS1/PRTS2，实验验证。

### 2) 核心洞察
- **保守性 ≠ 信息性**：ML 特征重要性排名与基序保守性排名无正相关，说明「进化保守」和「组织特异性功能」是两个正交维度。组织特异性启动子设计应优先考虑 ML 筛选出的高信息性 TFBS，而非仅看保守基序。
- **CRM 是 TFBS 的局部富集**：在 PopRTS1 启动子中，高重要性 TFBS 并非均匀分布，而是富集在 −396~−781 bp 区域，该区域单独即可驱动根特异表达；相邻区域（−1~−457 bp，含较多保守但低信息性 TFBS）则无此功能。这支持「CRM 是多个信息性 TFBS 的协同簇」这一模型。
- **负对照的价值**：PRTS2（含保守但低信息性 TFBS 的区域）丧失根特异性，反向验证了 ML 筛选的有效性。

### 3) 可能的普适教训 [Analysis]
- 在 TF–DNA 互作研究中，若目标是「组织/条件特异性结合」，则仅靠序列保守性或 ChIP-seq 峰的重叠是不够的；需要将 TFBS 与下游基因的表达状态（如 τ 值）联合建模，才能区分「管家结合」与「特异性调控结合」。
- 随机森林的置换重要性提供了一种可解释的特征筛选方式，适合作为深度学习模型的基线或预筛选步骤。
- 本文的「先全基因组筛选 → 再局部富集 → 最后合成验证」三步流程，可迁移到其他物种或细胞类型特异性的启动子设计。

## 07 方法总览

- **输入**：
  - P. trichocarpa（24 组织）和 P. tomentosa（8 组织）的 RNA-seq 表达数据；
  - 全基因组注释（41,335 / 34,106 个基因）；
  - 379 个已知 TF 的 PWM（PlantTFDB v5.0）；
  - 启动子序列（0.5–3.2 kb 多种长度，相对 ATG）。
- **输出**：
  - 组织特异性 TFBS 列表（按置换重要性排名）；
  - 根特异合成启动子 PRTS1（经验证）和 PRTS2（阴性对照）。
- **模块**：
  1. 表达分类模块：τ 值计算 → 四类基因标签；
  2. 基序扫描模块：FIMO 扫描启动子 → TFBS 二元特征矩阵；
  3. ML 训练模块：随机森林 + 10 折交叉验证 + 网格搜索超参数；
  4. 特征筛选模块：置换重要性排名，取 top 50；
  5. CRM 定位模块：在目标基因启动子中标注高重要性 TFBS 的富集区域；
  6. 合成与验证模块：组装 PRTS1/PRTS2 → 农杆菌渗透（杨树 84k）和稳定转化（烟草）→ GUS 染色。
- **训练**：80/20 训练/测试划分，10 折交叉验证，微 F1 分数 0.765–0.771。
- **反馈回路**：实验验证结果（PRTS1 阳性、PRTS2 阴性）反向确认了 ML 特征筛选的有效性，但未进一步迭代模型。
- **假设**：
  - TFBS 的「存在与否」足以作为组织特异性分类的特征（未考虑结合亲和力差异）；
  - τ = 1 的基因可代表组织特异性表达；
  - 启动子序列中的 TFBS 富集区域可独立驱动组织特异性表达。

## 09 关键公式符号

| 公式 | 符号含义 | 用途 | 来源 |
|---|---|---|---|
| τ = Σᵢ₌₁ⁿ (1 − x̂ᵢ) / (n − 1) | n：组织数；xᵢ：基因在组织 i 的平均表达；x̂ᵢ = xᵢ / max(xᵢ) | 衡量基因表达的组织特异性程度，τ=1 表示完全组织特异，τ=0 表示均匀表达 | Methods 4.4 节 |
| 微 F1 = 2·(微精确率·微召回率)/(微精确率+微召回率) | 基于所有类别总体 TP/FP/FN 计算的 F1 | 评估多分类模型整体性能 | Results 2.4 节（未给出具体公式，按标准定义） |
| 置换重要性（Permutation Importance） | 随机打乱某特征后模型性能下降幅度 | 衡量每个 TFBS 对分类的贡献 | Methods 4.8 节（未给出具体公式，按 RF 标准方法） |

> 注：本文未涉及序列编码、注意力权重或结构生物学相关公式。核心数学工具为 τ 指数和 RF 特征重要性。

## 11 结论正确解读

- **任务范围**：本文解决的是「组织特异性合成启动子设计」，具体为杨树根特异启动子。方法基于序列基序（TFBS 有无）和表达数据（τ 值），不涉及 TF–DNA 三维结构、结合动力学或染色质状态。
- **oracle/真值输入**：基因表达类别标签来自 RNA-seq 数据 + τ 值阈值，属于数据驱动的监督信号，非实验验证的 TF 结合真值。TFBS 的「存在」由 PWM 扫描定义，非 ChIP-seq 或 DAP-seq 实验验证。
- **端到端状态**：从组学数据到功能启动子的完整流程已跑通，但验证规模有限——仅 1 个根特异基因（PopRTS1）、2 个合成启动子、瞬时表达（杨树）+ 稳定表达（烟草）。未做稳定转基因杨树，未做定量表达分析。
- **算力成本**：随机森林 + 379 维特征，计算成本低，无需 GPU。
- **历史数据依赖**：依赖已发表的 RNA-seq 数据（[74]、[13]）和 PlantTFDB 基序库，未产生新的大规模组学数据。
- **模型依赖**：仅用随机森林一种模型；未与深度学习或线性模型对比。
- **最难情形**：模型对「组织特异性」的定义是二元的（τ=1 vs 其他），无法区分根特异 vs 叶特异 vs 花特异等具体组织类型；对弱特异或双组织表达基因的预测能力未知。
- **不确定性**：PRTS1 的根特异性在杨树中通过瞬时渗透验证，但瞬时表达可能受组织损伤、农杆菌污染等影响；烟草中的稳定表达不能完全代表杨树中的行为。
- **有边界的复述**：本文证明，在杨树中，用随机森林对全基因组 TFBS 进行特征重要性排序，可以筛选出能组装成功能性根特异合成启动子的 CRM 区域；该方法在单个基因上得到正反验证，但其普适性（其他组织、其他物种、其他基因）尚未建立。

## 14 学到什么

> 标题：Agent 提炼的知识候选

1. **「保守性 ≠ 功能性」的实证**：本文直接比较了基序保守性排名与 ML 特征重要性排名，发现无正相关。这提示在 TF–DNA 互作研究中，若目标是组织/条件特异性调控，应优先用表达数据监督的 ML 筛选，而非仅依赖进化保守性。可迁移到人类 TF 研究：对某个 TF 的 ChIP-seq 峰进行保守性分析时，应同时用下游基因的组织特异性表达做监督，区分「管家结合」与「特异调控结合」。

2. **CRM 定位的「信息性 TFBS 富集」策略**：本文不是找单个基序，而是找高重要性 TFBS 在启动子上的局部富集区，并将该区域整体作为合成启动子的核心。这一「区域而非单点」的思路可迁移到 TF–DNA 互作：在预测 TF 结合位点时，可考虑用 ML 特征重要性对基因组区域打分，而非仅做逐点峰 calling。

3. **正负对照的合成启动子设计**：PRTS1（含高信息性 TFBS）与 PRTS2（含保守但低信息性 TFBS）构成天然的正负对照，验证了 ML 筛选的因果贡献。这一实验设计可迁移到任何「计算预测 → 实验验证」的流程中：设计一个基于 ML 阳性特征的构建体和一个基于传统保守性特征的构建体，直接对比功能。

4. **随机森林 + 置换重要性作为可解释基线**：在启动子设计这类「需要知道哪些基序起作用」的问题中，RF 的置换重要性提供了直接可解释的输出。相比深度学习黑箱，RF 更适合作为第一轮筛选工具，后续再用深度学习捕捉高阶交互。可迁移到 TF–DNA 结合预测：先用 RF 筛选候选基序，再用 CNN 建模基序组合语法。

5. **τ 值作为组织特异性的量化标签**：τ 指数简单有效，可迁移到任何组织/细胞类型特异性调控元件的筛选中。在单细胞数据中，可用类似思路（如细胞类型特异性的表达熵）定义标签。

6. **瞬时渗透 + GUS 染色的快速验证管线**：3–4 天即可完成启动子活性初筛，适合作为高通量验证的第一道关卡。可迁移到 TF–DNA 互作的功能验证：在验证某个预测的增强子/启动子区域时，先用瞬时报告系统快速筛选，再做稳定转化。

## 15 与已有知识连接

1. **与「cis-regulatory code」研究的连接**：本文属于「从序列到表达」的调控密码解码研究，与人类基因组中 ENCODE 项目的调控元件预测、以及「调控基因组学」领域直接相关。方法上可类比于用随机森林预测增强子/启动子活性（如 DeepSEA、Enformer 的线性/树模型基线）。

2. **与「TF–DNA 结合特异性」数据库的连接**：本文使用的 379 个 PWM 来自 PlantTFDB v5.0，与动物研究中的 JASPAR、CIS-BP 数据库对应。本文的「TFBS 有无」特征构建方式，可视为对 TF 结合特异性的一种粗粒度编码；更精细的做法是使用 PWM 匹配得分或 k-mer 嵌入。

3. **与「合成启动子工程」的连接**：本文与哺乳动物合成启动子设计（如使用 ML 设计细胞类型特异性启动子）方法学同源。可参考的经典工作包括用深度学习设计肝细胞特异性启动子、用随机森林设计诱导型启动子等。

4. **与「共表达网络 + 调控元件」的连接**：本文用 WGCNA 鉴定根特异共表达模块，再结合 TFBS 筛选，这一「共表达 → 调控元件」的级联策略与动物研究中「eQTL → 共表达 → 调控元件」的思路一致。

5. **与「植物 TF–DNA 互作」实验数据的连接**：本文未使用 ChIP-seq/DAP-seq 数据，仅用 PWM 扫描。未来可迁移的方向是：将 DAP-seq 数据（植物中常用的 TF 结合实验）纳入特征，替代或补充 PWM 扫描，可能提升预测精度。

6. **与「跨物种调控元件保守性」的连接**：本文比较了毛果杨和毛白杨的保守基序，发现跨物种保守的 TFBS 不一定是组织特异性的。这与动物研究中「序列保守的增强子不一定功能保守」的发现一致，提示在跨物种迁移 TF–DNA 互作模型时需谨慎。

## 16 研究想法

> 标题：Agent 生成的研究候选

### 候选 1：基于深度学习的「组织特异性 CRM」端到端预测器
- **名称**：TissueCRM-Net
- **来源局限/观察**：本文用随机森林 + 手工 TFBS 特征，F1 仅 0.77；且无法捕捉基序间距、方向、组合效应。深度学习在序列直接编码上已证明优于手工特征。
- **核心假设**：用 CNN 或 Transformer 直接读启动子序列（one-hot 编码），以组织特异性表达标签为监督，可超越随机森林 + PWM 特征的预测精度，并自动学习基序组合语法。
- **初步方法**：以本文的杨树数据为基准，构建启动子序列（±2 kb around TSS）→ 训练 CNN（类似 DeepSEA 架构）→ 输出组织特异性类别；与随机森林基线对比 F1；用 saliency map 或 attention 可视化关键基序。
- **验证方式**：在本文的 PopRTS1 上做留一法验证；另选 2–3 个根特异基因做合成启动子实验验证。
- **创新状态**：unverified（方法在动物中成熟，植物组织特异性启动子 + 深度学习已有零星报道，但本文数据上未验证）

### 候选 2：整合染色质可及性数据的多模态启动子预测
- **名称**：MultiModal-Promoter
- **来源局限/观察**：本文仅用序列基序，未纳入表观基因组数据。作者在 Discussion 中也承认这一点。
- **核心假设**：在随机森林或深度学习模型中，加入 ATAC-seq 可及性、DNA 甲基化、组蛋白修饰作为额外特征，可显著提升组织特异性 CRM 的预测精度，因为 TF 结合高度依赖染色质状态。
- **初步方法**：对杨树根/叶/茎分别做 ATAC-seq 和甲基化测序 → 将可及性信号与 TFBS 特征拼接 → 训练多模态模型 → 对比单模态基线。
- **验证方式**：交叉验证 + 合成启动子实验（选择模型预测的高置信区域）。
- **创新状态**：unverified（植物中多模态启动子预测报道较少）

### 候选 3：从「组织特异 TFBS」到「TF–TF 协同互作网络」的推断
- **名称**：TF-Cooperativity-From-CRM
- **来源局限/观察**：本文鉴定了根特异 TFBS 列表，但未分析 TF 之间的协同关系。CRM 的功能往往依赖多个 TF 的协同结合。
- **核心假设**：在根特异 CRM 中，共现频率显著高于随机期望的 TFBS 对，对应协同结合的 TF 对；这些 TF 对在根发育中功能相关。
- **初步方法**：从本文的 top 50 TFBS 列表中，统计其在根特异基因启动子中的共现模式 → 用超几何检验或排列检验筛选显著共现对 → 用酵母双杂交或 DAP-seq 验证候选 TF 对的物理互作。
- **验证方式**：DAP-seq 共结合实验 + 根特异报告基因共表达实验。
- **创新状态**：unverified（TF 协同推断在动物中成熟，植物根特异 CRM 中未见系统报道）

### 候选 4：跨物种迁移学习的启动子设计框架
- **名称**：CrossSpecies-Promoter-Transfer
- **来源局限/观察**：本文在毛果杨和毛白杨两个物种上训练，但未做跨物种迁移验证。木本植物转化周期长，若能从一个物种学习迁移到另一个物种，将大幅降低成本。
- **核心假设**：在杨属内训练的 TFBS 重要性模型，可迁移到其他木本植物（如桉树、柳树）的启动子设计，且迁移学习优于从头训练。
- **初步方法**：在毛果杨上预训练随机森林或 CNN → 用少量柳树/桉树数据微调 → 对比从头训练和直接迁移的 F1 → 选一个预测的根特异启动子做实验验证。
- **验证方式**：跨物种交叉验证 + 至少一个异源物种的启动子实验。
- **创新状态**：unverified（跨物种启动子迁移在植物中报道极少）

### 候选 5：用 ML 重要性分数指导「最小 CRM」的合成优化
- **名称**：Minimal-CRM-Optimizer
- **来源局限/观察**：本文的 PRTS1 保留了 386 bp 的天然序列，未做最小化优化。实际应用中，更短的启动子更利于多基因堆叠和载体构建。
- **核心假设**：基于 ML 特征重要性分数，可以系统地截短/突变启动子，找到维持根特异性的最小 CRM 核心，且该核心可移植到异源核心启动子（如 35Smini）上。
- **初步方法**：对 PRTS1 做 5′/3′ 渐进截短 → 用 ML 分数预测每个截短体的活性 → 构建 5–8 个截短体做 GUS 定量 → 建立「ML 分数 vs 实验活性」的校准曲线 → 用该曲线设计最小 CRM。
- **验证方式**：GUS 定量（MUG 荧光法）+ 烟草稳定转化。
- **创新状态**：unverified（最小启动子优化已有报道，但用 ML 分数指导截短未见系统验证）
