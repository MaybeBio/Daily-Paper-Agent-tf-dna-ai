## 02 一句话总结

本文提出 BioSeq2Seq——一个基于 Transformer 的端到端深度学习框架，以 RO-seq 转录活性/方向性信号和 DNA 序列为输入，在单细胞系（K562）上训练后，可跨细胞系、跨物种地预测组蛋白修饰、功能元件、基因表达和 90 种 TF 的 TFBS，在四项下游任务上均达到或超过现有最优方法（组蛋白修饰 +14.27%、功能元件 +2.50%、基因表达 +2.90% AUC，TFBS 与 maxATAC 相当）。

## 03 研究问题

- **具体问题**：能否仅用单细胞系的 RO-seq 数据和 DNA 序列，端到端地预测多种转录调控相关基因组注释信号（组蛋白修饰、功能元件、基因表达、TFBS），并泛化到未见过的细胞系和物种？
- **为什么重要**：基因组注释目前依赖在数百种细胞/组织中开展数十种分子实验，成本极高，难以推广到所有物种和条件。若能以低成本、单细胞系数据实现跨细胞系/物种的准确预测，将大幅降低功能基因组学研究的门槛。
- **现有方法不足**：(i) 基于 DNA 序列的方法（如 Enformer）缺乏细胞系特异性信息，无法区分不同细胞状态；(ii) 基于单一表观遗传特征（如 DNase-seq）的方法（如 dREG）信息量有限；(iii) 现有 RO-seq 预测方法（如 dHIT）基于 SVR，计算效率低（预测单条染色体组蛋白修饰需 3–5 小时），且每个标记需单独训练模型；(iv) 多细胞系训练策略数据需求大，对稀有细胞系不适用。
- **精确研究问题**：Can a single-cell-line-trained, Transformer-based deep learning framework, using RO-seq transcriptional activity/directionality and DNA sequence as inputs, achieve state-of-the-art performance in predicting histone modifications, functional elements, gene expression, and TFBS across unseen cell lines and species?

## 06 核心思想

**1) 表面方法**：构建一个 Transformer 架构的深度学习模型，输入为 RO-seq 信号（正/负链）和 DNA 序列（one-hot 编码），输出为多种转录调控信号的基因组-wide 预测。模型包含三个模块：特征嵌入模块（卷积层提取局部特征）、注意力模块（Transformer 捕获长程依赖）、任务头模块（输出特定任务预测）。

**2) 核心洞察**：RO-seq 捕获的转录活性与方向性信号是细胞系特异性的"锚点"，能够将 DNA 序列的静态信息与细胞状态动态信息结合。双向转录模式（divergent transcription）与多种调控元件（启动子、增强子、绝缘子）的结构性关联，使得单一 RO-seq 实验即可提供丰富的调控信息。Transformer 的大感受野（>100 kb）使模型能够捕获增强子-启动子等长程互作。

**3) 可能的普适教训 [Analysis]**：在生物序列建模中，"静态特征 + 动态状态信号"的多模态输入策略可能优于单一模态。RO-seq 作为"转录活性的实时快照"，其信息密度远超静态 DNA 序列，这提示在 TF–DNA 互作建模中，整合转录活性信号（如 PRO-seq、GRO-seq）可能比仅依赖序列 motif 提供更强的预测能力。此外，多任务联合学习（共享底层特征 + 任务特定头）在生物信息学中具有广泛适用性。

## 07 方法总览

- **输入**：RO-seq 信号（正链、负链绝对值、正负链之和，3 通道）和 DNA 序列（one-hot，4 通道），共 7 通道，长度 196,608 bp（含两侧各 41 kb flanking）
- **输出**：中心 114,688 bp 区域的 N 个预测轨道（N 因任务而异：组蛋白修饰=10，功能元件=4，基因表达=10，TFBS=90）
- **特征嵌入模块**：7 个卷积块（每块含 2 层 1D 卷积 + BatchNorm + GELU + MaxPooling），将输入降采样至 896 个位置，每位置 C 维特征
- **注意力模块**：11 个 Transformer block（LayerNorm + 8 头 MHA + dropout 0.05 + MLP），输入加入相对位置编码（Enformer 风格）
- **任务头模块**：卷积块（2C filters）+ 全连接层，输出 N 个预测轨道
- **训练**：MSE 损失，Adam 优化器，学习率 1e-4 或 1e-5，batch size=1，随机采样 5000 样本/epoch
- **流程**：输入 7 通道特征 → 特征嵌入（卷积降采样）→ 注意力（长程建模）→ 任务头（多任务输出）→ 峰值调用（功能元件任务）

## 09 关键公式符号

**1) 自注意力机制**（Methods 节）：
$$\text{Output}_{\text{self-attention}} = \text{Softmax}\left(\frac{q \cdot k^\top}{\sqrt{d_k}} + E_{\text{pos}}\right) \cdot v$$

- $q, k, v$：查询、键、值向量（由输入 $x \in \mathbb{R}^{L \times C}$ 通过全连接层投影得到）
- $d_k$：键向量的维度
- $E_{\text{pos}}$：相对位置编码
- $L$：序列长度（896）
- $C$：通道数（768 或 576）

**2) Pearson 相关系数**（Methods 节）：
$$\text{Corr}(\hat{y}, y) = \frac{\text{Cov}(\hat{y}, y)}{\sqrt{\text{Var}(\hat{y}) \cdot \text{Var}(y)}}$$

- $\hat{y}$：预测信号
- $y$：实验 ground truth

**3) MSE 损失**（Methods 节）：
$$\text{Loss} = \frac{1}{n} \sum_{i=1}^{n} (\hat{y}_i - y_i)^2$$

**4) 分类指标**（Methods 节）：
- Accuracy = (TP + TN) / (TP + TN + FP + FN)
- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1 = 2·Precision·Recall / (Precision + Recall)

## 11 结论正确解读

- **任务范围**：本文覆盖四项任务——组蛋白修饰预测（10 种）、功能元件识别（4 种）、基因表达预测（10 种亚细胞类型）、TFBS 预测（90 种 TF）。所有任务均基于 K562 训练，跨细胞系/物种测试。
- **oracle/真值输入**：训练和评估使用实验测量的 ChIP-seq、RNA-seq 和注释数据作为 ground truth。RO-seq 数据是唯一的细胞系特异性输入。
- **端到端状态**：模型是端到端训练的，从原始 RO-seq 信号和 DNA 序列直接预测目标信号，无需中间特征提取或 motif 扫描。
- **边界条件**：(1) 性能提升主要在转录活跃相关的标记（H3K4me3, H3K27ac 等），抑制性标记（H3K27me3, H3K9me3）预测精度较低；(2) 跨物种泛化性能低于跨细胞系；(3) 分辨率限制在 128 bp，无法精确到单碱基；(4) 训练需要 RO-seq 数据，对无 RO-seq 的样本无法直接应用。
- **不确定性**：文中未报告预测的置信区间或不确定性估计；峰值调用的统计检验仅用于功能元件识别任务。

## 14 学到什么

**Agent 提炼的知识候选**：

1. **多模态输入策略**：将"静态 DNA 序列 + 动态转录活性信号"结合，比单一模态提供更丰富的调控信息。可迁移到 TF–DNA 互作课题：在预测 TF 结合时，除序列 motif 外，整合细胞系特异性的转录活性信号（如 PRO-seq、GRO-seq）可能显著提升跨细胞系泛化能力。

2. **Transformer 大感受野的价值**：11 层 Transformer + 197 kb 输入窗口使模型能捕获增强子-启动子等长程互作。可迁移到 TF–DNA 互作课题：TF 结合往往受远端调控元件影响，使用大感受野模型可能比局部窗口模型（如 DeepSEA、Basenji 的较小窗口）更准确地预测 TF 结合。

3. **多任务联合学习**：共享底层特征 + 任务特定头的架构，使模型能同时学习多种相关调控信号，通过任务间信息共享提升整体性能。可迁移到 TF–DNA 互作课题：同时预测多种 TF 的结合位点，利用 TF 之间的协同/竞争关系提升预测精度。

4. **峰值调用的统计检验框架**：将连续预测信号转为离散元件时，使用多元高斯分布假设检验而非简单阈值，可减少假阳性。可迁移到 TF–DNA 互作课题：在从预测分数中识别 TF 结合位点时，采用统计检验框架可提供更可靠的置信度评估。

5. **训练策略的经验**：单细胞系多 RO-seq 样本优于多细胞系训练，说明数据质量（同一细胞系的多重复）比数据多样性（多个细胞系）对模型泛化更重要。可迁移到 TF–DNA 互作课题：在数据有限时，优先收集同一细胞系的多重复实验数据，而非分散到多个细胞系。

6. **抑制性标记的挑战**：模型对抑制性组蛋白修饰（H3K27me3, H3K9me3）预测精度较低，提示这些标记可能受更复杂的调控机制（如 Polycomb 介导的沉默）影响，需要额外的信息源（如 DNA 甲基化）。可迁移到 TF–DNA 互作课题：抑制性 TF（如转录抑制因子）的结合预测可能比激活因子更具挑战性，需要整合额外的表观遗传特征。

## 15 与已有知识连接

- **Enformer（Avsec et al., 2021, Nature Methods）**：本文的 Transformer 架构和相对位置编码直接借鉴 Enformer，但输入从纯 DNA 序列扩展为 DNA + RO-seq 多模态。可连接：Enformer 的序列-only 方法缺乏细胞特异性，本文证明加入 RO-seq 信号可弥补这一缺陷。
- **dHIT（Wang et al., 2022, Nature Machine Intelligence）**：本文的直接对比基线，基于 SVR 和 RO-seq 预测组蛋白修饰。本文在精度和速度上均超越 dHIT。
- **dREG（Danko et al., 2015, PNAS）**：基于 RO-seq 识别调控元件的经典方法，本文的 TIR 预测任务直接对标 dREG。
- **maxATAC（Zhang et al., 2023, Nature Communications）**：基于 ATAC-seq 预测 TFBS 的最新方法，本文的 TFBS 预测任务与其对比。
- **DeepSEA（Zhou & Troyanskaya, 2015, Nature Methods）**：基于 DNA 序列预测调控效应的早期深度学习方法，本文在输入模态和任务范围上均有扩展。
- **Basenji（Kelley et al., 2018, PLoS Computational Biology）**：基于序列的调控预测模型，本文在窗口大小（197 kb vs 通常 1-10 kb）上显著扩展。
- **PRO-seq 的生物学基础（Core et al., 2008, Science）**：双向转录与增强子/启动子活性的关联是本文方法有效性的生物学基础。

## 16 研究想法

**Agent 生成的研究候选**：

1. **候选名称**：TF–DNA 结合特异性的多模态预测框架
   - **来源局限/观察**：BioSeq2Seq 的 TFBS 预测虽达到 SOTA，但未显式建模 TF 的序列偏好（motif），且对抑制性 TF 预测精度有限
   - **核心假设**：将 TF 的 DNA 结合域序列特征（氨基酸序列编码）作为条件输入，可提升未见 TF 的零样本预测能力
   - **初步方法**：在 BioSeq2Seq 架构中加入 TF 编码器（如 ESM-2 蛋白质语言模型），将 TF 嵌入与基因组特征融合，实现 TF-条件化的结合位点预测
   - **验证方式**：在 ENCODE 的 90 个 TF 上做留一 TF 交叉验证，评估零样本泛化
   - **创新状态**：unverified

2. **候选名称**：基于物理先验的 TF–DNA 结合能量约束
   - **来源局限/观察**：纯数据驱动模型缺乏物理可解释性，无法外推到突变体或非天然序列
   - **核心假设**：将统计力学模型（如 PWM 的能量解释）作为正则化项，可提升模型在低数据区域的预测可靠性
   - **初步方法**：在损失函数中加入 TF–DNA 结合自由能预测项（如基于 Rosetta 或 DeepBE 的预测），约束模型输出符合热力学规律
   - **验证方式**：在体外结合实验（如 HT-SELEX、PBMs）数据上验证，比较有无物理约束的预测精度
   - **创新状态**：unverified

3. **候选名称**：单细胞分辨率的 TF 结合动态预测
   - **来源局限/观察**：BioSeq2Seq 使用 bulk RO-seq，无法捕获细胞异质性；单细胞 RO-seq 技术正在发展
   - **核心假设**：单细胞 RO-seq 信号 + 细胞状态嵌入（如 scRNA-seq 衍生的细胞类型标签）可预测细胞类型特异的 TF 结合
   - **初步方法**：扩展 BioSeq2Seq 以处理单细胞分辨率的 RO-seq 数据，加入细胞状态编码器
   - **验证方式**：在已有单细胞 RO-seq 数据（如 scPRO-seq）上验证，与 bulk 预测对比
   - **创新状态**：unverified

4. **候选名称**：TF–DNA 共结合与竞争关系的图神经网络建模
   - **来源局限/观察**：BioSeq2Seq 独立预测每个 TF 的结合，未建模 TF 之间的协同/竞争关系
   - **核心假设**：TF 之间的物理互作（共结合、竞争同一 motif）可通过图神经网络显式建模，提升预测精度
   - **初步方法**：构建 TF-TF 互作图（基于已知蛋白-蛋白互作和共结合数据），在 BioSeq2Seq 输出层加入图卷积层
   - **验证方式**：在 ENCODE 共结合 ChIP-seq 数据上验证，比较有无图建模的预测精度
   - **创新状态**：unverified

5. **候选名称**：跨物种 TF 结合位点的进化守恒约束
   - **来源局限/观察**：BioSeq2Seq 跨物种泛化性能下降，未利用进化信息
   - **核心假设**：在进化上保守的 TF 结合位点更可能是功能性结合，加入多序列比对特征可提升跨物种预测
   - **初步方法**：在输入中加入 phyloP/PhastCons 等保守性分数，或使用多物种 DNA 序列的联合嵌入
   - **验证方式**：在人类-小鼠-果蝇的直系同源区域上验证，比较有无保守性特征的预测精度
   - **创新状态**：unverified
