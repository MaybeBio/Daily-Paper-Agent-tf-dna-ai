## 02 一句话总结
通过 3,548 个 TF 的过表达筛选结合 perturb-SHARE-seq 单细胞多组学分析，识别出 38 个可重复的 CD8+ T 细胞调控程序，发现 RUNX 作为"主协作因子"与 KLF2 在复合基序上协作调控耗竭相关基因表达，并通过 AlphaFold 3 结构预测和合成 tethering 实验验证了 RUNX2:KLF2 蛋白互作界面在 T 细胞状态工程中的功能。

## 03 研究问题
- **具体问题**: 转录因子（TF）如何通过协作（collaboration）在复合基序（composite motifs）上实现 CD8+ T 细胞状态的精确调控？特别是，哪些 TF 协作对驱动 T 细胞耗竭（exhaustion）状态至关重要？
- **为什么重要**: T 细胞耗竭是慢性感染和癌症中免疫功能障碍的核心机制，限制了免疫治疗（如 CAR-T）的疗效。理解 TF 协作的分子机制是实现 T 细胞状态理性工程（rational engineering）的关键前提。
- **现有方法不足**: 传统方法通常研究单个 TF 的功能，忽略了 TF 协作的复杂性；TF 组合空间巨大（3,548 个 TF 的配对组合超过 600 万），系统性筛选不可行；现有单细胞扰动方法缺乏同时测量染色质可及性和基因表达的能力。
- **精确研究问题**: "Can we systematically identify TF collaborations that specify CD8+ T cell exhaustion states, and can we engineer these collaborations to precisely control T cell state?"

## 04 背景与发展脉络
*注：以下脉络基于本文框架，未经外部系统核验，标注为「仅本文框架」。*

1. **TF 协作的早期研究**（~2010s）：已知 TF 共结合（co-binding）是基因调控的普遍特征，但缺乏系统性研究方法。
2. **单细胞基因组学时代**（~2018-2022）：单细胞 ATAC-seq 和 RNA-seq 使细胞状态的分子表征成为可能；大规模功能筛选（如 CRISPR 筛选）可鉴定细胞状态调控因子。
3. **扰动-多组学整合**（~2022-2024）：Perturb-seq 等将 CRISPR 扰动与单细胞测序结合，但多组学版本（同时测染色质和表达）仍稀缺。
4. **深度学习基序发现**（~2023-2025）：seq2PRINT 等基于 footprinting 的深度学习方法可从染色质可及性数据中推断 TF 结合基序，无需预先指定 motif。
5. **结构预测与蛋白设计**（~2024-2026）：AlphaFold 3 可预测 TF–DNA 复合物结构，使 TF–TF 互作界面的预测成为可能。
6. **本文位置**：首次将上述技术整合为完整流程——从 TF 筛选 → 单细胞多组学 → 深度学习基序发现 → 结构预测 → 合成 tethering 验证 → 工程应用，建立了「TF 协作发现-验证-工程」的闭环范式。

## 06 核心思想
1. **表面方法**: 大规模 TF 过表达筛选（3,548 TF）→ perturb-SHARE-seq 单细胞多组学 → 主题模型（LDA）识别调控程序 → seq2PRINT 深度学习基序发现 → AlphaFold 3 结构预测 → 合成 tethering 功能验证。
2. **核心洞察**: TF 协作（而非单个 TF 结合）是细胞状态特异性的主要决定因素。复合基序（composite motifs）比单体基序具有更高的状态特异性，而某些 TF（如 RUNX）作为"主协作因子"（master collaborator）广泛参与多种协作组合。通过合成 tethering 将协作 TF 物理连接，可以放大其协作效应，实现更精确的细胞状态工程。
3. **[Analysis] 可能的普适教训**: 
   - TF 协作的"主协作因子"概念可能适用于其他细胞类型和状态转换，识别这类枢纽因子可作为细胞工程的首选靶点。
   - 合成 tethering 策略将 TF 协作从"发现"转化为"工程"，为细胞状态重编程提供了新工具。
   - 深度学习基序发现与结构预测的整合，为从序列到功能的 TF 协作解析提供了可迁移的计算框架。

## 07 方法总览
- **输入**: 3,548 个 TF 过表达慢病毒文库（MORF 文库）；人原代 CD8+ T 细胞（3 个供体）；慢性 α-CD3/CD28 刺激诱导耗竭模型
- **输出**: 38 个可重复的调控程序；12,616 个 TF-程序连接；RUNX2:KLF2 协作机制；工程化 tethering 构建体
- **模块**:
  1. **TF 筛选模块**: MORF 文库转导 → 扩增/耗竭条件培养 → FACS 分选 TOX 高/低群体 → 条形码测序 → DESeq2 差异分析
  2. **单细胞多组学模块**: perturb-SHARE-seq（同时测染色质可及性、基因表达、扰动条形码）→ 83 个扰动 × 3 供体 × 4 条件
  3. **调控程序识别模块**: LDA 主题模型（分别对 ATAC 和 RNA）→ 迭代子采样 → 一致性主题聚类 → 38 个程序
  4. **基序发现模块**: seq2PRINT 深度学习（序列→footprint 预测）→ DeepLIFT 归因 → de novo motif 发现 → 复合基序识别
  5. **结构预测模块**: AlphaFold 3 预测 RUNX2:KLF2:DNA 复合物结构 → 识别蛋白-蛋白互作界面
  6. **功能验证模块**: 点突变破坏互作界面 → CUT&Tag 验证共结合 → 合成 tethering 构建体 → 功能表型分析
- **训练**: seq2PRINT 在 16.3 亿唯一比对 reads 上训练；LDA 主题模型 100 主题 × 500 迭代 × 10 bootstrap
- **工具**: Bowtie2, DESeq2, MALLET (LDA), scPrinter (seq2PRINT), DeepLIFT, AlphaFold 3, ConSurf, GATK, Drop-seq
- **反馈回路**: 筛选结果 → 单细胞验证 → 基序发现 → 结构预测 → 功能验证 → 工程应用
- **假设**: TF 过表达可模拟内源 TF 功能；体外耗竭模型可代表体内 T 细胞耗竭状态；染色质可及性变化反映 TF 结合变化

## 09 关键公式符号
本文核心方法为计算流程而非数学公式，未提供显式数学公式。以下为隐含的统计/计算框架：

1. **超几何检验（TF 富集）**:
   P(X ≥ kᵢ,ⱼ) = 1 − Σₓ₌₀^{kᵢ,ⱼ−1} [C(Kⱼ, x) × C(N−Kⱼ, nᵢ−x)] / C(N, nᵢ)
   - kᵢ,ⱼ: 细胞 i 中 TF j 的 UMIs 数
   - Kⱼ: 所有细胞中 TF j 的总 UMIs
   - N: 所有 UMIs 总数
   - nᵢ: 细胞 i 的总 UMIs
   - 用途: 判断细胞是否显著富集特定 TF 扰动

2. **LDA 主题模型**（隐含）:
   - 输入: 细胞×特征（基因/峰）计数矩阵
   - 输出: 主题×特征权重 + 细胞×主题载荷
   - 用途: 识别调控程序

3. **seq2PRINT footprint 预测**（隐含）:
   - 输入: 序列 one-hot 编码 + 侧翼区域
   - 输出: 多尺度 footprint 预测
   - 用途: 从序列预测 TF 结合模式

4. **Gini 系数**（状态特异性度量）:
   - 用于量化程序/基序在不同细胞状态间的分布均匀性
   - 均值: 单体基序 0.37 vs 复合基序 0.50

## 11 结论正确解读
- **任务范围**: 本文结论限于人原代 CD8+ T 细胞的体外耗竭模型（慢性 α-CD3/CD28 刺激），未在体内模型中验证。
- **oracle/真值输入**: 基序注释依赖现有数据库和 seq2PRINT 预测，存在注释偏差可能；AlphaFold 3 预测的互作界面未经晶体结构验证。
- **端到端状态**: 从筛选到工程验证的完整流程已建立，但 tethering 构建体的治疗效果仅在体外功能实验（细胞因子产生、杀伤能力）中验证，未进行动物模型或临床试验。
- **算力成本**: 未提供具体算力需求；seq2PRINT 训练需 16.3 亿 reads，计算成本较高。
- **历史数据依赖**: 依赖 Fraietta et al. 的 CAR-T 临床数据（2018 年），该数据集的治疗背景（CD19 CAR-T 治疗 CLL）可能不适用于其他癌症类型。
- **模型依赖**: 结论依赖 LDA 主题模型的参数选择（100 主题）和 seq2PRINT 的 footprint 预测准确性。
- **最难情形**: 本文方法在体外培养系统中有效，但体内 T 细胞耗竭涉及更复杂的微环境信号（如肿瘤微环境中的免疫抑制因子），这些因素未在模型中体现。
- **群体/领域边界**: 结论基于 3 个人类供体的 CD8+ T 细胞，未涵盖 CD4+ T 细胞、其他物种或疾病背景。
- **不确定性**: 82 个 TF 中仅 38 个产生可重复程序，其余 TF 的效应可能受限于检测灵敏度或供体异质性；tethering 的放大效应可能部分来自非特异性蛋白聚集。

**有边界的复述**: 在人原代 CD8+ T 细胞的体外耗竭模型中，通过 3,548 个 TF 的过表达筛选和单细胞多组学分析，识别出 RUNX 作为主协作因子，其与 KLF2 在复合基序上的协作通过直接蛋白互作调控耗竭相关基因表达；合成 tethering 可放大这一效应，为 T 细胞状态工程提供了新策略。这些结论限于体外模型和特定实验条件，体内效果和普适性尚待验证。

## 14 学到什么
**Agent 提炼的知识候选**:

1. **主协作因子（Master Collaborator）概念**: 某些 TF（如 RUNX）在多种协作组合中反复出现，可作为细胞状态工程的首选靶点。可迁移至其他细胞类型：在目标细胞类型中先进行全 TF 筛选，识别枢纽因子，再聚焦其协作网络。

2. **复合基序作为状态特异性编码单元**: 复合基序（如 RUNX:KLF）比单体基序具有更高的细胞状态特异性（Gini 系数 0.50 vs 0.37）。在 TF–DNA 结合预测模型中，应显式建模相邻基序的组合，而非仅关注单体基序。

3. **多组学扰动筛选范式**: perturb-SHARE-seq 将扰动条形码与染色质/表达同时测量，可直接建立"TF → 染色质 → 表达"的因果链。该范式可迁移至其他细胞类型或疾病模型，尤其适合研究 TF 协作的细胞类型特异性。

4. **seq2PRINT 的 de novo 基序发现能力**: 基于深度学习的 footprint 预测可从染色质可及性数据中直接发现基序，无需预先指定 motif 数据库。对 TF–DNA 结合研究，这意味着可从任意细胞类型的 ATAC-seq 数据中发现新的 TF 结合基序，包括复合基序。

5. **合成 tethering 作为功能验证工具**: 将协作 TF 物理连接可放大其功能效应，这不仅是验证工具，也是工程工具。对 TF–DNA 结合研究，tethering 策略可用于测试任意 TF 对的功能协作，无需等待自然突变。

6. **结构预测指导功能验证**: AlphaFold 3 预测的蛋白-蛋白界面可直接指导点突变设计，加速从"发现互作"到"验证功能"的流程。对 TF–DNA 结合研究，该策略可推广至其他 TF 对，预测并验证新的协作界面。

7. **从筛选到工程的闭环**: 本文展示了从全基因组筛选 → 单细胞验证 → 机制解析 → 工程应用的完整流程。对 TF–DNA 结合研究，该闭环可作为标准范式：先筛选，再解析，后工程。

## 15 与已有知识连接
- **TF 协作的经典研究**: 本文与已知的 TF 协作研究一致，如 AP-1 与 NFAT 在 T 细胞活化中的协作（Macian et al., 2001），以及 BATF 与 IRF4 在耗竭中的协作（Man et al., 2022）。本文扩展了协作因子的范围，将 RUNX 家族置于中心位置。
- **RUNX 家族功能**: RUNX1/2/3 在造血和免疫中的已知功能（如 RUNX3 在 CD8+ T 细胞中的角色，Cruz-Guilloty et al., 2009）为本文发现提供了背景。本文的新贡献在于揭示 RUNX 作为"主协作因子"的广泛协作网络。
- **KLF2 在 T 细胞中的功能**: KLF2 已知维持 T 细胞静息和迁移（Carlson et al., 2006），本文发现其在耗竭中的新角色，与已知功能形成互补。
- **深度学习基序发现**: seq2PRINT 与现有工具（如 BPNet, Avsec et al., 2021）类似，但专注于 footprint 预测。本文展示了其在复合基序发现中的优势。
- **AlphaFold 3 在 TF 研究中的应用**: 本文是少数将 AlphaFold 3 用于 TF–TF 互作预测的研究之一，与 AlphaFold 2 在蛋白-蛋白互作预测中的应用（如 Bryant et al., 2022）形成衔接。
- **CAR-T 治疗优化**: 本文与 CAR-T 耗竭预防策略（如 Fraietta et al., 2018）直接相关，提供了新的工程靶点（RUNX2:KLF2）。
- **可迁移领域**: 本文方法可迁移至其他细胞分化系统（如 Th17 分化、B 细胞记忆形成），以及疾病状态（如自身免疫、肿瘤浸润）。

## 16 研究想法
**Agent 生成的研究候选**:

1. **候选名称**: 跨细胞类型的 TF 协作网络图谱
   - **来源局限/观察**: 本文仅在 CD8+ T 细胞中验证了 RUNX 作为主协作因子，未测试其他细胞类型
   - **核心假设**: 主协作因子在不同细胞类型中保守，但协作伙伴具有细胞类型特异性
   - **初步方法**: 在多种免疫细胞类型（CD4+ T、B、NK、巨噬细胞）中重复 TF 筛选 + perturb-SHARE-seq 流程，构建跨细胞类型的 TF 协作网络
   - **验证方式**: 比较各细胞类型中 RUNX 的协作伙伴；用 seq2PRINT 分析各细胞类型的复合基序
   - **创新状态**: unverified

2. **候选名称**: 基于 AlphaFold 3 的 TF 协作界面预测平台
   - **来源局限/观察**: 本文仅预测了 RUNX2:KLF2 一个互作对，未系统评估 AlphaFold 3 在 TF 互作预测中的准确性
   - **核心假设**: AlphaFold 3 可高精度预测 TF–TF 互作界面，指导功能验证
   - **初步方法**: 对本文识别的 82 个 TF 进行全配对 AlphaFold 3 预测，与 CUT&Tag 共结合数据交叉验证，建立预测-验证闭环
   - **验证方式**: 随机选择预测的互作对进行点突变验证；与已知结构数据库（PDB）比对
   - **创新状态**: unverified

3. **候选名称**: 合成 tethering 文库用于系统性 TF 协作筛选
   - **来源局限/观察**: 本文仅测试了 RUNX2-KLF2 一个 tethering 组合
   - **核心假设**: 系统性 tethering 可发现新的 TF 协作对，并实现可预测的细胞状态转换
   - **初步方法**: 构建包含所有 82 个 TF 配对（~3,300 组合）的 tethering 文库，在 CD8+ T 细胞中筛选功能表型
   - **验证方式**: 与 untethered 共表达对照比较；用单细胞多组学验证 tethering 的染色质效应
   - **创新状态**: unverified

4. **候选名称**: 复合基序的深度学习预测模型
   - **来源局限/观察**: 本文发现复合基序比单体基序更具状态特异性，但未建立预测模型
   - **核心假设**: 深度学习模型可从序列直接预测复合基序的功能效应
   - **初步方法**: 扩展 seq2PRINT 架构，显式建模相邻基序的组合；在本文的 702,314 细胞数据上训练
   - **验证方式**: 独立数据集验证；与 CRISPRi 平铺筛选结果比较
   - **创新状态**: unverified

5. **候选名称**: KLF2 突变体用于 CAR-T 耗竭预防
   - **来源局限/观察**: 本文发现 KLF2 抑制耗竭程序，但未在 CAR-T 产品中验证
   - **核心假设**: 增强 RUNX2:KLF2 互作的 KLF2 突变体可提高 CAR-T 持久性和抗肿瘤活性
   - **初步方法**: 在 CAR-T 细胞中过表达 KLF2 或 tethering 构建体，在肿瘤模型中测试抗肿瘤效果
   - **验证方式**: 小鼠肿瘤模型中的肿瘤控制、T 细胞持久性、耗竭标志物表达
   - **创新状态**: unverified

6. **候选名称**: TF 协作的物理模型：从结构到动力学的多尺度模拟
   - **来源局限/观察**: 本文使用 AlphaFold 3 预测了静态结构，未考虑 DNA 结合动力学
   - **核心假设**: 分子动力学模拟可揭示 RUNX2:KLF2 在 DNA 上的协同结合机制
   - **初步方法**: 对 RUNX2:KLF2:DNA 复合物进行 MD 模拟，分析结合自由能、构象变化和 DNA 弯曲
   - **验证方式**: 与 footprinting 实验数据比较；突变体的模拟-实验一致性
   - **创新状态**: unverified
