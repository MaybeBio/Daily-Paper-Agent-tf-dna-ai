## 03 研究问题

- **具体问题**：基因表达预测通常依赖 cis-regulatory elements（CREs）的 DNA 序列特征，但 CREs 本身不足以决定 TF 结合，导致 cis-regulatory code 的解释存在歧义。本文提出：能否直接从 TF 结合谱（而非 DNA 序列）学习"TF regulatory code"，从而更准确地预测基因表达并揭示转录调控的机制？
- **为什么重要**：TF–DNA 互作是转录调控的核心，但现有研究多聚焦于 DNA 侧（cis 序列），忽略了 TF 侧（结合行为）的规律。理解 TF 结合的位置偏好与组合模式，有助于解析转录起始的机制，并为基因表达预测提供更直接的生物学特征。
- **现有方法为何不足**：cis-regulatory code 仅基于 DNA 序列，无法捕捉 TF 结合的实际行为（如竞争、协同、位置效应），导致预测精度有限且解释模糊。
- **精确的「Can ... ?」研究问题**：Can a deep learning model trained on TF binding profiles (encoded as TF sequence) predict gene expression with high accuracy and reveal interpretable TF regulatory grammar?

## 06 核心思想

1. **表面方法**：将 13 个 TF 结合谱（与转录起始相关）编码为"TF 序列"，作为深度学习模型 DeepTF 的输入，直接预测基因表达水平。

2. **核心洞察**：TF 结合在启动子上具有保守的位置偏好和组合模式，这些模式构成一种"TF regulatory code"，比 DNA 序列（cis code）更直接地反映转录调控机制。通过将 TF 结合谱作为输入，模型不仅预测表达，还能通过可解释性分析揭示调控语法。

3. **可能的普适教训** [Analysis]：在分子互作预测中，选择"功能侧"（如 TF 结合行为）而非"序列侧"（如 DNA 序列）作为编码对象，可能更接近机制本质，且能提升预测的可解释性。这一思路可迁移到其他 TF–DNA 互作任务（如结合强度预测、协同性建模）。

## 14 学到什么

**Agent 提炼的知识候选**：

1. **TF 侧编码思路**：将 TF 结合谱（而非 DNA 序列）作为模型输入，可更直接地捕捉结合位置与组合效应。  
   **迁移到本课题**：在 TF–DNA 互作预测中，可尝试将多个 TF 的 ChIP-seq 或预测结合谱编码为"TF 序列"，用于预测结合协同性、竞争或表达输出。

2. **位置偏好与组合模式作为特征**：TF 结合在启动子上的位置偏好（如距 TSS 的距离）和组合模式（如共结合）可能比单一基序更重要。  
   **迁移到本课题**：在构建 TF–DNA 结合模型时，显式加入位置编码（如相对 TSS 的距离）和 TF 对共现特征，可能提升预测精度。

3. **跨细胞系验证作为泛化性指标**：交叉验证设计可验证 TF regulatory code 的保守性。  
   **迁移到本课题**：在 TF–DNA 互作模型中，应设计跨细胞系或跨条件的验证，以确认机制的普适性。

4. **可解释性优先**：模型解释（如注意力权重）可用于提取调控语法。  
   **迁移到本课题**：在深度学习模型中引入注意力机制或 SHAP 分析，识别关键 TF 和结合位置。
