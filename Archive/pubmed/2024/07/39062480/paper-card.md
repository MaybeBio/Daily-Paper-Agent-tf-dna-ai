## 02 一句话总结

DeepIMAGER 将 TF–基因对的共表达模式转化为 32×32 二维直方图图像，利用 ResNet50 有监督学习（以 ChIP-seq 已知 TF–基因互作为标签）推断细胞特异性 GRN，在六种细胞系上 AUROC 达 0.95 以上，优于十种现有方法，并成功应用于多发性骨髓瘤树突状细胞的 GRN 推断。

## 03 研究问题

- **具体问题**：如何从 scRNA-seq 数据中准确推断细胞特异性的基因调控网络（GRN），特别是 TF–靶基因之间的直接调控关系？
- **为什么重要**：GRN 是理解细胞功能、组织发育和疾病机制的关键工具。细胞特异性 GRN 的准确推断有助于揭示疾病（如多发性骨髓瘤）中的异常调控通路，为靶向治疗提供依据。
- **现有方法不足**：
  1. 基于相关性的方法（如 SCENIC、SCODE）产生大量假阳性/假阴性，精度低；
  2. scRNA-seq 数据中的 dropout-zero 事件严重干扰表达相关性计算；
  3. 现有深度学习方法（如 CNNC、DeepDRIM）仅使用目标 TF–基因对的表达信息，忽略邻域基因的共表达上下文，导致无法区分直接互作与传递性互作。
- **精确研究问题（Can...?）**：Can a supervised deep learning model that transforms TF–gene pair co-expression patterns into image-like representations and incorporates neighborhood gene context achieve higher precision in cell-specific GRN inference than existing correlation-based and deep learning methods, while remaining robust to dropout-zero noise?

## 06 核心思想

### 1) 表面方法
DeepIMAGER 将每个 TF–靶基因对 (x, y) 的联合表达分布转化为 32×32 二维直方图（主图像），并额外生成 (2n+2) 张邻域图像（x 与其 top-n 协方差基因、y 与其 top-n 协方差基因的联合表达直方图）。所有图像分别输入两个 ResNet50 变体网络（网络 X 处理主图像，网络 Y 处理邻域图像），输出 512 维嵌入向量，拼接后经全连接层压缩，最终用 sigmoid 二分类判断是否存在调控关系。

### 2) 核心洞察
- **图像化表达保留联合分布信息**：将基因对的二维共表达直方图作为图像输入，比单纯使用相关性系数或一维表达向量保留了更丰富的分布形状信息，包括非线性模式和双峰分布。
- **邻域上下文区分直接与传递互作**：仅看目标基因对 (x, y) 的共表达无法区分「x 直接调控 y」与「x→z→y 的间接路径」。引入与 x、y 高协方差的邻域基因图像，使网络能学习到「x 与 y 的直接关系是否在邻域背景下仍然显著」，从而过滤传递性假阳性。
- **残差结构保证深度网络可训练**：ResNet50 的残差连接避免了 VGGNet 在深层时的梯度退化问题，使 50 层网络能稳定训练并提取高层特征。

### 3) 可能的普适教训 [Analysis]
- **将关系建模为图像而非标量/向量**：任何成对关系预测任务（包括 TF–DNA 结合）都可以考虑将两个实体的联合特征分布编码为图像，利用 CNN 的空间特征提取能力捕捉局部模式。
- **上下文信息是区分直接与间接因果的关键**：在 TF–DNA 结合预测中，仅看 TF 与靶基因的序列/表达特征可能不够，引入「邻域基因」或「染色质上下文」特征可能提升直接结合位点的识别精度。
- **有监督标签的质量决定上限**：本文依赖 ChIP-seq 作为 gold standard，但 ChIP-seq 本身有噪声和细胞异质性，模型性能上限受限于标签质量。

## 07 方法总览

- **输入**：scRNA-seq 表达矩阵（预处理后）；每个 TF–基因对 (x, y) 生成 1 张主图像 + (2n+2) 张邻域图像，共 (2n+3) 张 32×32 图像
- **输出**：TF–基因对是否存在调控关系的二分类概率（0–1）
- **预处理**：scanpy 归一化（total counts，size factor 10⁴）→ log 变换 → 选择 top 500 HVGs → 计算基因间协方差 → 分箱构建 2D 直方图 → log 归一化
- **网络结构**：
  - 网络 X：处理主图像，ResNet50 变体（48 卷积层 + 1 MaxPool + 1 AvgPool + FC），输出 512 维
  - 网络 Y：处理邻域图像，结构同 X，输出 512 维
  - 拼接层：512×(2n+3) 维向量
  - 分类头：两个全连接层（各 50% dropout）+ sigmoid
- **训练**：二分类交叉熵损失；小批量随机梯度下降（SGD），batch size 32；最多 100 epochs，早停（验证集精度不提升则停止）
- **标签来源**：ChIP-seq 数据（GTRD 数据库）提供的已知 TF–基因互作作为正样本，非互作对作为负样本
- **评测**：3 折交叉验证；AUROC 为主要指标；与 10 种方法对比（5 种无监督 + 5 种有监督）
- **反馈回路**：验证集 AUROC 用于早停和超参数选择
- **假设**：ChIP-seq 识别的 TF–基因互作代表真实调控关系；图像化共表达模式包含足够判别信息；邻域基因的共表达上下文有助于区分直接/间接互作

**文字流程**：
1. 预处理 scRNA-seq 数据，筛选 HVGs
2. 对每个 TF–基因对，计算联合表达直方图（主图像）和邻域直方图（邻域图像）
3. 主图像经网络 X、邻域图像经网络 Y 分别提取 512 维特征
4. 拼接所有特征向量，经全连接层压缩，sigmoid 输出互作概率
5. 用 ChIP-seq 标签训练，3 折交叉验证评估

## 09 关键公式符号

**1. 2D 直方图归一化**（方法节 2.2）：
\[
\tilde{H}_{ij} = \log_{10}\left(1 + \frac{10 H_{ij}}{\sum_{ij} H_{ij}}\right)
\]
- \( H_{ij} \)：第 i 行第 j 列 bin 的细胞计数（两基因表达值分别落在第 i、j 个表达区间的细胞数）
- \( \tilde{H}_{ij} \)：归一化后的像素值
- 用途：将直方图计数转换为适合 CNN 输入的图像像素值，同时压缩动态范围
- 直觉：log 变换使低计数 bin 的差异可见，避免高计数 bin 主导

**2. 二分类交叉熵损失**（方法节 2.3，未显式给出公式，但为标准形式）：
\[
\mathcal{L} = -\frac{1}{N} \sum_{k=1}^{N} \left[ y_k \log(\hat{y}_k) + (1 - y_k) \log(1 - \hat{y}_k) \right]
\]
- \( y_k \)：第 k 个样本的真实标签（1 = 有调控关系，0 = 无）
- \( \hat{y}_k \)：模型输出的 sigmoid 概率
- 用途：训练目标函数
- 来源：方法节 2.3 提及 "binary cross-entropy loss"

**3. 协方差选择邻域基因**（方法节 2.1，未给出显式公式）：
- 对每个目标基因，计算其与所有其他基因的表达协方差，选择 top-n 正协方差基因作为邻域
- 用途：确定哪些基因构成「邻域图像」的配对对象

## 11 结论正确解读

- **任务范围**：本文解决的是「从 scRNA-seq 表达数据推断 TF–基因调控关系」的二分类问题，而非连续调控强度预测或动态 GRN 建模。结论仅适用于细胞特异性 GRN 的静态推断。
- **Oracle/真值输入**：模型训练依赖 ChIP-seq 数据作为 gold standard 标签。这意味着：(1) 模型性能上限受 ChIP-seq 质量限制；(2) 对于缺乏 ChIP-seq 数据的细胞类型/物种，模型无法直接应用。
- **端到端状态**：DeepIMAGER 是端到端的有监督分类器，输入为 scRNA-seq 表达矩阵，输出为 TF–基因对互作概率。但「图像化」步骤需要预先计算协方差和分箱，并非完全端到端。
- **算力成本**：ResNet50 为 50 层深度网络，训练需要 GPU 资源；生成邻域图像需要计算全基因协方差矩阵，对高维数据（>20,000 基因）计算开销较大。
- **历史数据依赖**：模型在六种细胞系上训练/评估，这些细胞系涵盖人/小鼠、胚胎/成体、造血/免疫谱系，但未覆盖所有组织类型。MM 应用仅使用 168 个树突状细胞，样本量较小。
- **模型依赖**：结论基于 ResNet50 架构；作者自认 ResNet18 性能显著下降，说明架构选择对结果影响大。
- **最难情形**：跨细胞类型迁移（图 S4c-d）是模型最薄弱环节；低表达基因的 dropout 虽鲁棒，但极低表达基因的检测仍可能失败。
- **不确定性**：未报告置信区间或统计显著性检验；AUROC 的方差仅通过 boxplot 展示，未给出具体数值。
- **有边界的复述**：DeepIMAGER 在六种已测试细胞系上，以 ChIP-seq 标签为 gold standard，AUROC 达 0.95 以上，优于十种对比方法；该方法对 dropout 噪声鲁棒，但跨细胞类型泛化能力有限；在 MM 树突状细胞中识别的 GRN 包含已知疾病相关调控，但未经实验验证。

## 14 学到什么

> 标题：Agent 提炼的知识候选

| 知识候选 | 类型 | 可迁移性说明（面向 TF–DNA 结合 × AI/物理模拟） |
|----------|------|--------------------------------------------------|
| **将成对关系编码为 2D 直方图图像** | 方法 | 在 TF–DNA 结合预测中，可将 TF 的 DNA 结合域序列特征与靶基因启动子/增强子序列特征联合编码为 2D 图像（如 k-mer 共现矩阵），利用 CNN 捕捉结合 motif 的局部模式 |

| **ResNet 残差结构优于 VGG 平直结构** | 架构 | 在构建更深的 TF–DNA 结合预测网络时，优先选择残差连接以避免梯度退化；可迁移到基于 CNN 的 DNA 序列编码器设计 |
| **dropout 鲁棒性验证协议** | 实验设计 | 在 scRNA-seq 类噪声数据（如 ATAC-seq 的稀疏性）中，应系统性地引入 dropout 并测试模型稳定性；该协议可迁移到单细胞多组学整合的 TF 活性推断 |
| **有监督标签依赖 ChIP-seq 的局限** | 概念 | ChIP-seq 作为 gold standard 有细胞类型特异性和抗体质量偏差；在 TF–DNA 结合预测中应考虑标签噪声，或引入无监督/半监督信号 |
| **跨细胞类型迁移失败是重要基线** | 实验设计 | 在 TF–DNA 结合模型评估中，应报告跨细胞类型/跨物种迁移性能，而非仅报告同分布测试集结果 |
| **图像化 + 深度网络可解释性挑战** | 概念 | 图像化表示虽然提升精度，但解释「网络学到了什么」更困难；在 TF–DNA 结合预测中，若追求可解释的 motif 发现，需考虑注意力机制或可解释性模块 |

## 15 与已有知识连接

- **与 DeepDRIM 的关系**：DeepIMAGER 与 DeepDRIM 同属有监督深度学习方法，但 DeepIMAGER 引入邻域图像上下文，且将 ResNet50 替换 VGGNet。可对比两者在相同数据上的表现，验证邻域上下文和残差结构的增量贡献。
- **与 SCENIC/SCENIC+ 的关系**：SCENIC 使用相关性 + motif 分析推断 GRN，SCENIC+ 整合 scATAC-seq。DeepIMAGER 不依赖 motif 先验，而是从数据中学习，两者可互补——DeepIMAGER 的预测可作为 SCENIC+ 的候选边过滤。
- **与 BEELINE 框架的关系**：BEELINE 是 GRN 推断的标准评估框架，本文使用其预处理数据。可迁移 BEELINE 的评估协议到 TF–DNA 结合预测任务。
- **与 AlphaFold/Rosetta 等结构预测工具的关系**：DeepIMAGER 不涉及三维结构，但其「图像化 + CNN」思路可类比于结构预测中的 contact map 预测——将成对残基的共进化信息编码为 2D 特征图。TF–DNA 结合预测可借鉴此思路，将 TF 与 DNA 的共变异信息编码为 2D 图像。
- **与分子动力学（MD）模拟的关系**：MD 模拟可提供 TF–DNA 结合的物理细节，但计算成本高。DeepIMAGER 这类数据驱动方法可作为 MD 的粗筛工具——先用表达数据预测候选 TF–靶基因对，再用 MD 验证关键候选的物理结合可行性。
- **与 ChIP-seq 数据处理的关系**：本文使用 GTRD 数据库的 ChIP-seq 数据作为标签，与 ENCODE 等数据库的 ChIP-seq 数据可交叉验证。TF–DNA 结合预测中，ChIP-seq 峰 calling 的质量直接影响标签质量。
- **与单细胞多组学整合的关系**：作者在 Discussion 中提出未来整合 scATAC-seq、scHi-C、甲基化数据。这与当前单细胞多组学（如 10x Multiome）趋势一致，TF–DNA 结合预测可整合染色质可及性（scATAC）与表达（scRNA）信息。

## 16 研究想法

> 标题：Agent 生成的研究候选

### 候选 1：TF–DNA 结合位点的「共表达图像化」预测器
- **名称**：TF–DNA Contact Image Network (TDCIN)
- **来源局限/观察**：DeepIMAGER 将 TF–基因共表达编码为图像，但未利用 DNA 序列信息；TF–DNA 结合预测通常仅用序列特征，忽略表达上下文
- **核心假设**：将 TF 的序列偏好（PWM/k-mer 特征）与靶基因启动子的染色质可及性（scATAC）和共表达模式联合编码为 2D 图像，可提升结合位点预测精度
- **初步方法**：对每个 TF–启动子对，构建「序列相似性 × 表达共变」的 2D 特征图，输入 ResNet 变体；以 ChIP-seq 峰为标签
- **验证方式**：在 ENCODE 多细胞系 ChIP-seq 数据上评估 AUROC/PR-AUC，与 DeepBind、DeepSEA 对比
- **创新状态**：unverified

### 候选 2：跨细胞类型 TF–DNA 结合的域适应框架
- **名称**：Cell-type Adaptive TF Binding (CATB)
- **来源局限/观察**：DeepIMAGER 作者自认跨细胞类型迁移效果差；TF–DNA 结合具有强细胞类型特异性
- **核心假设**：通过对抗训练或元学习，提取细胞类型无关的 TF 结合特征，同时保留细胞类型特异的调控上下文
- **初步方法**：在 DeepIMAGER 框架中加入域对抗网络（DANN），源域为有 ChIP-seq 的细胞系，目标域为无 ChIP-seq 的细胞类型
- **验证方式**：在六种细胞系上做留一法（leave-one-cell-line-out）评估，比较域适应前后的 AUROC
- **创新状态**：unverified

### 候选 3：结合 MD 模拟的 TF–DNA 结合「图像 + 物理」双通道模型
- **名称**：IMAGER-MD Hybrid
- **来源局限/观察**：DeepIMAGER 纯数据驱动，无法解释结合的物理机制；MD 模拟可提供结合自由能但计算昂贵
- **核心假设**：将 DeepIMAGER 的共表达图像特征与 MD 模拟的接触图/结合能特征融合，可提升预测精度并提供物理可解释性
- **初步方法**：对候选 TF–DNA 对运行短时 MD 模拟，提取接触图作为第二通道输入；与共表达图像特征拼接后分类
- **验证方式**：在已知结构（PDB）的 TF–DNA 复合物上评估，比较融合模型与单通道模型的 AUROC
- **创新状态**：unverified

### 候选 4：dropout 鲁棒性的理论分析
- **名称**：Dropout-robust GRN Inference via Image Augmentation
- **来源局限/观察**：DeepIMAGER 对 dropout 鲁棒，但机制未解释；可能是图像化本身对稀疏性不敏感
- **核心假设**：2D 直方图的分箱操作天然具有对 dropout 的平滑效应，类似于数据增强
- **初步方法**：理论分析分箱操作对 dropout 噪声的方差压缩效应；在模拟数据上验证不同 dropout 率下图像化 vs 原始向量的误差界
- **验证方式**：模拟 scRNA-seq 数据（Splatter 等），比较图像化前后的互作预测误差
- **创新状态**：unverified

### 候选 5：多组学整合的 TF 活性推断
- **名称**：Multi-omics TF Activity via DeepIMAGER Extension
- **来源局限/观察**：作者在 Discussion 中提出整合 scATAC-seq、scHi-C、甲基化数据，但未实现
- **核心假设**：将染色质可及性、三维基因组（Hi-C）和 DNA 甲基化信息作为额外图像通道，可提升 GRN 推断的细胞类型特异性
- **初步方法**：扩展 DeepIMAGER 为多通道输入，每个组学数据生成独立 2D 直方图，通道融合后分类
- **验证方式**：在同时具有 scRNA-seq、scATAC-seq、Hi-C 的数据集（如人类造血分化）上评估
- **创新状态**：unverified
