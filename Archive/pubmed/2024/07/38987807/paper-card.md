## 02 一句话总结

本文提出 TFscope，一种基于 LASSO 逻辑回归的可解释机器学习框架，通过对比两组 ChIP-seq 数据（不同细胞类型、处理条件或旁系同源 TF），系统量化核心 motif、核甘酸环境与共因子三类序列特征对 TF 结合偏好差异的贡献，并在 350+ 对实验中验证其分类准确性与生物学可解释性。

## 03 研究问题

- **具体问题**：当同一 TF 在不同细胞类型、处理条件或旁系同源 TF 之间表现出不同的体内结合位点时，哪些序列特征（核心 motif 差异、核甘酸环境、共因子结合位点）能够解释这些结合偏好差异？各自贡献多大？
- **为什么重要**：真核 TF 的 PWM 通常不足以解释体内结合特异性；理解结合偏好差异的序列基础对解析基因调控机制、预测疾病相关变异的功能影响至关重要。
- **现有方法不足**：
  - 传统 PWM 是生成式模型，无法直接刻画两类位点间的判别性差异；
  - CNN 类深度学习方法预测准确但特征不可解释，难以拆解具体机制；
  - 已有研究多针对单一机制（如仅共因子或仅环境）在特定案例上验证，缺乏系统性、自动化的全局比较框架。
- **精确研究问题（Can...?）**：Can a linear model with explicitly controlled sequence features (discriminative PWM, k-mer environment, co-factor motifs) accurately classify TF binding sites from two different cellular contexts, and can the feature importance be reliably quantified?

## 04 背景与发展脉络

> 注：此脉络基于本文 Introduction 与 Discussion 的叙述，属于「仅本文框架」，未经外部系统核验。

1. **PWM 时代**：TF 结合特异性由 PWM/PPM 建模（如 JASPAR、HOCOMOCO 数据库），但真核 PWM 信息量不足，无法解释体内结合位点的特异性。
2. **ChIP-seq 揭示的复杂性**：全基因组 ChIP-seq 显示同一 TF 在不同细胞类型/条件下结合位点差异显著；大量体内位点缺乏高评分 motif 匹配，提示存在补充机制。
3. **补充机制假说**：
   - 共因子（co-factor）协同结合（TF-TF 互作，直接或 DNA 介导）；
   - 核甘酸环境（motif 侧翼序列的偏好性）；
   - 染色质可及性/组蛋白修饰（本文未直接建模，但通过环境特征间接捕获）。
4. **判别式 motif 学习**：DREME/STREME、DAMO、Homer 等工具可学习判别 motif，但针对的是「有/无 motif」的序列集，而非对齐后的核心区域判别，且依赖启发式。
5. **深度学习的兴起与局限**：CNN 可从序列预测 TF 结合（如 DeepBind、DeepSEA），准确率高但特征不可解释，难以拆解具体机制。
6. **本文位置**：提出一个**完全可控特征**的线性框架，在判别式 PWM 学习上给出最优算法（凸优化），并首次系统比较三类特征的相对贡献，填补了「可解释 + 系统性 + 自动化」的空白。

## 06 核心思想

### 1) 表面方法
TFscope 是一个三模块流水线：
- **TFscope-DM**：在已对齐的核心 motif 区域上，用 LASSO 逻辑回归学习判别式 PWM（直接优化分类目标，而非生成式概率）；
- **TFscope-NE**：基于 DExTER 的变体，在 motif 侧翼区域搜索判别性 k-mer（2-4 bp）及其富集区域；
- **TFscope-CF**：基于 TFcoop 的改进，在侧翼区域搜索共因子 PWM 的高分结合位点，并记录其相对位置；
- 最终将所有特征（DM 得分、k-mer 频率、共因子得分×位置）整合进一个全局 LASSO 逻辑回归模型，同时完成特征选择与分类。

### 2) 核心洞察
- **判别优于生成**：直接优化「区分两类位点」的目标，比分别估计每类的生成式模型更高效、更准确；
- **位置即信息**：共因子结合位点的相对位置（而非仅存在与否）对预测贡献显著；
- **可控特征 = 可解释性**：通过完全控制输入特征，特征重要性可直接通过 LASSO 系数或消融实验量化，避免了 CNN 的不可解释性；
- **对比设计规避背景问题**：通过直接对比两组 ChIP-seq 的独有位点，绕开了「结合 vs 未结合」的背景定义难题。

### 3) 可能的普适教训 [Analysis]
- 在序列建模中，**判别式目标 + 凸优化**可以在特定约束下达到最优，且比启发式更可靠；
- **特征的可控性**与**模型的可解释性**直接挂钩，对于生物学机制发现，线性模型 + 精心设计的特征往往优于黑箱深度学习；
- **位置编码**是序列特征工程中被低估的维度，尤其在蛋白-DNA 互作中，相对几何关系（如共因子在 motif 上游/下游、距离）可能携带关键信息。

## 07 方法总览

- **输入**：两组 ChIP-seq peak 文件（BED 格式），对应两种条件（细胞类型/处理/旁系同源 TF）
- **输出**：
  - 判别式 PWM（TFscope-DM）
  - 判别性 k-mer 及其区域（TFscope-NE）
  - 共因子 PWM 及位置（TFscope-CF）
  - 全局逻辑回归模型及特征重要性排序
  - 分类准确率（AUROC）
- **模块**：
  1. 序列选择与对齐：去除两组共有 peak，用 JASPAR PWM + FIMO 在 peak summit 附近定位最可能的 TFBS，提取以 TFBS 为中心的 1 kb 序列
  2. 特征提取：三个并行模块（DM/NE/CF）
  3. 模型学习：LASSO 逻辑回归（glmnet），自动特征选择
- **训练**：70% 训练 / 30% 测试，AUROC 评估
- **工具**：FIMO（motif 扫描）、glmnet（R 包，LASSO）、DExTER（k-mer 特征）、TFcoop（共因子分析）
- **反馈回路**：无显式迭代反馈；特征提取与模型学习为单向流水线
- **假设**：
  - 两组 ChIP-seq 的独有 peak 反映了真实的结合偏好差异（而非技术噪声）
  - JASPAR PWM 能可靠定位核心 TFBS
  - 共因子结合位点可通过 JASPAR 库中其他 TF 的 PWM 检测
  - 线性可加性：三类特征的贡献可线性叠加

**文字流程**：
```
输入两组 BED peak → 去除共有 peak → 用 JASPAR PWM + FIMO 定位 TFBS → 提取 1kb 对齐序列
→ [TFscope-DM: 学习判别式 PWM → DM(s) 得分]
→ [TFscope-NE: 搜索判别性 k-mer×区域 → NE_i(s) 频率]
→ [TFscope-CF: 搜索共因子 PWM×区域 → CF_j(s) 得分]
→ 所有特征拼接 → LASSO 逻辑回归 → 分类 + 特征重要性
```

## 09 关键公式符号

**公式 1：全局逻辑回归模型**
$$P(1|s) = S\left( a\cdot \text{DM}(s) + \sum_i b_i\cdot \text{NE}_i(s) + \sum_j c_j\cdot \text{CF}_j(s)\right)$$

- $P(1|s)$：序列 $s$ 属于第一类（如细胞类型 1）的概率
- $S$：sigmoid 函数
- $\text{DM}(s)$：判别式 PWM 对序列 $s$ 的得分
- $\text{NE}_i(s)$：第 $i$ 个 k-mer 在指定区域内的频率
- $\text{CF}_j(s)$：第 $j$ 个共因子 PWM 在指定区域内的最佳得分
- $a, b_i, c_j$：回归系数（LASSO 估计）

**公式 2：判别式 PWM 学习（TFscope-DM）**
$$P(1|s) = S\left( \sum_{k=1}^K \sum_{j=1}^4 a_{k,j} \cdot \mathbf{s}_{k,j} \right)$$

- $K$：PWM 长度
- $\mathbf{s}_{k,j}$：序列 $s$ 在位置 $k$ 是否为核苷酸 $j$ 的 one-hot 编码（0/1）
- $a_{k,j}$：位置 $k$、核苷酸 $j$ 的权重（即 PWM 参数）

**公式 3：双 PWM 逻辑回归（对比基线）**
$$P(1|s) = S\left( a + b_1 \text{PWM}_1(s) + b_2 \text{PWM}_2(s)\right)$$

- $\text{PWM}_1(s)$、$\text{PWM}_2(s)$：分别从两类序列独立估计的 PWM 对序列 $s$ 的得分
- $a, b_1, b_2$：回归参数

**公式 4：Jaccard 距离**
$$D_J = 1 - \frac{|A \cap B|}{|A \cup B|}$$

- $A, B$：两组 ChIP-seq peak 集合
- $|A \cap B|$：共有 peak 数；$|A \cup B|$：并集 peak 数

**用途说明**：公式 1 是最终预测模型；公式 2 是核心创新（判别式 PWM 学习）；公式 3 是用于对比的基线方法；公式 4 用于选择差异显著的 peak 对。

## 10 实验设计与证据链

### 数据集与规模
- **主数据集**：272 对 ChIP-seq 实验，来自 GTRD 数据库，涉及 86 个 TF、168 个细胞类型
- **处理条件数据集**：79 对 ChIP-seq 实验，同一细胞类型、不同处理
- **旁系同源 TF 数据集**：FOSL1 vs. FOSL2（同一数据集）、AR vs. NR3C1（MCF-7 细胞）
- **数据过滤**：UniBind p-value < 10⁻²；每类至少 100 个 peak；每对至少 500 个独有 peak
- **共因子验证**：ENCODE RNA-seq（RPKM）用于验证共因子表达差异

### 指标
- 分类准确率：AUROC（训练 70% / 测试 30%）
- PWM 简洁性：Gini 系数
- 特征重要性：LASSO 系数 + 消融实验（w/o DM、w/o NE、w/o CF）

- 原始 JASPAR PWM 得分
- DAMO 学习的判别 PWM
- 双 PWM 逻辑回归（公式 3）

## 11 结论正确解读

- **任务范围**：TFscope 解决的是「两类 ChIP-seq 位点间的**判别**」问题，而非「预测任意基因组位置的 TF 结合」问题。它不预测结合强度，只分类结合偏好差异。
- **特征类型**：仅使用序列特征（核心 motif、k-mer 环境、共因子 motif 得分），不包含染色质可及性、组蛋白修饰、DNA 甲基化等表观遗传特征。作者明确表示这些特征可能进一步增强预测，但超出本文范围。
- **oracle/真值输入**：ChIP-seq peak 本身是实验观测，但「独有 peak」的定义依赖于 peak calling 和交集/差集操作，存在技术噪声。UniBind p-value 过滤降低了假阳性，但不能完全消除。
- **端到端状态**：TFscope 是端到端可运行的流水线（BED 输入 → 分类模型输出），但特征提取依赖外部工具（FIMO、JASPAR 库），且需要用户提供目标 TF 的 PWM。
- **算力成本**：方法基于线性模型，计算开销低，远小于深度学习；主要成本在 FIMO 扫描（但可并行化）。
- **历史数据依赖**：依赖 ChIP-seq 数据库（GTRD）的历史数据，不同实验间的抗体质量、测序深度、peak calling 参数差异可能引入噪声。
- **最难情形**：当两类位点的序列差异极小时（如旁系同源 TF），分类准确率下降；当共因子 motif 与核心 motif 高度重叠或序列组成极端（如高 GC）时，特征归因可能不准确。
- **群体/领域边界**：结论基于人类（及部分小鼠）细胞系数据，对非模式生物的泛化性未验证。方法本身物种无关，但 JASPAR 库的覆盖度可能限制应用。
- **不确定性**：特征重要性基于 LASSO 系数和消融实验，但未提供置信区间；共因子识别依赖 JASPAR 库的完整性，未检测到的共因子可能被归入环境特征。

**有边界的复述**：TFscope 在 350+ 对 ChIP-seq 比较中，能够以中位数 AUROC > 80% 的准确率分类两类结合位点，且共因子位置信息是最重要的预测特征；核心 motif 差异在旁系同源 TF 比较中起主要作用；核甘酸环境贡献较小但不可忽略。这些结论仅适用于序列特征，不涉及染色质状态等非序列因素。

## 14 学到什么

> 标题：Agent 提炼的知识候选

1. **判别式 PWM 学习的最优性**：当序列已对齐且等长时，用逻辑回归直接优化判别目标可得到最优 PWM，且凸优化保证全局最优。可迁移到 TF–DNA 结合机制研究中，用于比较不同条件下（如突变 vs 野生型、不同旁系同源）的 motif 差异。
2. **特征可控性 = 可解释性**：通过显式设计三类特征（核心 motif、k-mer 环境、共因子×位置），并用 LASSO 做特征选择，可以在不牺牲预测能力的前提下获得生物学可解释的模型。这对课题方向中「从黑箱深度学习转向可解释模型」的趋势有直接借鉴意义。
3. **位置编码的重要性**：共因子结合位点的相对位置（而非仅存在与否）显著提升预测能力。在 TF–DNA 互作建模中，应显式编码 motif 间的相对距离和方向，而非仅使用全局特征。
4. **对比设计规避背景问题**：通过直接对比两组 ChIP-seq 的独有 peak，绕开了「结合 vs 未结合」背景集选择的难题。这一思路可推广到其他「两组条件比较」的场景（如不同处理、不同细胞类型）。
5. **Gini 系数作为 PWM 简洁性指标**：用 Gini 系数量化 PWM 的稀疏性/可解释性，是一个简单有效的模型复杂度度量，可用于比较不同方法学到的 motif 质量。
6. **消融实验设计**：通过「w/o DM」「w/o NE」「w/o CF」三类消融，系统量化每类特征的贡献。这种「特征类别消融」策略可迁移到课题方向的模型评估中，用于判断哪些序列特征真正驱动预测。
7. **共因子表达验证**：用 RNA-seq 验证共因子在对应细胞类型中的表达差异，为纯序列特征分析提供正交验证。在课题方向中，可结合蛋白互作数据库或共 ChIP-seq 数据做类似验证。

## 15 与已有知识连接

- **JASPAR / HOCOMOCO**：本文使用这两个数据库的 PWM 作为初始 motif 和共因子库。课题方向中，这两个数据库是 TF–DNA 结合机制研究的基础资源。
- **DREME/STREME、DAMO、Homer**：本文与这些判别式 motif 发现工具对比，指出它们在未对齐序列上的启发式局限，而 TFscope-DM 在对齐序列上给出最优解。课题方向中，这些工具是 motif 发现的常用基线。
- **DExTER**：本文的 NE 模块基于 DExTER 改进，DExTER 原本用于长调控元件识别。课题方向中，DExTER 可迁移到 TF 结合位点侧翼序列的特征提取。
- **TFcoop**：本文的 CF 模块是 TFcoop 的改进，TFcoop 用于识别共因子。课题方向中，TFcoop 是共因子分析的直接参考。
- **UniBind / GTRD**：本文使用 UniBind 的 p-value 过滤 ChIP-seq 数据，GTRD 提供大规模 ChIP-seq 数据。课题方向中，这两个数据库是 TF 结合数据的主要来源。
- **DeepBind / DeepSEA**：本文在 Introduction 中提及 CNN 方法预测准确但不可解释，与本文的可解释线性模型形成对比。课题方向中，深度学习方法与可解释方法的对比是核心议题。
- **Centrimo**：本文的序列对齐策略与 Centrimo 类似，Centrimo 用于在 ChIP-seq peak 中定位 motif 中心。课题方向中，Centrimo 是 motif 中心定位的常用工具。
- **RSAT-matrix clustering**：本文建议用 PWM 聚类处理共因子 motif 的相似性问题。课题方向中，PWM 聚类是处理 motif 冗余的常用方法。

## 16 研究想法

> 标题：Agent 生成的研究候选

### 候选 1：TFscope-3D — 将结构信息引入序列特征框架
- **名称**：TFscope-3D：融合 AlphaFold3 结构预测与序列特征的 TF 结合偏好分析
- **来源局限/观察**：TFscope 仅使用序列特征，未利用 3D 结构信息；而 TF–DNA 结合特异性本质上由三维互作决定
- **核心假设**：将 AlphaFold3 预测的 TF–DNA 复合物结构特征（如接触残基、氢键网络、结合界面形状互补性）作为额外特征，能显著提升结合偏好分类准确率，尤其在序列差异微小的旁系同源 TF 对中
- **初步方法**：对每对 ChIP-seq 独有 peak，用 AlphaFold3 预测 TF–DNA 复合物结构，提取结构特征（界面残基、DNA 弯曲角度、小沟宽度等），与 TFscope 的序列特征拼接，训练多模态逻辑回归或轻量 GNN
- **验证方式**：在 TFscope 的 272 对数据集上对比「序列-only」vs「序列+结构」的 AUROC；在 FOSL1/FOSL2 和 AR/NR3C1 旁系同源对上测试结构特征是否解决序列相似度高的问题
- **创新状态**：unverified

### 候选 2：动态共因子位置图谱
- **名称**：CoFactorPositionAtlas：TF 共因子结合位点相对位置的系统图谱
- **来源局限/观察**：TFscope 发现共因子位置信息重要，但仅输出单个最优区域，未系统刻画共因子位置的分布模式
- **核心假设**：不同 TF 家族具有特征性的共因子位置分布（如某些共因子偏好 motif 上游 50-100 bp，另一些偏好下游），这些分布模式可作为 TF 功能分类的新维度
- **初步方法**：对 TFscope 的 272 对结果，提取所有显著共因子变量的位置参数，聚类分析位置分布模式；与 TF 家族、DNA 结合域类型、共因子已知功能做关联分析
- **验证方式**：位置分布聚类是否与已知 TF 家族分类一致；能否预测未表征 TF 的共因子偏好
- **创新状态**：unverified

### 候选 3：序列-结构一致性评分
- **名称**：SeqStructScore：结合 PWM 与结构预测的 TF 结合位点质量评分
- **来源局限/观察**：TFscope 的判别 PWM 是纯序列模型，未考虑 DNA 结构可塑性（如 A-tract 弯曲、甲基化敏感位点）
- **核心假设**：某些序列变异虽不改变 PWM 得分，但通过改变 DNA 局部结构（如弯曲、柔韧性）影响 TF 结合；结合结构预测的评分能捕捉这些「隐形」变异
- **初步方法**：对 TFscope 分类错误的序列，用 MD 模拟或 DNA 结构预测工具（如 DNAshape）计算结构特征，训练纠错模型
- **验证方式**：纠错模型能否提升 AUROC；错误分类序列是否富集已知的结构敏感变异（如 CpG 甲基化位点）
- **创新状态**：unverified

### 候选 4：跨物种 TF 结合偏好迁移学习
- **名称**：TFscope-X：跨物种迁移的 TF 结合偏好预测
- **来源局限/观察**：TFscope 基于人类/小鼠数据，未测试跨物种泛化性；而许多物种的 ChIP-seq 数据稀缺
- **核心假设**：同源 TF 的结合偏好差异主要由少数关键氨基酸残基和 DNA 接触模式决定，可通过迁移学习从数据丰富的物种（人类）迁移到数据稀缺物种
- **初步方法**：用 TFscope 在人类数据上训练，提取判别 PWM 和共因子特征；对目标物种的同源 TF，用序列比对和结构预测识别关键差异位点，微调模型
- **验证方式**：在具有 ChIP-seq 数据的非人物种（如小鼠、斑马鱼）上测试迁移性能；与从头训练的模型对比
- **创新状态**：unverified

### 候选 5：TF 结合偏好与疾病变异的联合分析
- **名称**：TFscope-ClinVar：结合偏好差异与致病突变的关联分析
- **来源局限/观察**：TFscope 能识别两类条件下的结合偏好差异，但未与疾病关联；许多致病 SNP 位于 TF 结合位点附近
- **核心假设**：位于 TFscope 识别的高判别性特征区域（如共因子结合位点、特定 k-mer 环境）的 SNP 更可能具有致病性
- **初步方法**：对 ClinVar 中的调控区 SNP，计算其所在序列的 TFscope 特征值；比较致病 vs 良性 SNP 的特征分布差异；构建 SNP 致病性预测模型
- **验证方式**：特征区域 SNP 的致病性富集分析；与现有 SNP 功能预测工具（如 CADD、FunSeq2）对比
- **创新状态**：unverified
