## 02 一句话总结

Mut-Map 是一个以 UniProt ID 为输入、自动将 COSMIC 癌症突变映射到 PDB 实验结构和 AlphaFold 预测模型上的计算管道，通过残基重编号、溶剂可及性分类和距离阈值分析，将突变分类到 DNA 界面、配体结合位点、二聚体界面和核心区等结构上下文，并在 TP53 案例中验证了其识别 DNA 结合界面热点突变（如 R248Q、R273H）的能力。

## 03 研究问题

- **具体问题**：如何将大规模癌症体细胞突变数据系统地映射到蛋白质三维结构上，并自动分类其结构上下文（DNA 界面、配体结合位点、二聚体界面、核心区等），以支持突变功能影响的推断？
- **为什么重要**：突变的功能影响高度依赖于其在蛋白质结构中的位置。位于 DNA 结合界面的 TF 突变可能直接破坏 DNA 结合能力，而核心区突变可能影响蛋白质稳定性。系统化的结构映射是理解癌症驱动突变机制和开发靶向治疗的前提。
- **现有方法为何不足**：
  - COSMIC-3D 仅在已有 PDB 结构上渲染突变，不进行建模，且残基重编号有时不准确；
  - 现有工具（如 MutationMapper）缺乏基因水平的跨结构综合分析；
  - 缺乏对无实验结构区域的覆盖（未利用 AlphaFold 模型）；
  - 缺乏自动化的结构上下文分类（如 DNA 界面、配体位点、二聚体界面的区分）。
- **精确的「Can ... ?」研究问题**：Can an automated pipeline integrate COSMIC mutation data with PDB and AlphaFold structures to accurately map and classify cancer-associated mutations by their structural context (e.g., DNA-binding interface, ligand-binding site, dimer interface, core region) at the gene level?

## 04 背景与发展脉络

> 注：以下脉络基于本文引言与讨论，标注为「仅本文框架」——未逐一核验外部文献。

1. **阶段一：突变列表与一维注释**（早期）
   - 代表性方法：COSMIC 数据库本身，仅提供突变位置和频率，无结构上下文。
   - 优点：数据量大、覆盖广。
   - 局限：无法解释突变如何影响蛋白质三维结构和功能。

2. **阶段二：单结构可视化**（中期）
   - 代表性方法：MutationMapper、COSMIC-3D。
   - 优点：可在单个 PDB 结构上可视化突变位置。
   - 局限：仅覆盖有实验结构的区域；残基编号不一致导致映射错误；无自动化结构上下文分类；无建模能力。

3. **阶段三：结构预测与自动化管道**（当前，本文位置）
   - 代表性方法：Mut-Map（本文）。
   - 优点：基因水平全结构覆盖（PDB + AlphaFold）；自动化残基重编号（PDBrenum）；溶剂可及性分类（FreeSASA）；距离阈值分类（DNA 界面、配体、二聚体、锌离子）；突变体建模（Modeller）；Web 界面 + 数据库存储。
   - 局限：依赖外部数据库的准确性和更新频率；分类基于简单距离/可及性阈值，不包含能量计算或分子动力学模拟。

## 06 核心思想

### 1) 表面方法
构建一个自动化 Web 管道：输入 UniProt ID → 获取 COSMIC 突变数据 → 映射到所有相关 PDB 结构 + AlphaFold 模型 → 残基重编号 → 溶剂可及性计算 → 距离阈值分类（DNA 界面、配体、二聚体、锌离子）→ 突变体建模 → 可视化（MolStar）→ 输出综合表格。

### 2) 核心洞察
- **基因水平而非结构水平分析**：一个基因可能有多个 PDB 结构（不同构象、不同域、不同寡聚状态），单结构分析会遗漏突变在其他结构上下文中的影响。Mut-Map 将所有可用结构纳入分析，提供全面的结构上下文视图。
- **实验结构与预测模型互补**：AlphaFold 模型填补了实验结构的空白，确保无 PDB 覆盖的区域也能进行突变映射。
- **结构上下文分类是功能推断的桥梁**：将突变分类到 DNA 界面、配体位点、二聚体界面或核心区，为后续功能预测（如是否影响 DNA 结合）提供直接的结构依据。

### 3) 可能的普适教训 [Analysis]
- 对于 TF–DNA 互作研究，**结构上下文的自动化分类**（特别是 DNA 界面 vs. 非界面）是连接突变组学与功能机制的关键中间层。类似管道可直接迁移到其他 TF 家族（如 MYC、FOXO、STAT 等）的突变分析。
- **多结构覆盖优于单结构分析**：TF 常有多结构域、多构象，单结构分析可能产生误导性结论。
- 简单几何阈值（距离、可及性）虽粗糙，但在大规模筛选中具有实用价值，可作为更精确计算（如 MD、对接）的前置过滤器。

## 07 方法总览

- **输入**：UniProt ID 或基因名
- **输出**：综合表格（突变列表 + 结构上下文分类 + 频率 + 无序区域标注）、3D 可视化（MolStar）、突变体结构模型
- **模块**：
  1. **结构获取**：从 PDB 获取实验结构；从 AlphaFold DB 获取预测模型
  2. **残基重编号**：使用 PDBrenum 统一残基编号
  3. **突变数据获取**：从 COSMIC 获取体细胞突变及频率
  4. **溶剂可及性计算**：使用 FreeSASA，阈值 <25 = core，>80 = interface，25–80 = noninterface
  5. **结构上下文分类**：距离阈值 6 Å（配体结合位点）、5 Å（二聚体界面、DNA 界面、锌离子）
  6. **突变体建模**：使用 Modeller 生成突变体结构
  7. **可视化与展示**：MolStar 3D 查看器 + Web 前端（Flask + HTML5 + CSS + Bootstrap）
  8. **数据存储**：PostgreSQL 数据库，支持结果缓存与检索
- **训练**：不适用（非机器学习方法）
- **工具依赖**：PDBrenum、FreeSASA、Modeller、MolStar、Flask、PostgreSQL
- **反馈回路**：用户可通过 Web 界面查询已生成结果，无需重新运行管道
- **假设**：距离阈值和溶剂可及性阈值能有效近似功能相关的结构上下文；AlphaFold 模型质量足以用于突变映射

**文字流程**：
用户提交 UniProt ID → 管道查询 PDB 获取所有相关实验结构 → 查询 AlphaFold DB 获取预测模型 → 使用 PDBrenum 统一编号 → 从 COSMIC 获取突变列表及频率 → 对每个结构计算溶剂可及性（FreeSASA）→ 对每个突变计算其与配体、DNA、另一亚基、锌离子的距离 → 根据阈值分类 → 对感兴趣突变用 Modeller 生成突变体模型 → 结果存入 PostgreSQL → 用户通过 Web 界面查看综合表格和 MolStar 3D 可视化。

## 09 关键公式符号

本文为管道工具描述，未提供数学公式。核心参数为经验阈值：

- **溶剂可及性分类阈值**：
  - Core：可及性值 < 25
  - Interface：可及性值 > 80
  - Noninterface：25 ≤ 可及性值 ≤ 80

- **距离分类阈值**：
  - 配体结合位点：距离 ≤ 6 Å
  - 二聚体界面（同源/异源）：距离 ≤ 5 Å
  - 蛋白-DNA 界面：距离 ≤ 5 Å
  - 锌离子辅因子：距离 ≤ 5 Å

> 注：这些阈值是经验设定，文中未给出推导或优化过程。

## 11 结论正确解读

- **任务范围**：本文仅验证了管道在 TP53 上的可行性，未推广到其他基因或全基因组水平。
- **Oracle/真值输入**：输入为 UniProt ID，依赖 COSMIC 和 PDB/AlphaFold 的数据质量。
- **端到端状态**：管道已实现端到端自动化（输入 ID → 输出综合结果），但突变功能影响的推断仍依赖用户后续分析。
- **算力成本**：未提供；Modeller 建模可能为计算瓶颈。
- **历史数据依赖**：依赖 COSMIC 的突变注释和 PDB 的结构覆盖，两者均随时间更新。
- **模型依赖**：依赖 AlphaFold 模型质量；对低置信度区域（如无序区）的映射可能不准确。
- **最难情形**：无实验结构且 AlphaFold 置信度低的区域；多结构域蛋白质的域间突变；影响蛋白质动力学而非静态结构的突变。
- **群体/领域边界**：仅适用于人类癌症相关突变；不适用于种系突变或其他物种。
- **不确定性**：距离阈值和可及性阈值的生物学意义未经验证；突变对蛋白质功能的影响未通过实验或计算（如 MD、结合自由能计算）验证。

**有边界的复述**：Mut-Map 是一个能将 COSMIC 癌症突变自动映射到 PDB 和 AlphaFold 结构上并进行结构上下文分类的计算管道，在 TP53 案例中成功识别了 DNA 结合界面的高频突变。该工具适用于人类癌症体细胞突变的结构注释，但其分类基于简单几何阈值，不包含能量或动力学评估，且未在多个基因上系统验证。

| 未验证 AlphaFold 模型在突变映射中的可靠性 | AlphaFold 对无序区域和突变体的预测置信度可能低；突变可能改变局部构象 | 低质量模型可能导致错误映射 | 比较 AlphaFold 模型与实验结构在相同突变上的分类一致性 | Methods 节：使用 AlphaFold 模型 |

## 14 学到什么

> Agent 提炼的知识候选

1. **结构上下文分类作为突变功能预测的中间层**：Mut-Map 展示了将突变分类到 DNA 界面、配体位点、二聚体界面等结构上下文的方法。对于 TF–DNA 互作研究，可迁移此思路：将 TF 突变按是否位于 DNA 结合界面分类，作为预测突变是否影响 DNA 结合的先验特征。

2. **基因水平多结构覆盖策略**：一个 TF 可能有多个 PDB 结构（不同构象、不同域、不同物种同源物）。Mut-Map 的基因水平策略（而非单结构策略）可迁移到 TF 突变分析，避免因选择单一结构而遗漏关键突变上下文。

3. **实验结构与预测模型互补**：AlphaFold 填补实验结构空白。对于缺乏实验结构的 TF 家族，可先使用 AlphaFold 模型进行突变映射，再用实验结构验证关键发现。

4. **简单几何阈值作为高效预筛选**：距离阈值（5–6 Å）和溶剂可及性分类虽粗糙，但计算成本极低，适合大规模突变筛选。可将其作为 MD 模拟或结合自由能计算的前置过滤器，减少计算负担。

5. **Web 工具 + 数据库缓存模式**：将管道封装为 Web 服务并缓存结果，可提升研究效率。对于 TF 突变数据库建设，可参考此架构。

6. **无序区域突变的显式处理**：Mut-Map 显式计算无序百分比并统计无序区域突变。对于 TF 的 intrinsically disordered regions（如 activation domains），此方法可帮助区分 DNA 结合域突变与调控域突变的功能差异。

## 15 与已有知识连接

- **COSMIC 数据库**（Forbes et al.）：本文的突变数据来源。TF 突变研究可直接使用 COSMIC 的突变频率数据，结合 Mut-Map 的结构分类进行功能推断。
- **AlphaFold**（Jumper et al., Nature 2021）：本文使用 AlphaFold 模型填补结构空白。对于 TF–DNA 互作研究，AlphaFold 预测的 TF 结构可与实验结构（如 ChIP-exo、X-ray 共晶结构）结合使用。
- **PDBrenum**：残基重编号工具。在 TF 突变映射中，不同 PDB 结构的 numbering 不一致是常见问题，此工具可迁移使用。
- **FreeSASA**（Mitternacht, 2016）：溶剂可及性计算。TF 的 DNA 结合界面残基通常具有特征性可及性模式，可与此工具结合分析。
- **FoldX / SDM / mCSM**：作者计划集成的突变稳定性预测工具。这些工具可用于 TF 突变的 ΔΔG 预测，与 Mut-Map 的结构分类互补。
- **Pino et al. (2022)**：本文引用的关于癌症突变结构背景的研究，发现肿瘤抑制因子富集结构破坏性突变，癌基因富集结构温和突变。此发现对 TF 突变研究有直接启示：TF 作为肿瘤抑制因子（如 p53）或癌基因（如 MYC），其突变的结构模式可能不同。
- **MolStar**（Sehnal et al., 2021）：3D 可视化工具。可用于 TF–DNA 复合物的突变可视化。

## 16 研究想法

> Agent 生成的研究候选

### 候选 1：TF 突变结构上下文分类器（TF-MutClass）
- **名称**：TF-MutClass: A Structural Context Classifier for Transcription Factor Mutations
- **来源局限/观察**：Mut-Map 提供结构分类但无功能预测；现有工具未针对 TF 家族优化 DNA 界面定义
- **核心假设**：TF 的 DNA 结合域具有保守的结构特征，基于这些特征训练的突变分类器能比通用距离阈值更准确地区分 DNA 界面突变与非界面突变
- **初步方法**：收集多个 TF 家族的 DNA 结合域结构（PDB + AlphaFold），用已知 DNA 复合物结构定义每个残基的 DNA 接触状态；训练一个基于残基环境特征（可及性、保守性、静电势、到 DNA 距离）的分类器；与 Mut-Map 的固定阈值方法对比
- **验证方式**：使用已知功能影响的 TF 突变数据集（如 TP53 功能丧失突变数据库）评估分类器对功能影响的预测能力
- **创新状态**：unverified

### 候选 2：TF 突变对 DNA 结合亲和力影响的 MD 预筛管道
- **名称**：MD-PreScreen: Integrating Mut-Map Classification with Molecular Dynamics for TF-DNA Binding Affinity Prediction
- **来源局限/观察**：Mut-Map 仅做静态结构分类，不评估突变对 DNA 结合动力学的影响；MD 模拟计算成本高，不适合大规模突变筛选
- **核心假设**：Mut-Map 的结构上下文分类可作为 MD 模拟的预筛条件，优先模拟位于 DNA 界面的高频突变，从而在有限计算预算内获得最大信息量
- **初步方法**：以 TP53 为测试体系，从 Mut-Map 输出中选取 DNA 界面突变（如 R248Q, R273H）和非界面突变作为对照；对每个突变进行短时 MD 模拟（如 100 ns），计算 DNA 结合界面残基的 RMSF 变化和氢键网络破坏程度；与实验结合亲和力数据（如表面等离子共振数据）对比
- **验证方式**：MD 预测的亲和力变化与实验数据的相关性
- **创新状态**：unverified

### 候选 3：基于图神经网络的 TF 突变功能影响预测
- **名称**：TF-GNN: Graph Neural Network for Predicting Functional Impact of TF Mutations from Structural Context
- **来源局限/观察**：Mut-Map 输出为结构化分类数据，适合作为图神经网络（GNN）的节点特征；现有突变预测工具（如 PolyPhen、SIFT）未充分利用 3D 结构上下文
- **核心假设**：将蛋白质结构表示为图（节点=残基，边=空间邻近），以 Mut-Map 的分类特征（可及性、界面状态、突变频率）作为节点特征，GNN 能捕捉突变对局部结构环境的扰动模式，从而预测功能影响
- **初步方法**：构建 TF 蛋白质结构图数据集；节点特征包括 Mut-Map 分类、保守性（PhyloP）、突变频率；标签为已知功能影响（如肿瘤抑制 vs. 中性）；训练 GNN 分类器；与序列-based 方法对比
- **验证方式**：独立测试集上的 AUC、精确率-召回率
- **创新状态**：unverified

### 候选 4：TF 无序区域突变的系统分析
- **名称**：Disorder-Aware TF Mutation Analysis: Extending Mut-Map to Intrinsically Disordered Regions
- **来源局限/观察**：Mut-Map 统计无序区域突变但未深入分析；TF 的 activation domains 常为无序区域，其突变可能影响相分离或共调控因子招募
- **核心假设**：位于 TF 无序区域的癌症突变通过影响相分离行为或共调控因子结合来改变功能，而非通过破坏 DNA 结合
- **初步方法**：从 Mut-Map 输出中提取位于无序区域的 TF 突变；用 AlphaFold 预测无序区域；结合共调控因子互作数据（如 BioGRID）分析无序区域突变是否富集在互作界面；对候选突变进行体外相分离实验
- **验证方式**：无序区域突变与共调控因子互作破坏的相关性
- **创新状态**：unverified

### 候选 5：跨 TF 家族的突变结构模式比较
- **名称**：Pan-TF Structural Mutation Atlas: Comparative Analysis of Mutation Patterns Across Transcription Factor Families
- **来源局限/观察**：Mut-Map 在 TP53 上验证，但未扩展到其他 TF 家族；不同 TF 家族（锌指、bZIP、bHLH、homeodomain）的 DNA 结合域结构差异大
- **核心假设**：不同 TF 家族的癌症突变在结构上下文分布上存在系统性差异，反映其不同的功能约束
- **初步方法**：对 50+ 个 TF 基因运行 Mut-Map 管道；按 TF 家族分组，比较 DNA 界面突变比例、核心区突变比例、无序区域突变比例；结合肿瘤类型数据，分析家族特异的突变-结构模式
- **验证方式**：家族间差异的统计显著性；与已知功能数据的一致性
- **创新状态**：unverified
