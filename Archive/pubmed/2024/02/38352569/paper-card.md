## 02 一句话总结

本文构建了一个基于序列特异性热力学模型的 MPRA 计算模拟流水线，通过生成数万个合成单细胞表达谱并计算信息足迹与表达位移矩阵，系统揭示了突变率、库大小、TF 拷贝数、结合自由能、诱导物浓度及重叠结合位点等参数对从 MPRA 数据中推断 TF 结合位点的能力的影响边界。

## 03 研究问题

- **具体问题**：在 MPRA 实验中，哪些生物学和实验参数会影响我们从表达数据中准确推断转录因子结合位点的能力？如何优化实验设计以最大化信息足迹的信噪比？
- **为什么重要**：绝大多数已测序基因组中的基因缺乏转录调控注释。MPRA 是理解序列-表型关系的关键高通量工具，但缺乏对实验参数如何影响数据解读的系统性理论分析。
- **现有方法不足**：传统热力学模型通常不具序列特异性（结合能为唯象参数），且缺乏对 MPRA 实验流程（突变库构建、测序噪声、TF 滴定效应等）的系统模拟；实验上无法逐一穷举参数空间。
- **精确研究问题**：Can we use sequence-specific thermodynamic models to generate synthetic MPRA datasets that reveal the parameter regimes under which TF binding sites are recoverable from information footprints?

## 04 背景与发展脉络

*注：以下脉络基于本文框架，未经外部系统核验，标注为「仅本文框架」。*

1. **阶段一：经典热力学模型（2000s-2010s）**
   - 代表：Ackers、Shea、Bintu 等人的统计力学模型，用 Boltzmann 权重描述 TF 与 RNAP 竞争结合启动子。
   - 优点：解析表达式简洁，能解释简单调控架构（如简单抑制）的平均表达。
   - 局限：结合能通常为唯象参数，不具序列特异性；无法预测突变效应。

2. **阶段二：序列特异性热力学模型（2010s）**
   - 代表：Sort-Seq（Kinney et al.）实验测定能量矩阵，使热力学模型具备碱基分辨率。
   - 优点：可计算任意序列变体的结合能，实现序列→表达的理论预测。
   - 局限：能量矩阵的测定依赖特定实验体系，推广性有限。

3. **阶段三：MPRA 实验与信息足迹分析（2015-2020s）**
   - 代表：Reg-Seq（Ireland et al.）用 RNA-seq 测量突变库表达，计算互信息生成信息足迹。
   - 优点：高通量、可并行测量数千序列变体。
   - 局限：缺乏对实验参数（突变率、库大小、TF 拷贝数）如何影响足迹解读的系统理论分析。

4. **阶段四：本文的合成数据模拟框架（2024）**
   - 主张位置：在序列特异性热力学模型与 MPRA 实验之间建立桥梁，通过生成合成数据系统评估参数效应，为实验设计提供理论指导，并初步扩展到非平衡态（图论方法）。

## 06 核心思想

### 1) 表面方法
构建一个计算流水线：输入启动子序列和能量矩阵 → 用热力学模型（公式 1）计算每个序列变体的 RNAP 结合概率 → 通过 occupancy hypothesis（公式 3-5）预测 mRNA 表达水平 → 模拟突变库构建（设定突变率、库大小、突变偏好）→ 计算信息足迹（公式 6-8）和表达位移矩阵（公式 9-10）→ 评估不同参数下结合位点的可检测性。

### 2) 核心洞察
- **κ 参数作为信号可检测性的理论预测器**：TF 与 RNAP 的 Boltzmann 权重之比 κ（公式 12）决定了突变对表达的影响方向与幅度。κ≈1 时信号最强；κ≫1 或 κ≪1 时信号减弱。
- **Hitch-hiking 效应是噪声的主要来源**：小库中非结合位点突变与结合位点突变偶然共现，产生虚假信号。
- **信息足迹的解读需要先验知识**：缺乏信号不等于缺乏结合位点，可能是弱结合、低拷贝或高突变率所致。

### 3) 可能的普适教训 [Analysis]
- **理论-实验对话需要"实验的理论"**：本文展示了如何为一种实验技术建立完整的理论模型，从而在实验前预测参数效应、在实验后正确解读数据。这一思路可迁移到其他高通量技术（如 STARR-seq、DAP-seq）的优化。
- **信号可检测性存在参数边界**：任何测量技术都有其可检测的参数空间边界，明确这些边界是正确解读数据的前提。

## 07 方法总览

- **输入**：启动子序列（如 lacZYA）、能量矩阵（RNAP 和 TF 的序列特异性结合能，来自 Sort-Seq 实验）、生物学参数（P、R、NNS、Δε）、实验参数（突变率 θ、库大小 N、突变偏好）
- **输出**：合成表达数据集、信息足迹、表达位移矩阵、信噪比
- **核心模块**：
  1. 序列→结合能映射（公式 2，能量矩阵加法模型）
  2. 结合能→RNAP 结合概率（公式 1，平衡态热力学）
  3. 结合概率→mRNA 表达（公式 3-5，occupancy hypothesis）
  4. 突变库生成（设定突变率和偏好）
  5. 信息足迹计算（公式 6-8，互信息）
  6. 表达位移矩阵计算（公式 9-10）
  7. 非平衡扩展（图论方法，公式 44-47）
- **训练**：无监督（无实验数据拟合，纯前向模拟）
- **反馈回路**：通过改变参数观察足迹变化，形成"参数→足迹"的映射关系
- **文字流程**：给定启动子序列 → 用能量矩阵计算每个位点的结合能 → 代入热力学模型计算 RNAP 结合概率 → 乘以转录速率得到 mRNA 水平 → 对每个序列变体重复 → 生成突变库（含突变率和偏好）→ 计算每个位点的互信息和表达位移 → 绘制信息足迹和表达位移矩阵 → 改变参数重复上述过程

## 09 关键公式符号

**公式 1（简单抑制的 RNAP 结合概率）**：
```
p_bound = (P/N_NS)·e^(−βΔε_pd) / (1 + (P/N_NS)·e^(−βΔε_pd) + (R/N_NS)·e^(−βΔε_rd))
```
- P：RNAP 拷贝数；R：TF 拷贝数；N_NS：非特异性结合位点数；Δε_pd：RNAP 特异性结合能；Δε_rd：TF 特异性结合能；β = 1/(k_B T)

**公式 2（序列→结合能）**：
```
Δε = Σᵢ ε_{i,bᵢ}
```
- ε_{i,bᵢ}：位置 i 处碱基 bᵢ 的能量矩阵元素

**公式 3-5（occupancy hypothesis）**：
```
dm/dt = Σᵢ rᵢ·p_bound,ᵢ − γ·m
m* = (1/γ)·Σᵢ rᵢ·p_bound,ᵢ = α·Σᵢ p_bound,ᵢ
```
- rᵢ：状态 i 的转录速率；γ：mRNA 降解速率；α = r/γ

**公式 6（互信息）**：
```
Iᵢ = Σ_b Σ_μ Prᵢ(b,μ) · log₂( Prᵢ(b,μ) / (Prᵢ(b)·Pr(μ)) )
```
- b：碱基身份（或突变状态）；μ：表达水平分箱

**公式 9（表达位移）**：
```
Δsₗ = (1/n)·Σᵢ₌₁ⁿ ξᵢ,ₗ·(cᵢ − ⟨c⟩)
```
- ξᵢ,ₗ = 1 若位置 l 突变；cᵢ：第 i 个变体的表达；⟨c⟩：平均表达

**公式 10（表达位移矩阵）**：
```
Δs_{b,l} = (1/n)·Σᵢ ξ_{b,i,l}·(cᵢ/⟨c⟩ − 1)
```
- ξ_{b,i,l} = 1 若位置 l 突变为碱基 b

**公式 12（κ 参数）**：
```
κ = (R/P)·e^(−β(Δε_rd − Δε_pd + m_r·ΔΔε_rd − m_p·ΔΔε_pd))
```
- m_r、m_p：TF 和 RNAP 结合位点内的突变数；ΔΔε：每个突变的平均能量效应

**公式 41（诱导物依赖的 TF 活性）**：
```
p_active(c) = (1 + c/K_A)² / [(1 + c/K_A)² + e^(−βΔε_AI)·(1 + c/K_I)²]
```
- c：诱导物浓度；K_A、K_I：活性/非活性态诱导物解离常数；Δε_AI：活性-非活性态能量差

**公式 44-47（非平衡图论）**：
- 使用 Matrix Tree Theorem 计算稳态概率，涉及速率常数 k_on、k_off 和能量投资 U（公式 46：k_off = k_off^eq · e^(βU)）

## 11 结论正确解读

- **任务范围**：本文仅针对原核生物（大肠杆菌）的转录起始调控，使用平衡态热力学模型（及初步非平衡扩展）。结论不直接适用于真核生物（染色质、增强子-启动子环化等额外复杂性）。
- **oracle/真值输入**：能量矩阵来自 Sort-Seq 实验测定，属于"已知答案"的输入；合成数据完全由模型生成，无真实实验噪声。
- **端到端状态**：非端到端。模型从序列预测表达，但未包含 RNA-seq 实验的完整噪声模型（如 PCR 扩增偏差、测序深度波动仅部分模拟）。
- **算力成本**：未提供具体计算资源需求，但模拟数万序列的计算成本较低。
- **历史数据依赖**：依赖 Sort-Seq 测定的能量矩阵，该矩阵的准确性直接影响所有下游结论。
- **模型依赖**：所有结论基于热力学模型的假设（平衡态、无协同性、无 DNA 构象变化等）。非平衡扩展仅初步。
- **最难情形**：重叠结合位点、弱结合位点、高突变率下的位点检测。
- **群体/领域边界**：结论适用于原核启动子调控；对真核增强子、染色质调控的适用性未验证。
- **不确定性**：未提供置信区间或敏感性分析；κ 阈值（0.1）为经验设定。

**有边界的复述**：在平衡态热力学假设下，对于大肠杆菌 lacZYA 类启动子，MPRA 信息足迹对 TF 结合位点的检测能力受突变率（最优约 10%）、库大小（≥5000 可有效抑制 hitch-hiking 噪声）、TF 拷贝数（需使 κ≥0.1）和结合强度（Δε_rd≤-11 k_BT）的联合约束；重叠位点和非平衡过程可能进一步降低检测能力。

## 14 学到什么

### Agent 提炼的知识候选

1. **"实验的理论"框架**：为高通量实验建立完整的前向模型，在实验前预测参数效应、实验后正确解读数据。可迁移到 TF–DNA 结合机制研究中其他高通量技术（如 DAP-seq、STARR-seq、HT-SELEX）的优化与数据解读。

2. **κ 参数作为信号可检测性的理论预测器**：TF 与 RNAP 的 Boltzmann 权重之比决定了突变对表达的影响方向与幅度。这一概念可推广到其他竞争性结合场景（如激活子与抑制子竞争、不同 TF 竞争同一结合位点）。

3. **Hitch-hiking 效应的定量理解**：小库中非结合位点突变与结合位点突变偶然共现产生虚假信号。这一统计效应在 AI 辅助的 TF 结合位点预测中同样重要——训练数据的库大小直接影响模型对噪声的鲁棒性。

4. **信息足迹 + 表达位移矩阵的组合分析**：互信息识别位点位置，表达位移矩阵提供结合类型（激活/抑制）信息。这种双通道分析策略可迁移到 AI 模型的可解释性设计——不仅预测结合位点，还预测调控方向。

5. **非平衡效应的初步建模**：通过图论方法（Matrix Tree Theorem）打破细致平衡假设，展示了能量投资如何改变足迹解读。对 AI 方法而言，这意味着训练数据中可能包含非平衡调控的样本，模型需要能够区分平衡与非平衡机制。

6. **参数扫描的系统方法论**：逐一扰动生物学参数（拷贝数、结合能、诱导物）并观察足迹变化，建立了"参数→可检测性"的映射。这种敏感性分析框架可直接用于评估 AI 模型在不同生物学条件下的泛化能力。

7. **重叠结合位点的信号混淆问题**：高度重叠的 TF 结合位点导致信号不可分。这对 AI 模型意味着：训练数据中重叠位点的标注需要特别谨慎，模型可能需要显式建模位点间的竞争关系。

8. **弱结合位点的检测极限**：结合能低于阈值（约 -11 k_BT）时信号消失。这对 TF–DNA 结合机制研究有直接启示：弱结合位点可能在功能上重要但难以通过 MPRA 检测，需要互补方法（如 SELEX 或 MD 模拟）来表征。

## 16 研究想法

### Agent 生成的研究候选

**候选 1：基于深度学习的 MPRA 足迹反演模型**
- **名称**：FootprintNet——从信息足迹到调控架构的端到端反演
- **来源局限/观察**：本文展示了正问题（序列→足迹），但未解决反问题（足迹→架构）。实际应用中，实验者只有足迹数据，需要推断底层调控架构。
- **核心假设**：信息足迹和表达位移矩阵包含足够的统计信息，可训练深度学习模型反推出 TF 结合位点位置、结合类型和相对强度。
- **初步方法**：用本文的合成数据生成器产生大量（足迹，架构）配对，训练 CNN/Transformer 模型学习映射；在合成数据上验证后，用 Reg-seq 实验数据测试。
- **验证方式**：在合成数据上比较模型推断的架构与真实架构的准确率；在实验数据上与人工注释对比。
- **创新状态**：unverified（本文未涉及反问题，但正问题模型可作为训练数据生成器）

**候选 2：非平衡效应的 AI 可解释性研究**
- **名称**：NonEquilibrium-AI——检测 MPRA 数据中的非平衡调控信号
- **来源局限/观察**：本文 Sec 4 显示非平衡过程可导致 TF 表现为激活子或抑制子，但仅初步探索。AI 模型若忽略非平衡效应，可能系统性地误分类 TF 功能。
- **核心假设**：非平衡调控在足迹中产生可检测的统计特征（如不对称的位移矩阵模式），可训练分类器识别。
- **初步方法**：用图论方法生成平衡与非平衡合成数据，训练二分类器区分；分析分类器关注的特征，提取非平衡调控的统计指纹。
- **验证方式**：在已知非平衡调控系统（如磷酸化调控的 TF）的实验数据上验证分类器。
- **创新状态**：unverified（本文仅展示非平衡可改变足迹，未提出检测方法）

**候选 3：重叠结合位点的解卷积算法**
- **名称**：DeconvolveTF——从混合足迹中分离重叠 TF 结合事件
- **来源局限/观察**：本文图 14 显示重叠结合位点导致信号混淆，但未提出解决方案。这是 MPRA 数据解读的实际瓶颈。
- **核心假设**：重叠位点的足迹是各独立位点足迹的某种组合（线性或非线性），可通过稀疏编码或独立成分分析分离。
- **初步方法**：生成不同重叠程度的合成数据，训练稀疏编码模型学习独立位点的足迹基元；在合成数据上验证分离准确率。
- **验证方式**：在已知重叠位点架构的合成数据上测试；与人工设计的解卷积算法比较。
- **创新状态**：unverified（本文仅描述问题，未提出解法）

**候选 4：TF 拷贝数波动的随机模拟扩展**
- **名称**：StochasticFootprint——考虑 TF 拷贝数波动的 MPRA 足迹预测
- **来源局限/观察**：本文假设 TF 拷贝数为常数，但实际细胞中 TF 拷贝数存在显著波动（Brewster et al. 2018）。这种波动可能影响足迹的统计特性。
- **核心假设**：TF 拷贝数波动会加宽足迹峰并降低信噪比，但可通过多次独立模拟平均来恢复。
- **初步方法**：在热力学模型中引入 TF 拷贝数的随机分布（如 Log-Normal），生成随机足迹集合；分析波动对互信息和位移矩阵的影响。
- **验证方式**：与单细胞实验数据（如 smFISH 或流式分选）对比。
- **创新状态**：unverified（本文 Sec 3.1 仅考虑测量噪声，未考虑 TF 拷贝数波动的生物学噪声）

**候选 5：多 TF 调控架构的组合爆炸解决方案**
- **名称**：FactorGraphTF——用因子图模型处理多 TF 调控
- **来源局限/观察**：本文承认三个以上 TF 的调控架构难以用状态-权重图表示（组合爆炸）。但真实启动子常受多个 TF 调控。
- **核心假设**：因子图模型可以高效表示多 TF 调控的联合概率分布，避免显式枚举所有状态。
- **初步方法**：将 TF 结合事件建模为因子图中的变量，用信念传播或变分推断计算 RNAP 结合概率；与显式状态枚举在小规模系统上对比。
- **验证方式**：在 3-4 个 TF 的合成系统上比较因子图与显式枚举的预测一致性。
- **创新状态**：unverified（本文未提出此方向，但明确指出现有方法的局限）
