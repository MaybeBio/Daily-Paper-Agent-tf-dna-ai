## 02 一句话总结

本文通过 RNA-seq 和 WGCNA 筛选出 PLXNC1 作为胃癌细胞增殖及 M2 极化相关靶基因，证明 STAT3 作为转录因子直接结合 PLXNC1 启动子并激活其转录，而天然产物 EGCG 通过直接结合 STAT3 减少其核定位，从而转录抑制 PLXNC1，阻断 PLXNC1 介导的外泌体 miR-92b-5p 诱导的巨噬细胞 M2 极化。

## 03 研究问题

- **具体问题**：胃癌细胞中哪些 mRNA 受中药注射液 HDI 调控，且同时影响胃癌细胞增殖和肿瘤相关巨噬细胞（TAM）M2 极化？其上游转录因子调控机制是什么？能否从 HDI 中鉴定出靶向该转录因子的天然小分子？
- **为什么重要**：M2 型 TAM 在肿瘤微环境中占主导，促进肿瘤生长、血管生成、转移、免疫抑制和化疗耐药。从肿瘤细胞角度阻断其诱导的 M2 极化，可能提供更有效的治疗策略。
- **现有方法不足**：M2 极化的分子机制尚未完全阐明，缺乏有效治疗靶点和药物；已有研究多聚焦于巨噬细胞本身，较少从肿瘤细胞分泌角度系统筛选靶基因及其上游转录调控。
- **精确研究问题（Can 问题）**：Can STAT3 作为转录因子直接结合 PLXNC1 启动子并调控其表达，且 EGCG 通过靶向 STAT3 转录抑制 PLXNC1，从而阻断胃癌细胞外泌体 miR-92b-5p 介导的 M2 极化？

## 04 背景与发展脉络

1. **阶段一：TAM 与 M2 极化的认识**（背景）
   - 代表性工作：TAM 在 TME 中促进肿瘤进展的多种功能（生长、血管生成、转移、免疫抑制、耐药）。
   - 优点：确立了 M2 极化的临床重要性。
   - 局限：分子机制不完整，缺乏有效靶点。

2. **阶段二：从肿瘤细胞角度干预 M2 极化**（背景）
   - 代表性思路：肿瘤细胞通过分泌炎症因子和外泌体招募巨噬细胞并促 M2 极化。
   - 优点：将干预视角从巨噬细胞转向肿瘤细胞，可能更直接阻断免疫抑制微环境的建立。
   - 局限：缺乏具体分子靶点。

3. **阶段三：中药来源小分子筛选**（背景）
   - 代表性工作：Hedyotis diffusa Willd（HDI）具有免疫调节和抗肿瘤特性。
   - 优点：天然产物库是双功能小分子（抑制肿瘤生长 + 抑制 M2 极化）的直接来源。
   - 局限：活性成分和分子靶点不明确。

4. **本文主张的位置**：在阶段三基础上，通过 RNA-seq + WGCNA + 生存分析 + 免疫浸润关联筛选出 PLXNC1，进一步通过 TF 预测和网络药理学锁定 STAT3，最终鉴定 EGCG 为靶向 STAT3 的天然小分子，形成「药物 → TF → 靶基因 → 外泌体 → 巨噬细胞极化」的完整调控链。

## 06 核心思想

### 1) 表面方法
- 用 RNA-seq 分析 HDI 处理 MKN45 细胞的差异表达 mRNA（HRmRNAs），结合 WGCNA、生存分析和免疫浸润关联筛选出 PLXNC1。
- 通过 shRNA 敲低和过表达验证 PLXNC1 在胃癌细胞增殖和 M2 极化中的作用。
- 用 TF 预测 + 网络药理学构建「HDI 成分–TF–HRmRNA」网络，锁定 STAT3 和 EGCG。
- 用分子对接、SPR、CETSA 验证 EGCG–STAT3 结合；用 ChIP-QPCR 和双荧光素酶验证 STAT3–PLXNC1 启动子结合。
- 用外泌体分离、small RNA-seq 和巨噬细胞共培养验证 PLXNC1 通过外泌体 miR-92b-5p 调控 M2 极化。

### 2) 核心洞察
- **PLXNC1 是连接肿瘤细胞增殖与免疫微环境重塑的双功能节点**：它既促进胃癌细胞自身增殖，又通过外泌体 miR-92b-5p 激活巨噬细胞 STAT3 信号，驱动 M2 极化。
- **STAT3 在肿瘤细胞和巨噬细胞中扮演双重角色**：在胃癌细胞中作为 TF 转录激活 PLXNC1；在巨噬细胞中作为信号分子被外泌体 miR-92b-5p 激活。
- **EGCG 通过「减少 STAT3 核定位」而非直接抑制其 DNA 结合活性**来实现转录抑制，这提示小分子干预 TF 的方式可以是调控其亚细胞定位。

### 3) 可能的普适教训 [Analysis]
- 肿瘤细胞内在的 TF 调控网络可以同时控制自身增殖和细胞间通讯（外泌体），这提示 TF 是连接「肿瘤自主性」与「微环境重塑」的关键枢纽。
- 天然产物筛选与 TF 网络结合的策略，可推广到其他「TF–靶基因–分泌因子–免疫细胞」调控链的研究。
- 小分子–TF 相互作用的验证需要多层级证据（对接 → 物理结合 → 功能读出），单一计算预测不足以支撑结论。

## 07 方法总览

- **输入**：
  - 细胞模型：MKN45 胃癌细胞系
  - 药物处理：HDI（Hedyotis diffusa Willd 注射液）

- **输出**：
  - 靶基因：PLXNC1
  - 上游 TF：STAT3
  - 活性小分子：EGCG
  - 机制模型：EGCG → STAT3 核定位减少 → PLXNC1 转录抑制 → 外泌体 miR-92b-5p 减少 → 巨噬细胞 SOCS7-STAT3 互作恢复 → M2 极化逆转

  1. 转录组筛选模块（RNA-seq + WGCNA + 生存分析 + 免疫浸润关联）

  3. 外泌体模块（超速离心分离 + NTA + TEM + Western blot + small RNA-seq）
  4. 转录调控模块（TF 预测 + ChIP-QPCR + 双荧光素酶报告基因）
  5. 药物–靶点模块（UHPLC-QE-MS 成分分析 + 网络药理学 + 分子对接 + SPR + CETSA）
  6. 巨噬细胞极化模块（流式细胞术 + 共培养）
- **训练**：不适用（非机器学习方法）
- **工具**：RNA-seq、WGCNA、UHPLC-QE-MS、分子对接、SPR、CETSA、ChIP-QPCR、双荧光素酶报告基因、流式细胞术
- **反馈回路**：体外功能实验验证转录组筛选结果 → 机制实验（ChIP/报告基因）确认 TF–靶基因关系 → 药物实验确认小分子–TF 结合 → 外泌体实验连接肿瘤细胞与巨噬细胞

## 11 结论正确解读

- **任务范围**：本文聚焦于胃癌细胞（MKN45）中 PLXNC1 的表达调控及其通过外泌体 miR-92b-5p 对巨噬细胞 M2 极化的影响，以及 EGCG 对该通路的干预。
- **oracle/真值输入**：STAT3 对 PLXNC1 启动子的直接结合通过 ChIP-QPCR 和双荧光素酶报告基因验证；EGCG 对 STAT3 的直接结合通过分子对接、SPR 和 CETSA 验证。
- **端到端状态**：从药物处理 → 转录组变化 → 靶基因筛选 → 功能验证 → 外泌体机制 → TF 调控 → 小分子干预 → 体内验证，形成了完整的证据链。

## 14 Agent 提炼的知识候选

### 可迁移的概念、方法、公式、实验设计（面向 TF–DNA 互作 × AI/物理模拟）

1. **TF–靶基因直接结合的验证流程**：ChIP-QPCR + 双荧光素酶报告基因的组合是验证 TF–DNA 直接互作的金标准。对于 AI 预测的 TF–DNA 结合位点，此流程可作为湿实验验证的参考方案。
   - **迁移方式**：当用深度学习模型（如 DeepBind、DeepSEA）预测 STAT3 或其他 TF 的新靶基因时，可用此流程验证预测结果。

2. **小分子–TF 结合的多层级验证**：分子对接（虚拟筛选）→ SPR（物理结合亲和力）→ CETSA（细胞内靶点 engagement）→ 功能读出（核定位变化、下游基因表达）。这一「计算预测 → 物理验证 → 功能验证」的递进逻辑可直接迁移到 AI 辅助药物筛选项目中。
   - **迁移方式**：用 AI 方法（如 AlphaFold 3、DiffDock）预测小分子–TF 结合模式后，用 SPR/CETSA 验证。

3. **「药物 → TF → 靶基因 → 外泌体 → 免疫细胞」的跨细胞调控链**：该研究展示了肿瘤细胞内在 TF 如何通过外泌体远程调控免疫细胞。对于计算建模，可构建「TF 调控网络 + 外泌体 miRNA 转运 + 免疫细胞极化」的多尺度模型。
   - **迁移方式**：将 TF–DNA 结合数据与 miRNA 靶基因预测结合，构建跨细胞类型的调控网络模型。

4. **WGCNA 用于靶基因筛选**：WGCNA 将共表达基因聚类为模块，并与临床特征和免疫浸润关联。此方法可迁移到 TF 靶基因的优先级排序中。
   - **迁移方式**：将 TF ChIP-seq 数据与 WGCNA 模块结合，识别 TF 调控的共表达模块。

5. **STAT3 的双重角色（肿瘤细胞中为 TF，巨噬细胞中为信号分子）**：同一蛋白在不同细胞类型中功能不同，这对 AI 建模有重要启示——TF 结合位点预测应考虑细胞类型特异性。
   - **迁移方式**：在训练 TF–DNA 结合模型时，加入细胞类型/染色质状态作为条件输入。

6. **EGCG 通过影响 TF 核定位而非直接抑制 DNA 结合来调控转录**：这提示 TF 的亚细胞定位是转录调控的重要维度，AI 模型可考虑将核质穿梭信号纳入特征。
   - **迁移方式**：在预测小分子对 TF 功能的影响时，不仅考虑结合亲和力，还考虑对核定位信号、核转运蛋白互作的影响。

## 15 与已有知识连接

- **STAT3 作为转录因子**：STAT3 是 JAK-STAT 信号通路的核心 TF，在多种癌症中持续激活，调控增殖、存活、免疫逃逸相关基因。本文发现 STAT3 直接调控 PLXNC1，扩展了 STAT3 的靶基因谱。与已有 STAT3 ChIP-seq 数据库（如 ENCODE、Cistrome）可交叉验证。
- **PLXNC1 与肿瘤**：Plexin C1 是 Semaphorin 7A 的受体，参与免疫调节和肿瘤进展。本文首次将 PLXNC1 与胃癌外泌体 miRNA 和 M2 极化联系起来，属于较新的发现。
