## 03 研究问题

- **具体问题**：scATAC-seq 数据具有高维性和稀疏性，现有分析方法难以有效建模单细胞水平的染色质可及性异质性。
- **为什么重要**：染色质可及性反映调控元件的活性状态，是理解细胞身份和基因调控的关键；单细胞分辨率进一步揭示细胞异质性，但数据稀疏性限制了传统方法的性能。
- **现有方法为何不足**：传统方法（如基于降维或矩阵分解的方法）未利用 DNA 序列信息，无法将可及性模式与潜在的序列调控逻辑关联；且对稀疏数据的鲁棒性有限。
- **精确研究问题（Can ... ?）**：Can a sequence-based convolutional neural network model leverage DNA sequence information underlying accessibility peaks to achieve state-of-the-art performance in scATAC data analysis tasks, including cell clustering, denoising, integration, and TF activity inference?

## 04 背景与发展脉络

**脉络标注**：以下脉络为「经外部核验」的领域常识，结合本文摘要中的定位。

1. **阶段一：bulk ATAC-seq 分析**（如 peak calling、差异可及性分析）
   - 代表方法：MACS2、HOMER
   - 优点：成熟、稳定
   - 局限：无法解析细胞异质性

2. **阶段二：单细胞 ATAC-seq 基础分析**（聚类、可视化）
   - 代表方法：SnapATAC、ArchR、cisTopic
   - 优点：实现单细胞分辨率
   - 局限：依赖降维/矩阵分解，未利用序列信息；对稀疏数据敏感

3. **阶段三：序列-based 深度学习模型**（如 BPNet、Basenji）
   - 代表方法：Basenji（Kelley 等）、BPNet
   - 优点：直接从序列预测调控信号，可解释性强
   - 局限：主要面向 bulk 或连续信号，未适配单细胞稀疏数据

4. **本文主张的位置**：将序列-based CNN 引入单细胞 ATAC-seq 分析，利用序列信息弥补稀疏性，统一解决聚类、去噪、整合和 TF 活性推断等多个任务。

## 06 核心思想

1. **表面方法**：构建一个 CNN 模型，输入为 scATAC-seq peak 区域的 DNA 序列（one-hot 编码），输出为每个细胞在每个 peak 的可及性预测值。模型在多个任务上微调或直接应用。

2. **核心洞察**：DNA 序列本身携带调控信息，可及性峰值的序列模式（如 TF 结合 motif）可以预测单细胞水平的可及性状态。通过序列建模，模型能够**在稀疏数据中借用序列相似性进行信息共享**，从而缓解稀疏性问题。

3. **可能的普适教训 [Analysis]**：在单细胞稀疏数据中，**引入先验结构（如序列 motif）可以作为一种正则化或信息增强手段**，弥补计数数据的不足。这一思路可迁移到 TF–DNA 结合机制研究：即使实验数据稀疏，序列特征仍可提供稳定的预测信号。

## 14 学到什么

**Agent 提炼的知识候选**

1. **序列-based CNN 可迁移到 TF–DNA 结合机制研究**  
   - 概念：用 CNN 从 DNA 序列直接预测调控信号（可及性），可扩展到预测 TF 结合强度或结合位点。
   - 迁移方式：将 scBasset 的架构用于 TF–DNA 结合预测，输入为 TF 候选结合位点序列，输出为结合概率或亲和力。

2. **序列信息作为稀疏数据的正则化**  
   - 概念：在单细胞稀疏数据中，序列先验可弥补计数不足。
   - 迁移方式：在 TF–DNA 结合数据（如 ChIP-seq 或 HT-SELEX）中，若实验覆盖不足，可用序列特征增强模型。

3. **多任务统一框架**  
   - 概念：一个模型同时解决聚类、去噪、整合、TF 活性推断。
   - 迁移方式：在 TF–DNA 互作研究中，可构建统一模型同时预测结合位点、亲和力和下游调控效应。

4. **TF 活性推断的序列基础**  
   - 概念：通过序列模型推断 TF 活性，暗示序列 motif 与 TF 活性的直接关联。
   - 迁移方式：可用于预测 TF 在特定细胞类型或条件下的活性变化。
