## 03 研究问题

- **具体问题**：如何基于序列信息准确、高效地识别 DNA-binding proteins（DBPs）和 RNA-binding proteins（RBPs）？
- **为什么重要**：蛋白质与核酸的互作调控生物体的生命活动，准确识别 NABPs 对理解基因调控机制、疾病机理和药物设计具有重要意义。
- **现有方法为何不足**：
  1. 已有方法的基准数据集忽略了 NABPs 在真实世界中的比例（即正负样本比例失衡问题），导致模型在真实场景下泛化能力有限；
  2. 部分集成方法仅集成传统机器学习算法（如 SVM、随机森林等），未充分利用深度学习在高层特征表示上的优势，预测性能受限。
- **精确研究问题（Can 问题）**：Can a sequence-based hybrid framework that incorporates deep learning and uses a benchmark dataset reflecting real-world positive-negative ratios achieve state-of-the-art performance in identifying both DBPs and RBPs?

## 06 核心思想

### 1) 表面方法
- 构建考虑真实世界正负样本比例的基准数据集；
- 使用 down-sampling 生成三个相对平衡的数据集用于训练；
- 将深度学习算法（具体架构未在摘要中详述）集成到「可扩展立方混合框架」（extensible cubic hybrid framework, ECHF）中；
- 在独立测试集上评估 DBP 和 RBP 预测性能。

### 2) 核心洞察
- **真实世界比例意识**：训练数据中正负样本的比例应反映真实世界分布，否则模型在部署时会产生系统性偏差；
- **深度学习作为特征提取器**：深度学习不仅能做端到端分类，还能作为特征提取器嵌入集成框架，提供比手工特征更紧凑的高层表示；
- **可扩展框架设计**：框架设计为「立方混合」（cubic hybrid），意味着可以在多个维度（特征、算法、数据）上扩展，而非固定单一模型。

### 3) 可能的普适教训 [Analysis]
- 在生物序列预测任务中，**数据分布的真实性**与**模型架构的先进性**同等重要——即使模型再强，训练数据分布失真也会导致部署失败；
- 深度学习与传统机器学习并非互斥，**将深度学习作为特征提取器嵌入传统集成框架**是一种低风险、高收益的迁移策略；
- 「可扩展框架」的设计哲学（允许后续替换/增加组件）值得借鉴，尤其在快速演进的 AI 方法领域。

## 07 方法总览

> 注：以下基于摘要推断，具体细节原文未提供，标注为「推断」。

- **输入**：蛋白质序列（氨基酸序列）
- **输出**：二分类标签（DBP / non-DBP；RBP / non-RBP）
- **模块**：
  1. 特征提取模块（传统序列特征 + 深度学习特征）
  2. 数据平衡模块（down-sampling 生成三个平衡数据集）
  3. 分类器集成模块（立方混合框架，集成多个分类器）
- **训练**：在三个 down-sampled 平衡数据集上分别训练，集成最终预测
- **工具**：未提供（推测为 Python + 深度学习框架，但原文未说明）
- **反馈回路**：未提及
- **假设**：序列信息足以区分 DBP/RBP；真实世界正负比例可估计；down-sampling 不会丢失关键正样本信息

**文字流程**：
1. 收集蛋白质序列，标注 DBP/RBP 标签；
2. 构建基准数据集，使正负样本比例反映真实世界分布；
3. 对负样本进行 down-sampling，生成三个相对平衡的训练子集；
4. 对每条序列提取传统特征（如 PSSM、组成特征）和深度学习特征（通过深度学习模型获得的高层表示）；
5. 将特征输入立方混合框架中的多个分类器；
6. 集成三个子集上训练的分类器输出，得到最终预测；
7. 在两个独立测试集上评估性能。

### 候选 1：真实比例感知的 TF–DNA 结合位点预测框架
- **名称**：RealRatio-TFBind
- **来源局限/观察**：本文强调真实世界正负比例的重要性，但仅用于蛋白级 DBP/RBP 分类；TF–DNA 结合位点预测同样面临严重的类别不平衡（结合位点远少于非结合位点）
- **核心假设**：在 TF 结合位点预测中，使用反映真实基因组中结合/非结合比例的负样本集，可提升模型在真实 ChIP-seq 场景下的泛化能力
- **相对本文的增量**：将「真实比例」思想从蛋白级分类迁移到核苷酸级结合位点预测；引入基因组背景模型估计真实比例
- **初步方法**：从 ChIP-seq 数据构建正样本集，从基因组随机区域（匹配 GC 含量、重复序列比例）构建负样本集，使比例反映真实 TF 结合密度；使用 CNN/Transformer 提取序列特征，结合 PSSM 进化信息
- **验证方式**：在多个 TF 的独立 ChIP-seq 数据集上评估，对比传统平衡采样方法；报告 AUC-PR（类别不平衡下的关键指标）
- **创新状态**：unverified

### 候选 2：深度学习特征 + 物理评分融合的 TF–DNA 结合预测
- **名称**：DeepPhysBind
- **来源局限/观察**：本文仅用序列特征，未利用结构/物理信息；TF–DNA 结合机制研究中，物理模拟（MD、docking）可提供序列之外的结合亲和力线索
- **核心假设**：将深度学习提取的序列特征与物理模拟评分（如 docking 能量、MD 结合自由能）融合，可提升 TF–DNA 结合预测的准确性和物理合理性
- **相对本文的增量**：在特征层面引入物理约束，弥补纯序列方法的盲区
- **初步方法**：对候选 TF–DNA 复合物进行快速 docking（如 HDOCK、Zdock），提取能量项作为物理特征；与深度学习序列特征拼接，输入集成分类器
- **验证方式**：在 TF–DNA 结合数据集上对比纯序列方法；分析物理特征对预测的边际贡献；在低序列同源性 TF 上测试泛化
- **可能的失败模式**：docking 评分噪声大，可能引入干扰；计算成本高，难以大规模应用
- **创新状态**：unverified

### 候选 3：可扩展混合框架用于 TF–DNA 结合机制的多任务预测
- **名称**：ExtTFBind
- **来源局限/观察**：本文的「可扩展立方混合框架」设计允许模块化扩展；TF–DNA 结合机制涉及多个子任务（是否结合、结合位点定位、结合亲和力、结合构象）
- **核心假设**：一个可扩展的混合框架可同时处理 TF–DNA 结合的多层次预测任务，共享底层特征表示
- **相对本文的增量**：从单一二分类扩展到多任务；引入结构预测模块（如 AlphaFold 3 的 TF–DNA 复合物预测）
- **初步方法**：设计多任务学习框架，共享序列编码器，分别输出结合分类、位点定位、亲和力回归；将 AlphaFold 3 的预测结构作为辅助输入
- **验证方式**：在多个 TF 数据集上评估各任务性能；对比单任务模型；分析任务间知识迁移效果
- **可能的失败模式**：多任务间冲突导致性能下降；AlphaFold 3 预测结构质量不稳定
- **创新状态**：unverified

### 候选 4：真实比例数据集的动态采样策略
- **名称**：AdaptiveRatioSampling
- **来源局限/观察**：本文用静态 down-sampling 生成三个平衡数据集；但真实世界中 TF 结合密度因细胞类型、染色质状态而异
- **核心假设**：根据输入样本的细胞类型/染色质状态动态调整正负样本比例，可提升预测的上下文适应性
- **相对本文的增量**：从静态比例到动态比例；引入细胞类型/染色质状态作为条件变量
- **初步方法**：训练一个条件采样器，根据细胞类型/染色质状态估计 TF 结合密度，动态生成训练批次
- **验证方式**：在多种细胞类型的 ChIP-seq 数据上评估；对比静态采样
- **可能的失败模式**：条件变量估计不准；采样器训练不稳定
- **创新状态**：unverified
