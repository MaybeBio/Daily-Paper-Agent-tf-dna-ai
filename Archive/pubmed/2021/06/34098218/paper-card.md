## 03 研究问题

- **具体问题**：如何利用植物 omics 数据（特别是 TF 结合谱、染色质可及性、基因表达数据）来预测和推断 cis-regulatory code，即 DNA 序列中决定转录调控的规则？
- **为什么重要**：cis-regulatory code 是理解基因表达调控机制的核心，对植物发育、胁迫响应和作物改良具有重要意义。解析该 code 有助于预测 TF 结合位点、理解调控变异和设计合成启动子。
- **现有方法为何不足**：植物 omics 数据积累曾落后于动物，早期方法受限于数据量；现有方法多依赖单一数据类型（如仅 ChIP-seq 或仅 motif 扫描），缺乏对 TF 协同、染色质状态和远端调控元件的整合建模；机器学习方法虽强大，但可解释性差，且对数据质量和实验验证依赖高。
- **精确研究问题（Can ... ?）**：Can current bioinformatics and machine learning methods, applied to plant omics data, accurately infer the cis-regulatory code that governs TF–DNA binding and transcriptional output?

## 04 背景与发展脉络

**脉络标注**：仅本文框架（基于综述内容整理，未做外部核验）

1. **早期阶段（数据匮乏期）**：植物 omics 数据积累滞后于动物，研究者开发了从有限数据中提取最大信息的计算方法，如基于 motif 的保守性扫描和简单位置权重矩阵（PWM）预测。
   - 优点：在数据少时仍可进行初步预测。
   - 局限：无法捕捉 TF 协同、染色质背景和远端调控。

2. **中期阶段（数据积累期）**：拟南芥和玉米中 TF 结合谱（如 ChIP-seq）的大规模研究出现，公共数据库（如 PlantCARE、JASPAR）开始积累统一处理的 omics 数据。
   - 优点：数据量增加，可进行更复杂的统计建模。
   - 局限：数据异质性大，跨物种迁移性差。

3. **当前阶段（大数据与机器学习期）**：植物领域进入“big leagues”，机器学习方法（如随机森林、深度学习）被用于整合多类型 omics 数据（ChIP-seq、ATAC-seq、RNA-seq）预测 TF 结合和调控输出。
   - 优点：可整合多维度信息，预测性能提升。
   - 局限：模型可解释性差，cis-regulatory code 的“语法”（如 motif 间距、方向、协同性）仍未被充分解析。

**本文主张的位置**：作者认为当前方法已能有效预测 TF 结合位点，但完整解析 cis-regulatory code 仍需更系统的数据整合和实验验证。

## 07 方法总览

- **输入**：植物 omics 数据，包括 TF 结合谱（ChIP-seq）、染色质可及性（ATAC-seq/DNase-seq）、基因表达（RNA-seq）、基因组序列。
- **输出**：cis-regulatory code 的预测模型，包括 TF 结合位点、motif 组合规则、调控元件注释。
- **模块**：
  1. 数据预处理与标准化（统一处理不同来源的 omics 数据）
  2. motif 发现与 TF 结合位点预测（基于 PWM、位置权重矩阵或机器学习）
  3. 调控语法推断（motif 间距、方向、协同性分析）
  4. 表达关联建模（将预测的调控元件与基因表达数据关联）
- **训练**：依赖于已注释的 TF 结合位点和表达数据作为训练集；机器学习方法（如随机森林、深度学习）用于整合多类型数据。
- **工具**：未具体列出，但提及“advanced bioinformatics”和“machine learning methods”。
- **反馈回路**：预测结果需通过实验验证（如报告基因、突变分析）反馈优化模型。
- **假设**：cis-regulatory code 是可从序列和 omics 数据中学习的；TF 结合位点与表达之间存在可预测的映射关系。

**文字流程**：从原始 omics 数据出发 → 数据标准化 → 提取 TF 结合特征（如 ChIP-seq 峰、ATAC-seq 可及性）→ 结合序列信息进行 motif 扫描 → 使用机器学习整合多特征预测调控元件 → 推断调控语法 → 与表达数据关联 → 实验验证 → 迭代优化。
